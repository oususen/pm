# 社内AIナレッジの入口

このフォルダは、社内AIが参照できる業務知識を機能別に育てる入口である。
現時点の正式な原本はリポジトリ直下の `仕様書/` と `pm-ui/public/manual/` に置き、このフォルダへ同じ内容を重複保存しない。

| 区分 | 正式な原本 | 追加時の扱い |
| --- | --- | --- |
| PMアプリ構造・DB辞書 | `仕様書/PMアプリ構造辞書.md`、`仕様書/AI運用規約・AI用DB辞書.md` | 正規テーブル・数値定義を確定後に追記する |
| マニュアル | `pm-ui/public/manual/` | 業務画面の操作手順を追加する |
| 手順書・トラブル対応 | `仕様書/` または対応するマニュアル | 承認済みの内容だけを追加する |

社内AIは、この表の正式原本をMarkdown単位で検索するRAGを実装済みである。質問文と起点画面から最大4断片だけを選び、選択中のLLMへ参考情報として渡す。全文・リポジトリ外ファイル・READMEの案内文は送らない。AI設定の「AIナレッジ」で無効にした区分は検索対象から除外する。

AI設定から追加するPDF、Excel（`.xlsx` / `.xls`）、CSV、TSVは `media/ai_knowledge/` に原本を保存する。DBへ保存するのは資料名、区分、保存パス、有効状態だけであり、抽出本文やベクトルデータは保存しない。質問時に必要な範囲だけをテキスト化して検索し、該当断片だけをLLMへ渡す。

PNG、JPG、WEBP、BMPはローカルTesseract OCRで日本語・英数字を文字化してから検索する。利用者がチャットで明示添付した資料は、一覧の有効/無効にかかわらず今回の会話だけに使う。画像はAI設定で許可されている場合だけ、OpenRouterの画像対応モデルへ縮小画像を一時送信して内容を判定できる。PDFも明示添付時は先頭3ページを画像化して一時送信できる。元画像・PDFと変換画像は追加保存しない。OCR実行ファイルは `OCR_TESSERACT_PATH`、言語データの配置先は `OCR_TESSDATA_DIR` で変更できる。

DBの数値が必要な質問は、RAGの記述ではなく読み取り専用DBツールの結果を正とする。RAGは画面の使い方、業務用語、手順、数値の定義を説明するために使用する。
