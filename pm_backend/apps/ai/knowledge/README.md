# 社内AIナレッジの入口

このフォルダは、社内AIが参照できる業務知識を機能別に育てる入口である。
現時点の正式な原本はリポジトリ直下の `仕様書/` と `pm-ui/public/manual/` に置き、このフォルダへ同じ内容を重複保存しない。

| 区分 | 正式な原本 | 追加時の扱い |
| --- | --- | --- |
| PMアプリ構造・DB辞書 | `仕様書/PMアプリ構造辞書.md`、`仕様書/社内AI運用規約・AI用DB辞書.md` | 正規テーブル・数値定義を確定後に追記する |
| マニュアル | `pm-ui/public/manual/` | 業務画面の操作手順を追加する |
| 手順書・トラブル対応 | `仕様書/` または対応するマニュアル | 承認済みの内容だけを追加する |

文書RAGを導入する場合も、原本をこの表で管理し、検索対象・外部送信可否・更新責任を明示する。
