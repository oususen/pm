# 基本操作

## 画面の基本構成

- 上部に画面タイトルと操作エリアが表示されます。
- 中央の一覧エリアでデータを確認します。
- 一覧が長い場合は、ページ切替が表示されます。

## 入力と絞り込み

- 文字入力欄は「部分一致」で絞り込みます。
- 日付欄はカレンダーから選択します。
- 条件を変えた後に「更新」や「再取得」が必要な画面があります。

## 一覧の見方

- 数値が 0 の項目は空欄で表示される画面があります。
- マイナス値は赤色で強調される画面があります。
- 表示件数は一覧の下部で変更できます。

## よくあるメッセージ

- 読込中: データ取得中の表示です。
- データがありません: 条件に合うデータがない状態です。
- エラー: 通信やデータの問題が発生しています。
