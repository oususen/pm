# 自動納入リスト送信 ― 業務説明資料

---

## 背景と目的

### 現状の課題

| 手順 | 作業者 | 内容 | 問題点 |
|------|--------|------|--------|
| 1 | 事務員 | Excelテンプレを出力 | 数量が空白のため手作業で記入 |
| 2 | 事務員 | メールで仕入先へ送付 | 毎回手動でメール作成・添付 |
| 3 | 仕入先 | 数量を確認・修正して返送 | ― |
| 4 | 事務員 | 返送Excelを取込 | ― |
| 5 | 検収担当 | 検収確定 | ― |

**課題**: 手順1・2が毎回の手作業。数量計算も手動で時間がかかり、ミスのリスクもある。

### 改善後

| 手順 | 作業者 | 内容 | 改善点 |
|------|--------|------|--------|
| 1 | **システム** | 数量を自動計算してExcel作成 | **自動** |
| 2 | **システム** | 仕入先へメール自動送信 | **自動** |
| 3 | 仕入先 | 数量を確認・修正して返送 | 変更なし |
| 4 | 事務員 | 返送Excelを取込 | 変更なし |
| 5 | 検収担当 | 検収確定 | 変更なし |

**効果**: 手順1・2が完全自動化。毎朝指定時刻にシステムが実行する。

## 機能概要

### 自動送信の流れ

```
毎朝 指定時刻（例: 7:00）に自動実行
         │
         ▼
  ┌─────────────────────────┐
  │  N営業日後が納入日か判定   │
  │  （納入パターンに基づく）   │
  └─────────┬───────────────┘
            │
     ┌──────┴──────┐
     ▼             ▼
  納入日          納入日でない
     │             │
     ▼             ▼
  数量を自動     担当者へ通知して
  計算して       終了
  Excel作成
     │
     ▼
  仕入先へ
  メール送信
  （CC: 業務員）
```

### 送信される添付ファイル（3件）

| ファイル | 内容 | 用途 |
|---------|------|------|
| 納品リスト.xlsx | 品番・数量・日別内訳 + 修正方法説明 + 製品リスト | 仕入先が確認・修正して返送 |
| 進度表.xlsx | 全製品の内示・確定・実績・進度 | 仕入先が進度状況を把握 |
| 進度表.pdf | 同上（PDF版） | 印刷・閲覧用 |

## 納品リストExcelの中身

### シート構成（3シート）

**シート1「納品リスト」** ― 仕入先が記入・返送するメインシート

| 品番 | 品名 | 数量 | 納品日 | 6/9(月) | 6/10(火) | 仕入先コード | 伝票番号 |
|------|------|------|--------|---------|----------|------------|---------|
| YD400... | ブラケット | 15 | 2026-06-09 | 8 | 7 | 000095 | |
| YD400... | カバー | 20 | 2026-06-09 | 20 | | 000095 | |

- **数量**: システムが自動計算した値がセット済み
- **日別列**: カバー期間（納入日～次回納入日前日）の各日の内訳
- 仕入先は「数量」列だけ確認・修正すればOK

**シート2「確認・修正方法」** ― 仕入先向けの操作説明

- 数量を変更したい → 数量列を書き換える
- 納入しない製品がある → 数量を0にする
- 新しい品番を追加 → 「製品リスト」シートからコピー

**シート3「製品リスト」** ― 品番コピー用の全製品一覧

- 手入力すると品番不一致でエラーになるため、ここからコピーしてもらう

## 進度表の見方

全製品の進度状況を一覧で確認できます。

| | 繰越 | 5/27 水 | 5/28 木 | ... | **6/3 火** | 6/4 水 | ... |
|--|------|---------|---------|-----|-----------|--------|-----|
| **品番: YD400...** | | | | | | | |
| 内示 | | | | | 12 | | |
| 確定 | | 13 | 12 | | 13 | 13 | |
| 実績 | | | | | | | |
| 進度 | -88 | -100 | -112 | | **-150** | -163 | |
| 計進 | -88 | -100 | -112 | | **-150** | -163 | |

- **当日の列**: 薄い青で強調
- **休日の列**: ピンクで表示
- **進度がマイナス（遅れ）**: 赤字
- **進度がプラス（先行）**: 青字
- **繰越**: 表示開始日の前日の進度値

```

  進度表も添付しておりますのでご参照ください。

  （このメールは送信専用です。返信は上記アドレスへお願いいたします。）
```

## 設定画面

仕入れ管理メニュー > **業務自動タスク** > **自動納入リスト送信**

### 設定項目一覧

| 項目 | 説明 | 例 |
|------|------|-----|
| 仕入先 | 自動送信する仕入先（1社1設定） | 000095 有限会社ゼンツー |
| 実行時刻 | 毎日の自動実行時刻 | 7時00分 |
| 納入日 | 実行日から何営業日後を納入日とするか | 4営業日後 |
| 進度表期間 | 進度表の表示範囲 | 5営業日前 ～ 30日後 |
| 有効 | ON/OFFの切替 | ON |
| 返信先メール | 仕入先からの返送先アドレス | wang@daiso-ind.co.jp |
| CC送信先 | 業務員へも同時送信（複数行で複数人） | wang@daisoind.onmicrosoft.com |
| 失敗時通知先 | 送信失敗時に社内通知を受ける人 | 王崇栓 |
| 納入日でない時通知先 | 該当日が納入日でない場合に通知を受ける人 | 王崇栓 |

### 操作

| ボタン | 説明 |
|--------|------|
| 新規追加 | 新しい仕入先の自動送信設定を作成 |
| 編集 | 既存設定の変更 |
| 削除 | 設定を削除（自動送信を停止） |
| 今すぐ実行 | 設定を即時テスト実行（実際にメール送信される） |

## 通知について

自動タスクの実行結果は、設定した通知先に社内通知が届きます。

| 状況 | 通知先 | 通知内容 |
|------|--------|---------|
| 送信成功 | ― | 通知なし（設定画面のステータスで確認） |
| 送信失敗 | 失敗時通知先 | 「自動納入リスト送信失敗: ○○」+ エラー内容 |
| 納入日でない | 納入日でない時通知先 | 「○月○日は○○の納入日ではありません」 |
| パターン未設定 | 納入日でない時通知先 | 「○○の納入パターンが未設定です」 |
| メール未設定 | 失敗時通知先 | 「○○のメールアドレスが未設定です」 |

## 手動テンプレ出力（従来機能の改善）

納入予定画面の「納品リストテンプレ出力」ボタンも、自動送信と同じ形式のExcelを出力するように改善しました。

- **従来**: 品番・品名のみ、数量は空白
- **改善後**: 数量入り + 日別内訳 + 確認修正方法シート + 製品リストシート

自動送信に登録していない仕入先でも、手動で同じ形式のExcelを出力・送付できます。

## 事前準備（運用開始前に必要なこと）

| 項目 | 担当 | 内容 |
|------|------|------|
| 納入パターン設定 | 管理者 | 仕入先の納入スケジュールを設定（毎週○曜日等） |
| 仕入先メール設定 | 管理者 | 仕入先マスタに送信先メールアドレスを登録 |
| 自動送信設定 | 管理者 | 設定画面で各項目を入力して保存 |

| 仕入先への案内 | 事務員 | 仕入先に新しい運用フローを説明 |

## よくある質問

**Q: 仕入先が数量を修正して返送したら？**
A: 事務員が納入予定画面でExcelを取込→保存するだけ。従来と同じ手順です。

**Q: 自動送信を一時停止したい**
A: 設定画面で「有効」チェックを外して保存。再開時はチェックを入れるだけ。

**Q: 送信に失敗したらどうなる？**
A: 設定した通知先に社内通知が届きます。設定画面のステータス・メッセージでも確認できます。

**Q: 数量計算はどこのデータを使っている？**
A: 社内の需要データ（内示+確定）から、納入日～次回納入日前日分を合計しています。

**Q: 仕入先が品番を追加したい場合は？**
A: Excelの「製品リスト」シートから品番をコピーして追記してもらいます。手入力はエラーの原因になります。

**Q: CCに複数人を入れたい**
A: 設定画面のCC送信先メール欄に、1行に1アドレスずつ入力します。
