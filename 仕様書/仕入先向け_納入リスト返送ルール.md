# 【ご案内】発注・納入業務のデジタル化に伴う「納品リスト」運用開始のお願い

拝啓　貴社におかれましては、ますますご清栄のこととお慶び申し上げます。平素は格別のご高配を賜り、厚く御礼申し上げます。

さて、弊社では現在、発注から納入、検収、実績入力にいたる一連の業務において、より迅速に実態を反映できるよう、業務のデジタル化を推進しております。その一環といたしまして、今後、貴社へ送付する資料の一部を、これまでのPDF中心の運用から、Excelを活用したデータ中心の運用へと順次切り替えてまいりたいと考えております。

以下、本取り組みの背景と運用ルールについてご説明いたします。

---

## 1. 背景と目的

### 従来の運用における課題

これまでの運用では、既存の基幹システムからPDF形式の外作注文書を送付しておりました。PDFは閲覧用としては見やすい一方で、管理においてはデータとして扱いにくい面があり、手入力などの手間が増えやすい状況がございました。

また、内示の扱い方を含め、最新の変更内容が進度や納入予定へ即座に反映されにくく、手直しや進度確認に手作業が発生しやすい面もございました。さらに、貴社におかれましても、PDFの情報だけでは自社の管理用データへ変換しにくい場合があるのではないかと考えております。

弊社におきましても、発注・納入・検収といった一連の業務の各ステップがPDFや紙ベースを中心に運用されており、最終的に基幹システムへ納入実績を反映する際に手入力が発生しております。

### 目指す姿

本取り組みは、発注・納入・検収・実績入力などの一連の業務において、情報をできるだけそのままデータとしてつなげ、業務全体をデジタル化していくことを目的としております。

現行のPDF情報に加え、新たに進度表Excelおよび納品リストExcelをあわせてご提供することで、貴社におかれましても数量や進捗状況をデータ上で管理しやすくなり、差異の早期把握や変更時の確認負担の軽減にお役立ていただけるかと存じます。

また、**貴社に納品リストをExcelでご確認・ご返送いただくことで、納入予定数量をデータのまま次の工程へ引き継ぐことができ、納入予定登録、検収、実績反映までをより正確かつ迅速に行うことが可能となります。** この点が、貴社にご協力を賜りたい最も重要なポイントでございます。

## 2. 弊社から送付する4つのファイル

弊社からは、以下の4つのファイルを送付いたします。

### (1) 納品リスト.xlsx ― **貴社にご返送いただく対象ファイル**

納入予定の一覧が記載されたExcelファイルです。以下の情報が含まれております。

- 品番・品名
- 数量
- 納品日・日別内訳
- 仕入先コード
- 伝票番号

**貴社には、このファイルの「数量」列をご確認・修正のうえ、そのまま返送いただきますようお願いいたします。**

### (2) 進度表.xlsx ― 参考資料（返送不要）

製品ごとの進度状況をご確認いただくための参考資料です。納入予定数量の背景確認用としてご活用ください。

### (3) 進度表.pdf ― 参考資料（返送不要）

進度表Excelと同じ内容を、見やすいPDF形式にしたものです。印刷や閲覧用の資料としてご利用ください。

### (4) 外作納品書.pdf ― 帳票（返送不要）

納品時にご使用いただくための帳票です。納品書・受領書・購入先控などの用途でご使用ください。

## 3. 貴社にご対応いただきたいこと

ご対応いただきたいのは、**「納品リスト.xlsx」の確認と返送**のみでございます。

### 基本の流れ

1. 弊社より納品リストExcelを送付いたします
2. 貴社にて数量をご確認いただきます
3. 数量変更がある場合はExcel上で修正いただきます
4. 修正後のExcelをそのまま返送いただきます
5. 弊社にて返送Excelを取り込み、納入予定として登録いたします
6. 納品当日は、登録済みの内容をもとに受入・検収を行います

**ご返送いただいた数量が、そのまま受入基準となる運用**でございます。

### 修正していただけるファイル・項目

修正していただくファイルは **「納品リスト.xlsx」のみ** です。  
また、修正していただく項目は基本的に **「数量」列のみ** です。

それ以外のファイルや、列名・シート名・並び順につきましては、変更されませんようお願いいたします。

### 送信・返送のタイミング

弊社からの納品リストは、**納入日の５営業日前の１７時**にメールにて自動送信いたします。（設定変更可）

| 項目 | 内容 |
| --- | --- |
| 弊社からの送信 | 納入日の5営業日前（営業日の17時にシステム自動送信） |
| 貴社からのご返送 | **納品日の前日まで**にお願いいたします |
| 返送先 | メール本文に記載の返送先アドレス宛にご返送ください |

※ 送信元メールアドレスは**送信専用**です。ご返送の際は、メール本文に記載の返送先アドレスへお送りくださいますようお願いいたします。

## 4. 数量の確認・修正ルール

弊社システムでは、ご返送いただいたExcelの数量欄を以下のように処理いたします。

| 数量欄の状態 | システムの処理 |
| --- | --- |
| 数値が入力されている（1以上） | その数量を納入予定として登録 |
| `0` が入力されている | 納入なし（0）として登録 |
| 空白 または 行が削除されている | その行は取り込まれません（無視されます） |

この仕組みにより、初回のご返送時と、一度返送いただいた後の再返送時とでは、対応方法が異なる部分がございます。以下にそれぞれのケースをご説明いたします。

### 4-1. 初回返送時の対応

弊社からお送りした納品リストを初めてご返送いただく場合は、以下のようにご対応ください。

| やりたいこと | やること |
| --- | --- |
| 記載通りに納入する | 数量を変えずにそのまま返送 |
| 数量を変更したい | 「数量」列を変更後の値に書き換えて返送 |
| 納入しない品番がある | 「数量」列を `0` にして返送 |

初回返送時に限り、納入しない品番の行を空白のままにしたり、行を削除していただいても問題ございません（まだ登録データがないため、影響はございません）。ただし、**取消の意思を明確にするため、`0` を入力していただくことを推奨**いたします。

### 4-2. 一度返送された後に変更が生じた場合（再返送）

一度ご返送いただいた後に数量変更や取消が必要になった場合は、**最新の数量に修正した「納品リスト.xlsx」をもう一度ご返送ください**。弊社では、同じ納入日・同じ製品について、**最後にご返送いただいた内容で上書き**いたします。

| やりたいこと | やること |
| --- | --- |
| 数量を変更したい | 「数量」列を変更後の値に書き換えて再返送 |
| 納入を取り消したい | 「数量」列を `0` に変更して再返送 |

**⚠ 再返送時のご注意**

再返送時に行を削除したり数量を空白にしても、**前回ご返送いただいた数量がそのまま残ります**。取消にはなりませんのでご注意ください。

| 操作 | 結果 |
| --- | --- |
| 数量を `0` にして再返送 | ✅ 前回の数量が `0` に上書きされ、取消として処理されます |
| 行を削除して再返送 | ❌ その行は取り込まれず、前回の数量がそのまま残ります |
| 数量を空白にして再返送 | ❌ その行は取り込まれず、前回の数量がそのまま残ります |

### 4-3. 具体例

**例1: 数量変更（再返送）**

1. 初回返送: `A製品 100`
2. その後、変更が発生
3. `A製品 50` に修正して再返送 → 弊社では `100` を `50` に上書きして取り込みます

**例2: 取消（再返送）**

1. 初回返送: `B製品 200`
2. その後、納入が不要になった
3. `B製品 0` に修正して再返送 → 弊社では `200` を `0` に上書きして取り込みます

**例3: 誤った取消操作（再返送）**

1. 初回返送: `C製品 150`
2. その後、納入が不要になった
3. `C製品` の行を削除して再返送 → ❌ `150` がそのまま残ります（取消されません）

## 5. 品番を追加する場合

品番を追加する必要がある場合は、「納品リスト.xlsx」内の **「製品リスト」シートから品番をコピー**して納入リストの末行の下に追加してください。

品番の手入力は、入力ミスや取込エラーの原因となりますため、お控えくださいますようお願いいたします。

- 受け取った「納品リスト.xlsx」を**そのまま**ご使用ください
- 納品日は**全行同じ日付のまま**にしてください
- 修正は受け取った「納品リスト.xlsx」で行ってください
- 「進度表.xlsx」「進度表.pdf」「外作納品書.pdf」は返送不要です
