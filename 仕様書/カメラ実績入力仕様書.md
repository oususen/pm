# カメラ実績入力仕様書

## 1. 概要

現場スマホの内蔵カメラを利用して、`ライン × 工程 × 製品` 単位で生産実績を自動入力する。
第1段階は PoC として、サーバ推論（YOLO）でフレームを判定し、通過判定時に実績を加算する。
手動 `検知+1` モードは切替用として残す。

## 2. 業務ルール

- 日替わりは 8:00 締め。
  - 07:59:59 までは前日
  - 08:00:00 から当日
- `camera_event_id` で冪等制御し、同一イベントは二重加算しない。

## 3. データモデル

### 3.1 カメライベント `t_camera_count_event`

- `camera_event_id`（ユニーク）
- `line_id`
- `process_id`
- `product_id`
- `count`
- `event_at_client`
- `event_at_server`
- `business_date`
- `device_id`
- `confidence`
- `shape_code`（推論形状コード）
- `shape_confidence`（形状信頼度）
- `status`（`accepted` / `replayed`）

### 3.2 日次実績 `t_production_result_daily`

- `business_date`
- `line_id`
- `process_id`
- `product_id`
- `actual_count`

ユニークキー: `business_date + line_id + process_id + product_id`

## 4. API

### 4.1 カメライベント登録

`POST /api/camera-events/`

Request 例:

```json
{
  "camera_event_id": "evt-xxx",
  "line_id": 1,
  "process_id": 10,
  "product_id": 100,
  "event_at": "2026-05-06T10:00:00+09:00",
  "count": 1,
  "device_id": "device-xxx",
  "confidence": 0.9000
}
```

Response 例:

```json
{
  "accepted": true,
  "idempotent_replay": false,
  "total_count": 120,
  "business_date": "2026-05-06"
}
```

### 4.2 日次実績取得

`GET /api/camera-results-daily/?line_id=1&process_id=10&product_id=100&business_date=2026-05-06`

`business_date` 省略時はサーバ現在時刻から 8:00 締めで算出する。

### 4.3 自動検知（サーバ推論）

`POST /api/camera-auto-detect/`

Request 例:

```json
{
  "session_id": "autosess-xxx",
  "line_id": 1,
  "process_id": 10,
  "product_id": 100,
  "frame_data_url": "data:image/jpeg;base64,...",
  "frame_captured_at": "2026-05-06T10:00:00+09:00",
  "device_id": "device-xxx"
}
```

Response 例:

```json
{
  "detected_count": 3,
  "pass_count": 1,
  "total_count": 121,
  "business_date": "2026-05-06"
}
```

- フレーム送信間隔はフロントで約1.2秒固定（PoC）。
- 通過判定は「画面中央の仮想ラインを左→右に横断」で判定する。
- 重複防止はセッショントラッキングと短時間デバウンスで行う。
- `pass_count` 件分、サーバ側で `camera_event_id` を自動採番して冪等テーブルへ保存する。

## 5. フロント運用（PWA）

- 画面: `実績入力（カメラ）`
- 選択必須: ライン・工程・製品
- モード: `自動検知（YOLO PoC）` / `手動検知（PoC）` を切替可能
- カメラ開始中は選択をロック
- 通信失敗時は端末ローカルキューに退避し、5秒間隔で再送
- キュー保持目安: 24時間
