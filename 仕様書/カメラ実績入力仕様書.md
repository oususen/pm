# カメラ実績入力仕様書

## 1. 概要

現場スマホの内蔵カメラを利用して、`ライン × 工程 × 製品` 単位で生産実績を自動入力する。
第1段階は PoC として、画面上の `検知+1` 操作を検知イベントとして扱う。

## 2. 業務ルール

- 日替わりは 8:00 締め。
  - 07:59:59 までは前日
  - 08:00:00 から当日
- `camera_event_id` で冪等制御し、同一イベントは二重加算しない。

## 3. データモデル

### 3.1 カメライベント `t_camera_count_event`

- `camera_event_id`（ユニーク）
- `line_id`
- `process_id`
- `product_id`
- `count`
- `event_at_client`
- `event_at_server`
- `business_date`
- `device_id`
- `confidence`
- `status`（`accepted` / `replayed`）

### 3.2 日次実績 `t_production_result_daily`

- `business_date`
- `line_id`
- `process_id`
- `product_id`
- `actual_count`

ユニークキー: `business_date + line_id + process_id + product_id`

## 4. API

### 4.1 カメライベント登録

`POST /api/production/camera-events/`

Request 例:

```json
{
  "camera_event_id": "evt-xxx",
  "line_id": 1,
  "process_id": 10,
  "product_id": 100,
  "event_at": "2026-05-06T10:00:00+09:00",
  "count": 1,
  "device_id": "device-xxx",
  "confidence": 0.9000
}
```

Response 例:

```json
{
  "accepted": true,
  "idempotent_replay": false,
  "total_count": 120,
  "business_date": "2026-05-06"
}
```

### 4.2 日次実績取得

`GET /api/production/camera-results-daily/?line_id=1&process_id=10&product_id=100&business_date=2026-05-06`

`business_date` 省略時はサーバ現在時刻から 8:00 締めで算出する。

## 5. フロント運用（PWA）

- 画面: `実績入力（カメラ）`
- 選択必須: ライン・工程・製品
- カメラ開始中は選択をロック
- 通信失敗時は端末ローカルキューに退避し、5秒間隔で再送
- キュー保持目安: 24時間
