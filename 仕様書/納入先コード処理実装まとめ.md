# 納入先コード処理実装まとめ

## 実装日
2026-01-09

## 概要

リーデン確定受注CSVインポート時に、納入先コード（`ship_to_code`）を自動検出・抽出し、ダイソウカレンダーの営業日計算を使用して納入先別リードタイムに基づく出荷日自動計算を可能にする機能を実装しました。

---

## 実装内容

### 1. 営業日計算ユーティリティ作成

**ファイル**: `pm_backend/orders/utils/calendar_utils.py`

#### 機能
- カレンダーマスタ（`m_calendar`, `m_calendar_day`）に基づいて営業日を判定
- 営業日ベースで日付を加算・減算
- カレンダー未設定時は週末判定で代替（月～金を営業日とする）

#### クラス: `WorkingDayCalculator`

```python
from orders.utils import WorkingDayCalculator

# 得意先のカレンダーを使用
calculator = WorkingDayCalculator(calendar=customer.calendar)

# 納期から2営業日前の出荷日を計算
shipping_date = calculator.subtract_working_days(due_date, 2)
```

#### 主要メソッド

| メソッド | 説明 | 使用例 |
|---------|------|--------|
| `is_working_day(date)` | 営業日判定 | `calculator.is_working_day(date(2026, 1, 15))` |
| `subtract_working_days(date, days)` | 営業日を逆算 | `calculator.subtract_working_days(due_date, 2)` |
| `add_working_days(date, days)` | 営業日を加算 | `calculator.add_working_days(base_date, 2)` |
| `get_prev_working_day(date)` | 直前の営業日 | `calculator.get_prev_working_day(today)` |
| `get_next_working_day(date)` | 直後の営業日 | `calculator.get_next_working_day(today)` |

#### 関数版（シンプルな使用方法）

```python
from orders.utils import subtract_working_days

# 納期から2営業日前を計算
shipping_date = subtract_working_days(due_date, 2, calendar=customer.calendar)
```

#### 営業日計算の例

```
納期: 2026-01-15（水）
リードタイム: 2営業日

計算結果:
2026-01-15（水） ← 納期
2026-01-14（火） ← 1営業日前
2026-01-13（月） ← 2営業日前 ← 出荷日

※ 土日（1/11, 1/12）は自動的にスキップ
```

##### 2-1. 納入先コード列の自動検出

以下のキーワードでCSVヘッダーから納入先コード列を自動検出：

**日本語パターン**:
- 「納入先コード」
- 「納入先ｺｰﾄﾞ」
- 「納入コード」
- 「配送先コード」

**英語パターン**:
- 「delivery code」
- 「ship to code」

```python
SHIP_TO_KEYWORDS = ('納入', '納入先', 'delivery')
SHIP_TO_CODE_KEYWORDS = ('コード', 'ｺｰﾄﾞ', 'code', 'cd')
```

##### 2-2. 納入先コード正規化

```python
def _normalize_ship_to_code(value: str) -> str:
    """
    処理内容：
    1. Unicode正規化（NFKC）- 全角→半角変換
    2. ハイフン・スペース除去
    3. 数字のみの場合、6桁ゼロパディング

    例：
    "10" → "000010"
    "１０" → "000010"
    "0-0-0-1-0" → "000010"
    """
```

##### 2-3. 納入先別リードタイム設定

```python
SHIP_TO_LEAD_TIME_DAYS = {
    '000010': 2,  # 神立 → 2営業日前出荷
    '000030': 2,  # つくば → 2営業日前出荷
    '000050': 0,  # 滋賀 → 当日出荷
}
```

##### 2-4. CSVデータフロー

```
CSV Row
  ↓
1. 納入先コード列を検出（ヘッダーマッチング）
  ↓
2. 納入先コードを抽出・正規化
  ↓
3. StgOrderRawRieden.raw_payload['ship_to_code'] に保存
  ↓
4. StgOrderDaily.ship_to_code に展開
  ↓
5. OrderLine.ship_to_code に反映（受注作成時）
  ↓
6. ShipmentActual.ship_to_code に記録（出荷実績作成時）
```

### 3. 出荷指示書での納入先コード利用

**ファイル**: `pm_backend/apps/shipping/services/shipping_order_service.py`, `pm_backend/apps/shipping/services/shipping_pdf_generator.py`

#### 3-1. リーデン受注の動的識別

出荷指示書データ取得時に、`StgOrderDaily.raw_rieden IS NOT NULL` を使用してリーデン顧客IDを動的に特定します。顧客コードのハードコードは行いません（桁数不一致リスク回避）。

```python
# リーデン顧客のIDをStgOrderDailyから動的に特定
rieden_customer_ids = set(
    StgOrderDaily.objects.filter(
        raw_rieden__isnull=False
    ).values_list('customer_id', flat=True).distinct()[:5]
)
```

各OrderLineに `is_rieden` フラグを付与：

```python
'is_rieden': (line.order.customer_id in rieden_customer_ids) if line.order else False,
```

#### 3-2. 2便目への振り分けとPDF表示

- リーデン受注はすべて **2便目** に振り分け（`is_rieden=True` で判定）
- メイングリッドからは除外し、**ピンク枠の特記事項ボックス** に表示
- 表示形式: `リーデン / 納入先:{場所名} / 製品番号 数量`
- 納入先の表示マッピング: `ship_to_code` → 表示名（000010=神立, 000030=つくば, 000050=滋賀）

#### 3-3. 納入先別リードタイムによる日付範囲

出荷指示書の対象納期日範囲は、`ship_to_code` ごとのリードタイムを逆算して決定：

```python
SHIP_TO_LEAD_TIME_DAYS = {
    '000010': 2,  # 神立 → 2営業日前出荷
    '000030': 2,  # つくば → 2営業日前出荷
    '000050': 0,  # 滋賀 → 当日出荷
}
```

例: 出荷日が2026-02-12の場合

- 000050（滋賀）: 納期=2026-02-12（当日出荷）
- 000010（神立）: 納期=2026-02-14（2営業日後に到着）
- 000030（つくば）: 納期=2026-02-14（2営業日後に到着）

## 使用方法

### 1. CSVインポート時

**前提条件**:
- CSVに「納入先コード」または類似の列が存在すること
- 列名は自動検出されるため、正確な列名は不要

**処理**:
1. CSVアップロード
2. 納入先コード列を自動検出
3. 納入先コードを正規化して `raw_payload` に保存
4. `StgOrderDaily` に展開

### 2. 営業日計算の使用例

```python
from orders.utils import WorkingDayCalculator
from masters.models import Customer

# 得意先を取得
customer = Customer.objects.get(customer_code='000018')  # リーデン

# カレンダーを使用して営業日計算
calculator = WorkingDayCalculator(calendar=customer.calendar)

# 納期から2営業日前の出荷日を計算
due_date = date(2026, 1, 15)  # 水曜日
shipping_date = calculator.subtract_working_days(due_date, 2)
# → 2026-01-13（月曜日）※ 土日をスキップ
```

### 3. 納入先別リードタイムの追加

新しい納入先にリードタイムを設定する場合：

```python
# pm_backend/apps/shipping/services/shipping_order_service.py

SHIP_TO_LEAD_TIME_DAYS = {
    '000010': 2,  # 神立
    '000030': 2,  # つくば
    '000050': 0,  # 滋賀（当日出荷）
    '000060': 1,  # ← 新しい納入先を追加する例
}
```

## 注意事項

### 1. カレンダーマスタの設定

営業日計算を使用するには、得意先マスタに `calendar` を設定する必要があります：

```python
from masters.models import Customer, Calendar

# カレンダーを作成
calendar = Calendar.objects.create(
    calendar_code='RIEDEN_2026',
    calendar_name='リーデン 2026年カレンダー'
)

# 得意先にカレンダーを設定
customer = Customer.objects.get(customer_code='000018')
customer.calendar = calendar
customer.save()

# カレンダ日を登録（営業日/休日の設定）
# ※ 別途、カレンダ日マスタ（CalendarDay）にデータを登録する必要があります
```

カレンダーが未設定の場合は、週末判定（月～金を営業日）で代替されます。

### 2. 納入先コードは任意項目

`ship_to_code` はNULL許容のため、納入先がない場合は空文字列となります。

### 3. リードタイム設定の変更

リードタイムを変更する場合は、`shipping_order_service.py` の `SHIP_TO_LEAD_TIME_DAYS` 定数を更新します。出荷指示書の日付範囲計算に即時反映されます。

### 4. リーデン受注の識別方法

リーデン受注の識別には顧客コードのハードコードを使用しません（桁数不一致リスク: `000018` vs `0000018`）。代わりに `StgOrderDaily.raw_rieden IS NOT NULL` で動的に判定します。

from datetime import date
from orders.utils import WorkingDayCalculator
from masters.models import Calendar

# カレンダーを取得またはNoneで週末判定
calendar = Calendar.objects.filter(calendar_code='RIEDEN_2026').first()

calculator = WorkingDayCalculator(calendar=calendar)

# テストケース1: 水曜日から2営業日前
