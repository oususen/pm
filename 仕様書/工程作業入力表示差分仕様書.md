# 工程作業入力 表示差分仕様書

## 対象画面

- ` /production/desktop-process-input `
- ` /production/dual-process-input `

## 前提

- `dual-process-input` は独立した入力フォームを持たない。
- `dual-process-input` は `desktop-process-input` を `iframe` で 2 面表示する親画面である。
- `dual-process-input` から `desktop-process-input` を呼ぶ際は `embed=tablet` を付与する。
- したがって、同じ `desktop-process-input` でも「単体表示」と「dual 埋め込み表示」で見た目が異なる。

## 表示差分一覧

| 項目 | desktop 単体表示 | dual 埋め込み表示 |
| --- | --- | --- |
| 画面構成 | 1 画面で一覧・フォーム・最近記録を表示 | 親画面の左右 2 面の一部として表示 |
| ヘッダー左側 | タイトル「工程作業記録」を表示 | タイトルは非表示 |
| ヘッダー右側ボタン | テキスト中心のボタンを表示 | アイコン中心のボタンを表示 |
| 記録種別切替 | 左列のテキストボタンを表示 | アイコンボタンを表示 |
| 表示設定 | 左列のチェックボックス群を表示 | アイコンボタン化して横並びで表示 |
| 最近の記録 | 右列として表示可能 | 既定では折りたたみ、必要時のみ表示 |
| 左側コントロール列 | 表示する | 非表示 |
| 品番一覧列 | 表示する | 縮小表示する |
| フォーム全体 | 標準の余白・文字サイズ | コンパクト表示 |
| 製品コード | 22px 前後の大きめ表示 | 16px 前後まで縮小 |
| 製品名・時間 | 標準表示 | 文字サイズを縮小して詰める |
| オペレータアクション | 「アクション」ラベルで表示 | 「AC」ラベルに短縮 |
| オペレータボタン | 標準サイズ | 高さ・余白を縮小して横並びに寄せる |
| 計画サマリ | 標準サイズで表示 | 数字・ラベルを縮小 |
| 数量入力 | 標準の入力欄 | 幅・高さを縮小 |
| バッチ入力 | 標準幅 | 縮小幅で表示 |
| クイック数量ボタン | 標準サイズ | 小型ボタンで表示 |
| 連産品通知 | 展開したまま表示 | 折りたたみ可能な簡易表示 |
| 備考入力 | 標準サイズの textarea | 縮小した padding で表示 |
| 作業日入力 | 表示する | 埋め込み側では非表示 |
| 保存・取消ボタン | 標準高さ | 高さ・余白を縮小 |
| 画面高さの使い方 | 1 画面で完結 | 親画面の iframe 内に収まる前提で圧縮 |

## 補足

- `dual-process-input` 側のレイアウト差は、`desktop-process-input` そのものを別コンポーネントに置き換えているのではなく、`embed=tablet` の query による表示分岐で発生する。
- そのため、フォーム仕様の差分は `dual` 専用ではなく、`desktop-process-input` の埋め込み表示仕様として扱う。
