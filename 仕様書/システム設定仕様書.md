# システム設定仕様書

## 目的

システム全体に影響するパラメータを管理者がUIから変更できるようにする。
将来の設定追加はDBに行を追加するだけで対応可能（マイグレーション不要）。

## アーキテクチャ

- バックエンド: `pm_backend/apps/system_settings/`
- フロントエンド: `pm-ui/src/views/settings/SystemSettings.vue`
- 設定メニュー: `設定 > システム設定`

## データモデル

テーブル名: `system_settings`

| カラム | 型 | 説明 |
|---|---|---|
| id | BigAutoField | PK |
| key | CharField(100) | 設定キー（一意） |
| value | CharField(500) | 設定値（文字列） |
| description | CharField(200) | 説明（管理画面表示用） |
| updated_at | DateTimeField | 最終更新日時（auto） |
| updated_by | FK(User) | 最終更新者 |

## API

| メソッド | パス | 権限 | 説明 |
|---|---|---|---|
| GET | `/api/system-settings/` | 全ログインユーザー | 辞書形式で全設定を返す（ポーリング用） |
| GET | `/api/system-settings/detail/` | 全ログインユーザー | リスト形式で全設定を返す（管理画面用） |
| POST | `/api/system-settings/detail/` | 管理者のみ | 新規設定を作成 |
| PATCH | `/api/system-settings/update-by-key/` | 管理者のみ | `{ key: value, ... }` 形式で複数キーを一括更新 |

## 初期設定値

| キー | デフォルト値 | 説明 |
|---|---|---|
| `notification_polling_sec` | `60` | 通知ポーリング間隔（秒） |
| `task_polling_sec` | `120` | タスクポーリング間隔（秒） |
| `call_polling_sec` | `3` | 通話着信監視間隔（秒） |
| `call_signal_polling_ms` | `1500` | 通話シグナル監視間隔（ms） |

## ポーリング動作

- `GlobalNavigation.vue` がログイン時に `/api/system-settings/` を取得し、ポーリング間隔を決定する。
- 通知（`notifications/`）とタスク件数（`purchase-order-tasks/`, `equipment-inspection-tasks/`）は独立した間隔で動作する。
- 通話着信監視は `call_polling_sec` を使い、全画面共通の着信一覧取得と通話画面のセッション更新に反映する。
- 通話中シグナル監視は `call_signal_polling_ms` を使い、`/notifications/calls` での offer/answer/ICE 取得間隔に反映する。
- 設定取得に失敗した場合はデフォルト値（通知60秒・タスク120秒）を使用する。
- 設定変更は次回ログイン（またはページリロード）から有効になる。

## 権限

- 閲覧: 全ログインユーザー
- 編集・新規作成: `is_staff` または `is_superuser` のユーザーのみ
