# 自動納入リスト送信 機能仕様書

---

## 1. 概要

仕入先へ納品リスト（数量入りExcel）と進度表（Excel + PDF）を自動送信する機能。
納入リスト方式を採用する仕入先に対して、指定時刻にメールで送信する。

- メニュー: `仕入れ > 業務自動タスク > 自動納入リスト送信`
- URL: `/purchase/auto-delivery-list`
- 権限リソース: `purchase.auto_delivery_list`

## 2. 全体フロー

```
① 設定画面で仕入先・実行時刻・納入日(N営業日後)・進度表期間等を設定
  ↓
② スケジューラ(APScheduler)が設定時刻にタスクを起動
  ↓
③ daisoカレンダーでN営業日後を算出
  ↓
④ 仕入先の納入パターンで納入日か判定
  ├─ 納入日でない → 通知先ユーザーへ通知して終了（SKIPPED）
  └─ 納入日 → 次へ
  ↓
⑤ カバー範囲（納入日～次回納入日前日）で数量算出（進度方式: LineDemand）
  ↓
⑥ 納品リストExcel生成（数量入り + 日別内訳 + 確認修正方法シート + 製品リストシート）
  ↓
⑦ 進度表Excel + 進度表PDF生成（全製品の進度表）
  ↓
⑧ 仕入先メールアドレスへ送信（CC: 業務員、Reply-To: 返信先）
  ├─ 成功 → ステータスSUCCESS
  └─ 失敗 → ステータスFAILED + 通知先ユーザーへ通知
```

## 3. 設定モデル

### テーブル: `purchase_auto_delivery_list_config`

| フィールド | 型 | 説明 |
|-----------|-----|------|
| supplier | FK(Supplier, unique) | 対象仕入先（1仕入先1設定） |
| is_enabled | Boolean | 有効/無効 |
| scheduled_hour | SmallInt | 実行時（0-23） |
| scheduled_minute | SmallInt | 実行分（0-59） |
| lead_time_days | SmallInt | 納入日 = 実行日からN営業日後（デフォルト2） |
| progress_days_back | SmallInt | 進度表開始 = 今日からN営業日前（デフォルト7） |
| progress_days_forward | SmallInt | 進度表終了 = 開始日からN日後（デフォルト30） |
| reply_to_email | Email | 返信先メールアドレス |
| cc_emails | Text | 業務員CC送信先メール（改行区切り、複数可） |
| notify_on_failure | M2M(User) | 送信失敗時の通知先ユーザー |
| notify_on_non_delivery | M2M(User) | 納入日でないときの通知先ユーザー |
| last_run_at | DateTime | 最終実行日時 |
| last_run_status | Char | SUCCESS / FAILED / RUNNING / SKIPPED |
| last_run_message | Text | 最終実行メッセージ |
| last_run_duration_seconds | Float | 最終実行時間（秒） |

### 設定画面の項目（全て必須）

- 仕入先
- 実行時刻（時・分）
- 納入日（実行日から何営業日後）
- 進度表期間（何営業日前 ～ 何日後）
- 有効チェック
- 返信先メールアドレス（Reply-To）
- 業務員CC送信先メール（改行区切り）
- 失敗時の通知先（ユーザー検索+チップ選択）
- 納入日でないときの通知先（同上）

## 4. 納品リストExcel

### シート1: 納品リスト

列順: `品番 | 品名 | 数量 | 納品日 | [日別内訳列...] | 仕入先コード | 伝票番号`

- **数量**: 進度方式（`LineDemand` の `firm_qty + forecast_qty`）でカバー範囲を合算
- **日別内訳列**: カバー範囲の各日の数量（例: `6/9(月)`, `6/10(火)`）
- **カバー範囲**: 納入日 ～ 次回納入日の前日
- 仕入先コード・伝票番号は右端（使用頻度が低いため）

### シート2: 確認・修正方法

仕入先向けの操作説明:
- 数量の確認・修正方法（変更/取消/空白の扱い）
- 品番追加時は「製品リスト」シートからコピーすること
- ファイルをそのまま返送する旨の注意事項

### シート3: 製品リスト

- `RoutingStep` でこの仕入先ラインに割当てられた `output_product` を品番順で一覧
- 品番コピー用（手入力による不一致エラー防止）

### 取込互換性

このExcelは既存の「納入予定」画面（`/purchase/delivery-schedule`）でそのまま取込可能。
取込はヘッダー名でマッピングするため、日別内訳列など追加列は自動的に無視される。
ただし取込時の納品日は `YYYY-MM-DD` / `YYYY/MM/DD` / `YYYY/M/D` 形式のみ許可し、内部では `YYYY-MM-DD` に正規化して扱う。返送Excel内で全行同一、かつ画面の対象日と一致している必要がある。年なしの `M/D` 形式は許可しない。

## 5. 進度表Excel

### 構成

- ヘッダー: タイトル・発行日・期間・凡例（当日=青、休日=ピンク）
- 製品ごとのブロック:
  - 品番・品名行
  - 繰越列（開始日前日の進度・計進）
  - 日付ヘッダー行
  - データ行: 内示 / 確定 / 実績 / 進度 / 計進

### データソース

| 行 | ソース |
|----|--------|
| 内示 | `LineDemand.forecast_qty` |
| 確定 | `LineDemand.firm_qty` |
| 実績 | `LineBacklog.actual_qty` |
| 進度 | `LineBacklog.progress_qty` |
| 計進 | `LineBacklog.planned_progress_qty` |

### 期間

- 開始日: 今日からN営業日前（daisoカレンダー `WorkingDayCalculator.subtract_working_days`）
- 終了日: 開始日からN日後（暦日）

## 6. 進度表PDF

- 用紙: A4横向き
- 1ページあたり最大34日分
- 日付超過時は自動ページ分割（日付方向・製品方向の両方）
- 罫線: 0.25pt細線、製品区切り0.5pt
- 凡例: 当日=薄青、休日=ピンク（各ページヘッダーに表示）
- 進度値: マイナス=赤、プラス=青
- 繰越列: 開始日前日の進度・計進を表示

## 7. メール送信

### 宛先

| 種類 | ソース |
|------|--------|
| To | `Supplier.order_email` |
| CC | `config.cc_emails`（改行区切り） |
| Reply-To | `config.reply_to_email` |

### 添付ファイル（最大3件）

1. `納品リスト_{仕入先コード}_{納入日}.xlsx`
2. `進度表_{仕入先コード}_{今日}.xlsx`
3. `進度表_{仕入先コード}_{今日}.pdf`

### 本文

```
{仕入先名} 御中

お世話になっております。
納品リスト（納入日: {納入日}）を送付いたします。

対象品目: {件数}件
カバー期間: {開始日} ～ {終了日}

添付のExcelの「確認・修正方法」シートを参照のうえ、数量確認・修正後にご返送ください。
進度表も添付しておりますのでご参照ください。

※ 返送先: {返信先メール}
（このメールは送信専用です。返信は上記アドレスへお願いいたします。）

------------------------------
ダイソウ工業株式会社
```

## 8. スケジューラ

- 基盤: APScheduler（`run_scheduler` management command）
- 5分ごとに設定変更を自動検知してジョブを再登録
- ジョブID: `auto_delivery_list_{config.id}`
- タスク関数: `purchase.tasks_auto_delivery_list.run_auto_delivery_list_send`

## 9. 手動テンプレ出力

納入予定画面（`/purchase/delivery-schedule`）の「納品リストテンプレ出力」ボタンも同じ形式のExcelを出力する。

- API: `GET /purchase-receiving/delivery-list-excel/?supplier_id={id}&target_date={date}`
- 選択日をそのまま納入日として扱い、パターンからカバー範囲を算出
- 自動送信と同一の `_generate_excel` 関数で生成

## 11. 通知

### 通知タイミング

| 条件 | 通知先 | 内容 |
|------|--------|------|
| 納入日でない | `notify_on_non_delivery` | 「{日付} は {仕入先名} の納入日ではありません」 |
| 送信失敗 | `notify_on_failure` | 「自動納入リスト送信失敗: {仕入先名}\n{エラー詳細}」 |
| パターン未設定 | `notify_on_non_delivery` | 「{仕入先名} の納入パターンが未設定です」 |
| メール未設定 | `notify_on_failure` | 「{仕入先名} のメールアドレスが未設定です」 |

### 通知モデル

```python
Notification.objects.create(
    title=message[:200],
    category='購買',
    domain='PURCHASE_AUTO_DELIVERY',
    valid_from=today,
    valid_to=today + timedelta(days=7),
    description=message,
    operator_name='system',
)
notification.target_users.set(user_ids)
```
