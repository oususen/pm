# 通知編集

## 目的
通知の新規作成と編集を行う。

## 導線
- グローバルナビゲーションのタブ「通知作成」から遷移する。
- ダッシュボードのカード「通知作成」から遷移する。

## 権限
- `notifications / can_edit` を持つユーザーのみ表示・操作可能。
- 権限制御はフロントエンドUIのみ。

## 入力項目
- タイトル（必須）
- カテゴリ（選択式、必須）
- 種別（選択式、必須）
- 対象事業部（複数選択）
- 対象係（複数選択、事業部選択後に絞り込み）
- 対象班（複数選択、係選択後に絞り込み）
- 対象役職（複数選択、部署選択に応じて候補取得）
- 有効開始日
- 有効終了日
- 表示順
- 説明
- 入力者（必須、デフォルトはログインユーザー）

## 対象者の扱い
- 対象部署・対象役職が未設定の場合は全員向けとする。
- 対象部署は「事業部/係/班」を複数選択可能。

## API
- 一覧: `GET /api/notifications/`
- 登録: `POST /api/notifications/`
- 更新: `PUT /api/notifications/{id}/`
- 削除: `DELETE /api/notifications/{id}/`
