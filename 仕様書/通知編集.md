# 通知編集

## 目的
通知の新規作成と編集を行う。

## 導線
- グローバルナビゲーションのタブ「通知作成」から遷移する。
- ダッシュボードのカード「通知作成」から遷移する。

## 権限
- `notifications / can_edit` を持つユーザーのみ表示・操作可能。
- 権限制御はフロントエンドUIのみ。

## 入力項目
- タイトル（必須）
- カテゴリ（選択式、必須。生産/品質/在庫/購買/出荷/設備/共通）
- 種別（選択式、必須。進捗/遅延/異常/品質不良/在庫不足/工程変更/保全/出荷トラブル/その他）
- 対象事業部（複数選択）
- 対象係（複数選択、事業部選択後に絞り込み）
- 対象班（複数選択、係選択後に絞り込み）
- 対象役職（複数選択、部署選択に応じて候補取得）
- 対象ユーザー（個別指定、上記条件に応じて候補を絞り込み）
- 有効開始日
- 有効終了日
- 表示順（デフォルト10、上に固定したい場合は9以下）
- 説明
- 入力者（必須、デフォルトはログインユーザー）

## 対象者の扱い
- 対象部署・対象役職・対象ユーザーが未設定の場合は全員向けとする。
- 対象部署は「事業部/係/班」を複数選択可能。
- 対象ユーザーを指定した場合は、対象部署・対象役職の条件と合わせて判定する（AND条件）。

## 登録済み一覧
- 作成日（作成日時）を表示する。
- 並び順は作成日（新しい順）を優先する。
- 未閲覧者は対象者判定（部署・役職・個別ユーザーの条件）に基づいて表示する。
- 登録済み一覧は対象者、または入力者（作成者）のみ閲覧可能とする。

## API
- 一覧: `GET /api/notifications/`
- 登録: `POST /api/notifications/`
- 更新: `PUT /api/notifications/{id}/`
- 削除: `DELETE /api/notifications/{id}/`
