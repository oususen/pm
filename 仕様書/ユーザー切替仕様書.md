# ユーザー切替（Impersonation）仕様書

## 概要

admin ユーザーが他のユーザーとしてシステムを操作できる機能。
権限確認・画面表示確認・問題調査の際に、対象ユーザーの視点でシステムを利用可能にする。

## 利用権限

| 条件 | 切替可否 |
|---|---|
| `username = 'admin'`（大文字小文字不問） | 可 |
| `is_superuser = True` でも admin 以外 | 不可 |
| 切替中のユーザー（セッションに元ユーザーIDが残っている） | 可（別ユーザーへの再切替・元に戻る） |
| 一般ユーザー | 不可 |

## 切替対象の制約

- `is_active = True` のユーザーのみ
- `username = 'admin'` へのなりすましは不可（`exclude(username__iexact='admin')`）

## API仕様

### GET `/auth/switchable-users/`

切替可能なユーザー一覧を取得。

**権限**: `IsAuthenticated` + impersonation権限チェック

**レスポンス**:
```json
{
  "current_user": { "id": 1, "username": "admin", "display_name": "管理者" },
  "impersonation": { "can_switch": true, "active": false, "origin_user": null },
  "users": [
    { "id": 2, "username": "yamada", "display_name": "山田 太郎" },
    { "id": 3, "username": "suzuki", "display_name": "鈴木 花子" }
  ]
}
```

### POST `/auth/switch-user/`

指定ユーザーに切り替える。

**権限**: `IsAuthenticated` + impersonation権限チェック

**リクエスト**:
```json
{ "user_id": 2 }
```

**レスポンス**: 切替後のユーザー情報（`_user_payload` 形式 + `csrfToken`）

**動作**:
1. 権限チェック（admin または切替中セッション）
2. 対象ユーザーの存在・有効確認
3. `login(request, target_user)` でセッションを切替
4. セッションに元ユーザーID（`auth_impersonation_origin_user_id`）を保存
5. 監査ログ出力

### POST `/auth/switch-back/`

元ユーザー（admin）に戻る。

**権限**: `IsAuthenticated`

**レスポンス**: 元ユーザーの情報（`_user_payload` 形式 + `csrfToken`）

**動作**:
1. セッションから元ユーザーIDを取得
2. 元ユーザーが見つからない場合は 400 エラー
3. `login(request, origin_user)` でセッションを復帰
4. セッションから impersonation キーを削除
5. 監査ログ出力

## セッション管理

| イベント | セッション処理 |
|---|---|
| 通常ログイン | `IMPERSONATION_ORIGIN_SESSION_KEY` を削除 |
| ユーザー切替 | `IMPERSONATION_ORIGIN_SESSION_KEY` に元ユーザーIDを保存 |
| 元に戻る | `IMPERSONATION_ORIGIN_SESSION_KEY` を削除 |
| ログアウト | `IMPERSONATION_ORIGIN_SESSION_KEY` を削除 |
| 切替中に別ユーザーへ再切替 | 元ユーザーID（最初のadmin）を維持 |

## フロントエンド

### 表示場所

`GlobalNavigation.vue` のユーザーメニュー内に表示。

### 表示条件

`authState.user.impersonation.can_switch === true` の場合のみ表示。

### UI構成

- ユーザー選択ドロップダウン（admin を除く全アクティブユーザー）
- 「切替」ボタン
- 切替中は「adminに戻る」ボタンを追加表示
- 切替中は「元ユーザー: 〇〇」を表示
- ステータスメッセージ（成功/エラー）

### 切替後の画面遷移

切替後、現在のページに対する権限がない場合はホーム（`/`）にリダイレクト。
権限がある場合は現在のページをリロード。

## 監査ログ

切替・復帰時に以下をログ出力（`logging.info`）：

| フィールド | 内容 |
|---|---|
| `action` | `switch` / `switch_back` |
| `actor` | 操作を実行したユーザー名・ID |
| `target` | 切替先ユーザー名・ID |
| `origin` | 最初の切替元ユーザー名・ID |
| `ip` | リクエスト元IPアドレス |
| `ua` | User-Agent |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `pm_backend/apps/accounts/views.py` | API実装（switch/switch-back/switchable-users） |
| `pm_backend/apps/accounts/urls.py` | URLルーティング |
| `pm-ui/src/api/resources/auth.js` | API呼び出し定義 |
| `pm-ui/src/auth.js` | `switchUser()` / `switchBack()` 関数 |
| `pm-ui/src/components/GlobalNavigation.vue` | UI（ユーザーメニュー内） |

## セキュリティ考慮

- admin アカウントへの切替は明示的にブロック
- ログイン・ログアウト時に impersonation セッションをクリア
- 切替・復帰の全操作を監査ログに記録（IP・UA含む）
- 社内ネットワーク限定運用を前提（セッション盗難リスクは許容）
