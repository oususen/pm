# 納入実績照会マッピング権限 実装計画

## 目的

納入実績照会画面のマッピング設定を、照会本体とは独立した権限で表示・操作制御する。

## 実装内容

| 項目 | 内容 | 状態 |
| --- | --- | --- |
| 権限リソース | `purchase.actual_inquiry_mapping`（仕入: 納入実績照会マッピング設定）を追加 | 実装済み |
| 閲覧制御 | `can_view`でタブ表示、設定参照、テンプレ出力を許可 | 実装済み |
| 編集制御 | `can_edit`で入力、コピー、Excel導入、保存を許可 | 実装済み |
| フォールバック | `purchase`および`purchase.actual_inquiry`へフォールバックしない | 実装済み |
| 既存機能 | 照会タブと基幹システム入力用Excel出力は変更しない | 実装済み |
| API・データ | API権限チェック、保存形式、既存権限データを変更しない | 実装済み |
| マイグレーション | 権限選択肢変更のaccountsマイグレーションを追加 | 実装済み（未適用） |
| evaluator指摘対応 | 各処理入口の権限再確認、権限喪失時の照会タブ復帰、マッピングパネルの表示条件を追加 | 実装済み |

## 権限別確認項目

- 権限なしではマッピング設定タブが表示されない。
- 閲覧のみでは設定の参照とテンプレ出力ができ、入力、コピー、Excel導入、保存はできない。
- 編集ありではマッピング設定の全操作ができる。
- 親権限だけではマッピング設定タブが表示されない。
- 照会タブと基幹システム入力用Excel出力の挙動が変わらない。
