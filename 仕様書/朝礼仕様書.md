# 朝礼仕様書

## 概要

朝礼機能は生産メニュー配下で利用し、朝礼の事前準備から実行記録までを管理する。

## 対応画面

- 朝礼一覧
- 朝礼作成/編集
- 朝礼実行
- テンプレート選択

## データ構成

### 朝礼ヘッダ

- 朝礼日（テンプレートでは任意）
- タイトル
- テンプレートフラグ
- 対象部署（複数選択）
- 対象ライン（複数選択、対象部署に紐づく社内ラインのみ）
- 司会者
- 議題
- 連絡事項
- 注意事項
- 実行メモ
- 状態: `下書き` `準備完了` `実行中` `完了`
- 開始日時
- 終了日時

### 朝礼添付資料

- 朝礼
- 添付ファイル
- 元ファイル名
- Content-Type
- ファイルサイズ
- 添付種別: `PDF` `画像` `Excel`
- 表示順

### 朝礼参加者

- 朝礼
- ユーザー
- 参加状態: `未確認` `出席` `欠席` `遅刻`
- 確認日時
- 備考
- 表示順

## 業務ルール

- 朝礼は `生産` メニュー内に配置する
- テンプレートは朝礼本体で管理し、通常一覧とは表示区分で切り替える
- テンプレートは実行不可とし、利用可能操作は `編集` `複製` `削除` のみ
- テンプレート作成時は朝礼日を未入力で保存できる
- 作成/編集画面では `下書き` または `準備完了` まで更新できる
- `完了` への更新は実行画面からのみ行う
- 対象部署は複数選択できる
- 対象ラインは複数選択でき、対象部署配下ユニットに紐づく社内ラインのみ選択可能
- 添付資料は PDF / 写真 / Excel を複数登録できる
- 添付資料は PDF / 画像 を画面内プレビューでき、Excel はファイルを開いて確認する
- 実行画面の `開始` で状態を `実行中` にする
- 実行画面の `完了` で状態を `完了` にし、終了日時を記録する
- 参加者は明示指定を優先し、未指定の場合は対象部署から自動設定する
- 一覧から既存朝礼を複製して新規朝礼を作成できる
- テンプレートから新規朝礼を作成できる
- 複製時は対象部署、対象ライン、司会者、議題、連絡事項、注意事項、参加者、添付資料を引き継ぎ、状態・実行メモ・出欠状態は初期化する
- 実行画面の一括操作（`全員出席` `未確認を欠席` `備考一括クリア`）は司会者のみ実行できる
- 部署レベルごとの参加者抽出は、選択された対象部署の和集合を基準とする
- `事業部`: `profile.division`
- `係`: `profile.group`
- `班`: `profile.team` または `profile.supervisor_teams`
- `グループ`: `profile.unit` または `profile.leader_units`

## API

- `GET /api/morning-meetings/`
- `POST /api/morning-meetings/`
- `GET /api/morning-meetings/{id}/`
- `PATCH /api/morning-meetings/{id}/`
- `DELETE /api/morning-meetings/{id}/`
- `POST /api/morning-meetings/{id}/duplicate/`
- `POST /api/morning-meetings/{id}/start/`
- `POST /api/morning-meetings/{id}/save_execution/`
- `POST /api/morning-meetings/{id}/complete/`
