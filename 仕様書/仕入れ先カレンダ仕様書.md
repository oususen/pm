# 仕入れ先カレンダ仕様書

## 1. 概要

仕入先ごとの稼働カレンダを管理する画面。カレンダの新規作成・既存カレンダの割当/割当解除・日別の稼働日トグル・曜日一括設定・メモ編集が可能。

- メニュー: `仕入れ > 仕入れ先カレンダ`
- URL: `/purchase/supplier-calendar`
- 権限リソース: `purchase.supplier_calendar`

## 2. データモデル

### 2.1 関連テーブル

| テーブル | 役割 |
|----------|------|
| `Supplier` | 仕入先マスタ |
| `Line` (`line_type='PURCHASE'`) | 購買ライン。`line_code = supplier.supplier_code` で紐付く |
| `Calendar` | カレンダマスタ。`Line.calendar` で参照 |
| `CalendarDay` | カレンダ日別レコード。`is_working_day`, `work_minutes`, `note` 等 |

### 2.2 仕入先→カレンダの関係

```
Supplier.supplier_code  ─(一致)─>  Line.line_code  ─(FK)─>  Calendar
```

- 購買ラインの `calendar` フィールドがカレンダへの参照
- カレンダ未割当の場合、ダイソウカレンダ（`calendar_code='daiso'`）をフォールバック表示

## 3. 画面レイアウト

### 3.1 ヘッダ

| 要素 | 説明 |
|------|------|
| ページタイトル | 「仕入れ先カレンダ」 |
| 注意書き | 「未設定日はダイソウカレンダの稼働日を既定値として表示します」（赤字） |
| 新規作成ボタン | 新規カレンダ作成セクションの表示/非表示トグル |

### 3.2 ツールバー

| 要素 | 説明 |
|------|------|
| 仕入れ先セレクト | `Supplier` 一覧から選択。変更で現在カレンダを自動表示 |
| カレンダセレクト | 全カレンダ一覧から選択。変更でカレンダ日をプレビュー表示 |
| 割当ボタン | 選択カレンダを仕入先の購買ラインに割り当て（確認ダイアログ付き） |
| 割当解除ボタン | カレンダ割当を解除（ダイソウカレンダがフォールバックに戻る） |

### 3.3 新規作成セクション（折りたたみ）

| フィールド | 説明 |
|------------|------|
| カレンダコード | 一意のコード（例: `sup_A001`） |
| カレンダ名 | 表示名（例: `A社カレンダ`） |
| 作成して割当 | カレンダ新規作成 + 即座に仕入先へ割当 |

### 3.4 カレンダグリッド

| 要素 | 説明 |
|------|------|
| 月ナビゲーション | 「前月へ」「YYYY年M月」「次月へ」 |
| 曜日ヘッダ | 日〜土の7列。各曜日にチェックボックス（一括 ON/OFF） |
| 日セル | 日付番号 + 稼働チェックボックス + メモテキストエリア |

### 3.5 日セルの表示

| 状態 | 背景色 |
|------|--------|
| 稼働中 | 緑系 (`#ecfdf5`) |
| 休み | 赤系 (`#fef2f2`) |
| 月外 | グレー (`#f8fafc`) |

## 4. 機能詳細

### 4.1 カレンダ割当

1. 仕入先を選択
2. カレンダドロップダウンから既存カレンダを選択（プレビューとしてカレンダ日が即時表示）
3. 「割当」ボタンで確認ダイアログ → `Line.calendar` を PATCH 更新

```
PATCH /api/lines/{line_id}/
{ "calendar": calendar_id }
```

### 4.2 カレンダ割当解除

1. 「割当解除」ボタンで確認ダイアログ
2. `Line.calendar` を `null` に PATCH

```
PATCH /api/lines/{line_id}/
{ "calendar": null }
```

### 4.3 新規作成して割当

1. カレンダコード・名を入力
2. 「作成して割当」で:
   - `POST /api/calendars/` でカレンダ作成
   - `PATCH /api/lines/{line_id}/` で割当

### 4.4 日別稼働日トグル

- 日セルのチェックボックスをクリック
- 既存レコードがあれば PUT、なければ POST
- `work_minutes`: 稼働時=480（8時間）、休み時=0

```
PUT /api/calendar-days/{id}/
{ "calendar": id, "target_date": "YYYY-MM-DD", "is_working_day": bool, "work_minutes": int }
```

### 4.5 曜日一括設定

- 曜日ヘッダのチェックボックスで月内の同曜日を一括 ON/OFF
- 対象月内の全該当日に対して PUT/POST を並列実行

### 4.6 メモ編集

- 日セルのテキストエリアに入力し、blur で保存
- 内容が変更されていない場合は API 呼び出しをスキップ

### 4.7 ダイソウカレンダ・フォールバック

- カレンダ未割当、またはカレンダ割当済みだが特定日のレコードがない場合
- ダイソウカレンダ（`calendar_code='daiso'`）の稼働日を既定値として表示
- ダイソウカレンダにもレコードがない場合は、土日=休み、平日=稼働

## 5. ファイル構成

| ファイル | 役割 |
|----------|------|
| `pm-ui/src/views/purchase/PurchaseSupplierCalendar.vue` | フロントエンド画面 |
| `pm-ui/src/router/purchase.js` | ルーティング定義 |
| `pm_backend/apps/masters/views.py` → `CalendarViewSet`, `CalendarDayViewSet` | カレンダ CRUD API |
| `pm_backend/apps/masters/views.py` → `LineViewSet` | ライン PATCH API（calendar 割当） |

## 6. API エンドポイント

| メソッド | パス | 説明 |
|----------|------|------|
| GET | `/api/suppliers/` | 仕入先一覧 |
| GET | `/api/lines/` | ライン一覧（`line_type=PURCHASE` でフィルタ） |
| GET | `/api/calendars/` | カレンダ一覧 |
| POST | `/api/calendars/` | カレンダ新規作成 |
| GET | `/api/calendar-days/?calendar=N&target_date__gte=...&target_date__lte=...` | カレンダ日取得 |
| POST | `/api/calendar-days/` | カレンダ日新規作成 |
| PUT | `/api/calendar-days/{id}/` | カレンダ日更新 |
| PATCH | `/api/lines/{id}/` | ライン更新（カレンダ割当/解除） |
