# 工程実績入力ルーティング検証仕様書

## 対象

- 通常の工程実績登録 API
- 後入力セッション作成 API
- セッションの品番変更 API

## 検証ルール

実績を登録または品番変更する前に、対象日の有効ルーティングを確認する。

- 対象製品が `RoutingStep.output_product` に登録されていること
- 入力工程がその `RoutingStep.process` と一致すること
- 工程のラインが `RoutingStep.line` と一致すること。`RoutingStep.line` が未設定の場合は、工程に設定されたラインと一致すること
- ルーティングの有効期間・有効状態は `build_effective_routing_q` に従うこと

いずれかを満たさない場合、実績・セッション・LineBacklog は作成または更新しない。

ただし、当日時点で有効な連産BOM（`BOM.is_coproduct=True`）の親製品・子品番は、ルーティング検証の対象外とする。連産品にはルーティングを登録しないため、入力工程との一致確認も行わない。

## エラー

ルーティング外の工程へ入力した場合は、HTTP 400 で次のメッセージを返す。

```
{品番} は {工程コード} {工程名}工程の加工品ではないため、入力できません。
```

例:

```
YD60000441 は 4021 タンクサブ―工程の加工品ではないため、入力できません。
```

## 対象外

- 不良・スクラップ記録
- 設備状態のみの記録
