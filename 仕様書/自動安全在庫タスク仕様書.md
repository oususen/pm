# 自動安全在庫タスク仕様書

## 1. 概要

`/settings/task-settings` から設定できる定時タスクとして、以下2分類の自動安全在庫を追加する。

- 社内（`AUTO_SAFETY_STOCK_INTERNAL`）
- 購入品（`AUTO_SAFETY_STOCK_PURCHASE`）

本タスクは、`t_stock_allocation.min_stock_qty`（最小在庫数）を定期更新する。

## 2. UI仕様

画面:

- タスク設定メニュー: `pm-ui/src/views/settings/TaskSettingsMenu.vue`
- 定時タスク設定: `pm-ui/src/views/settings/ScheduledTasks.vue`

表示モード:

- `mode=safety-stock` で自動安全在庫セクションを表示

設定項目（2分類それぞれ）:

1. 実行日・時刻
   - `scheduled_dom`（1-31）
   - `scheduled_hour`（0-23）
   - `scheduled_minute`（0-59）
2. 実行日から何日間の平均日あたりを計算
   - `average_days_window`（1-365）
3. 上記の日当たりの何日分を安全在庫とする
   - `safety_days`（1-365）

共通項目:

- `is_enabled`（有効/無効）
- 保存
- 今すぐ実行
- 最終実行情報（日時/結果/実行時間/詳細）

## 3. 権限

既存の定時タスク設定と同じ。

- 閲覧: `settings.scheduled_tasks` `can_view`
- 保存/実行: `settings.scheduled_tasks` `can_edit`

権限制御はフロントエンドUIのみ（バックエンドで認可しない）。

## 4. データモデル

`production_schedule_config` に以下を追加。

- `average_days_window`（`PositiveSmallIntegerField`, default `60`）
- `safety_days`（`PositiveSmallIntegerField`, default `1`）

`task_name` 選択肢に以下を追加。

- `AUTO_SAFETY_STOCK_INTERNAL`
- `AUTO_SAFETY_STOCK_PURCHASE`

## 5. API仕様（既存エンドポイント拡張）

- `GET /api/schedule-config/`
- `POST /api/schedule-config/`
- `POST /api/schedule-config/run-now/`

保存時バリデーション:

- `average_days_window`: 1〜365
- `safety_days`: 1〜365
- 安全在庫タスクでは `scheduled_dom` 必須

## 6. 実行ロジック

実装: `pm_backend/apps/production/scheduler/tasks_safety_stock.py`

対象分類:

- 社内: `line.line_type='PROD'`
- 購入品: `line.line_type='PURCHASE'`

対象期間:

- 業務日付（8時境界）`today` を基準に、`today` 〜 `today + (average_days_window - 1)`（将来期間）

算出式:

`安全在庫数 = (期間合計需要数(確定+内示) / average_days_window) × safety_days`

- 需要数: `line_demand.firm_qty + line_demand.forecast_qty`
- 保存先: `t_stock_allocation.min_stock_qty`（整数、四捨五入）
- 算出結果が0以下の場合でも、最小在庫は `1` を下限として保存する

更新方法:

- 既存 `StockAllocation` があれば `min_stock_qty` を更新
- 無い場合は `location='MAIN'` で新規作成（在庫/引当は0）

## 7. スケジューラ登録

実装: `pm_backend/apps/production/management/commands/run_scheduler.py`

- `AUTO_SAFETY_STOCK_INTERNAL` -> job id `auto_safety_stock_internal`
- `AUTO_SAFETY_STOCK_PURCHASE` -> job id `auto_safety_stock_purchase`
- Cron: 毎月 `scheduled_dom` 日の `scheduled_hour:scheduled_minute`

## 8. 手動実行

`POST /api/schedule-config/run-now/` で非同期実行可能。

- 10分以内の同一タスク二重実行は409で拒否
- 実行結果は `ScheduleConfig.last_run_*` に反映
