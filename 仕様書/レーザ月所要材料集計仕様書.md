# レーザ月所要材料集計仕様書

## 概要

`/production/plan-input` のレーザ3番目タブ「月所要材料集計」で、レーザーパターンに登録した完成品情報と受注明細を使って月次の所要材料を集計する。

対象は `LaserPattern.is_budget_target = true` のパターンのみ。

## 目的

- レーザ完成品の月次注文量から必要材料数を算出する
- パターンごとの必要材料数を把握する
- 材料別の月次所要を一覧化する

## 使用データ

### レーザーパターン

- `t_laser_pattern`
  - `pattern_no`
  - `material`
  - `equipment`
  - `process_time_min`
  - `is_budget_target`
- `t_laser_pattern_finished`
  - `finished_product`
  - `units_per_shot`

### 受注明細

- `t_order`
  - `status`
  - `order_type` (`FIRM` / `FORECAST`)
- `t_order_line`
  - `product_code`
  - `due_date`
  - `quantity`

## 集計ルール

### 1. 対象月

- 入力: `YYYY-MM`
- 対象期間: 月初日 〜 月末日
- 未指定時は業務日付の当月を使用

### 2. 注文量の採用ルール

完成品ごと、納期ごとに以下で採用数量を決定する。

- 同一完成品・同一納期に **確定（FIRM）** がある場合:
  - その日の採用数量 = 確定数量合計
- 確定がなく **内示（FORECAST）** のみある場合:
  - その日の採用数量 = 内示数量合計

月次の完成品採用数量は、上記日次採用数量の月内合計とする。

## 3. 完成品ごとの必要材料数

パターン内の完成品ごとに:

`完成品1個あたり材料 = 1 / 完成品取り数`

`完成品必要材料数 = 月次採用数量 / 完成品取り数`

複数完成品が同じパターンに登録されている場合でも、同時生産の最大値合わせではなく、各完成品の必要材料数を個別に計算する。

### 4. 必要材料数

- `パターン必要材料数 = 各完成品の必要材料数の合計`
- 材料別集計では、同一材料を使う全パターンの必要材料数を合算する

### 5. 加工時間

- `総加工時間(分) = パターン必要材料数 × process_time_min`
- 設備別集計では、同一設備を使う全パターンの `総加工時間(分)` を合算する

## 重複登録の扱い

同じ完成品が複数の材料予算用パターンに登録されている場合は、集計結果に警告を返す。

- 警告例:
  - `完成品 FIN-001 ... が複数パターンに登録されています: PT01, PT02`

現行版では警告表示のみ行い、集計自体は継続する。

## UI

### 画面

- `http://.../production/plan-input`
- レーザタブ
- サブタブ: `月所要材料集計`

### 表示内容

- 対象月入力
- Excel出力
- 材料別集計テーブル
- 設備別加工時間テーブル
- パターン別明細テーブル
- 重複登録警告

### 表示ルール

- パターン別明細では完成品ごとに `完成品1個あたり材料`、`確定数`、`内示数`、`採用数`、`完成品必要材料数` を表示する
- 設備別加工時間では設備ごとに `使用パターン数` と `総加工時間(分)` を表示する
- 採用区分は `確定のみ` / `内示のみ` / `日別で確定優先` を表示する
- Excel出力は `材料別集計` / `設備別加工時間` / `パターン別明細` の3シート構成とする

## 補足

- 現行版は **所要材料数** と **加工時間** の集計までを対象とする
- 金額算出は単価マスタ未整備のため未対応
