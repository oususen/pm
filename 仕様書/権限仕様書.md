# 権限仕様書（フロントエンドUIのみ）

## 概要

本システムの権限制御はフロントエンドUIのみで行う。  
バックエンドは権限判定ロジックを持たず、APIは認証のみ（または無制限）で動作する。

## 権限データの取得元

ログイン後、`/api/auth/me/` の `user.effective_permissions` を参照する。  
形式は以下の通り。

```
[
  { "resource": "orders", "can_view": true, "can_edit": false },
  { "resource": "production", "can_view": true, "can_edit": true }
]
```

## 判定ルール

- `can_edit = true` の場合は閲覧も許可扱いとする。
- `can_view = false` かつ `can_edit = false` は非表示または押下不可とする。

## 適用範囲（UIのみ）

### 1. グローバルナビゲーション（タブ）

各タブの表示・押下可否は `resource` 単位で判定する。  
未許可の場合は非表示、または押下不可とする。

| タブ | resource |
| --- | --- |
| 受注 | orders |
| 生産 | production |
| 仕入 | purchase |
| 出荷 | shipping |
| 在庫 | inventory |
| 品質 | quality |
| マスタ | masters |
| 設定 | settings |

### 2. 生産管理メニュー（タイル）

生産タブ内のボタンはタイル単位で許可を判定する。  
既定の判断基準は以下の通り（必要に応じて変更可能）。

| タイル | 既定の必要権限 |
| --- | --- |
| 工程作業入力 | production / can_view |
| 仕損品記録 | production / can_edit |
| 生産計画入力 | production / can_edit |
| 在庫/残量一覧 | production / can_view |
| 仕損履歴 | production / can_view |
| 進捗管理 | production / can_view |
| ライン需要一覧 | production / can_view |
| ライン勤務カレンダ | production / can_edit |
| 在庫引当 | production / can_edit |
| 製造指示 | production / can_edit |
| ミックス順序ボード | production / can_view |
| ライン稼働監視 | production / can_view |
| モバイル作業入力（ライン） | production / can_edit |

※「表示しない」か「押下不可」はUI側で切替可能。

## 注意事項

- この仕様はUI制御のみ。URL直打ちやAPI呼び出しは制限しない。
- 権限の正当性・セキュリティはバックエンドで保証しない。
