# 権限仕様書（フロントエンドUIのみ）

## 概要

本システムの権限制御はフロントエンドUIのみで行う。  
バックエンドは権限判定ロジックを持たず、APIは認証のみ（または無制限）で動作する。

## 権限データの取得元

ログイン後、`/api/auth/me/` の `user.effective_permissions` を参照する。  
形式は以下の通り。

```
[
  { "resource": "orders", "can_view": true, "can_edit": false },
  { "resource": "production", "can_view": true, "can_edit": true }
]
```

## 判定ルール

- `can_edit = true` の場合は閲覧も許可扱いとする。
- `can_view = false` かつ `can_edit = false` は非表示または押下不可とする。
- 下層ボタン用の権限が未設定の場合は、上位（例: `production`）の権限でフォールバック判定する。

## 適用範囲（UIのみ）

### 1. グローバルナビゲーション（タブ）

各タブの表示・押下可否は `resource` 単位で判定する。  
未許可の場合は非表示、または押下不可とする。

| タブ | resource |
| --- | --- |
| 受注 | orders |
| 生産 | production |
| 仕入 | purchase |
| 出荷 | shipping |
| 在庫 | inventory |
| 品質 | quality |
| 通知 | notifications |
| マスタ | masters |
| 設定 | settings |

### 2. 生産管理メニュー（タイル）

生産タブ内のボタンはタイル単位で許可を判定する。  
既定の判断基準は以下の通り（必要に応じて変更可能）。

| タイル | 既定の必要権限 |
| --- | --- |
| 工程作業入力 | production.process_input / can_view |
| 仕損品記録 | production.scrap_record / can_edit |
| 生産計画入力 | production.plan_input / can_edit |
| 在庫/残量一覧 | production.inventory / can_view |
| 仕損履歴 | production.scrap_history / can_view |
| 進捗管理 | production.progress / can_view |
| ライン需要一覧 | production.line_demands / can_view |
| ライン勤務カレンダ | production.line_calendars / can_edit |
| 在庫引当 | production.stock_allocations / can_edit |
| 製造指示 | production.orders / can_edit |
| ミックス順序ボード | production.sequence_board / can_view |
| ライン稼働監視 | production.line_monitor / can_view |
| モバイル作業入力（ライン） | production.mobile_input / can_edit |

### 3. 通知（タブ）

| 画面 | 既定の必要権限 |
| --- | --- |
| 知らせ源入力 | notifications / can_edit |

※「表示しない」か「押下不可」はUI側で切替可能（`PERMISSION_MODE`）。

## 設定方法

権限はテンプレートを基本とし、必要なユーザーのみ個別に上書きする。

1. テンプレート（部署・役職/部署/役職）で基本権限を設定  
2. ユーザー管理で個別権限を有効化し、例外のみ追加/変更  

テンプレートと個別権限の両方が設定されている場合、個別権限が優先される。

## 注意事項

- この仕様はUI制御のみ。URL直打ちやAPI呼び出しは制限しない。
- 権限の正当性・セキュリティはバックエンドで保証しない。
