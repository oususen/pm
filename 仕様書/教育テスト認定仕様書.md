# 教育・テスト・認定仕様書

## 概要

品質メニュー配下の `教育・テスト・認定` 画面で、教材・問題・試験定義・受験結果・教育/認定実績を管理する。

- 問題はDB管理とする
- 受講者/試験官は `auth_user` + `accounts_userprofile` から選択する
- 実施情報には受講時点の組織情報を保持する

## データモデル

### 教材・問題

- `quality_training_book`
  - 教材コード、教材名、取込元ファイル、取込元シート、問題数、教材URL
- `quality_training_question`
  - 教材FK、問題コード、カテゴリ、問題形式、難易度、重要度、リスク、問題文、選択肢JSON、正答、解説、根拠情報JSON
- `quality_training_exam_definition`
  - 教材FK、試験名、ランダム出題フラグ、全問題バンクフラグ、ランダム出題数
- `quality_training_exam_question`
  - 固定試験に紐づく問題一覧
- `quality_training_track`
  - 個人進捗画面に表示する教育項目

### 実施情報

- `quality_training_exam_session`
  - 試験開始時点の出題セッション
  - 受講者、試験官、実施日時、実施場所、推進判定対象フラグ、出題問題ID一覧
- `quality_training_exam_attempt`
  - 採点済み結果
  - 得点、総問題数、正答率、判定、回答JSON、採点明細JSON
- `quality_training_step_record`
  - 教育/認定の手動実績

### 組織連携

`quality_training_exam_session` / `quality_training_exam_attempt` / `quality_training_step_record` には、以下の受講者組織スナップショットを保持する。

- 所属部署
- 事業部
- 係
- 班
- グループ

いずれも `accounts_department` へのFKで保持する。

## 画面仕様

### 画面モード

- `問題集編集`
  - 教材、試験定義、進捗項目を確認する
- `練習`
  - 受講者、試験官、実施日時、実施場所の入力は不要
  - 出題と採点のみ行い、DB保存はしない
- `テスト`
  - 受講者、試験官、実施日時、実施場所を入力して正式テストとして記録する

### テストモード

- 教材一覧を表示する
- 教材ごとに試験ボタンを表示する
- 試験開始時に受講者・試験官・実施日時・実施場所・推進判定対象を確定する
- ランダム試験は開始時点で問題を確定し、セッションに保存する

### 受験履歴

- 受講者単位で受験履歴を表示する
- 教材、試験、実施日時、実施場所、試験官、判定、得点、正答率、組織情報を確認できる

### 個人進捗

- 教育 / テスト / 認定 の3列で表示する
- テストは `formal_exam=True` かつ `合格` の結果を進捗判定対象とする
- 認定は、テスト対象の教育項目ではテスト合格後のみ登録可能とする

## 採点ルール

- 合格基準は `全問正解（100%）`
- 合格時の判定は `PASS`
- 不合格時の判定は `RETRAIN`（画面表示は `補足教育・再教育`）

## API

- `GET /api/training-books/`
  - 教材一覧と試験定義一覧を返す
- `GET /api/training-tracks/`
  - 個人進捗の項目一覧を返す
- `POST /api/training-exam-sessions/start/`
  - 試験開始、出題確定
- `POST /api/training-practice/start/`
  - 練習開始、出題確定（DB保存なし）
- `POST /api/training-practice/grade/`
  - 練習採点（DB保存なし）
- `GET /api/training-attempts/`
  - 受験履歴一覧
- `POST /api/training-attempts/`
  - 回答提出、採点、結果保存
- `GET /api/training-progress/summary/`
  - 受講者単位の個人進捗
- `GET /api/training-step-records/`
  - 教育/認定実績一覧
- `POST /api/training-step-records/`
  - 教育/認定実績登録
