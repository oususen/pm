# 富士商事出荷指示書 仕様書

## 1. 概要

富士商事向けの専用出荷指示書を PDF で生成する機能。  
対象日はティエラ顧客（`customer_code=000001`）の受注から抽出し、フロア製品の数量を集計して 2 便分の台車レイアウトとして出力する。

- 画面: `出荷 > 富士商事出荷指示書`
- 権限キー: `shipping.fujishoji_document`
- ルート: `/shipping/fujishoji-document`

実装参照:
- `pm-ui/src/views/shipping/FujishojiShippingDocument.vue`
- `pm_backend/apps/shipping/views_fujishoji_document.py`
- `pm_backend/apps/shipping/services/fujishoji_pdf_generator.py`

---

## 2. 対象データ

### 2.1 受注抽出条件

`OrderLine` から以下条件で集計する。

- 得意先: `order__customer = customer_code "000001"`（ティエラ）
- 受注状態: `order__status = "OPEN"`
- 受注種別: `FIRM` のみ  
  判定条件: `order_type='FIRM'` または `order_type IS NULL かつ order.order_type='FIRM'`
- 数量: `quantity > 0`
- 納期: 指定日 (`due_date = target_date`)
- 製品コード: 富士商事対象のフロア製品コード群

### 2.2 製品マッピング

固定マッピング（番号・ラベル・色）を使用する。  
新旧品番はエイリアスで旧品番へ正規化して同じ表示（色・番号）に統合する。

- 固定定義: `FLOOR_PRODUCT_MAPPING`
- エイリアス: `FLOOR_PRODUCT_ALIAS_MAP`

---

## 3. 台車・便ロジック

### 3.1 定数

- `ITEMS_PER_CART = 2`（台車 1 台あたり 2 個）
- `CARTS_PER_TRIP = 14`（1 便 14 台車）
- 便数: ①8:00便、②8:00便（固定）

### 3.2 台車数計算

製品ごとの台車数:

- `carts = ceil(qty / ITEMS_PER_CART)`

### 3.3 便への割り当て

`_build_cart_layout` により、製品順に台車を作成して充填する。

- ①便が 14 台車に達したら ②便へ繰り下げ
- 1 製品は可能な限り連続して積む
- ②便を超える分は出力対象外（切り捨て）

---

## 4. API 仕様

ベース: `/api`

### 4.1 利用可能日付取得

- `GET /shipping/fujishoji-document/available-dates/`
- 返却:
  - `dates`: 受注のある日付配列（降順）
  - `count`: 件数

### 4.2 指定日データ取得（プレビュー用）

- `GET /shipping/fujishoji-document/<target_date>/`
- `target_date` 形式: `YYYY-MM-DD`
- 返却例:
  - `date`
  - `products[]`（`product_code`, `number`, `label`, `color`, `qty`, `carts`）
  - `trip1[]`, `trip2[]`（各台車情報）
  - `carts_per_trip`, `items_per_cart`

### 4.3 PDF 生成

- `POST /shipping/fujishoji-document/generate-pdf/`
- リクエスト:
```json
{ "target_date": "YYYY-MM-DD" }
```
- レスポンス: PDF バイナリ（添付ファイル名: `富士商事出荷指示書_YYYY-MM-DD.pdf`）

### 4.4 設定取得

- `GET /shipping/fujishoji-document/config/`
- 返却:
  - `new_code_switch_date` (`YYYY-MM-DD` または空文字)

### 4.5 設定保存

- `POST /shipping/fujishoji-document/config/save/`
- リクエスト:
```json
{ "new_code_switch_date": "YYYY-MM-DD" }
```
解除時:
```json
{ "new_code_switch_date": "" }
```

## 5. 画面仕様

対象: `FujishojiShippingDocument.vue`

- 日付入力（`type=date`）
- 新品番切替日入力（`type=date`）と保存ボタン
- 「利用可能な日付を表示」ボタン
- 「データプレビュー」ボタン
- 「PDF生成」ボタン
- プレビュー表示内容:
  - ①便 / ②便台車数
  - 合計台車数
  - 超過台車数（`max(0, trip1+trip2-28)`）
  - 凡例（1-5 / A-F）
  - ①②便の台車セル表示
  - ③④追加便（空欄表示のみ）

### 5.1 新品番切替日設定

- 保存先: `SystemSetting.key = shipping.fujishoji_new_code_switch_date`
- 判定ルール:
  - 切替日未設定: 旧品番表示
  - 対象日 `<` 切替日: 旧品番表示
  - 対象日 `>=` 切替日: 新品番表示
- 対象:
  - 画面プレビュー凡例
  - 台車セルの品番データ
  - PDF の凡例品番表示
- 数量集計は新旧品番を内部で統合して計算する。

## 6. PDF 仕様

対象: `fujishoji_pdf_generator.py`

- 用紙: A4 縦
- タイトル: `富士商事様向け 出荷指示書`
- 日付: 和暦でなく和文曜日付き日付表示（`format_japanese_date`）
- 右上に確認/作成欄
- 便表示:
  - ①8:00便（7列×2行）
  - ②8:00便（7列×2行）
  - ③追加_日商便（2列×2行、空）
  - ④追加便（2列×2行、空）
- セル表示:
  - `[番号]`
  - 種別（例: キャブ/キャノピ）
  - モデル + 数量記号（`②` or `×n`）
- 合計表示:
  - `合計 XX台車（2個入り×14台車/便×2便）`
  - 28 台車超過時は超過警告を赤表示

---

## 7. エラー仕様

- 日付フォーマット不正: `400`
- `target_date` 未指定: `400`
- ティエラ顧客未登録: `404`
- その他サーバーエラー: `500`

---

## 8. 運用上の注意

- 品番マッピングはコード定数で管理しているため、対象品番変更時は実装更新が必要。
- 3便/4便は現在入力・自動割付対象ではなく、帳票上の空欄枠のみ表示。
- 2便を超える台車は帳票出力されないため、ピーク日は別運用でフォローが必要。
