# 生産管理システム プロジェクトサマリー（最新版）

## 1. プロジェクト概要

本システムは **量産型生産（同一製品を毎日複数製造）** を前提とし、\
**受注 → 日次生産計画 → 日次工程着手日 → 外作 → 運送 → 在庫 →
進捗管理**\
までを一元管理する **Web 生産管理システム（Django + Vue）** を構築する。

従来の Excel や口頭管理を排除し、工程の負荷・在庫・進捗・外作を\
リアルタイムに可視化して安定生産を実現する。

------------------------------------------------------------------------

## 2. システム目的

### 2.1 ビジネス目的

-   **リードタイム短縮**
-   **計画 vs 実績の可視化**
-   **在庫最適化（重点強化）**
-   **外作・運送の漏れ防止**
-   **Excel・個人依存からの脱却**
-   **量産に特化した安定生産の実現**

### 2.2 システム目的（IT）

-   全情報を Django + SQLDB に統一\
-   Vue によるリアルタイム Web 操作\
-   日付ベース → 将来時間ベースの計画へ進化可能\
-   モジュール構造で拡張性を確保

## 4. 業務フロー（量産型に最適化）

1.  **受注登録（内示・確定）**
2.  **日次生産計画（同一製品を毎日複数生産）**
3.  **工程計画（ProcessPlan：日単位）**
4.  **外作工程 → PO 発行**
5.  **運送計画**
6.  **現場作業指示**
7.  **実績入力 → 在庫反映（計画/実績）**
8.  **進度管理（受注数 × LT）**
9.  **遅れアラート（工程・外作・出荷・材料）**

------------------------------------------------------------------------

## 5. 機能一覧（モジュール）

### 5.1 マスタ管理

-   顧客／仕入先\
-   製品\
-   工程\
-   ライン\
-   ルーティング（RoutingStep）\
-   カレンダ（客先別／仕入先別）\
-   構成（BOM）\
-   従業員\
-   ユーザー・権限

### 5.2 受注管理

-   内示／確定\
-   受注一覧\
-   納期回答補助

### 5.3 生産計画（量産型）

-   日別必要数の決定\
-   同一製品を複数生産する前提のスケジュール\
-   在庫量と顧客需要から日産数量を算出

### 5.4 工程計画（量産・日単位）

-   RoutingStep 展開\
-   工程 LT とバッファ日数から **着手日を逆算**\
-   将来、時間粒度へ拡張可能

### 5.5 在庫管理

-   計画在庫・実績在庫\
-   入出庫履歴（倉庫概念なし）\
-   LT を使った未来在庫推移

### 5.6 外作管理

-   外作PO\
-   持込・引取予定\
-   外作進捗・検収

### 5.7 運送計画

-   出荷スケジュール\
-   配送便・業者割付き

### 5.8 ダッシュボード

-   工程遅れ\
-   稼働負荷\
-   在庫アラート\
-   外作遅れ\
-   出荷遅れ

## 7. 生産計画と工程計画（量産向け定義）

### ✔ 生産計画（製品レベル）

-   「その日に何個作るか」を決める\
-   同一製品を複数生産する前提で日次計画を作成

### ✔ 工程計画（工程レベル：日単位）

-   工程 LT（秒/分）と工程順から\
-   **日単位で着手日を逆算**\
-   将来は時間ベース（start_time/end_time）にも移行可能
