# 生産管理システム プロジェクト設計まとめ

## 1. プロジェクト概要

本プロジェクトは、受注〜生産計画〜工程計画〜外作〜運送〜在庫〜進捗までを一元管理する
**Webベースの生産管理システム（Django + Vue）**
を構築することを目的とする。

ユーザーが送付した資料（production_system_design.pdf）および会話で整理された構想を集約し、実装イメージ（画面構成・UI・ルーティング）を統合した仕様をまとめている。

------------------------------------------------------------------------

## 2. システム目的まとめ

### ビジネス目的

-   リードタイム短縮
-   計画 vs 実績の可視化
-   在庫最適化（欠品／過剰の防止）ここ強化したい
-   外作・運送の段取り漏れ削減
-   Excel・個人管理の排除

### システム目的

-   全情報の統一データベース化
-   最新状況を誰でも参照可能
-   拡張性を考慮したモジュール設計
-   Web化による操作性向上

------------------------------------------------------------------------

## 3. 想定ユーザーとロール

-   営業：受注管理、納期確認
-   生産管理：生産計画、工程計画、外作、運送
-   現場：作業指示／実績入力　
-   物流：出荷／納入
-   購買：PO・外作管理

------------------------------------------------------------------------

## 4. 業務フロー（ハイレベル）

1.  受注登録（SalesOrder）内示　確定　多得意先
2.  生産計画生成（ProductionPlan）　自動生成
3.  工程計画生成（ProcessPlan）　工程能力　段替え優化
4.  外作工程 → PO 発行
5.  出荷日から運送計画生成（TransportPlan）
6.  現場で実績入力　作業指示　作業順番　加工物の構成部品　作業内容　注意事項　品質確認表　所要材料の在庫情報
7.  在庫反映（計画在庫／実績在庫）計画在庫　実績在庫　（計画数、実績数　とltで計算
8.  進度管理　（受注数とltで計算）
9.  進捗モニタリング（遅れアラート）

------------------------------------------------------------------------

## 5. 機能一覧（モジュール）

### 5.1 マスタ管理

-   顧客マスタ
-   仕入先マスタ
-   製品マスタ
-   工程マスタ
-   ラインマスタ
-   ルーティング（Routing / RoutingStep）
-   カレンダマスタ（客先別　）購入先別
-   構成マスタ（BOM）
-   従業員
-   ユーザー

### 5.2 受注管理

-   受注入力
-   受注一覧
-   納期回答補助

### 5.3 生産計画

-   ProductionPlan 自動生成
-   ProcessPlan 自動生成
-   ガントチャート（工程別／ライン別）
-   負荷確認

### 5.4 在庫管理

-   在庫一覧
-   入出庫履歴（倉庫が存在しない）
-   計画在庫推移

### 5.5 外作管理

-   外作PO発行
-   持ち込み／引き取り予定
-   検収管理

### 5.6 運送計画

-   出荷スケジュール
-   配送業者・便割り当て

### 5.7 ダッシュボード

-   遅延工程一覧
-   稼働率・負荷
-   在庫アラート
