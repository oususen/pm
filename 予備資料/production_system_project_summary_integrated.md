# 生産管理システム プロジェクトサマリー（工程統合版・最新版）

## 1. プロジェクト概要

本システムは **量産型生産（同一製品を毎日複数製造）** を前提に、\
**受注 → 日次生産計画 →（工程日付を内包した）生産計画 → 外作 → 運送 →
在庫 → 進捗管理**\
までを一元管理する **Web生産管理システム（Django + Vue）** を構築する。

------------------------------------------------------------------------

## 2. システム目的

### 2.1 ビジネス目的

-   リードタイム短縮\
-   計画 vs 実績の可視化\
-   在庫最適化（重点強化）\
-   外作・運送の段取り漏れ削減\
-   Excel・属人化の排除\
-   量産に特化した安定生産の実現

### 2.2 システム目的（IT）

-   Django + SQLDB によるデータ統合\
-   Vue によるリアルタイム操作\
-   日単位 → 将来時間単位に拡張可能なモデル\
-   工程統合によりシステム構造をシンプル化

## 4. 業務フロー（工程統合版）

1.  **受注登録（内示・確定）**\
2.  **日次生産計画（製品別必要数を確定）**\
3.  **工程日付を内包した生産計画自動生成（ProductionPlan）**\
4.  **外作工程 → PO 発行**\
5.  **運送計画（出荷日逆算）**\
6.  **現場作業指示**\
7.  **実績入力 → 在庫反映**\
8.  **進度管理（計画数・実績数・LT）**\
9.  **遅れアラート（工程・外作・出荷・材料）**

------------------------------------------------------------------------

## 5. 生産計画と工程計画（統合方針）

### ✔ 統合理由（量産向け）

-   同一製品を毎日複数生産する\
-   工程LTが安定しており工程計画が製品計画に従属\
-   サブ品は当日完了でOK\
-   現場運用が日単位\
-   工程計画を独立させるメリットが少ない

### ✔ 統合モデルの例

``` json
{
  "product": "A1001",
  "quantity": 300,
  "plan_date": "2025-01-10",
  "process_dates": {
    "cut": "2025-01-10",
    "bend": "2025-01-11",
    "weld": "2025-01-12",
    "paint_out_motikom": "2025-01-12",
    "paint_out_hikitri": "2025-01-13"
  }
}
```

### 6.2 受注管理

-   内示／確定\
-   納期回答補助\
-   受注一覧
