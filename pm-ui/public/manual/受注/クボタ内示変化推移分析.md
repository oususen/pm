# クボタ内示分析

クボタから受け取る内示（予測受注）の変化を可視化・統計分析する画面です。
**変化推移分析**と**一括分析レポート**の2機能をタブで切り替えて使用できます。

## 画面への行き方

1. 上のグローバルナビゲーションの「受注管理」を開く
2. 「受注管理メニュー」→「クボタ内示分析」を選択

---

## タブ1：変化推移分析

1製品を選択して、内示のブレ幅や確定との差を分析します。安全在庫量の設計に活用できます。

### 使い方

1. **品番を選択**する（プルダウンからクボタ製品を選ぶ）
2. **納期範囲を指定**する（開始日・終了日）
3. **「分析実行」ボタンを押す**
4. 画面上部の**期間全体サマリー**で統計を確認する
5. **納期タブ**をクリックして、その日の内示推移グラフを確認する

### 期間全体サマリーの見方

分析期間全体を通じた統計が4ブロックで表示されます。

---

#### 予測誤差（全内示スナップショット − 確定）

内示と確定の差を全スナップショット分まとめて集計した指標です。

| 項目 | 意味 |
|------|------|
| **最大差（内示 − 確定）** | 内示が確定を最も大きく上回ったケースの差。プラスが大きいほど「内示が過大だった瞬間がある」。右の日付はその納期。 |
| **最小差（内示 − 確定）** | 内示が確定を最も大きく下回ったケースの差。マイナスは「内示より確定が多かった」= 欠品リスクがあったことを示す。右の日付はその納期。 |
| **平均絶対誤差（MAE）** | 差の絶対値の平均。プラス・マイナスを問わず「平均的にどれだけズレていたか」を表す。 |
| **平均差（符号付き）** | 内示 − 確定の平均。マイナスなら「内示が体系的に少ない傾向」。安全在庫の必要性が高い。 |
| **予測誤差 σ（標準偏差）** | 内示のブレの大きさ。大きいほど内示が不安定で安全在庫が多く必要。 |

---

#### 欠品リスク（内示 < 確定）

内示が確定を下回った（= 内示通りに準備すると在庫が不足する）ケースの集計です。

| 項目 | 意味 |
|------|------|
| **内示過小率** | 分析期間中の納期のうち、一度でも内示が確定を下回った納期の割合（%）。高いほど欠品リスクが高い。 |
| **最大過小量（ワースト）** | 内示が確定を下回ったケースの中で最も大きかった不足量。「最悪このケースに備えるには何個必要か」の目安。 |

---

#### 推奨安全在庫量（Z × σ）

内示のブレ（σ）を基に、欠品しない確率（サービスレベル）別の安全在庫量を計算したものです。

| サービスレベル | Z値 | 意味 | 目安 |
|---|---|---|---|
| **90%** | 1.28 | 10回に1回の欠品を許容する水準 | 比較的余裕がある製品向け |
| **95%** | 1.65 | 20回に1回の欠品を許容する水準 | 一般的な推奨水準 |
| **99%** | 2.33 | 100回に1回の欠品を許容する水準 | 欠品が許されない重要製品向け |

**「個」の意味：** 通常の発注・在庫計画に加えて、**さらに余分に持つべき在庫数量**です。
単位はCSV内示数量と同じ（クボタ内示が台単位なら台、個単位なら個）。

> **例）95%水準 = 14 の場合**
> 通常の計画在庫はそのまま維持した上で、常時14個を安全バッファとして積んでおくと、20回に1回しか欠品しない水準になります。

内示が体系的に過小な場合（平均差がマイナス）は、その分も上乗せ（**バイアス補正**）しています。

---

#### 収束安定期間（内示＝確定が続いた日数）

各納期について「内示が確定値と同じになってから、その後ずっと変わらなかった日数」を集計した指標です。

| 項目 | 意味 |
|------|------|
| **平均** | 全納期の収束日数の平均。大きいほど「早い段階から正確な内示が出ていた」ことを示す。 |
| **最短** | 最も直前になってから確定値と一致した納期の日数。右に納期日付を表示。 |
| **最長** | 最も早い段階から確定値と一致していた納期の日数。右に納期日付を表示。 |
| **対象納期数** | 最終的に内示と確定が一致して終わった納期の件数。 |

> **例）3/2 納期で最短 4日 の場合**
> 2/26のスナップショット時点で初めて内示が確定値（48）と同じになり、その後 3/2（納期）まで変わらなかった = 4日前まで確定値がわからなかったことを意味します。

---

### 納期別グラフ・統計の見方

**納期タブ**をクリックすると、その納期の内示推移グラフが表示されます。

- **横軸**: 内示を取り込んだ日（スナップショット日）
- **縦軸**: 内示数量
- **青い折れ線**: 各取込日時点での内示数量の推移
- **赤い破線**: 確定数量（現在の OPEN 受注の合計）

グラフ右の統計テーブルには、その納期の平均・標準偏差・変動係数・最終内示と確定の差などが表示されます。

---

## タブ2：一括分析レポート

複数製品を一括で分析し、各製品のサマリーをExcelファイルに出力します。

### 一括レポートの使い方

1. **製品を複数選択**する（チェックボックスで選択。「全選択」「全解除」ボタンあり）
2. **納期範囲を指定**する（省略可）
3. **「Excelレポート出力」ボタンを押す**
4. 画面にプレビュー表示され、Excelファイルが自動でダウンロードされる

### Excelの構成

1行1製品で、以下の列が出力されます。

| カテゴリ | 列 |
| --- | --- |
| 製品情報 | 品番・品名・スナップショット数・分析納期数 |
| 予測誤差 | 最大差・最大差日・最小差・最小差日・MAE・平均差・σ |
| 欠品リスク | 内示過小率(%)・最大過小量 |
| 推奨安全在庫 | 90%水準・95%水準・99%水準 |
| 収束安定期間 | 平均日数・最短日数・最短日・最長日数・最長日・対象件数 |

---

## 注意点

- 分析対象は `data_no='36'`（クボタ内示CSV）の取込済みデータです
- 確定数量は現在の OPEN 受注（確定受注）の合計で、過去の履歴は含みません
- 休日（クボタカレンダー基準）の納期は分析対象から除外されます
- スナップショットが1件しかない場合、標準偏差・安全在庫は計算できません
