# 受注取込

CSVファイルをアップロードして受注データを取り込みます。得意先と受注タイプを選んで取り込みを実行します。

## 画面への行き方

1. 上のグローバルナビゲーションの「受注管理」を開く
2. 「受注管理メニュー」→「受注取込」を選択

## 使い方

1. 得意先をタイルから選択します。
2. 受注タイプ（FIRM または FORECAST）を選択します。
3. クボタ（得意先コード 000196）の場合は工場を選択します。枚方の新受注フォーマットを使う場合は「枚方工場（27年以降）」を選択します。
4. 枚方の特殊確定CSVの場合は「枚方特殊確定」をオンにします。
5. CSVファイルを選択します。
6. 「アップロード」を押します。

## 入力項目

- 得意先: タイルから選択します。
- 受注タイプ: FIRM（確定）/ FORECAST（内示）を選択します。
- 工場: クボタのみ表示されます。`堺工場` `枚方工場` `枚方工場（27年以降）` `KMT工場` の4つから選択します。
- 枚方特殊確定: クボタ・確定・枚方の場合のみ表示されます。
- 取込システム: 既定は CSV です（必要に応じて変更）。
- CSVファイル: 拡張子 .csv のみ選択できます。

## 結果の見方

- 成功: 受注数・明細数・内示上書き数が表示されます。
- お知らせ: 追加取込（ファイル名に `-tuika` を含む確定取込）の場合、「追加注文がありました」と部番・数量が表示されます。
- お久しぶり製品通知: 設定した判定日数内に同一品番の受注がなかった明細がある場合、対象件数と対象一覧、メール送信結果が表示されます。
- 警告: 一部行の注意点が表示されます。
- エラー: 取り込みに失敗した理由が表示されます。

## お久しぶり製品通知設定

1. 「受注管理メニュー」→「お久しぶり製品通知設定」を開きます。
2. 「お久しぶり判定日数」を入力します。
3. 「送信宛先」にメールアドレスを入力します。
4. 保存すると、以後の受注取込時に自動判定・自動送信されます。

### 判定ルール

- 取込後に今回作成された `OrderLine` を走査します。
- 各明細の納期から指定日数さかのぼった期間に、同一得意先・同一品番の受注明細がなければ通知対象です。
- 対象が1件以上あり、送信宛先が設定されている場合のみ自動でメール送信します。

## 注意点

- 同じファイル名が過去に取り込まれている場合、警告が表示されアップロードできません。
- 得意先・受注タイプ・ファイルが未選択の場合は取り込めません。
- 枚方の特殊確定CSVは「枚方特殊確定」をオンにして取り込みます。
