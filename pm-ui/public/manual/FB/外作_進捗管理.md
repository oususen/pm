# 外作 進捗管理

## 1. 対象画面

- 進捗管理: `/outsource/progress`

## 2. 概要

FB外作案件の進捗状況を一覧で確認・更新する画面。発注・支給・加工・出荷の4段階の進捗をプログレスバーで可視化する。

## 3. フィルタ

- **ステータス**: 全ステータス / 分割計画登録済 / 加工中 / 完了
- **塗装日**: 日付範囲指定（前月/次月ボタンで月単位移動可能）

## 4. 一覧の表示項目

| 項目 | 説明 |
|---|---|
| 案件番号 | 案件の識別番号 |
| 品目名称 | 品目の名称 |
| 数量 | 受注数量 |
| 塗装日 | 塗装の予定日 |
| ステータス | 案件の進行状況 |
| 発注進捗 | 材料発注の進捗率（紫バー） |
| 支給進捗 | 材料支給の進捗率（青バー） |
| 加工進捗 | 加工完了の進捗率（緑バー） |
| 出荷進捗 | 出荷完了の進捗率（オレンジバー） |

## 5. 進捗率の計算

- **発注進捗**: 全材料が発注済の分割数 / 材料がある分割数 × 100
- **支給進捗**: 支給済の分割数 / 全分割数 × 100
- **加工進捗**: 加工完了の分割数 / 全分割数 × 100
- **出荷進捗**: 出荷済の分割数 / 全分割数 × 100

## 6. 進捗更新モーダル

案件行の「更新」ボタンで進捗更新モーダルが表示される。

### 6.1 モーダルの表示項目

| 項目 | 説明 |
|---|---|
| # | 分割連番 |
| 加工日 | 加工予定日 |
| 数量 | 分割数量 |
| 材料支給 | チェックボックスで支給済みを管理 |
| 加工完了(受入) | チェックボックスで加工完了を管理 |
| 出荷済 | チェックボックスで出荷済みを管理 |

### 6.2 自動ステータス

一部のステータスは他の画面での操作により自動更新される:
- **自動（緑タグ）**: 材料支給画面・納入出荷画面から自動でチェックが入った状態。手動変更不可
- **部分タグ（オレンジ）**: 一部の受入/出荷が登録されているが全数には達していない状態

### 6.3 手動更新

自動タグがないチェックボックスは手動で更新可能。チェックを入れると即時保存される。

## 7. 関連画面

- 材料支給: 支給ステータスの管理元
- 納入・出荷管理: 加工完了・出荷ステータスの管理元
