# 外作 外作先展開Excel出力

## 1. 対象画面

- 外作先展開Excel出力: `/outsource/excel-export`

## 2. 概要

取込済みの案件を選択し、外作先へ送付する分割計画テンプレートExcelを出力する画面。出力後、案件ステータスは「展開送付済」に更新される。

## 3. フィルタ

- **ステータス**: 取込済（未送付）/ 展開送付済 / 全て
- **塗装日**: 日付範囲指定（前月/次月ボタンで月単位移動可能）

## 4. 表示項目

| 項目 | 説明 |
|---|---|
| 案件番号 | 案件の識別番号 |
| 品目コード | 対象品目のコード |
| 品目名称 | 品目の名称 |
| 数量 | 受注数量 |
| 塗装日 | 塗装の予定日 |
| 調達最長LT | 材料の最長調達リードタイム |
| 材料コード | 最長LTの材料コード |
| 調達先 | 最長LTの調達先名 |
| 最早着手 | 最も早く着手可能な日付 |
| 最遅完了 | 遅くとも完了すべき日付 |
| ステータス | 案件の進行状況 |

## 5. Excel出力手順

1. 対象案件をチェックボックスで選択（ヘッダのチェックで全選択可能）
2. 「Excel出力（N件）」ボタンを押下
3. `split_plan_template.xlsx` がダウンロードされる
4. ダウンロードしたExcelを外作先へ送付

## 6. 制約日の一括再計算

1. 対象案件をチェックボックスで選択
2. 「選択行を再計算（N件）」ボタンを押下
3. 再計算条件入力ダイアログが表示される:
   - **外作先展開日数**: 外作先への展開にかかる日数
   - **社内承認日数**: 社内承認にかかる日数
   - **業務処理日数**: 業務処理にかかる日数
   - 発注LT = 外作先展開日数 + 社内承認日数 + 業務処理日数
4. 「この条件で再計算」を押下
