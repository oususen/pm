# 外作 案件詳細

## 1. 対象画面

- 案件詳細: `/outsource/orders/:id`

## 2. 概要

個別案件の詳細情報と分割計画を確認・編集する画面。受注一覧から行をクリックして遷移する。

## 3. 基本情報

以下の案件情報が表示される:

| 項目 | 説明 |
|---|---|
| 品目コード | 対象品目のコード |
| 品目名称 | 品目の名称 |
| 受注数量 | 総受注数量 |
| 塗装名 | 塗装の種類 |
| 塗装日 | 塗装の予定日 |
| ステータス | 案件の進行状況 |
| 最早着手日 | 業務日付 + 材料調達LT + 支給運送LT（営業日） |
| 最遅完了日 | 塗装日 - 顧客納入LT（営業日） |

## 4. 制約日の計算ルール

- **最遅完了日** = 塗装日 - 顧客納入LT（営業日）
- **最早着手日** = 業務日付 + 材料調達LT + 支給運送LT（営業日）
- 営業日計算は調達先カレンダ優先、未設定時はDAISOカレンダを使用

## 5. 制約日再計算

「制約日を再計算」ボタンで、最早着手日・最遅完了日を再計算できる。マスタの変更を反映したい場合に使用する。

## 6. 分割計画

### 6.1 表示項目

| 項目 | 説明 |
|---|---|
| # | 分割の連番 |
| 加工予定日 | 加工を行う予定日 |
| 数量 | 分割された数量 |
| 材料発注 | 材料発注の進捗（未発注 / 発注済数/全数） |
| 材料支給 | 支給済みかどうか |
| 加工完了 | 加工が完了したかどうか |
| 出荷済 | 出荷が完了したかどうか |

### 6.2 分割計画の編集

各分割行の「編集」ボタンで、加工予定日と数量をインライン編集できる。

- 編集後「保存」で確定
- 「取消」で編集をキャンセル
- 合計行で分割数量の合計を確認可能
