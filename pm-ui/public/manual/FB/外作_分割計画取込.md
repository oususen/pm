# 外作 分割計画取込

## 1. 対象画面

- 分割計画取込: `/outsource/splits/import`

## 2. 概要

外作先から返却された分割計画Excelを取り込み、案件の分割情報を登録する画面。BOM展開も同時に自動実行される。

## 3. 操作手順

1. 「分割計画Excel選択」でExcelファイル（.xlsx / .xls）を選択
2. 「取込実行」ボタンを押下
3. 取込結果を確認

## 4. 取込結果

### 4.1 結果サマリ

- **更新**: 正常に分割計画が登録された件数
- **警告**: 処理はされたが注意が必要な件数
- **エラー**: 取込に失敗した件数

### 4.2 更新された案件の詳細

| 項目 | 説明 |
|---|---|
| 案件番号 | 更新された案件の番号 |
| 分割数 | 登録された分割計画の件数 |
| 合計数量 | 分割計画の数量合計 |
| 材料支給 | BOM展開により生成された材料支給レコード数 |

## 5. 注意事項

- 取込と同時にBOM展開が実行され、各分割計画に対して必要な材料の支給レコードが自動生成される
- 既存の分割計画がある場合は上書きされる

## 6. 関連画面

- 外作先展開Excel出力: テンプレートExcelを生成する画面
- 材料手配: BOM展開で生成された材料の発注を管理
