# 外作 受注取込・受注一覧

## 1. 対象画面

- 受注取込: `/outsource/orders/import`
- 受注一覧: `/outsource/orders`

## 2. 受注取込（/outsource/orders/import）

### 2.1 概要

FB外作の受注CSVファイルを取り込み、案件を登録する画面。

### 2.2 操作手順

1. 「CSVファイル選択」でCSVファイルを選択
2. 文字コードを選択（UTF-8 / Shift_JIS）
3. プレビューで取込内容を確認
4. 「取込実行」を押下

### 2.3 CSVフォーマット

| 列 | 内容 |
|---|---|
| 1列目 | 品目コード |
| 2列目 | 品目名称 |
| 3列目 | 塗装名 |
| 4列目 | 塗装日 |
| 5列目 | 数量 |

### 2.4 案件番号の採番ルール

案件番号は `塗装日(YYYYMMDD)-品目コード` の形式で自動採番される。

### 2.5 取込結果

取込完了後、以下の結果が表示される:
- **作成**: 新規登録された件数
- **スキップ**: 既に登録済みの件数（案件番号が重複）
- **エラー**: 取込失敗の件数（エラー詳細が表示される）

## 3. 受注一覧（/outsource/orders）

### 3.1 概要

取り込まれたFB外作案件を一覧表示する画面。各行クリックで案件詳細へ遷移。

### 3.2 フィルタ

- **ステータス**: 全ステータス / 取込済 / 展開送付済 / 分割計画登録済 / 加工中 / 完了
- **塗装日**: 日付範囲指定（前月/次月ボタンで月単位移動可能）
- **キーワード検索**: 品目コード・名称で絞り込み

### 3.3 表示項目

| 項目 | 説明 |
|---|---|
| 案件番号 | 自動採番された案件番号 |
| 品目コード | 対象品目のコード |
| 品目名称 | 品目の名称 |
| 数量 | 受注数量 |
| 塗装名 | 塗装の種類 |
| 塗装日 | 塗装の予定日 |
| 最早着手 | 最も早く着手可能な日付 |
| 最遅完了日 | 遅くとも完了すべき日付 |
| ステータス | 案件の進行状況 |
| 分割数 | 分割計画の件数 |

### 3.4 ステータス遷移

1. **取込済** → CSVから取り込まれた直後
2. **展開送付済** → 外作先展開Excel出力を実行した後
3. **分割計画登録済** → 分割計画Excelを取り込んだ後
4. **加工中** → 加工が開始された状態
5. **完了** → 全工程が完了

## 4. 関連画面

- 案件詳細: 一覧の行をクリック
- CSV取込: 受注一覧右上の「CSV取込」ボタン
