# 外作 材料支給

## 1. 対象画面

- 材料支給: `/outsource/materials`

## 2. 概要

外作先へ支給する材料の便計画・出庫管理を行う画面。3つの表示モード（案件別・支給日別・材料別集約）を切り替えて使用できる。

## 3. フィルタ

- **出庫状態**: 未出庫のみ / 全て / 出庫済のみ
- **塗装日**: 日付範囲指定（前月/次月ボタンで月単位移動可能）
- **表示モード**: 案件別 / 支給日別 / 材料別集約

## 4. サマリバッジ

画面上部に以下のサマリが表示される:
- **全N件**: 表示対象の材料支給レコード総数
- **未出庫**: まだ出庫されていない件数
- **期限超過**: 支給予定日を過ぎて未出庫の件数（赤表示）

## 5. 表示モード

### 5.1 案件別表示

案件番号ごとにグループ化して表示。各グループはクリックで展開/折りたたみ可能。

| 項目 | 説明 |
|---|---|
| 支給予定日 | 外作先へ支給する予定日（期限超過は赤表示） |
| 加工日 | 外作先での加工予定日 |
| 材料コード | 材料の識別コード |
| 材料名称 | 材料の名称 |
| 調達先 | 材料の調達先 |
| 必要数量 | 支給すべき数量 |
| 状態 | 未対応 / 便計画済み / 出庫済 / 期限超過 |

### 5.2 支給日別表示

支給予定日ごとにグループ化して表示。
- 期限超過日は赤色ヘッダ
- 当日は緑色ヘッダ

### 5.3 材料別集約表示

材料コードごとに必要数量・支給済数量・残数を集約表示。全体の材料過不足を俯瞰する際に使用。

## 6. 操作

### 6.1 個別操作

材料支給は3段階のワークフローで進行する:

1. **便計画済み**: 「便計画済み」ボタンで配送計画に入った状態にする
2. **出庫済**: 「出庫済」ボタンで出庫（支給）完了にする
3. **出庫取消**: 「出庫取消」ボタンで出庫状態を元に戻す

### 6.2 一括操作

グループヘッダの「一括出庫済」ボタンで、グループ内の未出庫材料をまとめて出庫済にできる。
