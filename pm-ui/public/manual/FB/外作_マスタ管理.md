# 外作 マスタ管理

## 1. 対象画面

- マスタ管理: `/outsource/masters`

## 2. 概要

FB外作に必要なマスタデータを管理する画面。4つのタブ（外作先・品目・構成品・BOM）で構成される。

## 3. 外作先マスタ

外作先（加工委託先）の基本情報を管理する。

| 項目 | 説明 |
|---|---|
| 外作先名 | 外作先の名称 |
| 日キャパ | 1日あたりの加工能力 |
| 支給運送LT | 弊社→外作先への運送リードタイム（日数） |
| 完成品運送LT | 外作先→弊社への運送リードタイム（日数） |

### 操作

- 上部フォームに入力して「追加」で新規登録
- 一覧の「編集」ボタンでフォームに値をセットし「更新」で変更

## 4. 品目マスタ

外作対象の品目（完成品）を管理する。

| 項目 | 説明 |
|---|---|
| 品目コード | 品目の識別コード |
| 品目名称 | 品目の名称 |
| 外作先 | 加工を委託する外作先 |
| 顧客納入LT | 顧客への納入リードタイム（日数） |

### 操作

- 上部フォームに入力して「追加」で新規登録
- 品番は受注取込時に自動紐付けされる
- 一覧の「編集」ボタンでフォームに値をセットし「更新」で変更

## 5. 構成品マスタ

品目の構成材料を管理する。BOMで使用する材料の元データ。

| 項目 | 説明 |
|---|---|
| 材料コード | 材料の識別コード |
| 材料名称 | 材料の名称 |
| 調達先 | 材料の仕入先 |
| 調達LT | 仕入先からの調達リードタイム（日数） |

### フィルタ

- **コード検索**: 材料コードで絞り込み
- **調達先**: 調達先で絞り込み

### 操作

- 上部フォームに入力して「追加」で新規登録
- 一覧の「編集」ボタンでフォームに値をセットし「更新」で変更
- 一覧の「削除」ボタンで削除（確認ダイアログあり）

## 6. BOM（部品表）

品目ごとに必要な構成材料と員数を定義する。分割計画取込時のBOM展開で使用される。

| 項目 | 説明 |
|---|---|
| 材料コード | 構成品マスタに登録された材料コード |
| 材料名称 | 材料の名称 |
| 員数 | 品目1個あたりに必要な材料数量 |
| 調達先 | 材料の仕入先 |
| 調達LT | 仕入先からの調達リードタイム（日数） |

### 操作

1. 上部の品目選択ドロップダウンで対象品目を選択
2. 構成品選択ドロップダウンで材料を選択し、員数を入力
3. 「追加」で登録
4. 一覧の「編集」ボタンでフォームに値をセットし「更新」で変更
5. 一覧の「削除」ボタンで削除（確認ダイアログあり）

## 7. マスタ登録の順序

初回セットアップ時は以下の順序でマスタを登録する:

1. **外作先マスタ** → 外作先名とリードタイムを登録
2. **構成品マスタ** → 使用する材料を登録
3. **品目マスタ** → 品目コードと外作先の紐付けを登録
4. **BOM** → 品目と構成材料の紐付けと員数を登録

## 8. 関連画面

- 受注取込: 品目コードで品目マスタとの紐付けが行われる
- 分割計画取込: BOMを元に材料支給レコードが自動生成される
- 材料手配: 構成品マスタの調達LTが使用される
