# FB外作管理 全体マニュアル

## 1. 目的

FB外作業務の全体フロー（受注取込〜材料〜納入・出荷〜進捗）を、画面操作ベースで説明する。

## 2. 対象メニュー

- 入口: `/outsource/menu`
- 主な画面:
  - 受注取込: `/outsource/orders/import`
  - 受注一覧: `/outsource/orders`
  - 外作先展開Excel出力: `/outsource/excel-export`
  - 分割計画取込: `/outsource/splits/import`
  - 材料手配: `/outsource/procurement`
  - 材料検収: `/outsource/material-receiving`
  - 材料支給: `/outsource/materials`
  - 材料在庫: `/outsource/material-stock`
  - 完成品在庫: `/outsource/product-stock`
  - 納入・出荷: `/outsource/delivery`
  - 進捗管理: `/outsource/progress`
  - マスタ管理: `/outsource/masters`

## 3. 全体フロー

1. 受注取込でFB受注CSVを取り込む
2. 外作先展開Excel出力で対象案件を出力し、外作先へ送付
3. 分割計画取込で返却Excelを反映
4. 材料手配で発注数・材料納期を確認し、発注済にする
5. 材料検収で入庫（検収）を登録
6. 材料支給で便計画・出庫・支給状態を更新
7. 納入・出荷で完成品の受入/出荷を登録
8. 進捗管理で案件進捗を確認

## 4. 日付と在庫の考え方

- 材料納期と支給予定日は別管理
  - 材料納期: 調達先→弊社
  - 支給予定日: 弊社→外作先
- 材料納期の初期値:
  - 支給予定日から営業日1日逆算
  - 調達先カレンダ優先、未設定時は daiso カレンダ
- 在庫は総量管理（整数、マイナス在庫許可）
