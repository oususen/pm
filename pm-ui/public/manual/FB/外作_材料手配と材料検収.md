# 外作 材料手配・材料検収

## 1. 対象画面

- 材料手配: `/outsource/procurement`
- 材料検収: `/outsource/material-receiving`

## 2. 用語

- 材料納期: 調達先から弊社へ材料を入れる希望日
- 支給予定日: 弊社から外作先へ支給する予定日
- 発注数: 材料メーカーへ発注する数量（必要数量とは別管理）

## 3. 材料手配（/outsource/procurement）

### 3.1 画面の見方

- 行は調達先ごとにグループ表示
- 主な列:
  - 材料納期
  - 支給予定日
  - 必要数量
  - 在庫数
  - 発注数
  - 状態（未発注/発注済）

### 3.2 日付ルール

- 材料納期と支給予定日は別項目
- 初期値の材料納期は、支給予定日から営業日1日逆算
- 営業日カレンダは「調達先カレンダ優先、未設定時は daiso カレンダ」

### 3.3 操作

1. 対象行の `発注数` を入力（必要数量は変わらない）
2. 必要に応じて `材料納期` を編集
3. `発注済` ボタンで確定
4. 注文書が必要な場合は `注文書Excel出力`（全件）または `選択分の注文書Excel出力`

### 3.4 注意

- 発注数が 0 の行は注文書Excel出力対象外
- 注文書Excelの「納入希望日」は材料納期を使用

## 4. 材料検収（/outsource/material-receiving）

### 4.1 画面の見方

- 主なフィルタ:
  - 発注済のみ/全て
  - 塗装日
  - 支給予定日（ドロップダウン）
  - キーワード（材料コード・材料名・案件番号）
- 主な列:
  - 発注数
  - 検収済（累計）
  - 今回検収
  - 検収日
  - 理由

### 4.2 操作

1. 行ごとに `今回検収`、`検収日`、`理由` を入力
2. `検収登録` を押下
3. 検収済数量（累計）が更新されることを確認

## 5. 関連

- 材料支給: `/outsource/materials`
- 材料在庫: `/outsource/material-stock`
