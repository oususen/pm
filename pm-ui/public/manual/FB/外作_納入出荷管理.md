# 外作 納入・出荷管理

## 1. 対象画面

- 納入・出荷管理: `/outsource/delivery`

## 2. 概要

外作先からの完成品受入（検収）と、顧客への出荷を管理する画面。「外作先納入（検収）」タブと「顧客出荷」タブを切り替えて使用する。

## 3. フィルタ

- **塗装日**: 日付範囲指定（前月/次月ボタンで月単位移動可能）
- 分割計画登録済/加工中/完了ステータスの案件が対象

## 4. 画面構成

案件ごとにグループ化して表示。各案件のヘッダには以下が表示される:

| 項目 | 説明 |
|---|---|
| 案件番号 | 案件の識別番号 |
| ステータス | 案件の進行状況 |
| 品番・品名 | 対象品目の情報 |
| 塗装日 | 塗装の予定日 |
| 数量 | 受注数量 |
| 受入/出荷進捗 | 受入済（または出荷済）数量 / 受注数量 |

進捗バッジの色:
- 緑: 全数完了
- オレンジ: 一部完了
- グレー: 未着手

## 5. 外作先納入（検収）タブ

外作先から納入された完成品を受入（検収）登録する。

### 5.1 分割行の表示項目

| 項目 | 説明 |
|---|---|
| # | 分割連番 |
| 加工日 | 加工予定日 |
| 数量 | 分割数量 |
| 受入済 | 累計受入数量 |
| 残 | 未受入数量（赤字表示） |
| 納入日 | 受入日の入力欄 |
| 数量 | 今回受入数量の入力欄 |
| 検収者 | 検収者名の入力欄（ログインユーザー名が初期値） |

### 5.2 操作

1. 案件ヘッダをクリックして展開
2. 対象分割行に納入日・数量・検収者を入力
3. 「登録」ボタンで受入を記録
4. 登録済みの明細が分割行の下に表示される
5. 明細の「削除」ボタンで取消可能

## 6. 顧客出荷タブ

顧客への出荷を登録する。操作は納入タブと同様。

### 6.1 分割行の表示項目

| 項目 | 説明 |
|---|---|
| # | 分割連番 |
| 加工日 | 加工予定日 |
| 数量 | 分割数量 |
| 出荷済 | 累計出荷数量 |
| 残 | 未出荷数量（赤字表示） |
| 出荷日 | 出荷日の入力欄 |
| 数量 | 今回出荷数量の入力欄 |
| 担当者 | 担当者名の入力欄（ログインユーザー名が初期値） |

## 7. バリデーション

- 数量は1以上を入力
- 残数を超える数量は登録不可
- 検収者/担当者は必須

## 8. 関連画面

- 完成品在庫: 受入/出荷は完成品在庫に自動反映
- 進捗管理: 受入/出荷状況は進捗管理にも反映
