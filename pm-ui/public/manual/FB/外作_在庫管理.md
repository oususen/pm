# 外作 材料在庫・完成品在庫

## 1. 対象画面

- 材料在庫: `/outsource/material-stock`
- 完成品在庫: `/outsource/product-stock`

## 2. 概要

FB外作に関わる材料と完成品の在庫数量を確認し、棚卸調整を行う画面。どちらも「在庫一覧」タブと「在庫調整」タブの2画面構成。

## 3. 在庫一覧

### 3.1 現在庫（総量）

材料コード（または品目コード）ごとの現在庫数量を一覧表示する。マイナス在庫は赤字で表示される。

### 3.2 在庫履歴

入出庫の履歴を時系列で表示する。

| 項目 | 説明 |
|---|---|
| 日付 | 入出庫の発生日 |
| 区分 | 入庫 / 出庫 / 棚卸調整 |
| コード | 材料コードまたは品目コード |
| 名称 | 材料名称または品目名称 |
| 増減(個) | 数量の増減（プラス=緑、マイナス=赤） |
| 理由 | 入出庫の理由 |

### 3.3 フィルタ（材料在庫）

- **検索**: 材料コード・材料名で絞り込み
- **調達先**: 調達先で絞り込み
- **区分**: 入庫 / 出庫 / 棚卸調整
- **開始日・終了日**: 日付範囲の絞り込み

### 3.4 フィルタ（完成品在庫）

- **検索**: 品目コード・品番・品名で絞り込み
- **区分**: 入庫 / 出庫 / 棚卸調整
- **開始日・終了日**: 日付範囲の絞り込み

## 4. 在庫調整

### 4.1 個別調整

1. 品目を選択（現在庫数が自動表示される）
2. 増減数を入力（プラス=増加、マイナス=減少）
3. 調整日付を入力
4. 理由を入力（必須）
5. 「調整登録」ボタンで登録

### 4.2 一括調整

1. 理由を入力（必須）
2. 調整日付を入力
3. 一覧から対象行をチェックボックスで選択
4. 各行の「調整量(個)」に増減数を入力（0以外）
5. 「選択行を一括登録」ボタンで登録

## 5. 注意事項

- 在庫は総量管理（整数、マイナス在庫許可）
- 材料検収で検収登録すると材料在庫に自動反映（入庫）
- 材料支給で出庫済にすると材料在庫に自動反映（出庫）
- 納入・出荷画面で受入/出荷登録すると完成品在庫に自動反映

## 6. 関連画面

- 材料手配: 材料の発注管理
- 材料検収: 材料の入庫管理
- 材料支給: 材料の出庫管理
- 納入・出荷管理: 完成品の受入/出荷管理
