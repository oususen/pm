## 1. 役割と担当業務

生産計画員は、受注需要をもとに **ライン別の生産計画を立案・管理** し、現場が滞りなく生産できるよう調整する役割を担います。

> 受注取込は業務員が担当します。生産計画員は取り込まれた需要をもとに計画を立案します。

### 主な担当業務

| 業務 | 頻度 | 使用画面 |
|------|------|---------|
| 週間計画の立案・更新 | 毎日確認 | 生産計画入力 |
| 長期計画の立案・見直し | 月に１回 | 生産計画入力（期間: 業務と整合） |
| ガントチャートの確認・調整 | 毎日 | 生産計画入力（工程ガント） |
| 在庫・進度の確認と異常対応 | 毎日 | 在庫/残量一覧 |
| ライン稼働・進捗監視 | 随時 | ライン稼働監視 / 進捗管理 |
| 仕損の影響確認・計画調整 | 随時 | 仕損履歴 / 在庫/残量一覧 |
| 勤務カレンダの設定 | 月次 | ライン勤務カレンダ （都度確認）|

## 3. 重要な業務ルール

### 3-1. 日替わり時刻は8:00

本システムでは、**午前8:00を「業務上の日付の切り替わり」** として扱います。

| 操作時刻 | 業務上の扱い |
|---------|-------------|
| 1月20日 7:59 の実績入力 | **1月19日**の実績として計上 |
| 1月20日 8:00 の実績入力 | **1月20日**の実績として計上 |

> 夜間や早朝（8時前）に入力された実績は「前日分」として扱われます。在庫・進度の再計算もこのルールに従います。

### 3-2. 計画はロック期間あり

近い将来の計画は **ロック期間** として通常は変更できません。ロック期間内の計画を変更する場合は「計画変更」ボタンから変更理由を入力して解除します。

### 3-3. 計画立案は「最終ライン → 前工程」の順

**後工程の計画を先に立てないと前工程の需要が確定しません。**

| 順序 | ライン（例） | 操作 |
|------|------------|------|
| 1 | 最終ライン（タンクライン） | 計画入力・保存 |
| ↓ | | 取り込み（次のラインで実行） |
| 2 | 中間ライン（ブレーキライン） | 計画入力・保存 |
| ↓ | | 取り込み（次のラインで実行） |
| 3 | 前工程ライン（レーザーライン） | 計画入力・保存 |

各ラインの操作は **「取り込み → 計画入力 → 保存」** の順です。

### 3-4. 在庫の見方（2種類ある）

| 在庫の種類 | 意味 | 見るタイミング |
|-----------|------|---------------|
| **実在庫** | 今、物理的に実際にある数量 | 現場確認・棚卸 |
| **計画在庫** | 計画通りに進んだ場合の将来在庫 | 欠品リスクの判断 |

- **実在庫がマイナス** → 現在すでに欠品している（緊急対応が必要）
- **計画在庫がマイナス** → このまま進むと将来欠品する（計画の見直しが必要）

### 3-5. 進度の見方

**進度 = 顧客需要に対して実績が遅れているか先行しているか** を示す指標です。

- **プラス**: 需要より実績が多い（先行 → 余裕あり）
- **マイナス**: 需要より実績が少ない（遅れ → 後工程に影響の可能性あり）

## 4. 日次業務フロー

### STEP 1: 生産計画の立案（後工程 → 前工程の順）

**画面**: 生産管理 → 生産計画入力

**各ラインについて、以下の操作を「後工程 → 前工程」の順に繰り返す。**

#### 1-1. 画面の準備

1. **ライン**を選択する（必須）
2. **表示開始日** と **期間**（14日/30日/60日/90日）を選択する（デフォルト: 14日）
3. 「**取り込み**」ボタンを押す（または **F4キー**）
   - 後工程の需要が取り込まれ、**需要欄**に数量が表示される

#### 1-2. 計画入力

| 列 | 意味 | 操作 |
|----|------|------|
| 需要 | 後工程から算出された必要数量 | 参照のみ |
| 実績 | 実際に生産した数量 | 参照のみ |
| 在庫 | 現在の実在庫 | 参照のみ |
| 計画在庫 | 計画通りに進んだ場合の在庫見込み | 参照のみ |
| **計画** | **生産計画数量** | **ここに数量を入力** |
| **順序** | **当日内の生産順序** | **ここに順序番号を入力** |

**入力のポイント**:

- 計画数量を「0」または空欄にすると削除扱いになる
- 順序番号は同ライン・同日内で重複不可
- 同日に複数ロットを登録する場合は計画セルの「**+**」で行を追加する
- **計画在庫がマイナスになっている日付は欠品リスクあり** → 計画数量を増やして対応

#### 1-3. 保存

「**保存**」ボタンを押す。

保存すると以下が自動実行されます:
1. 工程展開（ライン内の全工程に計画を反映）
2. 在庫・計画在庫の再計算
3. ガントチャートの再生成

#### 1-4. ロック期間内の計画変更が必要な場合

1. 「**計画変更**」ボタンをクリック
2. 変更理由を入力して「確定」
3. ロック期間のセルが編集可能になる
4. 修正後「保存」

---

### STEP 2: ガントチャートの確認・調整

計画保存後、工程ガントを開いて各工程の開始時間と数量を確認・調整します。

**画面**: 生産計画入力（ガント表示切替）

#### 2-1. 工程ガントを表示する

「**工程ガント表示**」ボタンを押す。

- 計画バーが日付列に工程ごとに表示される
- 日付ヘッダーには **最終工程の開始時刻（緑）** と **勤務時間帯（赤）** が表示される
- バーにカーソルを置くと、工程名・品番・数量・時間帯・所要分が表示される

#### 2-2. ガントの確認ポイント

| 確認内容 | 対応 |
|---------|------|
| 工程の開始時間が勤務開始前になっていないか | 開始時刻を修正する |
| 複数ロットの順序が意図通りか | 順序番号を修正して再保存 |
| 工程間の時間に余裕があるか | 計画数量・開始時刻を調整 |
| 工程が終業時刻を大幅に超えていないか | 計画数量を分割するか翌日へ移動 |

> **分解表示 / 連結表示の切り替え**: 工程ガントは「分解」「連結」の2つの表示モードがあります。バーの編集（ドラッグ・開始時刻・数量変更）は **「分解」表示のみ** 対応しています。

#### 2-3. 開始時刻を変更する

1. 「**分解**」表示に切り替える
2. 変更したいバーの **開始時刻をクリック** する
3. 新しい開始時刻を入力する

#### 2-4. 数量を変更する

1. 「**分解**」表示に切り替える
2. バーの左側の **数値（数量）をクリック** する
3. 新しい数量を入力する

#### 2-5. バーをドラッグして位置を調整する

1. 「**分解**」表示に切り替える
2. バーをドラッグして開始位置を移動する

#### 2-6. 工程ガントを保存する

変更があると「**工程ガント保存**」ボタンが **赤色** に変わります。

「**工程ガント保存**」ボタンを押して保存する。

> 工程ガントの保存は「計画の保存」とは別操作です。ガントを編集したら必ず工程ガント保存を行ってください。

#### 2-7. 工程負荷の確認

「**工程負荷表示**」ボタンを押すと、工程別の負荷時間が確認できます。
負荷が高い工程（キャパシティ超え）がないか確認します。

---

### STEP 3: 在庫・進度の確認

**画面**: 生産管理 → 在庫/残量一覧

1. **ライン**（または工程・品番）を選択する（いずれか1つ必須）
   - ラインや工程のコードがわからない場合は入力欄を **F4キー** または **ダブルクリック** するとコード一覧が表示される
2. **開始日**と**期間**を指定する
3. 「**更新**」または「**再計算**」を押す

| ボタン | 処理内容 | 使うタイミング |
|-------|---------|--------------|
| 更新 | データ取得のみ（高速） | 現在の値を確認するだけのとき |
| 再計算 | 需要・仕損・在庫・進度をすべて再計算 | 最新の受注・実績を反映したいとき |

#### 製品情報欄（左側）の見方

各製品カードの左側に以下が表示されます。

| 項目 | 意味 |
|------|------|
| 品番・品名 | 対象製品 |
| 工程名・工程コード | 工程（購買の場合は仕入先名・仕入先コード） |
| 予定 | 表示月の計需合計 |
| 実需 | 表示月の実需合計 |
| 完成品向けLT | 完成品までの総リードタイム（日） |
| 自LT | 自工程のリードタイム（日） |

#### 日付マトリクス（右側）の確認ポイント

| 行 | 意味 | 異常の判断基準 |
|----|------|--------------|
| **計需** | 顧客の計画需要（旧：内示） | — |
| **実需** | 顧客の確定需要（旧：確定） | — |
| 計画 | 生産計画数量 | — |
| 実績 | 実際の生産数量 | — |
| 実在庫 | 現在の物理的な在庫 | **マイナス → 現在欠品中（緊急対応必要）** |
| 計画在庫 | 計画通りに進んだ場合の将来在庫 | **マイナス → 将来欠品の可能性（計画見直し）** |
| 進度 | 需要に対する実績の遅れ/先行 | **大きくマイナス → 遅れ気味（増産検討）** |

> 在庫・計画在庫・進度がマイナスの場合は赤色で表示されます。

---

### STEP 4: ライン稼働・進捗の確認

随時（勤務中に適宜）確認します。

#### ライン稼働監視

**画面**: 生産管理 → ライン稼働監視

- 「自動更新」ONでリアルタイム更新
- ラインカードで各ラインの稼働状態・達成率を確認
- KPI（稼働中ライン数・総生産数・平均達成率）を把握

#### 進捗管理

**画面**: 生産管理 → 進捗管理

- 画面を開くと現在の日付範囲のデータが**自動的に読み込まれます**
- ライン・工程・品番フィルターは入力すると**即座に絞り込まれます**（更新ボタン不要）
- 表示開始日や期間を変更した場合のみ「**更新**」を押してデータを再取得します

| 色 | 意味 |
|----|------|
| 緑 | 実績 = 計画（順調） |
| 黄 | 実績 > 計画（先行） |
| 赤 | 実績 < 計画（遅れ） |

> 1ページ20件表示。件数が多い場合はページ切替で移動します。

## 5. 長期計画・週間計画

### 長期計画（月〜四半期スパン）

**目的**: 内示需要をもとに、資材・人員・設備の過不足を事前に把握する。

**操作**:
1. 生産計画入力で期間を **60日 または 90日** に設定する
2. 「取り込み」で需要を取得する
3. 計画在庫が **マイナスになる日付** を確認し、増産または前倒し計画を入力する
4. 保存後、在庫/残量一覧で全ラインの計画在庫を確認する

**確認のポイント**:
- 需要の山（多い週）に合わせて計画が詰まっていないか
- 前工程ラインの計画在庫は、後工程ラインの計画保存後に取り込みを行ってから確認する
- 内示は変更される可能性があるため、確定受注が入り次第見直す

### 週間計画

**目的**: 今週・来週の生産を確定させ、現場に明確な指示を与える。

**操作**:
1. 期間を **14日 または 30日** に設定する
2. 「取り込み」で最新の需要を取得する
3. 今週・来週分の計画数量を確定値で入力する
4. 計画在庫・進度を確認し、遅れがある場合は増産計画を追加する
5. 工程ガントで各工程の開始時刻・数量を確認・調整して保存する

**週間計画の見直しタイミング**:
- 確定受注が更新されたとき
- 実績が計画から大きく乖離したとき
- 設備トラブルや欠員が発生したとき

## 6. 異常時の対応

### 6-1. 計画在庫がマイナス（将来欠品の見込み）

**状況**: 在庫/残量一覧の「計画在庫」行がマイナス

**対応**:
1. 「生産計画入力」で当該ラインを開く
2. 欠品が予測される日付より前の計画数量を**増産**する
3. 前工程ラインへの影響（需要増）も確認し、前工程計画も見直す
4. 保存後「在庫/残量一覧」で再計算して改善を確認する

### 6-2. 実在庫がマイナス（現在欠品）

**状況**: 在庫/残量一覧の「在庫」行が赤くマイナス表示

**原因を調べる手順**:
1. 「生産実績照会」で実績の入力漏れ・誤りを確認する
2. 「仕損履歴」で仕損の発生状況を確認する
3. 棚卸差異の可能性がある場合は現場に確認する

**対応**:
- 実績入力の漏れ/誤りがある場合 → システム担当者（実績変更権限者）に修正を依頼する
- 棚卸差異の場合 → 「在庫/残量一覧」の調整欄に補正値を入力しフォーカスを外す

### 6-3. 進度が大きくマイナス（遅れが拡大）

**状況**: 在庫/残量一覧の「進度」行が大きくマイナス

**確認手順**:
1. 「進捗管理」で計画 vs 実績を日別に確認する
2. 「仕損履歴」で仕損が多発していないか確認する

**対応**:
- 一時的な原因（トラブル・欠員）→ 計画を後ろに詰めて調整
- 継続的な遅れ → 増産計画を立案する

### 6-4. 仕損発生の報告を受けた場合

1. 「仕損履歴」で登録内容を確認する
2. 「在庫/残量一覧」で「再計算」を押し、計画在庫への影響を確認する
3. 計画在庫がマイナスになっている場合は計画を見直す

## 7. 月次業務

### 勤務カレンダの設定

**画面**: 生産管理 → ライン勤務カレンダ

1. ラインを選択し、割当カレンダを選択する
2. 翌月の期間を指定して勤務パターンを**一括登録**する
3. 祝日・特別休日は個別に「休日にする」で設定する
4. 残業など通常と異なる稼働時間の日は個別に更新する

> カレンダが未設定の日は稼働日として扱われることがあります。**必ず月初めに翌月分を設定してください。**

### 棚卸後の在庫調整（現在は実施禁止）

**画面**: 在庫/残量一覧（調整欄）

1. 棚卸差異がある製品を品番で絞り込む
2. 対象日の「調整」行のセルに補正値を入力する（不足は負の値）
3. フォーカスを外すと保存され、在庫・計画在庫が再計算される

## 8. 操作チートシート

### 生産計画入力 — よく使う操作

| 操作 | 方法 |
|------|------|
| セル間移動 | 矢印キー / Enter |
| 同日に複数ロット追加 | 計画セルの「+」ボタン |
| 工程ガント表示/非表示 | 「工程ガント表示」ボタン |
| 工程負荷確認 | 「工程負荷表示」ボタン |
| ガントバー編集（ドラッグ/時刻/数量） | 「分解」表示に切り替えてから操作 |
| ガントの変更を保存 | 「工程ガント保存」ボタン（赤色のとき未保存） |
| ロック期間の計画変更 | 「計画変更」→ 理由入力 → 確定 |
| Excel出力 | F10キー → Excel出力を選択 |
| PDF出力 | F10キー → PDF出力を選択 |

### 生産計画入力 — ファンクションキー一覧

| キー | 動作 |
|------|------|
| F1 | 戻る（ブラウザ履歴を1つ戻る） |
| F2 | 進む（ブラウザ履歴を1つ進む） |
| F3 | クリア（表示中の全行を削除） |
| F4 | 更新（後工程の需要を取り込み） |
| F5 | キャンセル（入力内容をクリア） |
| F10 | 印刷（出力形式選択ダイアログを表示） |

### 在庫/残量一覧 — よく使う絞り込み

| 目的 | 絞り込み方法 |
|------|------------|
| ライン全体の在庫確認 | ラインを選択 → 更新/再計算 |
| 特定品番の在庫確認 | 品番を入力 → 更新 |
| 最新状態に更新 | 再計算（全ライン反映済みの状態で実行） |

### システムの計算タイミング

| 処理 | 実行タイミング | 手動実行 |
|------|-------------|---------|
| 在庫・計画在庫の再計算 | 計画保存時（自動） | 在庫/残量一覧 → 再計算 |
| 工程展開 | 計画保存時（自動） | — |
| ガントチャート再生成 | 計画保存時（自動） | — |
| 前ライン需要への反映 | 手動（取り込みで実行） | 生産計画入力 → 取り込み |
