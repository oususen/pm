# BOM作成マニュアル

BOMマスタ画面で製品構成を登録し、前工程需要計算・購買需要計算・在庫計算・ルーティング自動生成の基礎データを整備する手順をまとめます。

## 1. 画面の行き方
1. グローバルナビの `マスタメンテ` を開く
2. `構成マスタ（BOM）` を選択する

## 2. 画面構成・説明・操作

### 画面の役割
- 親製品1個あたりの使用部品（数量・調達区分・リードタイム・加工情報）を定義します。
- 親子BOMをもとに需要展開・在庫計算を行える状態にします。
- 社内制作/外作/購入の工程情報からルーティングを自動生成できるようにします。

### 検索フィルター
| 項目 | 説明 |
|---|---|
| 親製品（品番/品名） | 部分一致で検索 |
| 最終品 | 最終品だけ/それ以外/すべて |
| ライン最終品 | ライン最終品だけ/それ以外/すべて |
| 連産品 | 連産品BOMのみ/非連産/すべて |
| 版 | 版で絞り込み |
| 作成日 From/To | BOM作成日の範囲で絞り込み |
| 有効 | 有効/無効/すべて |

### 一覧上部の主な操作
- `更新/検索`: 現在の条件で再取得
- `リセット`: フィルターを初期化して再取得
- `新規`: BOMヘッダを新規登録
- `取込テンプレートExcel`: BOM取込用テンプレート（入力用/工程/ライン/仕入先）を取得
- `取込テンプレートCSV`: BOM取込用CSVテンプレートを取得
- `CSV取込`: BOM取込ダイアログを開く（CSV/Excel対応）
- `逆展開`: 指定した部品を使用している親製品を検索

### 一覧行の主な操作
- `詳細`: BOM詳細ダイアログを開く
- `Excel出力`: 階層図をExcel形式で出力する
- `別タブ`: 詳細を別タブ表示する
- `階層図`: BOMツリーを表示する
- `編集`: BOMヘッダを編集する
- `削除`: BOMを削除する

### 画面で確認できること
- `詳細` でヘッダ情報と構成品目を確認・編集できます。
- `詳細` の `BOMをコピー` で、別の親製品へ構成を複製できます。
- `詳細` の `別バージョン作成` で、同じ親製品の将来版BOMを作成できます。
- `階層図` で親子関係、数量、工程、ライン、仕入先を確認できます。
- `逆展開` で、ある部品がどの親製品に使われているか確認できます。

## 3. BOM作成方法

### BOMの基本構造
**1つのBOMは「親製品」と「直下の子部品」の親子関係のみで構成されます。**

- BOM作成時は、親製品に対してその直下の子部品だけを登録します。
- 子部品が集合品（ASSEMBLY）の場合、その子部品を親とする別のBOMを作成します。
- 個々の親子BOMが連鎖することで、結果として多階層の構成（親→子→孫…）になります。
- システムが親子関係をたどって最下層まで自動展開し、構成部品表として利用します。

例：製品Aの構成が A → B → C の場合
1. BOM①: 親=A、子=B を登録
2. BOM②: 親=B、子=C を登録
3. システムがA→B→Cと展開

### 前提
- 製品マスタが登録済み（親・子とも）。連産品の場合は親に「仮想セット品番」を設定しておきます。
- 必要に応じて工程マスタ・ラインマスタ・仕入先マスタを登録しておきます。
- 同一親製品では `parent_product × version × valid_from` が一意です。改版は「版」または「有効開始日」を変えて新規登録します。
- 循環BOMは設定しません（階層取得時に循環検出エラーになります）。

### 連産品の扱い
- 連産品は同一工程で複数の実品が同時に得られる品番です。BOMでは在庫を持たない「仮想セット品番」を親として作成し、そこで必要部材・工程を管理します。
- 連産品を他のBOMの子として登録してはいけません。
- 連産品の実品（連産品の子）は、ほかの製品の子としてBOMを作成します。
- 連産品の製品番号ルールは `ST完成品番号-工程コード` です。

### ① 画面作成

#### 画面作成が向いているケース
- 少量のBOMを登録したいとき
- 既存BOMを修正したいとき
- 内容を確認しながら1件ずつ登録したいとき
- 既存BOMを元に、同一親製品の未来版BOMを作りたいとき

#### 画面作成の流れ
1. `新規` を押してBOMヘッダを登録する
2. 対象行の `詳細` を開く
3. `構成品目` フォームで子製品を追加する
4. `階層図` や `逆展開` で内容を確認する
5. 必要なら `BOMからルーティング生成` を実行する

#### 3. 同一親製品の別バージョンを作る
既存BOMを元に設変や切替用の future 版を作るときは、`詳細` 画面の `別バージョン作成` を使います。

1. 一覧から元になるBOMの `詳細` を開く
2. `別バージョン作成` を押す
3. `新しい版` を入力する  
   例: `v1` → `v2`
4. `有効開始日` を入力する  
   例: `2026-09-01`
5. 必要なら `有効終了日` を入力する
6. `作成実行` を押す
7. 新しく開いたBOMで、必要な明細だけ修正する

補足:
- `別バージョン作成` は親製品を変えません
- 明細は元BOMからそのまま複製されます
- `BOMをコピー` は別親製品へ複製する機能で、改版用途ではありません

#### 1. BOMヘッダを登録
| 項目 | 必須 | 説明・入力ルール |
|---|---|---|
| 親製品 | 必須 | 品番/品名で絞り込み可能。連産品BOMを作る場合は「仮想セット品番」の製品を選択。 |
| 連産品BOM | 任意 | 同一工程で複数製品を同時に生産する場合にチェック。作成後は変更不可。 |
| 版 | 必須 | 文字列。改版時は別の版名で新規登録。 |
| 有効開始日 | 必須 | BOMが適用され始める日。 |
| 有効終了日 | 任意 | 空欄なら無期限。 |
| 有効 | 任意 | 既定ON。無効にすると展開対象外。 |

> 編集モードでは「親製品」「連産品BOM」は変更できません。
> 同一親製品の改版は、既存BOMの `詳細` から `別バージョン作成` を使うと早く作れます。

#### 2. 構成品目を追加
| 項目 | 必須 | 説明・入力ルール |
|---|---|---|
| 子製品 | 必須 | 品番/品名で絞り込み可能。 |
| 数量 | 必須 | 親1個あたりの使用数（整数のみ、1以上）。 |
| ロス率 | 任意 | 0以上、0.001刻み。 |
| 調達区分 | 必須 | 自社製造(MAKE) / 購買(BUY) / 外注(SUBCON)。 |
| 仕入先 | 区分により | MAKEでは空、BUYは必須、SUBCONは必須。 |
| 工程 | 区分により | MAKEで必須。SUBCONは外注工程が自動設定される。BUYでは入力不可。 |
| ライン | 区分により | MAKEで必須。SUBCONは仕入先に応じたラインが自動設定される場合がある。BUYでは入力不可。 |
| 時間単位 | 区分により | MAKEは分/日を選択。BUYとSUBCONは日固定。 |
| リードタイム(日) | 区分により | BUY必須、time_unit=DAYのMAKEも1以上必須。 |
| 所要時間(分) | 区分により | time_unit=MINUTEかつMAKEで1以上必須。 |
| 備考 | 任意 | 200文字まで。 |

#### 調達区分ごとの挙動
- `MAKE`: 仕入先は空、時間単位の初期値は `分`、工程とラインが必須です。
- `BUY`: 工程・ラインは入力不可、時間単位は `日` 固定、仕入先とリードタイム(日)が必須です。
- `SUBCON`: 時間単位は `日` 固定、外注工程が自動設定されます。仕入先とリードタイム(日)が必須です。

### ② 取込作成

#### 取込作成が向いているケース
- 複数の親子関係をまとめて登録したいとき
- Excelで下準備してから一括登録したいとき
- 既存の構成表を流用したいとき

#### 取込作成の流れ
1. `取込テンプレートExcel` または `取込テンプレートCSV` を出力する
2. テンプレートへ必要項目を入力する
3. `CSV取込` を開く
4. ファイル、完成品、版、有効開始日を指定する
5. `取込前チェック` を実行する
6. 問題なければ `取込実行` を行う
7. 取込後に `詳細` や `階層図` で内容を確認する

#### テンプレートの使い分け
- `取込テンプレートExcel`
  - 推奨です。
  - `入力用` シートに加えて、`工程` `ライン` `仕入先` の参照シートが入っています。
  - `調達区分` と `時間単位` はプルダウン選択できます。
  - 工程コード/ラインコード/仕入先コードを入れると、名称列が自動表示されます。
- `取込テンプレートCSV`
  - 既存CSVをそのまま編集したい場合に使います。
  - 参照シートやプルダウンはありません。

#### 取込ファイルの列
1. 完成品
2. 親品番
3. 子品番
4. 数量
5. 工程コード
6. 工程名
7. ラインコード
8. ライン名
9. 調達区分
10. 仕入先コード
11. 仕入先名
12. ＬＴ(日)
13. 所要時間(分)
14. 時間単位

#### 取込時のルール
- 取込可能形式は `CSV(.csv)` / `Excel(.xlsx)` です。
- 必須ヘッダーは `親品番, 子品番, 数量, 調達区分` です。
- `完成品（画面入力）` は必須です。
- ファイル側の `完成品` 列が空なら、画面入力の完成品で補完されます。
- ファイル側の `完成品` と画面入力の完成品が不一致の場合はエラーです。

#### 区分別必須ルール（取込）
- `自社製造(MAKE)`
  - 工程コード 必須
  - ラインコード 必須
  - 時間単位 必須（分/日）
  - 時間単位=分: 所要時間(分) > 0 必須
  - 時間単位=日: LT(日) > 0 必須
- `購買(BUY)`
  - 仕入先コード 必須
  - 時間単位=日 必須
  - LT(日) > 0 必須
  - 工程コード 入力不可
- `外注(SUBCON)`
  - 仕入先コード 必須
  - 時間単位=日 必須
  - LT(日) > 0 必須
  - 工程コードが空欄なら `G` に自動補完
  - ラインコードは必須ではありません

#### 取込前チェックで確認されること
- 完成品/親品番/子品番の製品マスタ照合
- 区分別必須項目の不足
- 数量や時間値の不正
- 工程/ライン/仕入先コードのマスタ照合
- 既存BOMとの重複

## 4. ルーティング作成

### ルーティング作成を行う前に
- MAKE明細には工程・ライン・時間情報が入っていること
- BUY/SUBCON明細には仕入先とリードタイム(日)が入っていること
- 明細の並び順が工程順になっていること

### ルーティング作成手順
1. `詳細` ダイアログで対象BOMを開く
2. 必要に応じて `最終工程` を指定する
3. `BOMからルーティング生成` を押す

### ルーティング作成のポイント
- 既存のルーティングステップは削除され、再生成されます。
- 子BOM→親BOMの順で深さ優先に展開されます。
- BUY品は仕入先ごとに `supplier_code` と同じ `line_code` の購買ライン（`line_type='PURCHASE'`）と `PURCHASE` 工程を使用します。
- 最終工程を指定した場合は最後に1ステップ追加されます。
- 生成後、当該製品の既定ルーティングが自動で切り替わります。
- future版BOMからルーティング生成するときは、`有効開始日時` を切替日の `08:00` に合わせてください。

## 5. Q&A

### Q1. 画面作成と取込作成はどちらを使えばいいですか？
A. 少量登録や修正なら `画面作成`、まとまった件数を登録するなら `取込作成` が向いています。

### Q2. 1つのBOMに孫部品までまとめて直接入れていいですか？
A. できません。1つのBOMには `親製品と直下の子部品` だけを登録します。孫部品は子部品を親にした別BOMで作成します。

### Q3. 取込でエラーになるときは何を見ればいいですか？
A. まず `取込前チェック` を実行してください。未登録品番、必須項目漏れ、コード不一致、重複BOMを先に確認できます。

### Q4. 外注品は工程やラインを手入力する必要がありますか？
A. 取込時は工程コードが空なら `G` が自動補完されます。画面作成時は外注工程が自動設定され、仕入先に応じてラインが自動設定される場合があります。

### Q5. BOM変更後にルーティングを作り直したら終わりですか？
A. 製造ライン・工程が変わった場合は、旧ラインに残った在庫を新ラインへ移行する作業が必要です。  
→ [ルーティング変更後の在庫移行](ルーティング変更後の在庫移行.md)

### Q6. `BOMをコピー` と `別バージョン作成` の違いは何ですか？
A. `BOMをコピー` は別の親製品へ複製する機能です。`別バージョン作成` は同じ親製品のまま、版と有効開始日を変えた新BOMを作る機能です。
