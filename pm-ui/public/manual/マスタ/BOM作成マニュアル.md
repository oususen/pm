# BOM作成マニュアル

BOMマスタ画面で製品構成を登録し、前工程需要計算・購買需要計算・在庫計算・ルーティング自動生成の基礎データを整備する手順をまとめます。

## 目的
- 親製品1個あたりの使用部品（数量・調達区分・リードタイム・加工情報）を定義する
- 親子BOMをもとに需要展開・在庫計算を行える状態にする
- 社内制作/外作/購入の工程情報からルーティングを自動生成できるようにする

## BOMの基本構造
**1つのBOMは「親製品」と「直下の子部品」の親子関係のみで構成されます。**

- BOM作成時は、親製品に対してその直下の子部品だけを登録する
- 子部品が集合品（ASSEMBLY）の場合、その子部品を親とする別のBOMを作成する
- 個々の親子BOMが連鎖することで、結果として多階層の構成（親→子→孫…）になる
- システムが親子関係をたどって最下層まで自動展開し、構成部品表として利用する

例：製品Aの構成が A → B → C の場合
1. BOM①: 親=A、子=B を登録
2. BOM②: 親=B、子=C を登録
3. システムがA→B→Cと展開



## 前提
- 製品マスタが登録済み（親・子とも）。連産品の場合は親に「仮想セット品番」を設定しておく。連産品概念は下記参照
- 必要に応じて工程マスタ・ラインマスタ・仕入先マスタを登録しておく。
- 同一親製品では `parent_product × version × valid_from` が一意。改版は「版」または「有効開始日」を変えて新規登録する。
- 循環BOMは設定しない（階層取得時に循環検出エラーになります）。
  
## 連産品の扱い
- 連産品は同一工程で複数の実品が同時に得られる品番です。BOMでは在庫を持たない「仮想セット品番」を親として作成し、そこで必要部材・工程を管理します。
- 連産品を他のBOMの子として登録してはいけません（子登録禁止）。
- 連産品の実品（連産品の子）はほかの製品の子としてBOMを作成する。
- 連産品の製品番号に規律：ST完成品番号-工程コード
  例：タンクライン完成品YD40002386サブ―工程(工程コード4021)で　一サイクル加工するとYD40002386-10SUB,YD40002386-28SUB,YD40002386-10SUB　それぞれ１個ずつ生産される。
  その三種類の製品を子として擬似の親製品を連産品とする。その連産品の番号は
  STYD40002386-4021

## 事前準備（Excel下地作業）
写真のテンプレート（構成部品表）を前提に、アプリ登録前の整備手順をまとめます。CSVもこの形で最新化されています。



### テンプレート構造
- **ヘッダ部（上段）**  
  - 客先／品番／品名：案件情報の控え。  
  - 版／改訂日：アプリの「版」「有効開始日/終了日」と整合させる。  
  - 右側にデフォルトのカテゴリ・管理区分・工程・ライン・仕入先表は本番bom表の選択肢
- **階層グリッド**（確認用）作成しなくていい
  - 「階 層」見出しの下に 1〜7 列のインデント枠（灰色）。複数のBOMを展開した結果の全体構成を確認するための表示。
  - 実際のBOM登録は親子単位で行う。この階層グリッドは登録後の確認や、既存構成の把握に使用する。
- **明細列（写真の列順・CSVの列順と同じ）**  
  1. 構成部品品番  
  2. 構成部品品名  
  3. カテゴリ（例: 購入品 / 集合 / 単品 / 材料）  
  4. 数量（整数）  
  5. 工程  
  6. 工程コード  
  7. ライン  
  8. ラインコード  
  9. 仕入れ先  
  10. 仕入先コード  
  11. 管理区分（分=MINUTE / 日=DAY）  
  12. LT（日）  
  13. サイクルタイム（分）  
  14. ✓確認（チェック欄）

### 入力ルール（列の意味とアプリ対応）
- カテゴリ → 製品マスタの `category`。購入品は `PURCHASED`、集合は `ASSEMBLY`。  
- 数量 → 親1個あたり使用数（整数のみ）。  
- 工程/工程コード → BOM明細 `process`。MAKE/SUBCONでは必須。  
- ライン/ラインコード → BOM明細 `line`。MAKE/SUBCONでは必須。  
- 仕入れ先/仕入先コード → BOM明細 `supplier`。BUYでは必須、SUBCONは必須。  
- 管理区分 → `time_unit`（分=MINUTE、日=DAY）。  
- LT → `lead_time_days`。time_unit=DAY のとき必須。BUYは必須。  
- サイクルタイム → `duration_min`。time_unit=MINUTE のとき必須。  
- ✓確認 → 登録漏れ防止チェック（必須項目が埋まったらチェック）。

### 調達区分の決め方（カテゴリとセットで考える）
- 購入品 → `sourcing_type=BUY`。工程/ラインは空、仕入先とLT（日）を必須入力。  
- 自社製造 → `sourcing_type=MAKE`。工程必須。管理区分=分ならサイクルタイム必須、=日ならLT必須。仕入先は空。  
- 外注品 → `sourcing_type=SUBCON`。工程必須（外注工程）。管理区分に応じてサイクルタイム or LT 必須。仕入先は必須、入力規則は購入品と同じ。

### 下地作業チェックリスト
- 階層のインデントが意図どおりか（親より左に子が来ていないか／循環になっていないか）。
- 数量が1以上の整数か。
- 工程・ライン・仕入先のコードがマスタと一致しているか（typo防止）。
- BUY品に仕入先とLT（日）が入っているか。
- MAKE/SUBCONで time_unit に応じた必須項目（サイクルタイム or LT）が入っているか。

### アプリ登録の手順（Excelを見ながら）
1. **1つのBOMにつき、親製品とその直下の子部品のみを登録する。**
2. 子部品が集合品の場合は、その子部品を親とする別のBOMを新規作成し、さらにその子部品を登録する。
3. 明細の並び＝明細ID順＝ルーティング生成時の工程順になるため、工程順に並べてから入力する。
4. 入力後に「階層図」で全体構成と数量を確認。ずれがあればExcelを直して再入力する。
5. BUY品の仕入先漏れがあると「BOMからルーティング生成」でエラーになるので、✓確認列で再チェックする。

## 画面の見方（BOMマスタ）
- 左の一覧でBOMを検索・選択し、右の「詳細」ダイアログでヘッダと明細を編集します。  
- 「階層図」タブでインデント（階層）と数量を確認できます。  
- 「逆展開」で選択した子部品をどの親が使っているかを一覧できます。  
- 「Excel出力」で階層図をCSVとしてダウンロードできます。  
- 「BOMからルーティング生成」は明細の工程・仕入先・時間がそろっているときだけ実行してください。

## 操作手順（まとめ）
1. Excelで階層と必須項目を埋める（上記下地作業）。  
2. アプリでBOMヘッダを新規作成（親製品・版・期間・有効）。  
3. 明細を上から順に追加（数量・調達区分・工程/仕入先・時間）。  
4. 「階層図」で階層と数量を確認。  
5. 必要なら「ルーティング自動生成」を実行し、工程ステップを作る。  
6. 逆展開で親子関係を確認し、計画・在庫画面で動作を確認。

## 操作のポイント
- 明細は工程順（後から並べ替えできない）。Excelの順序どおりに入力する。  
- time_unit=MINUTE は duration_min 必須、time_unit=DAY は lead_time_days 必須。  
- BUY明細は仕入先が空だとルーティング生成でエラーになる。  
- 連産品BOMは親を仮想セット品番にし、子に実品をぶら下げる。  
- 版を変えたい場合は「新規」で別版を作成（既存は無効化も可）。

## 注意点
- 循環BOMは禁止（ツリー取得時にエラー）。  
- 数量は整数のみ。端数が必要なら単位や工程設計を見直す。  
- 有効期間が重なる複数版があると展開結果が不定になるので期間を分ける。  
- BUY/SUBCONで仕入先マスタ未登録のコードを入れると保存に失敗する。

## 画面への行き方
1. グローバルナビ「マスタメンテ」を開く  
2. 「構成マスタ（BOM）」を選択

## 画面構成と基本操作

### 検索フィルター
| 項目 | 説明 |
|---|---|
| 親製品（品番/品名） | 部分一致で検索 |
| 最終品 | 最終品だけ/それ以外/すべて |
| ライン最終品 | ライン最終品だけ/それ以外/すべて |
| 連産品 | 連産品BOMのみ/非連産/すべて |
| 版 | 版で絞り込み |
| 作成日 From/To | BOM作成日の範囲で絞り込み |
| 有効 | 有効/無効/すべて |

### 一覧の主な操作
- 「更新/検索」: 現在の条件で再取得
- 「リセット」: フィルターを初期化して再取得
- 「新規」: BOMヘッダを新規登録
- 「逆展開」: 指定した部品を使用している親製品を検索
- 行の操作: 「詳細」(ダイアログ) / 「別タブ」(詳細ページ表示) / 「階層図」(ツリー＋Excel出力) / 「編集」(ヘッダ編集) / 「削除」

## 登録フロー

### 1. BOMヘッダを登録（新規ダイアログ）
1. 「新規」を押す。
2. 必須項目を入力して「保存」を押す。

![BOM新規作成ダイアログ](スクリーンショット/bom_create.png)

| 項目 | 必須 | 説明・入力ルール |
|---|---|---|
| 親製品 | 必須 | 品番/品名で絞り込み可能。連産品BOMを作る場合は「仮想セット品番」の製品を選択。 |
| 連産品BOM | 任意 | 同一工程で複数製品を同時に生産する場合にチェック。作成後は変更不可。 |
| 版 | 必須 | 文字列。改版時は別の版名で新規登録。 |
| 有効開始日 | 必須 | BOMが適用され始める日。 |
| 有効終了日 | 任意 | 空欄なら無期限。 |
| 有効 | 任意 | 既定ON。無効にすると展開対象外。 |

> 編集モードでは「親製品」「連産品BOM」は変更できません。版や期間を変える場合は新規で登録してください。

### 2. BOM明細を登録/編集（詳細ダイアログ）
1. 一覧で対象行の「詳細」または「別タブ」を開く。
2. 「構成品目」フォームで子製品と必要項目を入力し、「明細を追加」を押す。既存行は「編集」→修正→「明細を更新」。
3. 「キャンセル」で編集中の内容を破棄、フォームを初期化。

![BOM明細ダイアログ](スクリーンショット/bom_create_詳細.png)

| 項目 | 必須 | 説明・入力ルール |
|---|---|---|
| 子製品 | 必須 | 品番/品名で絞り込み可能。 |
| 数量 | 必須 | 親1個あたりの使用数（整数のみ、1以上）。 |
| ロス率 | 任意 | 0以上、0.001刻み。歩留まり考慮が必要な場合に設定。 |
| 調達区分 | 必須 | 自社製造(MAKE) / 購買(BUY) / 外注(SUBCON)。選択に応じて必須項目が変わる。 |
| 仕入先 | 区分により | MAKEでは自動で空、BUYは必須、SUBCONは必須。 |
| 工程 | 区分により | MAKE/SUBCONで必須、BUYでは入力不可。 |
| ライン | 必須 | 区分によりMAKE/SUBCONで選択可、BUYでは入力不可。 |
| 時間単位 | 区分により | MAKE/SUBCONで選択可（分/日）。BUYは日固定。 |
| リードタイム(日) | 区分により | BUY必須、time_unit=DAYのMAKE/SUBCONも1以上必須。time_unit=MINUTEの場合は0可。 |
| 所要時間(分) | 区分により | time_unit=MINUTEかつMAKE/SUBCONで1以上必須。 |
| 備考 | 任意 | 200文字まで。 |

調達区分ごとの挙動
- **MAKE**: 仕入先は自動で空。時間単位の初期値は「分」、所要時間の初期値は60分。工程、ラインが必須。
- **BUY**: 工程・ラインは自動で空＆入力不可。時間単位は「日」に固定、リードタイム(日)が必須。仕入先が未設定だとルーティング自動生成に失敗します。
- **SUBCON**: 工程、ラインは必須。時間単位の初期値は「日」。time_unit=MINUTEなら所要時間必須、=DAYならリードタイム(日)必須。仕入先は任意だが設定推奨。

### 3. 階層確認とExcel出力
- 一覧の「階層図」ボタンでBOMツリーを表示。展開/折りたたみが可能。
- 「Excel出力」で階層図をUTF-8+BOM付きCSVとしてダウンロード（Excelで文字化けしない形式）。部番列には罫線記号で階層が表現されます。

### 4. 逆展開（Where Used）
- 画面右上「逆展開」を押し、部品を選択するとその部品を使う親製品一覧を表示。
- 「再帰的に最終製品まで辿る」にチェックすると上位階層まで表示。数量・調達区分・最終品フラグを確認できます。

### 5. ルーティング自動生成（任意）
1. 詳細ダイアログでBOMを開く。
2. MAKE/SUBCON明細には工程・時間情報、BUY明細には仕入先とリードタイム(日)が入っていることを確認。未入力があると生成エラーになります。
3. 必要に応じて「最終工程」を指定（工程/ライン/時間単位/所要時間orリードタイム）。
4. 「BOMからルーティング生成」を押す。

生成仕様のポイント
- 既存のルーティングステップは削除され、深さ優先（子BOM→親BOM、同階層は明細ID順）の順番でステップを再生成します。
- step_no は `(最大階層 - 現階層 + 1) × 1000` で付与され、並列グループは階層パス連結値。BOM明細の並び順が工程順になるよう並べてください。
- BUY品は仕入先ごとに仮想ライン `SUP-******` とPURCHASE工程を自動付与し、リードタイム(日)を使用します。
- 最終工程を指定した場合は最後に1ステップ追加されます。
- 生成後、当該製品の既定ルーティングが自動で切り替わります（is_default=true）。

## 運用上の注意
- 有効期間と有効フラグで適用可否を制御します。改版時は版と開始日を分けて履歴を残す運用を推奨。
- 数量は整数入力のみ。小数が必要な場合は単位や工程設計を見直してください。
- 連産品は親を仮想セット品番にし、子に実品をぶら下げます。親は在庫を持たない点に注意。
- 循環参照を避けて構成を組んでください（ツリー取得時に検出されます）。
