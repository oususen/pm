# ルーティング変更後の在庫移行

BOM変更に伴いルーティングを作り直した際、旧ラインに残った在庫を新ラインへ移行する操作手順です。

## この操作が必要なケース

- 品番の製造ライン・工程が変わった（BOM変更）
- 旧ルーティングを削除し、新BOMから新ルーティングを再生成した
- 旧ラインに在庫が残っている

## 画面への行き方

1. グローバルナビの「マスタ管理」を開く
2. 「ルーティングマスタ」を選択

## 操作手順

### Step 1：ライン選択

画面右上のヘッダーに **「ライン選択（在庫移行用）」** セレクタがあります。

新ルーティングが属するライン（移行**先**のライン）を選択してください。

> 例: BOM変更でタンクラインへ移行する場合 → `L2200 - タンクライン` を選択

### Step 2：在庫移行ボタンをクリック

**「ルーティング変更後の在庫移行」** ボタンをクリックします。

- 孤立在庫が検出された場合 → 移行確認ダイアログが表示されます
- 孤立在庫がない場合 → 「移行対象なし」と表示されます（操作完了）

### Step 3：移行内容を確認

ダイアログに移行候補の一覧が表示されます。

| 項目 | 説明 |
| --- | --- |
| 移行（チェックボックス） | 移行する品番を選択（デフォルト全チェック） |
| 品番 / 品名 | 対象品番 |
| 旧ライン / 旧工程 | 在庫が残っている移行元 |
| 新ライン / 新工程 | 新ルーティングによる移行先 |
| 現在在庫 | 旧ラインの現在在庫数 |
| 移行数量 | 移行する数量（変更可能） |

**移行基準日** を確認してください（通常は本日日付のままで問題ありません）。

### Step 4：移行実行

**「移行実行」** ボタンをクリックします。

「在庫移行が完了しました。○件」と表示されれば完了です。

### Step 5：在庫計算を実行

移行はadjust_qty（調整数）への加算で行われるため、**在庫計算を実行するまで生産計画画面に反映されません**。

1. 生産計画入力画面を開く
2. 対象ラインを選択
3. **「取込＋在庫計算」** を実行

## 確認方法

在庫計算実行後、以下を確認してください：

- **旧ライン**（例: L2200）：移行した品番の在庫が 0 になっている
- **新ライン**（例: L2201）：移行した品番の在庫が引き継がれている

## 注意事項

- **実績（actual_qty）は移行しません**。旧ラインの過去実績はそのまま残ります
- **二重移行に注意**：同じ品番を複数回実行すると在庫が二重に移行されます。一度だけ実行してください
- 移行履歴は管理者がDBで確認できます（テーブル: `production_routing_migration_log`）

## 全体の作業フロー

1. **BOM変更**（BOMMaster）
2. **旧ルーティング削除**（Django管理画面）
3. **新ルーティング自動生成**（BOMMaster）
4. **在庫移行**（ルーティングマスタ画面）← このページの操作
5. **取込＋在庫計算**（生産計画入力画面）
