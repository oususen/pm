# カレンダ一覧（運用まとめ）

本システムで扱うカレンダの種類と役割、参照先、フォールバック順を一枚で把握できるようにまとめました。カレンダ未設定時の代替ロジックも併記しています。

## 用語
- **稼働カレンダ**: 稼働/休日と稼働分・勤務パターンを日単位で管理するマスタ。
- **勤務パターン**: 1日の稼働時間帯テンプレート。休憩枠を組み合わせて使う。
- **ライン勤務カレンダ**: ラインが参照する稼働カレンダ（割当）。

## 種類と利用箇所

| 区分/用途 | 主データ | 参照・操作 | 主な利用 | 代替/注意 |
|---|---|---|---|---|
| 稼働カレンダ（共通ヘッダ） | `m_calendar` | API: `/api/calendars` / 画面: カレンダマスタ | 基準カレンダのコード・名称管理 | ― |
| カレンダ日 | `m_calendar_day` | API: `/api/calendar-days` / 画面: カレンダマスタ日一覧 | 稼働/休日、`work_minutes`、`work_pattern_id` による日別稼働枠 | 日跨ぎ計算の根拠 |
| 勤務パターン／休憩 | `m_work_pattern` ＋ `m_break_time` | モデル: `masters.models` / 登録は管理画面想定 | 日内の稼働セグメントを生成 | カレンダ日に紐付けて有効化 |
| ライン勤務カレンダ割当 | `m_line.calendar` | 画面: 「生産管理＞ライン勤務カレンダ」 | 生産計画逆算、在庫・進捗計算、仕損 `plan_date` 算出 | 無ければ `daiso` → 週末判定 → 暦日 |
| 顧客カレンダ | `m_customer.calendar` | 出荷サービス、受注ユーティリティ | 出荷日・納期の営業日換算 | 無ければ週末判定（月〜金稼働） |
| デフォルト稼働カレンダ | `calendar_code='daiso'` | ラインにカレンダがない場合に使用（スケジューリング/在庫系） | カレンダ未割当ライン・需要計算の既定 | 無ければ週末判定へ |
| 週末判定代替 | ロジック（土日非稼働） | `calendar_utils` | カレンダ未設定時の簡易営業日判定 | さらに無ければ暦日 |
| 暦日扱い | 代替 | 各計算の最終フォールバック | 休日考慮なしの連続日数計算 | ― |
| 8:00日替わり | `get_business_today/yesterday` | `apps/orders/utils/calendar_utils.py` | “今日/昨日”の判定基準（夜勤跨ぎ対応） | 全機能共通ルール |

## 関連画面・仕様
- カレンダマスタ: `pm-ui/src/views/masters/CalendarMaster.vue`（稼働カレンダとカレンダ日）
- ライン勤務カレンダ: `pm-ui/src/views/production/LineCalendar.vue`（ラインへの割当・日別切替）
- スケジューリング詳細: `仕様書/scheduling_logic_v3.md`
- 受注系営業日ユーティリティ: `pm_backend/apps/orders/utils/calendar_utils.py`

## フォールバック順（まとめ）
1. ライン/顧客などに割当カレンダがある場合はそれを使用  
2. 無い場合はデフォルト `daiso`  
3. さらに無い場合は週末判定（月〜金稼働）  
4. それも無い場合は暦日扱い（休日考慮なし）

## メモ
- 仕損登録や実績系では「8:00日替わり」ルールを踏まえて `plan_date` を決定。
- 勤務パターンと休憩を組み合わせることで、夜勤や変則シフトの稼働時間帯を柔軟に表現できます。
