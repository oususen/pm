# AI分析の使い方

AI画面（上のメニュー「AI」）の **「分析」タブ**の使い方です。目的を決めると、AIが分析の手順と、集計のためのSQL・Pythonを作ります。利用者が、内容を確認・承認してから、実行します。結果は、表・グラフで見ます。

> **現在の提供範囲**: 分析の実行（SQL試行・実行・結果）は、**開発環境だけ**で確認できています。**本番では、分析の実行基盤が、まだ使えません**（準備中）。そのため、SQL試行を含む、コード承認・実行までの流れは、本番では完了できません。分析案の作成・コード表示・履歴・テンプレートなどが、本番で正常に動くかは、確認中です。

AIは、数値を知らず、数値を作りません。生成されたコードが、検査・試行に合格しても、**分析結果が正しいとは限りません**。結果は、元の画面や、DBの集計と照らして、確認してください。

---

## 使うために必要な権限

| できること | 必要な権限 |
|---|---|
| 分析タブを見る、履歴・テンプレートの一覧を見る | 「AI分析」の表示権限 |
| 分析案の作成・承認・コード生成・実行、テンプレートの保存・再利用 | 「AI分析」の編集権限 |
| テンプレートの承認・却下、全員の履歴の閲覧 | システム管理者（設定「AI」の編集権限） |

表示権限だけの場合は、「閲覧のみです」と表示され、操作できません。

## 分析の進め方（右側の「分析の進め方」の6段階）

画面の右側に、①〜⑥の段階が並びます。今の段階には「今」、終わった段階には「済」が付きます。

| 段階 | 内容 |
|---|---|
| ① 分析目的 | 何を調べたいかを入力し、期間を選び、分析案を作る |
| ② 目的・手順 | AIが作った手順・出力案を読み、**「分析案・手順を承認」** |
| ③ 必要なデータ範囲 | 使うビュー・列・期間を確認し、**「対象件数を確認」** → **「データ範囲を承認」**（日付のないビュー(品番マスタ)は、件数確認の後に**「期間: 適用しない（全行）」**と出て、期間で絞らず全行が対象になります） |
| ④ SQL・Python | AIが作った**SQLとPython**を読む |
| ⑤ 試行・コード承認 | **「SQLを試行（実データなし）」** → **「確認したSQL・Pythonを承認」** |
| ⑥ 実行 | 左の「分析の実行・結果」の欄で、**「分析を実行」**（開発環境だけ）。表・グラフを見る。右の⑥は、「左で実行してください」という案内です |

承認は、**段階ごとに、毎回**行います。前の分析の承認は、引き継がれません。

### ① 分析目的を入力する

1. 上の「AIプロバイダ」と「モデル」を選びます（有料のモデルを選ぶと、確認が出ます）。
2. **目的**を入力します。例:「8月の出荷数量を、日ごとに集計して、推移を折れ線グラフにして」
3. **開始日・終了日**を選びます。目的の月と期間が、食い違うと、警告が出ます（後述）。
4. 目的を書きにくいときは、**「AIと目的を整える」**を開き、AIと相談します。AIの文案は、**「目的欄・期間欄に取り込む」**で、入力欄へ入ります（上書きの確認が出ます）。
5. 社外のAI（OpenRouter・DeepSeek）を選んでいるときは、先に、**「社外送信する目的文を確認」**を押します。**置換後の目的文**が出るので、内容を確認し、チェックを入れます。
6. **「確認した内容を社外AIへ送って分析案を作成」**を押します。ローカルのAIの場合は、**「分析案を作成」**です。

**社外のAIへ送るもの**: 目的文、期間、公開ビューの説明です。社員・顧客・仕入先などの登録名称は、**コードへ置換**されます。DBの明細行・数値は、送りません。**登録されていない人名・社名や、機密は、置換されません**。また、置換されるのは、登録名称とメールアドレスだけで、**電話番号の形などの数字の羅列は、置換されません**。目的文に、書かないでください。

### ④ SQL・Pythonを確認する

- 社外のAIの場合、**「コード生成で社外送信する全文を確認」**を押し、送る文面の全体を確認してから、**「確認した全文を社外AIへ送ってコードを生成」**を押します。再生成のたびに、確認が必要です。
- 生成できる回数には、上限があります（失敗も、回数に数えます）。
- 画面に、生成された**SQL**と**Python**が出ます。読んで、目的に合っているか、確認します。
- 変数（期間・品番など）が使われているときは、「変数」の欄に、その値が出ます。
- 目的・手順に書かれた品番などが、変数にされず、コードに直接書かれているときは、**警告**が出ます（再利用で、その値を変えられません）。

### ⑤⑥ 試行・承認・実行

- **「SQLを試行（実データなし）」**は、空のテーブルで、SQLの構文などを確認するだけです。実データでの成功や、分析の正しさは、保証しません。
- 承認すると、**「分析を実行」**ができます（開発環境だけ）。実行中は、**「実行を中止」**もできます。
- 結果は、表とグラフで出ます。**取得行数は、数量の合計ではありません**。結果は、DBの値と照合してください。
- 結果の下の**「改良して新しい分析案を作る」**で、追加の指示（例:「品番も付けて」）を足して、新しい分析案を作れます。この場合も、承認は、取り直します。

### 作り直す

**「目的・期間を変更して作り直す」**で、①に戻ります。参考にしたテンプレートがあるときは、同じテンプレートを参考にしたまま、戻ります（外すときは、**「参考を外す」**）。

## 警告の見方（赤字・点滅の「⚠！」）

分析案の作成のときや、コード生成のときに、**赤字・太字で、「⚠！」が点滅**する警告が出ることがあります。警告が出ても、**承認は、止まりません**。内容を読んで、必要なら、**「目的・期間を変更して作り直す」**を押して、目的を書き直します。警告の文の最後に、「次の操作」が書かれています。

| 警告 | 意味 |
|---|---|
| 目的に書かれた月より、期間が広い／目的の月が期間に含まれていない | 目的の「8月」と、期間欄（例: 7/31〜9/30）が合っていません。期間を直します |
| 除く期間の開始日（終了日）が書かれていません | 「7月31日までを除く」のように、片側だけが書かれています。「6月30日から7月31日までを除く」のように、両側を書きます |
| 目的の言葉と、取得する列の食い違い（納入場と顧客など） | 目的の言葉に合う列を使っているか、手順を読んで確認します |
| 目的・手順に書かれた値が、コードに直接書かれています | 品番などが、変数ではなく、固定で書かれています。この分析だけなら実行できますが、テンプレートにして、再利用で品番を変えられません。変えたいときは、再生成します |
| 変数 〇〇: （入力の表記）を、マスタの表記 （マスタの表記）に直しました | 目的に書かれた品番などの大文字・小文字が、マスタの表記と違っていたため、**マスタの表記**に直してコードに入れました（例: `v053904703` → `V053904703`）。直したあとの値で実行されます。操作は、不要です。マスタにない値は、直さずに、拒否されます |
| 参考のテンプレートにある値が、分析案の手順・出力案に入っています | 参考にしたテンプレートの、古い品番や日付が、今回の分析案に入っています。今回の目的の値になっているか、確認します |
| 同じ名前のテンプレートが、ほかにあります | テンプレートの保存のとき。区別しやすい名前にします（そのまま保存もできます） |

## 外枠が古い、という表示

④のコードの欄に、「**保存済みコードの外枠が古くなっています**」という赤字の案内が出ることがあります。システムの安全の枠が、更新されたためです。**「保存済みコードの外枠を更新（AI生成回数は消費しません）」**を押し、そのあと、試行・承認を、やり直します。AIは呼ばれず、生成回数も消費されません。

## テンプレート

分析案を、**テンプレート**として保存すると、あとで、同じ分析を、別の月・品番で、やり直せます。画面の下の**「▶ テンプレート管理」**の欄を開きます（最初は閉じています）。

- 保存できる状態（コードを承認した後）になると、欄が、自動で開きます。閉じているときは、見出しに、「保存できます」と出ます。
- 管理者には、見出しに、**「承認待ち n 件」**が出ます。

### テンプレートを保存する

1. コードを承認した後、**テンプレート名**（必須・300文字以内。初めは、AIが付けた題名）を確認・変更します。
2. **カテゴリ**（入荷・出荷・在庫・生産・品質・その他）を選びます。
3. 「コード確認済み・管理者承認待ちとして保存する」にチェックを入れ、**「テンプレートとして保存」**を押します。

保存するのは、名称・目的・手順・条件・承認済みのSQL・Python・期間・ハッシュだけです（実データ・結果・AIへ送った本文は、保存しません）。保存すると、**管理者承認待ち**になり、**作成者と管理者以外には、名称・目的・状態・カテゴリだけが表示されます**。システム管理者が、承認すると、「正式」になり、分析権限のある全員が使えます。

### 保存済みテンプレートの表

| 列 | 内容 |
|---|---|
| ID・カテゴリ | テンプレートの番号と、分類 |
| テンプレート名・目的 | 1行に省略して表示します（全文は、マウスを載せるか、「詳細」で見ます） |
| 状態 | 正式（緑）・管理者承認待ち（黄）・却下（赤）・置換済み（灰）。承認待ちの行は、背景が薄い黄色です |
| 作成者・保存日時 | 保存した人と、保存した日時 |
| 操作 | **詳細**／**分析案を作る**／**参考に分析する** |

上のカテゴリの絞り込み、「一覧を更新」、ページ送り（30件ずつ）が使えます。**状態の絞り込みは、管理者だけ**に表示されます。

### 「詳細」で、できること

- 目的・期間・条件・手順・SQL・Python・確認の情報（確認者・日時・却下理由）を見る。**全文を見られる人**は、状態によって違います。**正式**のテンプレートは、分析権限のある全員です。**管理者承認待ち・却下・置換済み**は、作成者と管理者だけです（ほかの人には、名称・目的・状態・カテゴリだけが表示されます）。
- 変数の入力は、「詳細」ではなく、**「分析案を作る」**を押したときに出る入力欄で行います。
- **名称の変更**（作成者と管理者。**管理者承認前だけ**）。承認後は、変更できません。
- **カテゴリの変更**（作成者と管理者）。
- 管理者は、**承認・却下**（却下は理由が必須）。

### 方法1: このテンプレートで分析案を作る（そのまま再利用）

保存済みのSQL・Pythonを、**そのまま**使います。**AIは使いません**。

- 変数（期間・品番など）があるテンプレートは、**入力欄**が出ます。値を変えて、**「この値で分析案を作成」**を押します。変えた値だけが、送られます。
- 空にした値は、受け付けられません（保存済みの値には、戻りません）。
- **全体の期間**は、元の期間の外にも変えられます。ただし、比べる期間・除く期間は、**自動では動きません**。一緒に直します。
- 目的・手順の説明は、**保存したときのまま**です（日付・品番を変えても、説明の文は、書き換わりません）。
- 作った分析案は、手順・データ範囲・試行・コード承認を、**取り直し**ます。

### 方法2: このテンプレートを参考に分析する（AIが新しく作る）

テンプレートを、**参考**にして、AIが、**今回の目的に合わせた、新しい分析案とコード**を作ります。

1. テンプレート一覧の**「参考に分析する」**、または、相談画面の「近い承認済みテンプレート」の**「このテンプレートを参考に分析する」**を押します。
2. 目的の入力の近くに、**「参考にするテンプレート」**が出ます。**今回の目的と期間を入力**します（参考の品番・日付は、**参考の値**です。今回の値を、目的に、はっきり書きます）。
3. **「社外送信する目的文を確認」**を押すと、**置換後の参考の全文**も、一緒に表示されます。確認して、分析案を作ります。
4. 以降は、通常の分析と同じ（承認は、取り直し）。コードの生成のときも、参考のコードが、送られます（全文を確認します）。

注意:
- **社外のAIだけ**で使えます。**ローカルのAIでは、使えません**。
- 管理者承認前のテンプレートを参考にしたときは、「管理者承認前のテンプレートを参考にしています」と、赤字・点滅で出ます。
- 参考のテンプレートの**コードの本文も、社外のAIへ送られます**（登録名称は置換されます。電話番号の形などの数字の羅列は、置換されません）。個人情報が含まれていないか、送信前の全文で確認してください。登録名称を置換できないときは、送られず、止まります。
- 参考を外すには、**「参考を外す」**を押します。
- 「追加の指示」（結果の改良）と、併用できます。
- 実行中は、参考の選択ができません。

## 実行履歴

「実行履歴」の**「履歴を取得」**で、過去の実行の一覧が出ます。コード・結果・明細の本文は、保存されません（保持期間を過ぎた結果は、再表示できません）。管理者は、**「全利用者の履歴」**を選べます。

## よくある質問

**Q. 同じ目的でも、AIが作るコードが、毎回、違います。**
AIは、同じ入力でも、答えが変わることがあります。承認の前に、手順とコードを、必ず、読みます。結果は、DBの値と、照らします。

**Q. 「専用ワーカーを再起動してください」と出ました。**
開発環境で、サーバーのコードが更新されたため、古い版の実行用の部品が、拒否されています。開発の担当者が、再起動します。

**Q. 生成の回数の上限に達しました。**
失敗した生成も、回数に数えます。分析案を、作り直してください。

**Q. 社外のAIへ、何が送られますか。**
段階ごとに、確認のしかたが違います。DBの明細行・数値は、どの段階でも、送られません。

| 段階 | 送られるもの | 確認 |
|---|---|---|
| AIとの相談 | あなたの発言、AIの過去の返事、承認済みテンプレートの名称と目的、公開ビューの説明、今日の日付（置換後） | 先に、**送ることを了承するチェック**を入れます。送った内容（置換後）は、各発言の下に、**送信の後に**表示されます |
| 分析案の作成 | 目的文、期間、（参考にしたときは）参考のテンプレートの内容（置換後）。実際には、AIへの**固定の指示と、公開ビューの説明**も、一緒に送られます | 送信前に、**置換後の目的文・期間・参考の内容**を確認して、チェックを入れます（固定の指示と、公開ビューの説明は、この確認の画面には出ません） |
| コード生成 | 承認した分析案、公開ビューの名前・列・説明、期間、参考のテンプレートのコード、実行環境の制約 | 送信前に、**送る文面の全文**（置換後）を確認します |
