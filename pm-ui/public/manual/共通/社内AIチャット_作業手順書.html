⚙ 前提条件

  • AIチャットの権限があること — 権限がない場合、Q&Aメニューには「リクエスト」「リクエスト履歴」だけが表示されます
  • AIは読み取り専用です。データの登録・更新・削除や、計画の入力などの操作はできません
  • 質問したい画面を開いてからAIを開くと、その画面を起点にして回答します

2
質問を送る
① 使うAIを選びます。モデルの選び方は、下の「モデルの選び方」を参照してください。現時点では、ローカルQwenは使えません。
② 入力欄に質問を書き、Enterキーまたは「↑」ボタンで送信します。改行したい場合は Shift+Enter を使います。
③ 回答を待ちます。待っている間、送信ボタンは「■」（中止）に変わります。

▶ モデルの選び方

パネルのヘッダにある2つの選択欄で、「AI（プロバイダ）」と「モデル」を選びます。表示される選択肢は、AI設定で有効になっているものだけです。最初に選ばれているのはOpenRouter ／ Gemma 4 26B A4B（有料・要クレジット）で、OpenRouterのモデルは3つから選べます。迷ったときは、最初に選ばれているままで使ってください。
OpenRouter ／ Qwen3.8 27B（無料枠）無料枠のモデルのため、レート制限がかかる場合が多いです。
OpenRouter ／ Gemma 4 26B A4B（無料枠）無料枠のモデルのため、レート制限がかかる場合が多いです。
OpenRouter ／ Gemma 4 26B A4B（有料・要クレジット）有料です。クレジットが必要です。最初に選ばれているモデルです。
DeepSeek API ／ DeepSeek V4 Pro（高精度）有料です。高精度のモデルです。
DeepSeek API ／ DeepSeek Flash（高速）有料です。高速のモデルです。
ローカルQwen現時点では使えません。
⚠DeepSeekと、OpenRouterの「Gemma 4 26B A4B（有料・要クレジット）」は有料です。選ぶと「DeepSeekは有料です。使いますか？」「このモデル（Gemma 4 26B A4B）は有料です。使いますか？」と確認が表示されます。「キャンセル」を押すと、選ぶ前の状態に戻ります。同じ画面を開いている間は、それぞれ1回承認すれば再確認されません。なお、最初に選ばれている有料モデルは、パネルを開いたときには確認が表示されません。
ⓘモデルを切り替えても、会話は続けられます。同じ質問で答えが変わったときは、別のモデルでも確認し、元の画面でも数字を確認してください。

4
資料の添付と音声入力

▶ 資料を添付して質問する

入力欄の「＋」を押して、資料を選びます。添付できるのは PDF・Excel（.xlsx / .xls）・CSV・TSV・画像（PNG / JPG / WEBP / BMP）です。添付した会話では、添付した資料だけを参照して回答します。添付を外す、または新しい会話にすると、元の動作に戻ります。

▶ 音声で入力する

入力欄の「🎤」を押して話し、もう一度押すと文字になって入力欄の末尾へ追加されます（最大60秒）。自動では送信されません。内容を確認してから送信してください。マイクの使用許可が必要です。
ⓘ音声の文字起こしは社内のPCで行います。音声や文字は外部へ送られず、保存もされません。

⚠ 6. 使うときの注意

  • 数字は元の画面で確認する: 重要な数字や判断に使う前に、必ず元の画面でも確認してください
  • 読み取り専用: AIはデータを登録・更新・削除できません。計画の入力などの操作もできません
  • 外部へ送る情報: 「OpenRouter」「DeepSeek API」を選ぶと、質問と、回答に必要な集計結果が外部のAIへ送られます。氏名・連絡先・明細は送られません。現時点ではローカルQwenは使えないため、外部へ送りたくない内容は質問しないでください
  • 古い発言は渡らない: 会話が長くなると、直近の発言だけがAIへ渡されます。「古い発言はAIへ渡していません」と表示されたら、新しい会話にしてください
  • 個人の評価には使わない: 個人の評価や順位付けに使ってはいけません
  • 個人別の残業: 閲覧権限がある人だけが照会できます。自分の残業は、権限がなくても自分の分に限って照会できます
  • 困ったとき: 不具合や要望は、右下の「Q&A」→「リクエスト」からシステム管理者へ送れます。送る前に、「リクエスト履歴」で同じ内容がないか確認してください（全員のリクエストが表示されます。依頼者・状態・キーワードで絞り込めます）
