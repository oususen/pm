# リクエスト

要望・不具合・問い合わせを、システム管理者へ送る機能です。送ったリクエストの状況は「リクエスト履歴」で確認できます。

[作業手順書（日本語）](リクエスト_作業手順書.html)

## 開き方

画面右下の丸い **「Q&A」** ボタンを押し、メニューから選びます。

| メニュー | 内容 |
|---|---|
| 1 AI | 社内AIチャットを開きます（AIの権限がある人のみ） |
| 2 リクエスト | リクエストを送ります |
| 3 リクエスト履歴 | 全員のリクエストを見ます |

AIの権限がない人は、「1 リクエスト」「2 リクエスト履歴」と表示されます。

---

## リクエストを送る

1. 送る前に、**「リクエスト履歴」で同じ内容がないか確認** します（下記）。
2. Q&Aメニューの **「リクエスト」** を開きます。
3. **種別** を選びます（要望／不具合／問い合わせ／その他）。
4. **件名＊** と **内容＊** を入力します（＊は必須です）。
5. 必要なら、ファイルを添付します。
6. **「送信」** を押します。「システム管理者へ送信しました。」と表示されれば完了です。

リクエスト画面とリクエスト履歴画面の右上（×の右）にある **「?」** を押すと、このマニュアルが別のタブで開きます。

### ファイルの添付

- **「ファイルを選択」** から選びます。
- 内容欄などで **Ctrl+V** を押すと、コピーした画面（スクリーンショット）を貼り付けて添付できます。
- 添付できるのは、最大5個、1ファイル10MBまで、合計20MBまでです。
- 対応形式: 画像（png / jpg / gif / webp）、Excel（xlsx / xlsm / xls）、Word（docx / doc）、PDF、CSV、テキスト（txt）。
- 添付ファイルは、システム管理者宛のメールにだけ添付されます。リクエスト履歴には表示されません。

---

## リクエスト履歴を見る

Q&Aメニューの **「リクエスト履歴」** を開くと、全員のリクエストが新しい順に表示されます。送る前の重複確認や、自分のリクエストの状況確認に使います。

- **絞り込み**: 依頼者、状態、キーワード（件名・内容）で探せます。
- 行をクリックすると、内容が開きます。
- 最新200件まで表示されます。古いものは、絞り込みで探してください。

### 状況の見方

| 状況 | 意味 |
|---|---|
| 未対応 | まだ対応が始まっていません |
| 対応中 | システム管理者が対応しています |
| 完了 | 対応が完了しました |
| 却下 | 対応しないことになりました |

- **却下** になった場合は、却下の理由が、登録されているメールアドレスへ届きます。
- 対応中・完了になったときは、メールは届きません。履歴で確認してください。
- 履歴には、却下の理由や、対応した人の名前は表示されません。

---

## 注意事項

- 件名・内容・依頼者名・状況は、**リクエスト履歴で全員に表示されます。** 個人情報は書かないでください。
- 送信したあとの取り消しや、内容の追記はできません。追加で伝えたいことは、新しいリクエストとして送ってください。
- 「システム管理者が設定されていません」と表示された場合は、システム管理者への連絡先が登録されていません。担当者へ直接連絡してください。
- メール送信に関するエラーが表示された場合は、添付ファイルを減らす、またはしばらくしてからもう一度送ってください。

---

## システム管理者向け

リクエストは、メールで届くと同時に、**タスク受信箱** にタスクとして表示されます（システム管理者のみ）。

1. 右上の **「タスク」** を開き、業務「リクエスト」の行で **「内容を見る」** を押します。
2. 内容を確認し、**状況** を選んで **「保存」** します。
3. **却下** にする場合は、**却下理由（必須）** を入力します。保存すると、依頼者へ返信メールが送られます。
4. 不要になったタスクは **「削除」** できます（元に戻せません。履歴からも消えます）。

詳しくは [タスク受信箱](タスク受信箱.md) を参照してください。
