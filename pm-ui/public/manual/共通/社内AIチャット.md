# 社内AIチャット

画面について質問すると、社内のデータに基づいて回答するAIチャットです。データの登録・更新・削除はできません（読み取り専用）。計画の入力などの操作もできません。

[作業手順書（日本語）](社内AIチャット_作業手順書.html)

## 開き方

- 画面右下の丸い **「Q&A」** ボタンを押し、メニューの **「1 AI」** を選びます。
- 画面上部のメニューの **「AI」** からは、全画面版のAIチャットを開けます。
- 全画面版は「検索」「分析」のタブ構成です。「AIフル画面とドロワー」権限で検索、「AI分析」権限で分析タブを表示します。ドロワーは検索専用のままです。
- 分析タブは現在準備中です。分析目的を入力できますが、データ取得・分析実行・保存はできません。入力はタブ切替時に保持し、画面を離れる・再読込する・利用者を切り替えると消えます。
- 検索タブの「分析する」は質問文と起点画面だけを分析タブへ渡します。回答・明細・会話履歴は渡しません。OCRには別の「OCR・文書読取」権限が必要です。
- AIチャットの権限がない場合、Q&Aメニューには **「リクエスト」「リクエスト履歴」** だけが表示されます。

AIは、開いた画面を **起点** にして回答します。ヘッダの「起点: 〇〇」で確認できます。

---

## 使い方

1. 使うAIとモデルを選びます（下の「モデルの選び方」を参照）。現時点では、ローカルQwenは使えません。
2. 入力欄に質問を書き、**Enter** または **「↑」** で送信します。改行は Shift+Enter です。
3. 回答を待ちます。待っている間、送信ボタンは **「■」**（中止）になります。

- 質問は **1200文字まで** です。超えると送信できません。
- 品番を指定すると、続く質問にも引き継がれます。
- まだ対応していない画面では、その旨のメッセージが表示されます。

### モデルの選び方

パネルのヘッダにある2つの選択欄で、「AI（プロバイダ）」と「モデル」を選びます。表示される選択肢は、AI設定で有効になっているものだけです。最初に選ばれているのは **OpenRouter ／ Gemma 4 26B A4B（有料・要クレジット）** で、OpenRouterのモデルは3つから選べます。迷ったときは、最初に選ばれているままで使ってください。

| AI ／ モデル | 内容 |
|---|---|
| OpenRouter ／ Qwen3.8 27B（無料枠） | 無料枠のモデルのため、レート制限がかかる場合が多いです |
| OpenRouter ／ Gemma 4 26B A4B（無料枠） | 無料枠のモデルのため、レート制限がかかる場合が多いです |
| OpenRouter ／ Gemma 4 26B A4B（有料・要クレジット） | 有料です。クレジットが必要です。**最初に選ばれているモデルです** |
| DeepSeek API ／ DeepSeek V4 Pro（高精度） | 有料です。高精度のモデルです |
| DeepSeek API ／ DeepSeek Flash（高速） | 有料です。高速のモデルです |
| ローカルQwen | 現時点では使えません |

- DeepSeekと、OpenRouterの「Gemma 4 26B A4B（有料・要クレジット）」は有料です。選ぶと「DeepSeekは有料です。使いますか？」「このモデル（Gemma 4 26B A4B）は有料です。使いますか？」と確認が表示されます。「キャンセル」を押すと、選ぶ前の状態に戻ります。同じ画面を開いている間は、それぞれ1回承認すれば再確認されません。
- 最初に選ばれている有料モデルは、パネルを開いたときには確認が表示されません。
- モデルを切り替えても、会話は続けられます。
- 同じ質問で答えが変わったときは、別のモデルでも確認し、元の画面でも数字を確認してください。

## 回答の使い方

| ボタン | 内容 |
|---|---|
| ⧉ コピー | 回答の文章をコピーします |
| ⇩ 回答の表をExcelでダウンロード | 「表で出して」「Excelにして」と頼んだときだけ表示されます。回答の表を .xlsx にして保存します（サーバーには保存されません） |
| ↻ 再送信 | エラー時・中止時に、直前の質問をもう一度送ります |

---

## 資料の添付・音声入力

- **「＋」**: 資料を添付して質問します。対応形式は PDF・Excel（.xlsx / .xls）・CSV・TSV・画像（PNG / JPG / WEBP / BMP）です。添付した会話では、添付した資料だけを参照して回答します。新しい会話にすると解除されます。
- **「🎤」**: 音声で入力します（最大60秒）。もう一度押すと文字になって入力欄へ追加されます。自動では送信されません。マイクの使用許可が必要です。音声は社内のPCで文字にし、外部へ送らず、保存もしません。

---

## 会話履歴・パネルの操作

| ボタン | 内容 |
|---|---|
| 🕘 | 自分の会話履歴を開きます。項目を押すと再開、「×」で削除します |
| ＋ | 新しい会話を始めます |
| › | パネルを右端に畳みます（右端のタブで開き直せます） |
| × | パネルを閉じます |
| ? | このマニュアルを別のタブで開きます |

パネルを開いたまま別の画面へ移動すると、起点の画面も切り替わります。それまでの会話は履歴から再開できます。

## 注意事項

- 重要な数字や判断に使う前に、必ず元の画面でも確認してください。
- 「OpenRouter」「DeepSeek API」を選ぶと、質問と回答に必要な集計結果が外部のAIへ送られます（氏名・連絡先・明細は送られません）。現時点ではローカルQwenは使えないため、外部へ送りたくない内容は質問しないでください。
- 会話が長くなると、直近の発言だけがAIへ渡されます。「古い発言はAIへ渡していません」と表示されたら、新しい会話にしてください。
- 個人の評価や順位付けには使わないでください。
- 個人別の残業は、閲覧権限がある人だけが照会できます。自分の残業は、権限がなくても自分の分に限って照会できます。
- 不具合や要望は、右下の「Q&A」→「リクエスト」からシステム管理者へ送れます。送る前に、「リクエスト履歴」で同じ内容がないか確認してください（全員のリクエストが表示されます。依頼者・状態・キーワードで絞り込めます）。
