# 棚卸レイアウト編集

棚卸現物入力で使う置き場マップを、PCで作成・編集する画面です。

[詳しい作業手順書はこちら](/manual/在庫/棚卸レイアウト編集_作業手順書.html)

## 画面への行き方

1. 上のグローバルナビゲーションの「在庫」を開く
2. 「棚卸レイアウト編集」を選択

## 何に使う画面か

- 棚卸エリアごとに置き場のマップを作成します
- 棚や設備をグリッド上に配置します
- スマホの「棚卸現物入力」画面で、進捗確認と置き場タップ移動に使われます

## 基本の流れ

1. 必要なら右上のエリア選択で対象エリアを選びます
2. 左側の「置き場」または「設備」から配置したい項目を選びます
3. グリッドの配置先をクリックしてマップに置きます
4. サイズや色を変えたい場合は、配置済みセルをクリックして編集します
5. 「保存」を押して確定します

## 補足

- エリアを選んで保存した場合、そのレイアウト内で使った置き場はエリア所属置き場にも自動反映されます
- スマホの「棚卸現物入力」では、このレイアウトを使って進捗確認できます
