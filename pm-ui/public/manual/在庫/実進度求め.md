# 実進度求め

対象部品の在庫と、完成品の需要窓（明日〜完成品別累積LT）を使って実進度を確認する画面です。

実進度は以下で計算します。

- 実進度 = 全状態在庫合計（部品換算） - 完成品別需要窓合計

## 画面への行き方

1. 上のグローバルナビゲーションの「在庫」を開く
2. 「在庫管理メニュー」→「実進度求め」を選択

## 使い方

1. 「品番」に対象部品コードを入力して「検索」を押します。
2. 「対象部品を反映」を押します。
3. 必要に応じて「基準日（棚卸日）」を変更し、再度「対象部品を反映」を押します。
4. 「完成品設定（累積LT）」「在庫（部品換算）」「需要（完成品別・日別）」を確認します。
5. 棚卸リストが必要な場合は、「在庫（部品換算）」の `Excel出力` で関連品一覧を出力します。
   出力ファイルには `棚卸在庫` 列があり、棚卸実数を記入できます。

## 画面の見方

### 設定

- 全状態在庫合計: 部品換算後の在庫合計
- 完成品別需要窓合計: 各完成品の需要窓に入る需要数量の合計
- 実進度: `全状態在庫合計 - 完成品別需要窓合計`

### 完成品設定（累積LT）

- 完成品ごとに累積LT(日)を表示します。
- 需要開始日/需要終了日は基準日（棚卸日）と累積LTから算出されます。

### 需要（完成品別・日別）

- 完成品ごとの日別需要を表示します。
- 需要窓判定が `1` の行だけが需要窓数量に加算されます。
- 需要窓数量は `注文数量 × 完成品係数` で計算されます。
- 完成品係数は「在庫（部品換算）」の `関連品（自品＋中間品＋完成品）` と完成品コードの完全一致で取得します。

## 需要集計ルール

- 需要ソース: `ORDER_LINE`
- 対象: `order.status = OPEN`
- 注文種別: `FIRM` / `FORECAST`
- 同一キー（得意先 + 納入先 + 納期）で `FIRM` がある場合は `FIRM` を優先
- 需要窓の日付判定は顧客カレンダを使用

## 注意点

- 「検索」だけでは集計されません。必ず「対象部品を反映」を押してください。
- 累積LTが `0` の完成品は需要窓の集計対象外です。
- 完成品係数が未設定（在庫テーブルの完成品コード未一致）の完成品は、警告表示され、需要窓数量は `0` になります。
- 在庫（部品換算）の自動反映では、`ST` で始まる連産品コードは表示対象外です。
- データが0件の場合、完成品別需要窓合計は `0` になります。
