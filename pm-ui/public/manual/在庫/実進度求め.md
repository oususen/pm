# 実進度求め

対象部品の在庫と、親製品の需要窓（明日〜親別累積LT）を使って実進度を確認する画面です。

実進度は以下で計算します。

- 実進度 = 全状態在庫合計（部品換算） - 親別需要窓合計

## 画面への行き方

1. 上のグローバルナビゲーションの「在庫」を開く
2. 「在庫管理メニュー」→「実進度求め」を選択

## 使い方

1. 「品番」に対象部品コードを入力して「検索」を押します。
2. 「対象部品を反映」を押します。
3. 必要に応じて「基準日」を変更し、再度「対象部品を反映」を押します。
4. 「親設定（累積LT）」「在庫（部品換算）」「需要（親別・日別）」を確認します。

## 画面の見方

### 設定

- 全状態在庫合計: 部品換算後の在庫合計
- 親別需要窓合計: 各親製品の需要窓に入る需要数量の合計
- 実進度: `全状態在庫合計 - 親別需要窓合計`

### 親設定（累積LT）

- 親製品ごとに累積LT(日)を表示します。
- 需要開始日/需要終了日は基準日と累積LTから算出されます。

### 需要（親別・日別）

- 親製品ごとの日別需要を表示します。
- 需要窓判定が `1` の行だけが需要窓数量に加算されます。

## 需要集計ルール

- 需要ソース: `ORDER_LINE`
- 対象: `order.status = OPEN`
- 注文種別: `FIRM` / `FORECAST`
- 同一キー（得意先 + 納入先 + 納期）で `FIRM` がある場合は `FIRM` を優先
- 需要窓の日付判定は顧客カレンダを使用

## 注意点

- 「検索」だけでは集計されません。必ず「対象部品を反映」を押してください。
- 累積LTが `0` の親製品は需要窓の集計対象外です。
- データが0件の場合、親別需要窓合計は `0` になります。
