# 進度調整

進度補正値を登録する画面です。  
調整値は調整対象日に保存され、再計算時に進度へ反映されます。

## 画面への行き方

1. 上のグローバルナビゲーションの「在庫」を開く
2. 「在庫管理メニュー」→「調整」→「進度調整」を選択

## 使い方（個別）

1. 「品番」に対象品番を入力し、`Enter`で読込します。
2. 工程候補が複数ある場合は、左側の工程一覧から対象工程を選択します。
3. 表示開始日を必要に応じて変更します。
4. 画面ガイドの手順で補正します。  
   - ① 進度再計算して確認  
   - ② 実進度（今日）を入力して差分確認  
   - ③ 調整を保存して再計算

## 使い方（一括）

1. タブを「一括」に切替えます。
2. 工程CDを入力し、対象品番を表示します。
3. ① 進度再計算して確認を実行します。
4. 各行の実進度を入力します（差分が自動計算されます）。
5. ② 調整を保存して再計算を実行します。

## 注意点

- 調整対象日は自動計算され、入力できるのは調整対象日の行のみです。
- 保存値は上書きではなく累積で扱われます。
- 保存後は必ず再計算し、値を再読込して確認してください。
