# 在庫管理メニュー

在庫管理で使用する機能へ遷移するためのメニュー画面です。

## 画面への行き方

1. 上のグローバルナビゲーションの「在庫」を開く
2. 「在庫管理メニュー」を表示

## メニュー項目

- 棚卸現物入力  
  現場で数量入力し、レイアウト画面で進捗確認します。
- 棚卸レイアウト編集  
  棚卸現物入力で使う置き場マップをPCで作成・編集します。
- 調整  
  進度/在庫の調整画面、調整履歴画面へ遷移します。
- 実進度求め  
  対象部品の在庫と親別需要窓から実進度を算出します。

## 注意点

- ここはメニュー画面です。データ更新は各遷移先画面で実行します。
