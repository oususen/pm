# 棚卸結果確認

棚卸入力の結果を一覧表形式で確認する画面です。

## 画面への行き方

1. グローバルナビゲーションの「在庫」を開く
2. 「棚卸結果確認」を選ぶ

---

## フィルタ

| フィルタ | 説明 |
|---------|------|
| 棚卸日 | 確認したい棚卸日を指定（必須） |
| エリア | 入力時に選択されたエリアで絞り込み |
| 品番 | 品番の一部で検索 |
| 置き場 | 製品の保管場所で絞り込み |

「検索」ボタンで結果を表示します。

---

## 表示モード切替

「表示: 合計 / 分行」ボタンで2つの表示モードを切り替えられます。

### 合計モード

製品ごとに集約した結果を表示します。

| 列 | 説明 |
|----|------|
| 品番 | 製品コード |
| 品名 | 製品名 |
| 入力エリア | 棚卸入力時に選択されたエリア名（複数あればカンマ区切り） |
| 置き場 | 製品の保管場所 |
| 机上在庫 | システム上の在庫数 |
| 机上進度 | 保存時点のシステム上の進度値 |
| 現物数 | 全入力レコードの合計 |
| 差異 | 現物数 − 机上在庫（正: 青、負: 赤） |
| 入力件数 | その製品の入力レコード数 |
| 最終入力者 | 最後に入力した人 |
| 最終更新日時 | 最後の入力日時 |

### 分行モード

個別の入力レコードを1行ずつ表示します。

| 列 | 説明 |
|----|------|
| 品番 | 製品コード |
| 品名 | 製品名 |
| 入力エリア | その入力時に選択されたエリア名 |
| 置き場 | 製品の保管場所 |
| 机上在庫 | システム上の在庫数 |
| 机上進度 | 保存時点のシステム上の進度値 |
| 現物数 | その回の入力数量 |
| 記入者 | 入力した記入者名 |
| カウンター | 現物を数えた人 |
| 備考 | 備考欄（他エリア品の場合「他エリア」が自動付与される） |
| 更新者 | システムユーザー名 |
| 更新日時 | 入力日時 |

---

## 注意点

- 棚卸日は必須です。指定しないと検索できません
- エリアフィルタは、棚卸入力時に保存されたエリア名で絞り込みます
- 机上進度は棚卸入力の保存時点の値です。保存後に進度再計算が行われた場合、現在の値と異なる可能性があります
- 「stocktake」権限が必要です
