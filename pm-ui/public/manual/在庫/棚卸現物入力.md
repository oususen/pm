# 棚卸現物入力（スマホ対応）

棚卸時に、現場でスマホから現物数を入力する画面です。

[詳しい作業手順書はこちら](/manual/在庫/棚卸現物入力_作業手順書.html)
[棚卸レイアウト編集マニュアルはこちら](/manual?path=在庫/棚卸レイアウト編集.md)

## 画面への行き方

1. グローバルナビゲーションの「在庫」を開く
2. 「棚卸現物入力」を選ぶ

---

## 事前準備：記入者を登録する

棚卸を始める前に、その日の記入者を登録します。

1. 画面上部の「板金班棚卸」の横にある **👤アイコン** をタップ
2. 記入者管理画面が開く
3. 名前を入力して **追加** をタップ
4. 必要な人数分繰り返す
5. **閉じる** をタップ

> 入力者とカウンターは棚卸日ごとに管理されます。社外応援者も登録できます。

---

## 基本の流れ

### ① 絞り込み

画面上部のフィルタで対象を絞り込みます。

- **加工先検索**: 工程を選択（レーザ1、ブレーキ等）
- **置き場検索**: 保管場所を選択
- **品番検索**: 品番の一部を入力

各フィルタの「クリア」で条件解除できます。

### ② 品番を選んで入力

1. 一覧から対象品番の **›** ボタンをタップ
2. 入力画面が開く
3. **入力者** をドロップダウンから選択（必須）
4. **カウンター** を必要に応じて選択
5. **数量** を入力
6. 必要なら **備考** を入力
7. **保存** をタップ

### ③ 同じ品番を複数回入力

同じ品番が複数の場所にある場合、何回でも入力できます。  
**›** をタップするたびに、空の入力画面が開きます。

---

## 入力履歴を確認する

入力済みの品番には、**›** ボタンの上に件数付きの履歴アイコンが表示されます。

1. **履歴アイコン** をタップ
2. その品番の当日入力一覧が表示される（数量・入力者・時刻）
3. 誤入力は **✕** で削除できる（権限が必要）

---

## 棚卸日の変更

画面上部中央の **日付** をタップすると日付ピッカーが開きます。  
日付を変更すると、その日のデータに切り替わります。

---

## 画面の見方

| 項目 | 説明 |
|------|------|
| 品番 | 製品コード |
| 品名 | 製品名 |
| 加工先 | 担当工程 |
| 置き場 | 保管場所 |
| 机上在庫 | システム上の在庫数 |
| 差異 | 入力合計 − 机上在庫 |
| 入力者 | 事前登録した入力者から選択 |
| カウンター | 現物を数えた人を選択 |
| 数量 | 現場で数えた現物数 |

---

## 注意点

- 入力者を選択しないと保存できません
- 写真・置き場・加工先は製品マスタの設定を参照します
- この画面は現物入力の記録です。確定処理は別画面で行います
- 履歴の削除には「棚卸履歴削除」権限が必要です
- レイアウトはPCの「棚卸レイアウト編集」で作成します
