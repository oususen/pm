# 調整履歴

在庫調整・進度調整などの登録履歴を確認する画面です。

## 画面への行き方

1. 上のグローバルナビゲーションの「在庫」を開く
2. 「在庫管理メニュー」→「調整」→「調整履歴」を選択

## 使い方

1. 必要に応じて以下の条件を入力します。  
   - 工程CD  
   - 品番  
   - 種別（在庫調整 / 進度調整 / 計画在庫調整 / 計画進度調整）  
   - 対象日（開始・終了）
2. 「検索」を押します。
3. 一覧で調整値・理由・更新日時・調整者を確認します。

## 画面の見方

- 調整値がマイナスの場合は赤表示されます。
- 件数表示が `上限500件` の場合、検索条件を絞って再検索してください。

## 注意点

- 検索条件を変更しただけでは更新されません。都度「検索」を押してください。
