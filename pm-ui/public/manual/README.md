# 生産管理システム PM ユーザーマニュアル

このマニュアルは、日々の業務で画面操作を行う利用者向けの手順書です。システム設定や開発向けの情報は含みません。

## 画面への入り方

- 上のグローバルナビゲーションから各機能へ移動します。
- 「出荷管理」などのメニューは、クリックで展開します。

## 画面でよく使う操作

- 入力欄に文字を入れると、一覧が絞り込まれます。
- 日付はカレンダーから選択します。
- 「更新」や「再取得」のボタンがある画面は、押すことで最新の情報を読み込みます。
- 一覧が長い場合は、下部のページ切替で表示件数を変更できます。
