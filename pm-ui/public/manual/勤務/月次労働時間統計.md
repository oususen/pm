# 月次労働時間統計

メンバーの承認済み労働時間を詳細・集計・月別で確認する画面です（リーダー・班長・係長・課長向け）。

[作業手順書（日本語）](月次労働時間統計_作業手順書.html)

## 画面パス

`勤務 > 月次統計`

---

## アクセス権限

- **リーダー・班長・係長・課長** のみアクセス可能です。

---

## 操作手順

### 1. 期間設定

1. **開始月** と **終了月** を指定します（デフォルト: 今月）。指定月の月初日から月末日までを集計します。
2. `表示` を押すとデータを取得します。

### 2. フィルター

- **班 / グループ / 氏名 / 有給** で絞り込みできます。

---

## タブ構成

### 詳細タブ

承認済み申請を1件ずつ一覧表示します。

| 列 | 内容 |
|----|------|
| 氏名 / 班 / グループ | 作業者の所属 |
| 日付 | 勤務日 |
| 種別 | 定時 / 時間外 / 休日出勤 / 午前半休 / 午後半休 / 有給 / 連続有給 |
| 開始時間 / 終了時間 | 残業の開始〜終了 |
| 労働時間(H) | 定時 + 残業の合計 |
| 残業(H) | 残業時間 |
| 休日出勤(H) | 休日出勤の勤務時間 |
| 所定外(H) | 残業 + 休日出勤の合計 |
| 午前半休 / 午後半休 / 前日有給 / 連続有給 | 該当する場合は「○」表示 |
| 有給数 | 有給換算（有給=1、半休=0.5） |

- **フッター**: 合計行（労働時間・残業・休日出勤・所定外・有給数の合計）
- **Excel出力**: フィルター後のデータをExcelファイルでダウンロード

### 集計タブ

氏名×日付のマトリクスで労働時間を表示します。

- セルに **労働時間（H）** が表示されます。
- 有給は「有給」、半休は「半休」とラベル表示されます。
- 空欄の `—` セルをクリックすると **勤務登録モーダル** が開き、定時（8H）/有給/午前半休/午後半休を簡易登録できます。
- 簡易登録した定時（8H）/有給/午前半休/午後半休のセルをクリックすると、該当する勤務記録を取り消せます。
- 右端に **合計列**、下端に **合計行** があります。

### 月別タブ

氏名×月のマトリクスで残業・労働時間・有給数を表示します。

- 各月に **残業(H)** / **労働(H)** / **有給(回)** の3列が表示されます。
- 右端に合計列があります。
- **Excel出力**: 表示中の月別マトリクスをExcelファイルでダウンロードできます。

---

## 補足

- 承認済み（リーダー承認〜承認完了）の申請のみが集計対象です。
- 記録のみの種別（午後半休・有給・連続有給）は全件が対象です。
- 連続有給は日ごとに分解して表示されます（DAISOカレンダーの非稼働日は除外）。
- 日付順 → 氏名順でソートされます。
