# 承認待ち一覧

提出された残業申請・休日出勤申請を承認・却下する画面です（リーダー・班長・係長・課長向け）。

[作業手順書（日本語）](承認待ち一覧_作業手順書.html)

## 画面パス

`勤務 > 承認待ち一覧`

---

## アクセス権限

- **リーダー・班長・係長・課長** のみアクセス可能です。
- 一般社員のメニューには表示されません。

---

## 操作手順

### 1. フィルター

- **班 / グループ / 日付** で絞り込みできます。

### 2. 一覧の見方

| 列 | 内容 |
|----|------|
| チェック | 一括承認用の選択チェックボックス |
| 日付 | 勤務日 |
| 班 / グループ | 申請者の所属 |
| 申請者 | 申請者名 |
| 種別 | 時間外 / 休日出勤 / 午前半休 |
| 勤務時間 | 定時の勤務開始〜終了 |
| 残業時間 | 残業開始〜残業終了 |
| 時間数 | 合計時間（深夜含む） |
| 発生理由 | 申請理由 |
| 提出日時 | 提出された日時 |
| 状態 | 提出済み / リーダー確認済み / 班長確認済み / 係長確認済み / 承認完了 / 却下 |
| 操作 | 詳細ボタン |

### 3. 個別承認・却下

1. 対象申請の `詳細` ボタンを押します。
2. モーダルが開き、申請内容（日付・種別・勤務時間・残業時間・時間数・理由・署名）が表示されます。
3. **コメント**（任意）を入力します。
4. `承認` または `却下` を押します。
   - 却下の場合は **却下理由**（必須）を入力してから `却下` を押します。

### 4. 一括承認

1. 一覧のチェックボックスで対象を選択します（ヘッダーのチェックで全選択も可能）。
2. 画面右上に `一括確認依頼（N件）` ボタンが表示されます。
3. ボタンを押すとモーダルが開き、選択した申請の一覧が表示されます。
4. **コメント**（任意）を入力し、`確認依頼` を押します。
5. 選択した全件が一括で承認されます。

---

## 承認フロー

```text
申請者 → リーダー → 班長 → 係長 → 課長（承認完了）
```

- 各承認者は自分の段階の承認のみ行えます。
- 承認すると次の承認者の一覧に表示されます。
- いずれかの段階で却下されると申請者に差し戻されます。

---

## 補足

- 勤務管理メニューのタイルに未承認件数がバッジ表示されます。
- 承認・却下後は一覧が自動更新されます。
