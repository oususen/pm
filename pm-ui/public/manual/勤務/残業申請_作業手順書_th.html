การยื่นคำขอโอที

คู่มือนี้อธิบายวิธีการยื่นคำขอโอที การทำงานวันหยุด ครึ่งวัน และวันลา

งาน > ยื่นคำขอโอที

ขั้นตอนโดยย่อ

  1. เลือกประเภทการยื่นคำขอ
  2. ตรวจสอบชื่อผู้ยื่น
  3. กรอกวันที่
  4. กรอกเวลาและเหตุผลเมื่อจำเป็น
  5. ลงลายเซ็นเมื่อเป็นรายการที่ต้องอนุมัติ
  6. บันทึกร่างหรือส่งคำขอ

ประเภทการยื่นคำขอ

ประเภทการอนุมัติลายเซ็นหมายเหตุ
โอทีจำเป็นจำเป็นกรอกเวลางานปกติและเวลาโอที
ทำงานวันหยุดจำเป็นจำเป็นเลือกแพทเทิร์นการทำงานและเวลาทำงาน
ลาครึ่งวันเช้าจำเป็นจำเป็นกรอกครึ่งวันเช้าและโอที
ลาครึ่งวันบ่ายไม่จำเป็นไม่จำเป็นบันทึกอย่างเดียว
ลาพักร้อนไม่จำเป็นไม่จำเป็นบันทึกอย่างเดียว
ลาต่อเนื่องไม่จำเป็นไม่จำเป็นกำหนดวันเริ่มและวันสิ้นสุด

วิธีใช้งาน

1. เลือกประเภท

เลือกประเภทการยื่นคำขอจากด้านบนของหน้าจอ

2. ตรวจสอบผู้ยื่น

ระบบเลือกชื่อตัวเองให้อัตโนมัติและไม่สามารถเปลี่ยนได้

3. กรอกวันที่

สำหรับโอที วันหยุด ครึ่งวัน และวันลา ให้กรอกวันที่ทำงาน ส่วนลาต่อเนื่องให้กรอกวันเริ่มและวันสิ้นสุด

4. กรอกเวลา

สำหรับโอทีและครึ่งวันเช้า ให้กรอกเวลาเริ่มงาน เวลาสิ้นสุดปกติ และเวลาสิ้นสุดโอที สำหรับทำงานวันหยุด ให้เลือกแพทเทิร์นการทำงานแล้วปรับเวลาได้ตามต้องการ

5. ตรวจสอบชั่วโมงที่คำนวณ

ชั่วโมงรวมและชั่วโมงดึกจะคำนวณอัตโนมัติ รวมทั้งหักเวลาพักอัตโนมัติ

6. กรอกเหตุผล

รายการที่ต้องอนุมัติจำเป็นต้องกรอกเหตุผล

7. ลงลายเซ็น

รายการที่ต้องอนุมัติ ให้ลงลายเซ็นด้วยเมาส์หรือระบบสัมผัส

8. ส่งคำขอ

ใช้ บันทึกร่าง หากยังไม่พร้อมส่ง หรือใช้ ส่งคำขอ เพื่อเข้าสู่ขั้นตอนอนุมัติ

กรณีต้องการแก้ไขหลังจากส่งแล้ว

  1. เปิด รายการคำขอ (คำขอของฉัน)
  2. กด แก้ไข ที่คำขอเป้าหมาย
  3. แก้ไขข้อมูล
  4. กด ส่งคำขอ อีกครั้ง
เมื่อแก้ไขคำขอที่ส่งแล้ว สถานะจะกลับเป็นร่างก่อน แล้วจึงต้องส่งใหม่อีกครั้ง
วันเดียวกันและประเภทเดียวกัน จะยื่นใหม่ไม่ได้จนกว่าจะลบหรือยกเลิกคำขอเดิมก่อน
