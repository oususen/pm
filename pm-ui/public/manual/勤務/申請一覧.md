# 申請一覧

自分の残業申請・有給申請の履歴を一覧で確認・管理する画面です。

[作業手順書（日本語）](申請一覧_作業手順書.html)
[班長承認取消の手順はこちら](/manual?path=勤務/班長承認取消.md)

## 画面パス

`勤務 > 申請一覧`

---

## 操作手順

### 1. 検索・フィルター

1. **期間**: 開始日〜終了日で対象期間を絞り込みます。
2. **ステータス**: 下書き / 提出済み / 班長承認 / 係長承認 / 承認完了 / 却下 から選択。
3. `検索` を押すとAPIからデータを再取得します。
4. **サブフィルター**（データ取得後）:
   - 班 / グループ / 種別（チェックボックス） / 氏名 / 日付 で追加絞り込みできます。
   - `却下を除く` チェックで却下済みを非表示にできます。

### 2. 一覧の見方

| 列 | 内容 |
|----|------|
| 勤務日 | 申請対象の日付 |
| 班 / グループ | 申請者の所属 |
| 種別 | 時間外 / 休日出勤 / 午前半休 / 午後半休 / 有給 / 連続有給 |
| 申請者 | 申請者名 |
| 勤務時間 | 定時の勤務開始〜終了 |
| 残業時間 | 残業開始〜終了 |
| 時間数 | 合計時間（深夜がある場合は別途表示） |
| 発生理由 | 申請理由（省略表示） |
| ステータス | 承認状態（色分けバッジ） |
| 提出日時 | 提出した日時 |
| 操作 | 編集 / 削除（取消） / 詳細 |

- **フッター**: フィルター後の件数と合計時間（深夜含む）が表示されます。

### 3. ステータスの色分け

| ステータス | 色 |
|------------|-----|
| 下書き | グレー |
| 提出済み | 青 |
| 班長承認 | 緑（薄） |
| 係長承認 | 緑（濃） |
| 承認完了 | 緑（最濃） |
| 却下 | 赤 |

### 4. 操作ボタン

- **編集**: 下書き・提出済みの申請を編集画面で修正できます。
- **取消 / 削除**: 提出済みは「取消」、下書きは「削除」。確認ダイアログが表示されます。
- **詳細**: モーダルで申請内容の全情報と承認ログを確認できます。

### 5. PDF出力

- `PDF出力` ボタンで、フィルター後の申請を残業申請書PDFとしてダウンロードできます。

### 6. 詳細モーダル

- 申請内容（日付・種別・勤務時間・残業時間・時間数・理由・署名）が表示されます。
- 却下された場合は却下理由も表示されます。
- **承認ログ**: 各承認者の役職・名前・承認/却下・コメント・日時が表示されます。
- 条件を満たす場合は **班長承認取消** ボタンが表示され、班長承認済みを一つ前の状態へ戻せます。

### 7. ページネーション

- 30件ずつ表示されます。ページ切り替えボタンで移動できます。

---

## 補足

- 画面右上の `新規申請` ボタンから残業申請画面に遷移できます。
- 下書きの申請は一覧の先頭に表示されます。
