# 勤務管理

残業申請・承認・労働時間統計・加工費集計・シフトを管理するメニューです。

## 画面パス

`勤務`

## 全体の流れ

```text
① 残業申請 → ② 申請一覧で確認 → ③ 承認待ちで承認 → ④ 統計・加工費で確認
```

1. **残業申請** で時間外・休日出勤・半休・有給を申請します。
2. **申請一覧** で自分の申請履歴を確認・編集・PDF出力します。
3. **承認待ち一覧** でリーダー/班長/係長/課長が申請を承認・却下します。
4. **月次統計** でメンバーの労働時間を詳細・集計・月別で確認します。
5. **加工費集計** で作業者別の加工費・出来高・稼働率を日別・期間集計で確認します。

## 各画面の詳細手順

### [残業申請](残業申請.md)

時間外・休日出勤・半休・有給を申請します。署名付きで提出し、承認フローに送ります。

[作業手順書（日本語）](残業申請_作業手順書.html)

### [申請一覧](申請一覧.md)

自分の申請履歴を確認・編集・削除します。PDF出力やフィルター機能があります。

[作業手順書（日本語）](申請一覧_作業手順書.html)

### [承認待ち一覧](承認待ち一覧.md)

提出された申請を個別・一括で承認または却下します（管理者向け）。

[作業手順書（日本語）](承認待ち一覧_作業手順書.html)

### [月次労働時間統計](月次労働時間統計.md)

承認済みの労働時間を詳細・集計・月別のタブで確認します。Excel出力も可能です。

[作業手順書（日本語）](月次労働時間統計_作業手順書.html)

### [加工費集計](加工費集計.md)

レーザー・ブレーキ・工程実績から加工費・出来高・稼働率を日別と期間集計で確認します。

[作業手順書（日本語）](加工費集計_作業手順書.html)

### シフト管理

シフトチャートで作業者・工程・開始時刻・実働時間を指定し、配置を追加・編集します。

- 日をまたぐ開始時刻は、`24:20`や`26:00`の形式で入力できます。
- 保存時はそれぞれ`00:20`・`02:00`となり、選択したシフト日付は維持されます。開始8時のチャートでは翌日の位置に表示されます。
- 分・秒は`00`～`59`で入力してください。

## 補足

- 承認待ち一覧・月次統計・加工費集計はリーダー・班長・係長・課長のみアクセス可能です。
- 午後半休・有給・連続有給は承認不要（記録のみ）です。
