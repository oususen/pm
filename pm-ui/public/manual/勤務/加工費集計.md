# 加工費集計

作業者別の加工実績（数量・加工費・出来高・時間当たり加工費）を日別・期間集計で確認する画面です。

[作業手順書（日本語）](加工費集計_作業手順書.html)

## 画面パス

`勤務 > 加工費集計`

---

## アクセス権限

- **リーダー・班長・係長・課長** のみアクセス可能です。

---

## 操作手順

### 1. 期間設定

1. **開始日** と **終了日** を指定します（デフォルト: 今月1日〜末日）。
2. `表示` を押すとデータを取得・集計します。

### 2. フィルター

- **班 / グループ / 氏名** で絞り込みできます。

---

## タブ構成

### 日別タブ

作業者×日付ごとの加工費・出来高を一覧表示します。

| 列グループ | 列 | 内容 |
|-----------|-----|------|
| 基本 | 氏名 / 班 / グループ / 日付 | 作業者情報 |
| 基本 | 加工数合計 / 加工費合計 | 生産数×単価の合計 |
| セッションから | 加工時間(H) | 実際の加工セッション時間 |
| セッションから | 出来高 | 加工数 ÷ 加工時間 |
| セッションから | 出来高順 | 日別の出来高ランキング |
| セッションから | 加工費/H | 加工費 ÷ 加工時間 |
| セッションから | 加工費/H順 | 日別の加工費/Hランキング |
| 勤務時間から | 出勤時間(H) | 残業申請ベースの勤務時間 |
| 勤務時間から | 出来高 | 加工数 ÷ 出勤時間 |
| 勤務時間から | 出来高順 | 日別の出来高ランキング |
| 勤務時間から | 加工費/H | 加工費 ÷ 出勤時間 |
| 勤務時間から | 加工費/H順 | 日別の加工費/Hランキング |
| 稼働率 | (加工時間/出勤時間) | 加工時間 ÷ 出勤時間（%表示） |

- 出来高・加工費/Hのセルはヒートマップ（緑の濃淡）で相対値を可視化しています。
- 日付ごとに4色の背景バンドで区切られます。

### 期間集計タブ

作業者ごとに期間全体の合計を表示します。

- 先頭行に **期間合計** が表示されます。
- 以降は作業者ごとの合計を加工数の降順で表示します。
- ランキング・ヒートマップは期間内全体で再計算されます。

---

## データソース

### 加工実績

以下の3つの実績ソースを統合して集計します:

1. **レーザー実績**: START/RESUME → END/PAUSE のペアから加工時間を算出
2. **ブレーキ/スポット実績**: ブレーキプレスと板金スポットは同じ専用実績テーブルを共有し、セッション単位で取得
3. **工程実績（PWS）**: BRAKE / LASER 以外のセッションを取得

- 重複排除: 同一日・同一作業者・同一製品・同一時刻の重複セッションは自動除外されます。
- 調査実績（2026-02-16〜2026-07-24、全12,949件）: 同一日・同一作業者・同一製品がソース間で二重登録されたケースは **0件** です。同一作業者が同日に複数ソースで記録されるケース（13件）はすべて異なる製品での作業であり、正常な運用です。

### 勤務時間

- 残業申請の承認済みデータから取得します。
- 加工時間（セッション）と出勤時間（勤務申請）の両方で生産性を比較できます。

### 単価

- 製品マスタの `unit_price` から取得して加工費を計算します。

---

## Excel出力

- `Excel出力` ボタンで現在表示中のタブ（日別 or 期間集計）をExcelファイルでダウンロードできます。
- セクションヘッダー（セッションから / 勤務時間から / 稼働率）も含めて出力されます。

---

## 補足

- **稼働率**: 加工時間 ÷ 出勤時間 で計算され、作業者の実稼働割合を示します。この値は出来高集計の係数設定で使う稼働率の算出元データにもなります。
- 画面読み込み時に自動でデータ取得・表示が行われます。
