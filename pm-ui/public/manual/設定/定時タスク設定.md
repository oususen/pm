# 定時タスク設定

定時タスク設定画面では、各種バッチ処理の実行時刻・有効/無効・対象条件を設定します。  
画面: `設定 > 定時タスク設定`

## できること

- 取り込み・在庫・進度系タスクの時刻設定
- 自動計画生成タスクの時刻/対象月/通知先設定
- 安全在庫タスクの実行日・時刻設定
- 受注展開タスクの時刻設定
- 実績整合チェック系タスクの時刻設定
- 計画実績自動セットタスク（ライン・工程別）の設定
- 各タスクの「今すぐ実行」

## 画面の見方

- 各カードに対象タスクが表示されます。
- `保存` を押すまで設定は確定されません。
- `今すぐ実行` はバックグラウンド実行です。完了後に最終実行情報へ結果が反映されます。

## 共通操作

1. 対象タスクの時刻/設定値を変更する
2. `保存` を押す
3. 必要なら `今すぐ実行` で手動実行する
4. `最終実行情報` で結果を確認する

## 取り込み・在庫・進度タスク

対象:
- 取り込み＋在庫再計算
- 取り込みのみ
- 在庫計算のみ
- 進度計算のみ

設定項目:
- 実行時刻
- 有効/無効
- 対象期間（タスク種別により表示差あり）

## 自動安全在庫

対象:
- `AUTO_SAFETY_STOCK_INTERNAL`（社内）
- `AUTO_SAFETY_STOCK_PURCHASE`（購入品）

用途:
- 将来の需要（確定+内示）の日当たり平均から安全在庫（最小在庫数）を自動算出し、在庫マスタへ反映します。

設定項目:
- **実行日**: 毎月何日に実行するか
- **実行時刻**: 実行する時・分
- **平均算出日数**: 実行日から何日間の需要を見るか（デフォルト: 60日）
- **安全在庫日数**: 日当たり平均の何日分を安全在庫にするか（デフォルト: 1日分）
- **有効/無効**: タスクの有効切り替え

### 計算式

```
安全在庫 = 日当たり平均需要 × 安全在庫日数（四捨五入、最低1）
```

### 計算の流れ

1. 実行日から「平均算出日数」先までの LineDemand（確定+内示）を製品ごとに集計する
   - 社内: 生産ライン（PROD）の需要
   - 購入品: 購入ライン（PURCHASE）の需要
2. 製品ごとに `総需要数 ÷ 需要がある日数` で日当たり平均を算出する
3. `日当たり平均 × 安全在庫日数` を四捨五入して安全在庫とする（最低1）
4. 在庫マスタ（StockAllocation）の `min_stock_qty` を更新する

### 計算例

平均算出日数=60日、安全在庫日数=1日の設定で、ある製品の需要が「20日間に合計100個」の場合:

- 日当たり平均 = 100 ÷ 20 = 5個/日
- 安全在庫 = 5 × 1 = **5個**

### 注意事項

- 需要がある日だけで平均を算出します（需要ゼロの日は母数に含まない）。そのため散発的に大量需要がある製品は安全在庫が大きくなる傾向があります。
- 算出結果が0でも最小在庫は最低1を保持します。
- 在庫マスタにレコードがない製品は新規作成されます。

## 計画実績自動セット（ライン・工程別）

対象:
- `PLAN_TO_ACTUAL_COPY`（新タスク）

用途:
- 指定時刻に、対象ライン・対象工程の計画数量を実績へ自動反映します。

手順:
1. 「計画実績自動セット（ライン・工程別）」で `ライン` と `工程` を選ぶ
2. `追加` を押す
3. 追加された行で `実行時刻` と `有効` を設定
4. 行の `保存` を押す

補足:
- `追加` 後は下書き行として表示されます。
- 下書き行は `保存` または `キャンセル` を押すまで残ります。
- 下書き状態では `今すぐ実行` はできません。

## 日付判定（8時境界）

業務日付は 8:00 区切りです。

- 7:59 実行: 前日扱い
- 8:00 実行: 当日扱い

例:
- `2026-04-28 07:59` 実行時は、`2026-04-27` の計画を対象にします。

## よくある確認ポイント

- 設定変更後に `保存` を押したか
- タスクが `有効` になっているか
- スケジューラが起動しているか
- `最終実行情報` にエラーが出ていないか
