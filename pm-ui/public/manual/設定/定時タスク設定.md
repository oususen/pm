# 定時タスク設定

定時タスク設定画面では、各種バッチ処理の実行時刻・有効/無効・対象条件を設定します。  
画面: `設定 > 定時タスク設定`

## できること

- 取り込み・在庫・進度系タスクの時刻設定
- 自動計画生成タスクの時刻/対象月/通知先設定
- 安全在庫タスクの実行日・時刻設定
- 受注展開タスクの時刻設定
- 実績整合チェック系タスクの時刻設定
- 計画実績自動セットタスク（ライン・工程別）の設定
- 各タスクの「今すぐ実行」

## 画面の見方

- 各カードに対象タスクが表示されます。
- `保存` を押すまで設定は確定されません。
- `今すぐ実行` はバックグラウンド実行です。完了後に最終実行情報へ結果が反映されます。

## 共通操作

1. 対象タスクの時刻/設定値を変更する
2. `保存` を押す
3. 必要なら `今すぐ実行` で手動実行する
4. `最終実行情報` で結果を確認する

## 取り込み・在庫・進度タスク

対象:
- 取り込み＋在庫再計算
- 取り込みのみ
- 在庫計算のみ
- 進度計算のみ

設定項目:
- 実行時刻
- 有効/無効
- 対象期間（タスク種別により表示差あり）

## 計画実績自動セット（ライン・工程別）

対象:
- `PLAN_TO_ACTUAL_COPY`（新タスク）

用途:
- 指定時刻に、対象ライン・対象工程の計画数量を実績へ自動反映します。

手順:
1. 「計画実績自動セット（ライン・工程別）」で `ライン` と `工程` を選ぶ
2. `追加` を押す
3. 追加された行で `実行時刻` と `有効` を設定
4. 行の `保存` を押す

補足:
- `追加` 後は下書き行として表示されます。
- 下書き行は `保存` または `キャンセル` を押すまで残ります。
- 下書き状態では `今すぐ実行` はできません。

## 日付判定（8時境界）

業務日付は 8:00 区切りです。

- 7:59 実行: 前日扱い
- 8:00 実行: 当日扱い

例:
- `2026-04-28 07:59` 実行時は、`2026-04-27` の計画を対象にします。

## よくある確認ポイント

- 設定変更後に `保存` を押したか
- タスクが `有効` になっているか
- スケジューラが起動しているか
- `最終実行情報` にエラーが出ていないか
