# 納入パターン設定

仕入先の納入タイミング（パターン）を定義し、各仕入先にパターンを割り当てる画面です。ここで設定した内容は、仕入れ検収の納入日判定や発注提案に使われます。

## 画面への行き方

1. 上のグローバルナビゲーションの「仕入」を開く
2. 「仕入れ管理メニュー」→「納入パターン設定」を選択

または

1. 上のグローバルナビゲーションの「設定」を開く
2. 「タスク設定」→「納入パターン設定」を選択

## 画面構成

この画面は2つのセクションで構成されています。

- **パターン定義**: 納入タイミングのパターンを作成・管理
- **仕入れ先割当**: 定義したパターンを各仕入先に割り当て

## パターン定義

### 一覧の見方

| 列 | 説明 |
|----|------|
| コード | パターンを識別するコード（例: `W-MON`） |
| パターン名 | わかりやすい名前（例: 「毎週月曜」） |
| 繰返し種別 | パターンの種類 |
| 条件 | 曜日・日付などの詳細条件 |
| 有効 | 有効/無効 |
| 備考 | メモ |

### 繰返し種別の種類

| 種別 | 説明 | 設定例 |
|------|------|--------|
| 毎週曜日 | 指定した曜日に毎週納入 | 毎週 月・木 |
| 毎月日付 | 指定した日付に毎月納入 | 毎月 5・15・25日 |
| 月の第N週の曜日 | 月の特定の週の特定の曜日に納入 | 第1・第3 水曜 |
| 毎営業日 | カレンダ上の営業日ごとに毎回納入 | — |
| N営業日ごと | 指定した営業日数間隔で納入 | 2営業日ごと |

### パターンの新規作成

1. 「パターン定義」セクションの「新規」ボタンを押します
2. 以下を入力します:
   - **パターンコード**: 一意のコード（例: `W-MON`）
   - **パターン名**: 表示名（例: 「毎週月曜」）
   - **繰返し種別**: ドロップダウンから選択
  - 種別に応じた追加条件（曜日・日付・間隔など）
   - **有効**: チェックを入れると有効
3. 「保存」を押します

### パターンの編集・削除

- 一覧の「編集」ボタンで内容を変更できます
- 「削除」ボタンで削除できます（仕入先に割当中のパターンは削除できません）

## 仕入れ先割当

### 一覧の見方

| 列 | 説明 |
|----|------|
| 仕入先 | 仕入先コード - 仕入先名 |
| パターン | 割り当てられた納入パターン |
| LT(日) | リードタイム（発注から納入までの日数） |
| 有効 | 有効/無効 |
| 備考 | メモ |

### 仕入先への割当

1. 「仕入れ先割当」セクションの「新規」ボタンを押します
2. 以下を入力します:
   - **仕入先**: ドロップダウンから選択
   - **パターン**: 上のパターン定義で作成した有効なパターンから選択
   - **開始基準日**: 「N営業日ごと」パターンを選んだ場合のみ必須。仕入先ごとに設定
   - **リードタイム(日)**: 発注から納入までの日数（デフォルト: 0）
   - **有効**: チェックを入れると有効
3. 「保存」を押します

### 割当の編集・削除

- 一覧の「編集」ボタンでパターンやリードタイムを変更できます
- 「削除」ボタンで割当を解除できます

## 設定が影響する機能

| 機能 | 影響内容 |
|------|----------|
| 仕入れ検収 | 納入日の判定とカバー日の計算 |
| 発注提案 | 発注タイミングの自動計算 |
| 仕入れ計画 | 納入予定日の参照 |

## 注意事項

- 1つの仕入先に複数のパターンを割り当てることは可能ですが、有効なものが1つだけになるように管理してください
- パターンを無効にすると、そのパターンを使っている仕入先割当のパターン選択肢に表示されなくなります
- 「N営業日ごと」の基準日は、パターン定義ではなく仕入れ先割当で設定します
