# ユーザー管理

## 目的

班長向けに、ユーザーの新規作成・編集・有効/無効の切り替えを行う画面です。

## 画面を開く

1. 上部メニューで「設定」を開きます。
2. 「ユーザー管理」を開きます。
3. 右上の検索条件で必要に応じて絞り込み、`更新`を押します。

## 新規作成

1. `新規ユーザー`を押します。
2. 必須項目を入力します。
   - ユーザー名（社員コードを入力）
   - 必要に応じてメール、姓/名、社員コード
   - 役割（班長/リーダー/一般 など）
3. 所属を設定します。
   - 事業部 → 係 → 班 → グループの順で選択
4. `有効`にチェックを入れます（運用開始する場合）。
5. `保存`を押します。

## 編集

1. 左のユーザー一覧から対象ユーザーを選択します。
2. 右側フォームの項目を修正します。
3. `保存`を押します。

## 有効/無効の設定

1. 対象ユーザーを選択します。
2. `有効`チェックを切り替えます。
   - チェックあり: ログイン可（有効）
   - チェックなし: ログイン不可（無効）
3. `保存`を押します。

## 検索・絞り込み

- キーワード: ユーザー名/氏名/メールで検索
- 事業部・係・班・グループ・役割で絞り込み
- `有効のみ` / `無効のみ` で状態を絞り込み

## 担当班（複数）・担当グループ（複数）の説明

- 担当班（複数）:
  班長向けの設定です。複数の班を兼務して管理する場合に選択します。
- 担当グループ（複数）:
  リーダー向けの設定です。担当するグループを複数選択します。
- 運用の目安:
  班長は担当班を設定し、リーダーは担当グループを設定してください。

## 注意事項

- 編集権限がない場合は閲覧のみです。
- `有効`を外して保存すると、対象ユーザーは次回以降ログインできません。
- 保存後に一覧へ反映されない場合は`更新`を押して再読込してください。
