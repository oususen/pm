# 基幹システム自動入力ツール マニュアル

## 概要

生産実績照会の「Excel出力2」ファイルを読み込み、基幹システム（SSE0040 生産実績入力）へ自動でキー入力するツールです。

---

## 事前準備

### 基幹システム側
1. SSE0040（生産実績入力）を開く
2. 入力したい日付・ラインの画面を表示する
3. **生産日フィールドにカーソルを置いた状態**にしておく

### Excelファイル側
- 生産実績照会画面から「Excel出力2」を出力しておく
- マッピング状態が「変換済み」のレコードのみ入力対象になります

---

## 画面説明

### Excelファイル（出力2）
- **参照...** ボタン：Excel出力2ファイルを選択
- **読み込み** ボタン：ファイルを読み込んでプレビュー表示

### Tab数設定 ★要確認

> **通常は変更不要です。** 以下がデフォルト値です。基幹システムの画面レイアウトが変わった場合のみ変更してください。

| 項目 | デフォルト値 | 説明 |
|------|:---:|------|
| 生産日 → 品番 | **1** | 生産日入力後、品番フィールドまでのEnter回数 |
| 品番確定後 → 工程順位 | **1** | Excelの「工程順行きエンター回数」列の値が優先（こちらはフォールバック値） |
| 工程順位 → 生産数 | **3** | 工程順位入力後、生産数フィールドまでのEnter回数 |
| 生産数 → 加工時間開始 | **8** | 生産数入力後、加工時間開始フィールドまでのEnter回数 |
| 加工時間開始 → 終了 | **1** | 加工時間開始入力後、終了フィールドまでのEnter回数 |

> **ポイント：Enter回数（品番確定後）について**
> 品番ごとの工程数によって異なります。Excelファイルの「工程順行きエンター回数」列の値が自動で使われます。
> - **2回以上**：品番確定 → Enter追加 → 工程順位入力 → 生産数へ
> - **1回**：品番確定後カーソルは「加工先」へ移動（工程順位は自動設定）→ 生産数へ

### 待機時間（秒）

> **通常は変更不要です。** 以下がデフォルト値です。

| 項目 | デフォルト値 | 説明 |
|------|:---:|------|
| キー間 | **1.0秒** | 各キー入力間の待機時間 |
| 品番確定後 | **2.0秒** | 品番確定後の画面変化最大待機時間 |
| 登録後 | **1.0秒** | F12登録後の完了最大待機時間 |
| 開始前(秒) | **10秒** | 入力開始前のカウントダウン秒数 |

> 基幹システムが重い場合は「品番確定後」「登録後」を大きくしてください。

### 入力対象レコード
読み込んだExcelのプレビューです。Enter回数列で各品番の設定を確認できます。

---

## 操作手順

### 1. ファイルの準備
1. 生産実績照会から「Excel出力2」を出力
2. 「参照...」でファイルを選択し「読み込み」をクリック
3. プレビューで入力対象レコードを確認

### 2. 設定の確認
1. Tab数設定・待機時間を確認（初回のみ）
2. 「設定保存」をクリックして保存（次回起動時に引き継がれます）

### 3. 基幹システムの準備
1. SSE0040（生産実績入力）を開く
2. 生産日フィールドにカーソルを置く

### 4. 入力開始
1. **「▶ 入力開始」** をクリック
2. カウントダウンが表示される（デフォルト5秒）
3. カウントダウン中に基幹システムの生産日にカーソルを置く
4. カウントダウン終了後、自動入力が開始される
5. **入力中はマウスカーソルが固定されます**

---

## 入力中の操作

### マウス固定の解除
**右クリック1回** → マウス固定を解除します（入力は継続）

### 緊急停止の方法
| 操作 | 動作 |
|------|------|
| **Ctrl + P** | 現在のレコード完了後に停止 |
| **右ダブルクリック** | 即座に停止（マウス固定も解除） |
| **マウスを画面左上角に移動** | フェイルセーフ緊急停止 |
| **「■ 停止」ボタン** | 停止リクエスト送信 |

---

## エラーへの対応

### 基幹システムがエラーダイアログを表示した場合
ツールが自動的にEnterキーでダイアログを閉じ、そのレコードをスキップします。
ログに「エラーダイアログ検出」と表示されます。

### 「変換済み」以外のレコードはスキップ
マッピング状態が「変換済み」でないレコード、または生産数量が0以下のレコードは自動的にスキップされます。

---

## 注意事項

- **入力中はキーボード・マウス操作をしないこと**（誤入力の原因になります）
- 入力中に別のウィンドウを前面に出さないこと
- 基幹システムが重い場合は待機時間を増やしてください
- **入力結果は必ず基幹システム側で確認してください**（ツールは入力操作を行うだけで、登録成否の完全な保証はありません）
- 設定ファイルは `kikan_input_config.json`（ツールと同じフォルダ）に保存されます

---

## トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| 基幹ウィンドウが見つからない | SSE0040を開いてからウィンドウタイトルを確認 |
| 入力がズレる | Tab数設定を見直す。基幹側で同じ品番を手動入力してEnter回数を数える |
| 品番確定後にエラーが出る | 品番が間違っている or 対象外の品番 |
| 動作が遅い/追いつかない | 待機時間（キー間・品番確定後）を増やす |
| 途中で止まる | ログを確認。エラーダイアログが出た可能性あり |
