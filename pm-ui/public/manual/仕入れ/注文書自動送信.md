# 注文書自動送信

仕入先への注文書Excel・進度表・外作納品書を自動で生成し、毎日メール送信するための設定画面です。
設定した時刻に毎日自動実行され、注文書作成・送付の手作業を削減します。

> **既存の「自動納入リスト送信」とは別機能です。** 本機能は注文書（計画数量ベース）を生成し、計画として保存した上でメール送信します。両機能は独立しており、互いに影響しません。

**[作業手順書（図解付き）を見る](注文書自動送信_作業手順書.html)**

## 画面への行き方

1. 上のグローバルナビゲーションの「仕入」を開く
2. 「仕入れ管理メニュー」→「業務自動タスク」カテゴリ →「注文書自動送信設定」を選択

## 基本的な流れ

1. 「新規追加」ボタンで設定を作成します
2. 仕入先・実行時刻・各項目を入力して保存します
3. 保存後、毎日指定時刻にシステムが自動で注文書を生成・送信します
4. 送信結果は「設定」タブの一覧、または「履歴」タブで確認できます

## 画面構成（3タブ）

本画面は3つのタブで構成されています。

| タブ | 用途 |
|------|------|
| 設定 | 仕入先ごとの送信条件を管理。手動実行・休日手動実行もここから |
| 履歴 | 過去の実行結果を確認。注文書Excelの再ダウンロードも可能 |
| トラック積載判定 | 注文品がトラックに収まるか事前に確認 |

## 設定タブ

### 一覧画面の見方

| 列 | 説明 |
|----|------|
| 仕入先 | 対象の仕入先コード・名称 |
| 実行時刻 | 毎日の自動実行時刻 |
| 納入日 | 実行日から何営業日後 |
| 進度表期間 | 進度表の表示範囲（何営業日前～何日後） |
| 納入日判定 | パターン or 仕入先カレンダ |
| 計算モード | 需要そのまま or ロット丸め |
| 安全在庫 | ON/OFFと倍率 |
| 有効 | 自動送信のON/OFF |
| 送信先 | 仕入先のメールアドレス |
| 添付内容 | 各ファイル種別のON/OFF |
| 通知先 | 失敗時・非納入日の通知先ユーザー |
| 最終実行 | 最後に実行した日時 |
| ステータス | SUCCESS / FAILED / SKIPPED / RUNNING |
| メッセージ | 実行結果の詳細 |

### 設定項目の説明

#### 仕入先

自動送信する仕入先を選択します。1社につき1設定です。同じ仕入先の設定を重複して作成はできません。

#### 実行時刻

毎日何時何分に自動実行するかを設定します。  
例: 7時55分 → 毎朝7時55分に実行。処理基準日は8時区切りのため、木曜日7:55は水曜日を基準に休日判定・納入日計算を行います。木曜日8:00以降は木曜日が基準です。

#### 納入日（実行日から何営業日後）

何営業日後を納入日とするかを設定します。土日祝は自動的にスキップされます。  
例: 5営業日後 → 月曜実行なら翌月曜が納入日（間の土日を除く）

#### 進度表期間

添付する進度表の表示範囲と進度再計算の対象範囲を設定します。

- **何営業日前**: 発行日から何営業日さかのぼるか（過去の進度推移を見るため）
- **何日後**: 発行日から何日先まで表示するか

例: 7営業日前 ～ 30日後（初期値）

#### 計算モード

発注数量の計算方式を選択します。

| モード | 説明 |
|--------|------|
| 需要そのまま | 需要と計進の差分をそのまま発注数量にします |
| ロット丸め | 製品マスタの最小納入数・納入倍数で丸めた数量を発注します |

**ロット丸めの計算:**
- 基準数量 = max(必要数, 最小納入数)
- 発注数量 = ceil(基準数量 ÷ 納入倍数) × 納入倍数

#### 納入日判定方式

次回の納入日をどの方法で決定するかを選択します。

| 方式 | 説明 |
|------|------|
| パターン | 納入パターンマスタ（設定 > 納入パターン設定）に登録した納入曜日で判定 |
| 仕入先カレンダ | 仕入先に割り当てたカレンダの「納入日フラグ」で判定 |

#### 安全在庫

ONにすると、在庫引当マスタの最低在庫数に倍率をかけた数量を、必要数に上乗せして発注します。  
例: 最低在庫数 100、倍率 1.5 → 150 が必要数に加算

#### 送信ファイル（4種類）

以下の4種類を個別にON/OFFできます。**最低1種類はON必須**です。

| ファイル | 説明 |
|---------|------|
| 注文書 Excel | 品番・品名・数量・納品日・日別需要内訳を含む注文書 |
| 進度表 Excel | 設定した進度期間の計画進度をExcel形式で出力 |
| 進度表 PDF | 同じ進度データをPDF形式で出力。印刷配布用 |
| 外作納品書 PDF | A4横の納品書（納品書・受領書・仕入先控の3枚組）。QRコード・容器情報付き |

設定がONでも元データや生成結果がない場合、そのファイルは添付されません。
4種すべてが空になった場合は、メール送信自体をスキップし、ステータスは SUCCESS で終了します。

#### 有効

チェックを外すと自動送信を一時停止できます。設定は保持されるので、再開時はチェックを入れるだけです。

#### メール本文

カスタムのメール本文を入力できます。未入力の場合は自動生成されます。
自動生成の件名は、実際に添付したファイル種別に応じて「注文書 / 外作納品書 / 進度表」を連結して作成されます。

#### 返信先メールアドレス（Reply-To）

仕入先がメールに返信する先のアドレスです。連絡先マスタから選択します。

#### CC送信先メール

送信メールのCC（控え）に入れるメールアドレスです。連絡先マスタから複数件追加できます。

#### 失敗時の通知先

メール送信に失敗した場合に、社内通知を受け取るユーザーを設定します。複数人設定可能です。

#### 納入日でないときの通知先

計算した納入日がパターン上の納入日でなかった場合に、社内通知を受け取るユーザーを設定します。

### 操作ボタン

| ボタン | 説明 |
|--------|------|
| 新規追加 | 新しい仕入先の設定を作成 |
| 編集 | 既存設定を変更 |
| 削除 | 設定を削除して自動送信を停止 |
| 今すぐ実行 | 即時実行。**実際にメールが送信されます。** 休日の場合はスキップ |
| 休日手動実行 | 休日判定を無視して即時実行。**仕入れ計画を再作成し、実際にメール送信します。** 納入日などの条件は引き続き判定します |

## 履歴タブ

過去の実行結果を一覧で確認する画面です。

### 絞り込み

| フィルタ | 説明 |
|---------|------|
| 仕入先 | 特定の仕入先に絞り込み |
| 結果 | SUCCESS / FAILED / SKIPPED / RUNNING で絞り込み |
| 実行種別 | 自動実行 / 手動実行 / 休日手動実行 で絞り込み |
| 件数 | 表示件数の上限（50 / 100 / 200） |
| キーワード | 仕入先コード・仕入先名・宛先・件名・メッセージで検索 |

### 一覧の見方

| 列 | 説明 |
|----|------|
| 開始 / 終了 | 実行の開始・終了日時 |
| 仕入先 | 仕入先コード・名称 |
| 種別 | SCHEDULED=自動 / MANUAL=手動 / HOLIDAY_TRIAL=休日手動実行 |
| 結果 | SUCCESS / FAILED / SKIPPED / RUNNING |
| 先頭納入日 | 今回の注文の最初の納入日 |
| 品目数 | 注文書に含まれた品目数 |
| 宛先 | 送信先メールアドレス |
| 添付内容 | 実際に添付されたファイルの種別 |
| メッセージ | 実行結果の詳細メッセージ |

### 詳細表示

各行の「詳細」ボタンを押すと、以下の情報が表示されます。

- 件名
- 宛先 / CC
- 添付内容
- 実行時間
- エラーメッセージ（失敗時）

### 注文書Excelの再ダウンロード

注文書Excelを添付した実行では、履歴から当時のExcelを再ダウンロードできます。  
「注文書Excel = OFF」で実行した履歴には再ダウンロードボタンは表示されません。

## トラック積載判定タブ

発注した品目がトラックに収まるかを事前に確認する機能です。

### 使い方

1. 「トラック」でトラックを選択します
2. 「納期」で判定する納入日を入力します
3. 「判定実行」ボタンを押します
4. 計算結果が表示されます

### 判定結果の見方

| 表示項目 | 説明 |
|---------|------|
| 積載可 / 積載超過 | 全容器がトラックに収まるかどうか |
| 占有率 | 荷台面積に対する使用率（%） |
| 配置図 | 荷台上の容器配置を図で表示。色分けは製品別 |
| 配置数 | 配置済み枠数 / 全枠数 |
| 容器内訳 | 容器種別ごとの数量サマリ |
| データソース | 「注文書」（注文書提案）or「購買計画」（購買計画データ）。利用可能なデータを自動選択 |

### 中断

大量の品目がある場合は計算に時間がかかることがあります。「中断」ボタンで途中停止できます。

## 数量計算のしくみ

本機能は在庫ではなく**計画進度（計進）**を基準に発注数量を計算します。

### 計算の流れ

1. 実行日から「リードタイム（何営業日後）」で**納入日**を算出
2. 納入日判定方式で**次回納入日**を特定
3. 「納入日～次回納入日の前日」の期間（カバー期間）の**需要合計**を取得
4. **納入日前日**の計進を取得
5. 必要数を算出: `必要数 = カバー期間の需要合計 − 納入日前日の計進`
6. 必要数が 0 以下なら、その品目は今回不要として計画を作成しない
7. ロット丸めモードの場合、製品マスタのロット設定で丸める
8. 安全在庫ONの場合、最低在庫数 × 倍率を加算
9. 計算結果を `LineBacklog (sequence_no=1)` に計画として保存
10. 保存後、進度を再計算

### 注意事項

- 注文書Excelの「数量」列と「日別内訳」列の合計が一致しないことがあります。これはロット丸めによる正常な動作です
- 同日に再実行した場合、前回保存した計画は削除されてから再計算されます

## ステータスの意味

| ステータス | 意味 | 対応 |
|-----------|------|------|
| SUCCESS | 送信完了、またはファイルが空のため送信スキップ | 対応不要 |
| FAILED | 送信失敗 | メッセージ欄でエラー内容を確認。設定を修正して再実行 |
| SKIPPED | 休日のためスキップ / 納入日でないためスキップ | 正常動作。対応不要 |
| RUNNING | 実行中 | しばらく待つと完了する。30分以上続く場合は自動復旧 |

## 安全機構

| 機構 | 説明 |
|------|------|
| 二重実行防止 | 同じ仕入先が実行中の場合、再実行はブロックされます |
| スタック自動復旧 | RUNNING状態が30分以上続いた場合、自動的にFAILEDに変更し、次回実行を受け付けます |
| 休日スキップ | ダイソウカレンダで休日の場合は自動でスキップします |
| 空送信防止 | 添付ファイルがすべて空の場合、メール送信をスキップします（SUCCESS扱い） |
| 失敗通知 | 送信失敗時に指定ユーザーへ社内通知を送信します（7日間有効） |
| バリデーション | 送信ファイルは4種のうち最低1種類ON必須。メールアドレスの形式チェックも実施 |

## 実行方法の比較

| 実行方法 | タイミング | 休日判定 | 用途 |
|---------|-----------|---------|------|
| 自動実行（SCHEDULED） | 毎日・設定時刻 | 休日ならスキップ | 通常の日次運用 |
| 今すぐ実行（MANUAL） | ボタン押下時 | 休日ならスキップ | 即時送信が必要な場合 |
| 休日手動実行（HOLIDAY_TRIAL） | ボタン押下時 | 休日でも実行 | 休日の動作確認・テスト |

## 運用開始前の準備

1. **納入パターンまたは仕入先カレンダの設定**: 納入日判定に使うマスタを設定してください
   - パターン方式: 設定 > 納入パターン設定
   - 仕入先カレンダ方式: 仕入先マスタでカレンダを割り当て
2. **仕入先メール設定**: 仕入先マスタに送信先メールアドレスを登録してください
3. **連絡先マスタ**: 返信先・CCのメールアドレスを連絡先マスタに登録してください
4. **ロット設定**（ロット丸めモードを使う場合）: 製品マスタの最小納入数・納入倍数を確認してください
5. **本画面で設定作成**: 各項目を入力して保存
6. **テスト送信**: 「今すぐ実行」または「休日手動実行」でテスト送信し、メール・添付ファイルの内容を確認

## よくある質問

**Q: 「自動納入リスト送信」とどう違う？**  
A: 「自動納入リスト送信」は納品リスト（仕入先が修正して返送するExcel）を送る機能です。「注文書自動送信」は注文書（計画数量ベース）を生成し、計画として保存した上で送信します。両機能は独立しており、同じ仕入先に対して両方の設定を作ることも可能です。

**Q: 設定を保存したのにメールが送信されない**  
A: 以下を確認してください。
- 「有効」にチェックが入っているか
- 仕入先マスタにメールアドレスが登録されているか
- 送信ファイルが1種類以上ONになっているか
- 当日が休日でスキップされていないか（履歴タブで確認）

**Q: 「今すぐ実行」と「休日手動実行」の違いは？**
A: 「今すぐ実行」は通常実行と同じ休日判定を行います（休日ならスキップ）。「休日手動実行」は休日判定を無視して実行します。どちらも**実際にメールが送信されます**。

**Q: SKIPPEDになった。問題ない？**  
A: 問題ありません。当日が休日、または計算した納入日が納入日でないため、送信をスキップした正常動作です。

**Q: 注文書Excelの数量と日別内訳の合計が一致しない**  
A: ロット丸めモードを使用している場合、発注数量はロットの倍数に丸められるため、日別需要の合計とは一致しないことがあります。これは正常な動作です。

**Q: RUNNINGのまま完了しない**  
A: 30分を超えてRUNNINGが続いた場合、次回実行時に自動的にFAILEDに更新されます。手動で再実行してください。

**Q: 複数の仕入先に自動送信したい**  
A: 仕入先ごとに「新規追加」で設定を作成してください。仕入先ごとに実行時刻や計算モードを個別に設定できます。

**Q: 休日（土日・祝日）にはどうなる？**  
A: 指定時刻にタスクは起動しますが、実行日がダイソウカレンダの休日の場合は送信処理を行わず `SKIPPED` で終了します。休日でも実行したい場合は「休日手動実行」を使ってください。

**Q: ダイソウカレンダが未設定だったら？**  
A: 営業日計算ができないため処理は `FAILED` で終了します。失敗時の通知先に通知が送られます。

**Q: トラック積載判定のデータはどこから来る？**  
A: まず注文書提案データを探し、なければ購買計画データ（LineBacklog sequence_no=1）を使います。どちらもない場合は判定できません。

**Q: 安全在庫の倍率はどう設定すればいい？**  
A: 倍率1.0で最低在庫数そのものが加算されます。例えば1.5倍なら最低在庫数の1.5倍が加算されます。仕入先の納入リスクに応じて調整してください。

**Q: 容器情報が外作納品書PDFに表示されない**  
A: 製品マスタに容器設定が登録されていない製品は、容器情報なしで出力されます。必要に応じて製品マスタの容器設定を確認してください。
