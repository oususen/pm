# 仕入れ実績入力

仕入先からの納入実績を登録する画面です。個別入力と一括入力（計画数コピー／CSV取込）に対応しています。

## 画面への行き方

1. 上のグローバルナビゲーションの「仕入」を開く
2. 「仕入れ管理メニュー」→「仕入れ実績入力」を選択

## 入力方式

### 個別

- 品番を1件ずつ読み取りまたは入力して登録します
- 数量、納入日、備考を確認して登録します

### 一括

- **計画の残数コピー**: 購入先と計画日を選び、「未納残数を入荷数へコピー」で登録します
- **CSV取込**: `資材入荷外注納入一覧表` CSV から品番と入荷数を取り込んで登録します
- どちらの方式も同じ一括登録処理を使用します

## 計画の分納と重複登録防止

- 「計画登録済」は、その計画から登録した実績の合計です。「未納残数」は計画数から計画登録済を引いた数量です。
- 分納では、コピーした入荷数を今回届いた数量に減らして登録します。登録後は残数が更新され、入荷数は空になります。次回も同じ計画を開いて残数をコピーしてください。
- 完納した計画は「登録済み」となり、追加登録できません。未納残数を超える登録もできません。
- 納入日と計画日が違う場合は確認が表示されます。納入日を変更しても元の計画の残数から差し引きます。
- 別画面での登録・訂正などで情報が変わった場合は登録を止めます。「計画を再読込」で最新の残数を確認し、再入力してください。再読込すると未登録の入力内容はクリアされます。
- 通信が切れて結果が不明な場合も再読込し、計画登録済を確認してください。同じ送信の再実行では実績を追加しません。
- 納入実績編集で数量を変更・削除すると残数に反映されます。計画に紐付く実績の仕入先・ライン変更は、削除して正しい計画から登録し直してください。
- **単品登録・CSV・手動追加行・この機能の導入前の実績は、計画登録済に含みません。分納の続きも一括画面の同じ計画から登録してください。導入前に登録した計画は、納入実績を確認して二重登録を避けてください。**

## CSV取込の注意

- CSV取込時は、仕入先・納入日を画面で事前選択しなくても構いません
- CSV内の `仕入先` と `入荷日` を読み取り、画面へ自動反映します
- 1回の取込で扱えるのは **1仕入先・1入荷日** のみです
- 複数の仕入先や複数の入荷日が含まれるCSVは取り込めません

## 登録後の反映

登録すると、次の処理を行います。

1. 納入実績を保存する
2. 対象日の `実績(actual_qty)` を更新する
3. 子部品がある場合は在庫・計画在庫を再計算する
4. 対象仕入先ラインの進度を自動再計算する

一括入力では、全行の登録後に対象品番をまとめて進度再計算します。行数分の進度再計算は行いません。

## 登録工程の判定

- 登録する工程は、納入日時点で有効なルーティングの工程から判定します
- `RoutingStep.output_product` が入荷品番と一致し、外作先またはラインが選択した仕入先と一致する工程を使用します
- `PURCHASE` 工程は購入品、`G` または外作区分の工程は外作品として扱います
- BOMがない品番でも、ルーティングが設定されていれば登録できます
- 対象工程がない場合や異なる工程が複数見つかった場合は登録できません

## 進度自動再計算

- 自動再計算の対象は、**今回入力した製品のみ** です
- 仕入先に紐づく全製品を毎回再計算するわけではありません
- 再計算期間は「自動納入リスト送信」設定の **進度表期間** を使用します
- 設定が未作成の場合は、既定値として **7営業日前 ～ 30日後** を使用します
- 入力・変更・削除した納入日がその開始日より古い場合は、納入日まで開始日を広げます

### 進度表期間の意味

- `何営業日前`
  - 今日から何営業日前までさかのぼって再計算するか
- `何日後`
  - 今日から何日先まで再計算するか

例:

- `7営業日前 ～ 30日後`
  - 過去7営業日分と、今日から30日先までを再計算します

## よくある注意

- 遡って登録した場合でも、入力した納入日に対して実績を反映します
- 進度再計算に失敗しても、実績登録自体は成功します
- 進度表期間を変更したい場合は、「自動納入リスト送信」画面で対象仕入先の設定を変更してください
