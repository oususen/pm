# 仕入れ検収

仕入先からの納入品を検収し、実績を記録する画面です。納入パターンに基づくカバー期間の予定数量を一覧表示し、検収数量を入力して確定します。

## 方式タブ

画面上部で検収方式を切り替えます。

- 進度方式: 従来どおり、需要/計画ベースの予定数量から検収
- 納品リスト: 仕入先から受領したExcel納品リストを取り込み、記載数量で検収

## 画面への行き方

1. 上のグローバルナビゲーションの「仕入」を開く
2. 「仕入れ管理メニュー」→「仕入れ検収」を選択

## 基本的な流れ

1. 仕入先を選択します。
2. 対象日を確認します（デフォルトは当日）。
3. 「検収データ取得」を押してデータを読み込みます。
4. 各製品を三点照合（現物・リスト・納品書）し、「確認済」ボタンを押します。
5. 全製品が確認済みになったら「検収確定」を押します。
6. 数量変更がある場合は「数変更」ボタンで保留し、後から数量を修正して「数変更検収確定」で確定します。

## 画面の見方

### パターン情報バー

| 項目 | 説明 |
|------|------|
| 納入パターン | 仕入先に設定された納入パターン名と種別（例: 「ゼンツー 1回/2日 (N営業日ごと)」）。未設定の場合は「毎日納入」扱い |
| 本日は納入日 / 本日は納入日ではありません | 当日がパターン上の納入日かどうかを表示 |
| 次回納入日 | 次の納入予定日 |
| 進度基準 / 在庫基準 | 予定数量のデータソースを切り替えます |
| 件数表示 | 「フィルタ後件数 / 全件数 / 実績件数」を表示 |

### データ一覧

| 列 | 説明 |
|----|------|
| 品番 | 品番コードと「数変更」ボタン |
| 品名 | 製品名 |
| 予定 | カバー期間の合計予定数量 |
| 確認済 / 検収済 | 三点照合の確認ボタン。検収済み（実績≧予定）の行は「検収済」バッジが表示される |
| 実績 | 既に検収済みの実績数量（読み取り専用） |
| 日別列 | カバー期間の各日の予定数量の内訳 |
| 実数 | 検収する数量を入力する欄。初期値は予定数量。検収済みの行は入力不可 |
| 差異 | 「予定 − 実績」の差。赤字＝不足、青字＝過剰 |
| 備考 | メモ入力欄。初期値は品番 |

### 行の色分け

| 色 | 意味 |
|----|------|
| 黄色 | 数変更（保留）中の品番 |
| 緑色 | 確認済みの品番 |
| グレー | 検収済み（実績≧予定）の品番 |

## 確認済ボタン（三点照合）

各製品行の「予定」列の右に「確認済」ボタンがあります。現物・リスト・納品書の三点照合が完了した製品について押してください。

- 全ての対象製品が確認済みにならないと「検収確定」ボタンは押せません
- 検収済み（実績≧予定）の行は自動的に「検収済」バッジが表示され、確認不要です

## Gフィルタ（品番末尾G）

品番の末尾が「G」で終わるかどうかで製品を絞り込むフィルタです。

| ボタン | 表示対象 |
|--------|----------|
| 全 | 全製品 |
| 有 | 品番末尾がGの製品のみ（外作品） |
| 無 | 品番末尾がGでない製品のみ（購入品） |

仕入先マスタの「仕入先区分」設定に応じて、仕入先選択時にGフィルタの初期値が自動設定されます。

| 仕入先区分 | Gフィルタ初期値 |
|-----------|----------------|
| 外作 | 有 |
| 購入 | 無 |
| 両方 | 全 |

## ダブル検収防止

実績が予定数量以上に達した行は自動的にロックされます。

- 「確認済」ボタン → 「検収済」バッジに変わり操作不可
- 実数入力 → 「-」表示で入力不可
- 検収確定時 → 検収済み行は自動的に除外

## 製品手動追加

リスト外の製品や、検収済み製品の追加納入に対応します。

### 使い方

1. テーブル下の「+ 製品追加」ボタンを押す
2. モーダルで品番・品名を検索する
3. 候補から製品を選択して追加する

### 検収済み製品の追加

既に検収済みの製品を追加する場合は「○○ は検収済みです。追加検収行を作成しますか？」と確認メッセージが表示されます。確認すると、追加分の検収行が作成されます。

### 既存製品の追加

リストに既にある（未検収の）製品を選択した場合は「○○ は既にリストにあります。」と表示されブロックされます。

## 進度基準と在庫基準

| 基準 | 予定数量の意味 |
|------|---------------|
| 進度基準（デフォルト） | 顧客からの需要数量（確定＋内示）。お客様がこの日に必要としている数量 |
| 在庫基準 | 仕入計画の計画数量。仕入れ計画画面で入力した計画値 |

通常は「進度基準」を使用してください。仕入計画と照合したい場合は「在庫基準」に切り替えます。

## フィルタの使い方

| フィルタ | 使い方 |
|----------|--------|
| 品番 | テキスト入力で品番を部分一致で絞り込みます |
| 移動先 | 製品の移動先（INLINE、CWL等）で絞り込みます |
| 後工程 | 仕入れの次工程（外作工程等）で絞り込みます |
| G（全/有/無） | 品番末尾Gの有無で絞り込みます |
| 数変更（全/有/無） | 保留中の品番だけ表示したい場合は「有」を選択 |
| 差異（全/有/無） | 予定と実績に差がある品番だけ表示する場合は「有」を選択 |
| 実績（全/有/無） | 検収済み品番を絞り込む場合に使用 |

## 数変更（保留）の使い方

仕入先が予定と異なる数量で納入した場合や、一部の品番だけ後から検収したい場合に使います。

### 手順

1. 対象品番の「数変更」ボタンを押します → 行が黄色になり、実数が 0 にリセットされます
2. 数変更していない品番を先に「検収確定」で確定します（保留品番は自動的に除外されます）
3. フィルタの数変更を「有」に切り替えます
4. 保留中の品番の実数を実際の納入数量に変更します
5. 「数変更検収確定」を押して確定します → 保留状態が自動的に解除されます

### 注意事項

- 保留状態はブラウザに保存されるため、ページをリロードしても消えません
- 保留状態は仕入先＋日付の組み合わせで管理されます
- 「数変更」ボタンをもう一度押すと保留を解除できます（実数が予定数に戻ります）

## 検収確定

「検収確定」を押すと、対象品番の実績が記録されます。

- 全対象品が「確認済」にならないと検収確定ボタンは押せません
- 検収済み（実績≧予定）の品番は自動的に除外されます
- 検収者にはログイン中のユーザー名が自動で記録されます
- 確定後、自動的に最新データが再読み込みされます

## 検収履歴

「検収履歴」ボタンを押すと、選択中の仕入先・日付の検収レコード一覧が表示されます。

| 列 | 内容 |
|----|------|
| 日時 | 検収した日時 |
| 品番 | 品番コード |
| 品名 | 製品名 |
| 数量 | 検収数量 |
| 検収者 | 検収を行ったユーザー名 |
| 備考 | 入力した備考 |

## Excel出力

「Excel出力」ボタンを押すと、現在フィルタ後の一覧を Excel ファイルとしてダウンロードします。ファイル名は「仕入れ検収_{仕入先コード}_{日付}.xlsx」です。

## 納品リスト方式

納品リスト方式は、1ファイルを「1仕入先・1日」で運用します。  
メール自動受信は行わず、画面から手動アップロードします。

### 使い方

1. 仕入先を選択し、対象日を確認します。
2. 「納品リストテンプレ出力」を押します。
3. 出力されたテンプレに数量・納品日・伝票番号を入力します。
4. Excelを取り込みます。
5. 取り込み一覧を確認し「納品リスト検収確定」を押します。

### テンプレ列

- 品番
- 品名
- 数量
- 納品日
- 仕入先コード
- 伝票番号

### 取込時の判定

- 品番が仕入先対象外の場合: エラー表示して除外
- 仕入先コード不一致の場合: エラー表示して除外
- 数量が1未満の場合: エラー表示して除外
- 同一品番が複数行ある場合: 数量を合算して1行にまとめる

## よくある質問

**Q: 予定数量が 0 なのにデータが表示されない**
A: 進度基準では顧客需要（確定＋内示）が 0 の品番は表示されません。在庫基準に切り替えて確認してください。

**Q: 保留を間違えて押してしまった**
A: もう一度「数変更」ボタンを押すと保留が解除され、実数が予定数に戻ります。

**Q: 一度検収した品番をもう一度検収できますか？**
A: 検収済み（実績≧予定）の行は自動的にロックされます。追加納入の場合は「+ 製品追加」ボタンから同じ品番を追加してください。確認メッセージが出た後、追加検収行が作成されます。

**Q: リストにない製品が届いた場合は？**
A: 「+ 製品追加」ボタンから品番を検索して追加できます。
