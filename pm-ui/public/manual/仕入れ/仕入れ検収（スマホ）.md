# 仕入れ検収（スマホ）

スマートフォンで仕入先からの納入品を品番ごとに検収し、入荷実績を登録する画面です。カメラでQRコードを読み取ると、対象品番の入荷数を入力できます。

[作業手順書（日本語）](/manual/仕入れ/仕入れ検収（スマホ）_作業手順書.html)

## 画面への行き方

1. 上のグローバルナビゲーションから「仕入」を開きます。
2. 「仕入れ管理メニュー」を選択します。
3. 「仕入れ検収（スマホ）」を選択します。

## 基本の流れ

1. 仕入先を選択します。
2. 対象日を確認または変更します。仕入先を選ぶと、その日のデータを読み込みます。
3. 「納入リスト」または「進度方式」を選びます。
4. 現物・納品書・画面の予定数を照合します。
5. 数量が予定どおりなら、その品番の「検収」を押します。
6. 数量が異なる場合は「分納」または「数変更」を使って数量を設定してから「検収」を押します。

検収は品番ごとに確定します。確定後は、その品番の実績数に反映されます。

## 方式の選び方

| 方式 | 使用する予定データ |
|---|---|
| 納入リスト | 「納入予定」画面で登録済みの納入予定 |
| 進度方式 | 需要・計画を基に算出した予定数量 |

通常は「納入リスト」が初期表示されます。登録済みの納入予定と照合する場合は、そのまま使用してください。

## 画面の見方

| 項目 | 説明 |
|---|---|
| 予定 | 今回検収する予定数量 |
| 実績 | すでに登録済みの検収数量 |
| 差異 | 予定と実績の差。赤字は不足、青字は過剰です |
| 実数 | 今回入荷した数量。未変更時は未検収の残数が入っています |
| 検収済 | 実績が予定数量に達した品番です。再入力は不要です |
| 保留 | 数変更中の品番です |

## QRコードで数量を入力する

1. 画面右下のQRボタンを押します。
2. カメラの利用を許可します。
3. 納入品のQRコードを枠内に表示します。
4. 該当する品番カードへ移動し、「実数」にQRの数量が入力されます。
5. 数量を確認して「検収」を押します。

QRコードの品番が現在の一覧にない場合は、検収できません。仕入先・対象日・方式が正しいか確認してください。

## 数量が予定どおりの場合

1. 品番カードの予定数と現物を照合します。
2. 「実数」が入荷数と一致していることを確認します。
3. 「検収」を押します。

## 分納・数量変更・未納の場合

### 分納

一部だけ入荷した場合は、次のように操作します。

1. 品番カードの「分納」を押します。
2. 今回の入荷数を入力します。
3. 「検収」を押します。

検収後、残数がある品番は次回の検収対象として残ります。

### 数変更

予定数と異なる数量を検収する場合は、次のように操作します。

1. 「数変更」を押します。
2. 「実数」に今回の入荷数を入力します。
3. 「検収」を押します。

数量を0で検収する場合は確認メッセージが表示されます。内容を確認して確定してください。

### 未納

入荷がなかった場合は、数変更中の品番で「未納」を押します。「実数」は0になり、備考に「未納」が設定されます。内容を確認して「検収」を押してください。

## 絞り込み

「絞り込み」を開くと、品番、移動先、G、数変更、差異、実績でカードを絞り込めます。対象品番が多いときや、数変更・未納の品番を確認するときに使用します。

## 注意事項

- 検収前に、現物・納品書・画面の予定数を必ず照合してください。
- 「検収済」と表示された品番は、予定数量までの検収が完了しています。
- カメラが起動しない場合は、ブラウザのカメラ権限を許可してから再度QRボタンを押してください。
- PCで一括検収や履歴確認を行う場合は、[仕入れ検収](仕入れ検収.md)を参照してください。
