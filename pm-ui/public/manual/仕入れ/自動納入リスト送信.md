# 自動納入リスト送信

仕入先へ納品リスト（数量入りExcel）と進度表を自動でメール送信するための設定画面です。
設定した時刻に毎日自動実行され、事務員の手作業を削減します。

## 画面への行き方

1. 上のグローバルナビゲーションの「仕入」を開く
2. 「仕入れ管理メニュー」→「業務自動タスク」カテゴリ →「自動納入リスト送信」を選択

## 基本的な流れ

1. 「新規追加」ボタンで設定を作成します
2. 仕入先・実行時刻・各項目を入力して保存します
3. 保存後、毎日指定時刻にシステムが自動で納品リストを送信します
4. 送信結果は一覧の「ステータス」「メッセージ」列で確認できます

## 一覧画面の見方

| 列 | 説明 |
|----|------|
| 仕入先 | 対象の仕入先コード・名称 |
| 実行時刻 | 毎日の自動実行時刻 |
| 納入日 | 実行日から何営業日後 |
| 有効 | 自動送信のON/OFF |
| CC送信先 | 業務員のメールアドレス |
| 最終実行 | 最後に実行した日時 |
| ステータス | SUCCESS=成功 / FAILED=失敗 / SKIPPED=スキップ / RUNNING=実行中 |
| メッセージ | 実行結果の詳細 |

## 設定項目の説明

### 仕入先

自動送信する仕入先を選択します。1社につき1設定です。同じ仕入先の設定を重複して作成はできません。

### 実行時刻

毎日何時何分に自動実行するかを設定します。  
例: 7時00分 → 毎朝7時に実行

### 納入日（実行日から何営業日後）

何営業日後を納入日とするかを設定します。土日祝は自動的にスキップされます。  
例: 4営業日後 → 月曜実行なら金曜が納入日

### 進度表期間

添付する進度表の表示範囲を設定します。

- **何営業日前**: 今日から何営業日さかのぼるか（過去の進度推移を見るため）
- **何日後**: 発行日から何日先まで表示するか

例: 5営業日前 ～ 30日後

開始側は発行日から営業日でさかのぼり、終了側は発行日から暦日で進めて計算します。
初期値は **7営業日前 ～ 30日後** です。
この設定は、自動納入リスト送信前の進度再計算だけでなく、「仕入れ実績入力」で実績登録した直後の自動進度再計算にも使用されます。
ただし、仕入れ実績入力後の自動進度再計算は、仕入先の全製品ではなく **今回入力した製品だけ** を対象にします。

### 有効

チェックを外すと自動送信を一時停止できます。設定は保持されるので、再開時はチェックを入れるだけです。

### 返信先メールアドレス（Reply-To）

仕入先が修正済みExcelを返送する先のメールアドレスです。  
送信メールは送信専用アドレスから送られるため、ここに返送先を設定してください。  
メール本文にもこのアドレスが明記されます。  
連絡先マスタから検索して1件選択します。

### 業務員CC送信先メール

送信メールのCC（控え）に入れるメールアドレスです。  
業務員も送信内容を確認できるようにするために設定します。  
連絡先マスタから検索して複数件追加できます。

### 失敗時の通知先

メール送信に失敗した場合に、社内通知を受け取るユーザーを設定します。  
社員コードまたは氏名で検索してチップを追加します。複数人設定可能です。

### 納入日でないときの通知先

計算した納入日がパターン上の納入日でなかった場合に、社内通知を受け取るユーザーを設定します。  
納入パターンが未設定の場合もこの通知先に通知されます。

## 操作ボタン

| ボタン | 説明 |
|--------|------|
| 新規追加 | 新しい仕入先の設定を作成 |
| 編集 | 既存設定を変更 |
| 削除 | 設定を削除して自動送信を停止 |
| 今すぐ実行 | 即時テスト実行。**実際にメールが送信されます** |

## 送信されるファイル

自動送信時、以下の4ファイルがメールに添付されます。

### 1. 納品リスト（Excel）

仕入先が確認・修正して返送するメインのファイルです。4シート構成:

- **納品リスト**: 品番・品名・移動先・数量（自動計算済み）・日別内訳・納品日
- **確認・修正方法**: 仕入先向けの操作説明
- **製品リスト**: 品番追加時にコピーするための全製品一覧
- **納品リスト印刷用**: ダイソウ工業宛ての印刷用納品書（A4縦、No.・品番・品名・数量・単価・金額・備考の一覧 + 合計行 + 受領/納入先サイン欄）

納品リストの並び順は `移動先` 優先で、`社内塗装 → CWL → 興和 → 直納 → 社内ライン`、同じ移動先内は品番順です。

### 2. 進度表（Excel）

全製品の進度状況を日付別に一覧で確認できるExcelです。`内示 / 確定 / 計画 / 実績 / 進度 / 計進` の6行が製品ごとに表示されます。

- `内示`: 顧客からの予定需要です。まだ確定していない見込み数量です。
- `確定`: 顧客から正式確定された需要です。出荷・生産として確実に必要な数量です。
- `計画`: その日納入予定の数量です。
- `実績`: その日納入された数量です。
- `進度`: 納入が需要に対してどれだけ先行/遅れしているかを表す差分です。
- `計進`: 納入計画ベースでの進度です。納入計画数量まで含めた進み具合を見るための数です。発行日の納入実績は計算されません。

左側には `当月` と `翌月` の合計列があります。`内示 / 確定 / 計画 / 実績` は月合計を表示し、`進度 / 計進` は月合計を表示しません。

### 3. 進度表（PDF）

同じ進度表のPDF版です。印刷・閲覧用です。月合計列は表の左側に配置されます。

### 4. 外作納品書（PDF）

品目ごとに「納品書」「受領書」「購入先控」の3枚組がセットになったPDFです。A4横で1ページ3品目。仕入先が納品時に添付して使います。各セットにQRコード（品番・納品日・数量）が含まれます。

## ステータスの意味

| ステータス | 意味 | 対応 |
|-----------|------|------|
| SUCCESS | 送信完了 | 対応不要 |
| FAILED | 送信失敗 | メッセージ欄でエラー内容を確認。設定を修正して再実行 |
| SKIPPED | スキップ | 該当日が納入日でないため送信しなかった。正常動作 |
| RUNNING | 実行中 | しばらく待つと完了する |

## 運用開始前の準備

1. **納入パターン設定**: 仕入先の納入スケジュールを設定してください（設定 > 納入パターン設定）
2. **仕入先メール設定**: 仕入先マスタに送信先メールアドレスを登録してください
3. **本画面で設定作成**: 各項目を入力して保存
4. **テスト送信**: 「今すぐ実行」でテスト送信し、メール・添付ファイルの内容を確認

## 納入予定画面での手動出力

納入予定画面（仕入れメニュー →「納入予定」）では、以下のボタンで手動出力ができます。

| ボタン | 説明 |
|--------|------|
| 納品リスト出力 | 数量入りExcelをダウンロード。仕入先に送付して確認・修正してもらう |
| 進度再計算 | 出力前に進度を最新化する |
| 進度表Excel | 進度表Excelをダウンロード |
| 進度表PDF | 進度表PDFをダウンロード |
| 納品書PDF | 外作納品書PDF（納品書・受領書・購入先控の3枚組）をダウンロード |
| 返送Excel取込 | 仕入先から返送されたExcelを取り込む |

自動送信に登録していない仕入先でも、これらのボタンで手動出力・送付が可能です。

- 手動出力では、先に「進度再計算」を実行する必要があります。
- 「納品リスト出力 / 進度表Excel / 進度表PDF / 納品書PDF」は、進度再計算完了後に押せます。

## 仕入先からExcelが返送されたら

1. 仕入れメニュー →「納入予定」画面を開く
2. 仕入先を選択
3. 返送されたExcelを「ファイルの選択」で取り込む
4. 内容を確認して「納入予定保存」を押す
5. 検収時は「仕入れ検収」画面の「納入リスト」タブで検収確定

## よくある質問

**Q: 設定を保存したのにメールが送信されない**  
A: 「有効」にチェックが入っているか確認してください。また、仕入先マスタにメールアドレスが登録されているか確認してください。

**Q: 「今すぐ実行」したらメールが届いた。毎日自動でも同じものが届く？**  
A: はい。設定時刻に毎日同じ処理が実行されます。ただし数量は毎日最新の需要データで再計算されます。

**Q: SKIPPEDになった。問題ない？**  
A: 問題ありません。計算した納入日がパターン上の納入日でなかったため、送信をスキップした正常動作です。

**Q: CC送信先を後から追加・変更したい**  
A: 「編集」ボタンから設定を開き、CC送信先メール欄で連絡先マスタから候補を追加・削除して保存してください。

**Q: 複数の仕入先に自動送信したい**  
A: 仕入先ごとに「新規追加」で設定を作成してください。仕入先ごとに実行時刻や営業日数を個別に設定できます。

**Q: 休日（土日・祝日）にはどうなる？**  
A: 指定時刻にタスクは起動しますが、実行日がダイソウ工業の休日（土日・祝日など）の場合は送信処理を行わず `SKIPPED` で終了します。この場合、仕入先へのメール送信は行わず、「納入日でないときの通知先」に `本日は休日のため、自動納入リストは実行しません` という通知を送ります。

**Q: ダイソウカレンダーが未設定だったら？**  
A: 営業日計算ができないため処理は `FAILED` で終了します。仕入先へのメール送信は行わず、「失敗時の通知先」に `ダイソウカレンダーが未設定のため、自動納品リスト実行できません` という通知を送ります。

**Q: カバー期間に休日が含まれる場合は？**  
A: カバー期間は「今回の納入日～次回納入日の前日」の全日です。土日・祝日もスキップせず含まれます。例えば金曜納入→月曜納入なら、カバー期間は金・土・日の3日間です。

**Q: 営業日の判定にはどのカレンダーを使っている？**  
A: ダイソウ工業の営業日カレンダー（daisoカレンダー）を使用しています。納入日の計算（実行日からN営業日後）と進度表の日付計算に使われます。

**Q: 納入先の納入日を一時的に変更したい場合は？**  
A: 納入パターン設定の「開始基準日」を変更してください。開始基準日を変更すると、次回以降の納入日が再計算されます。一時的な変更後は元に戻すことを忘れないようにしてください。
