# 仕入計画入力

仕入先別の購入計画を日付ごとに入力する画面です。需要・実績・在庫を参照しながら計画数量を入力します。

## 画面への行き方

1. 上のグローバルナビゲーションの「購買」を開く
2. 「購買メニュー」→「仕入計画入力」を選択

## 使い方

1. 仕入先、表示開始日、期間を選択します。
2. 「表示のみ」または「需要取込」を押してデータを読み込みます（定時タスクで計算済みの場合は「表示のみ」で十分です）。
3. 計画欄に数量を入力します。
4. 「保存」を押して登録します。

## 画面の見方

- 1日分が7列（需要、実績、在庫、計画、計庫、進度、計進）で表示されます。
- 計画は入力欄、それ以外は参照値です。
- 行は品番ごとに表示されます。

### 用語の説明

- **需要**: 後工程の生産計画などから計算された、この日に必要とされる部品の数量です。
- **実績**: この日に実際に入荷した数量です。
- **在庫**: 現時点の在庫数量です。
- **計画**: ユーザーが入力する、この日に入荷を予定する数量です。
- **進度**: 顧客需要に対して実績が遅れているか先行しているかを表す指標です。ラインの計画とは関係なく、顧客の需要（確定/内示）に対する実績の状況を示します。
- **計庫**: 計画在庫（計画通りに入荷した場合の在庫予測）
- **計進**: 計画進度（計画通り納入した場合、お客様の需要に対する過不足予測）

## ツールバー

### フィルタ・設定

| 項目 | 説明 |
|------|------|
| 仕入先 | 対象仕入先を選択 |
| 表示開始日 | グリッドの表示開始日を設定 |
| 期間 | 表示日数を 30日 / 60日 / 90日 / 120日 から選択（デフォルト: 30日） |
| 検索 | 品番・品名でグリッド行を絞り込み |

### ボタン

| ボタン | 説明 |
|--------|------|
| クリア | 表示中の全行を削除 |
| 自動計画 | 需要をそのまま計画値に一括コピー |
| 計画変更 | ロック期間内の計画を変更する際に変更理由を入力するダイアログを表示。理由を入力して「確定」すると、ロック期間内のセルが編集可能になります |
| 保存 | 計画データをサーバーに保存。保存後は在庫再計算が自動実行されます |
| 表示のみ | 計算なしでデータを取得して表示します。定時タスクで最新化済みの場合はこちらで十分です（F4） |
| 需要取込 | 購買需要を再計算（pickup）してからデータを表示します。需要だけ最新化したい場合に使用します（F6） |
| 取込＋在庫計算 | 購買需要の再計算に加え、在庫・計画在庫の再計算も実行してからデータを表示します（F8） |

### フッターショートカットキー

| キー | 説明 |
|------|------|
| F4 | 表示のみ（計算なしでデータ取得・表示） |
| F6 | 需要取込（購買需要を再計算してから表示） |
| F8 | 取込＋在庫計算（需要＋在庫・計画在庫を再計算してから表示） |

## 計画変更（ロック期間の編集）

通常、過去の計画はロック期間として編集できません。ロック期間内の計画を修正する場合は以下の手順で行います。

1. 「計画変更」ボタンをクリック
2. 変更理由入力ダイアログが表示される
3. 変更理由を入力して「確定」をクリック
4. ロック期間内のセルが編集可能になる
5. 計画を修正して「保存」

## 操作のポイント

- 「クリア」は表示中の行を削除します。
- キーボードの矢印キーと Enter で入力セルを移動できます。
- 「自動計画」で需要をそのまま計画値に一括コピーできます。既存の計画がある場合は上書き確認が出ます。

## 注意点

- 仕入先を選択しないと保存・取り込みはできません。
- 需要は「需要取込」実行時の表示期間（開始日〜期間）で集計した値です。期間を変えて取り込み直すと需要が変わります。
- 保存後は在庫再計算が実行されます。


## 計画数のロック

仕入先を選択して計画を表示し、「🔒ロック」を押してから日付×製品の計画セルをクリックします。
保存済みの計画数が固定され、黄色背景と🔒マークが表示されます。ゼロの計画も固定できます。
自動計画では固定した数量を使います。ロック中の計画数は編集できません。
変更する場合は **解除→編集→保存→再ロック** の順に操作してください。未保存の数量はロックできません。
ロック済み計画を含む日を一括削除する場合も、先に解除が必要です。
