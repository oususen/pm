発注業務 作業手順書

外作・購入品の注文書を作成し、承認を経て購入先へ送信するまでの手順です。
仕入 ▶ 仕入れ管理メニュー ▶ 発注業務

手順の流れ

  • 1注文書を作成する
  • 2明細を入力する
  • 3業務員サインをする
  • 4承認する（班長・係長・部長）
  • 5注文書PDFを作成する
  • 6購入先へ送信する
  • !差戻・キャンセルの対応

承認フロー 全体像

作成中→ 業務員サイン→ 班長承認→ 係長承認→ 部長承認→ 購入先送信
ステップ担当内容
1. 注文書作成業務員仕入先を選び、明細（品番・数量）を入力
2. 業務員サイン業務員内容を確定し承認フローを開始
3. 班長承認班長タスク通知を受け、承認 or 差戻
4. 係長承認係長タスク通知を受け、承認 or 差戻
5. 部長承認事業部長最終承認（代理承認者も可）
6. 注文書作成業務員注文書PDFを作成
7. 購入先送信業務員PDF添付メールを購入先へ送信
1

注文書を作成する

仕入れ管理メニューから発注業務を開き、新規作成します。

仕入→仕入れ管理メニュー→発注業務→新規作成
  1. 「新規作成」ボタンを押します。
  2. 仕入先を選択します（必須）。
  3. 発注日を確認します（初期値は当日）。
  4. 希望納入日を入力します（任意）。
  5. 備考があれば入力します。
  6. 「作成」を押すと詳細画面に遷移します。
2

明細を入力する

品番と発注数量を入力します。自動提案を使うと不足品を自動で提案できます。

自動提案（推奨）

  1. 「次回納入日」を入力します（自動提案の基準日）。
  2. 提案ボタンを押します。
ボタン基準説明
進度から提案進度顧客需要に対する進度の遅れから不足品を算出
計画進度から提案計画進度計画進度ベースで不足品を算出
計画在庫から提案計画在庫安全在庫を下回る品目を算出
ℹ自動提案は在庫・進度を最新に再計算してから実行されます。提案結果は手動で修正できます。

手動入力

  1. 「行追加」ボタンで明細行を追加します。
  2. 品番・購買ラインを選択します。
  3. 発注数を入力します。
  4. 「保存」を押して下書き保存します。
⚠「次回納入日」が未入力だと自動提案ボタンは押せません。先に次回納入日を入力してください。
3

業務員サインをする

明細の内容が確定したら業務員サインを行い、承認フローを開始します。

  1. 明細の内容を最終確認します。
  2. 「業務員サイン」ボタンを押します。
  3. 班長に承認タスクが自動通知されます。
⚠サイン後は明細の編集ができなくなります。修正が必要な場合は差戻してもらう必要があります。
ℹ明細が1件もない状態ではサインできません。
4

承認する（班長・係長・部長）

自分のタスクに承認待ちが届いたら、内容を確認して承認します。

  1. タスク受信箱またはメール通知から対象の注文書を開きます。
  2. 明細と承認履歴を確認します。
  3. 問題なければ「承認」ボタンを押します。
  4. 承認コメントを入力して確定します（任意）。
  5. 次のレベルの承認者に自動通知されます。
!問題がある場合は「差戻」ボタンを押し、差戻理由を入力してください（必須）。作成者に差戻通知が届きます。
5

注文書PDFを作成する

最終承認後、正式な注文書PDFを作成します。

  1. ステータスが「最終承認済」の注文書を開きます。
  2. 「注文書作成」ボタンを押します。
  3. PDFが新しいタブで表示されます（ポップアップ不可時はダウンロード）。
  4. 内容を確認します。
ℹ承認前でも「注文書プレビュー」ボタンでPDFを確認できます。押印欄は正式版のみ表示されます。
6

購入先へ送信する

注文書PDFを添付したメールを購入先に送信します。

  1. 「購入先へ送信」ボタンを押します。
  2. 送信ダイアログで宛先・件名・本文を確認します。
  3. 必要に応じて内容を編集します。
  4. 「送信」を押します。
  5. 送信完了後、ステータスが「送信済」に変わります。
項目初期値編集
宛先仕入先マスタの注文書メールアドレス可
CC注文書メール設定で登録済みの社内担当者不可（読み取り専用）
件名【発注書】注文書番号 仕入先名可
本文テンプレートから自動生成可
⚠仕入先マスタに送信メールアドレスが設定されていない場合、送信ボタンを押すとエラーになります。マスタ管理で事前に設定してください。
!

差戻・キャンセルの対応

差戻された場合（業務員）

  1. 注文書一覧で「差戻」ステータスの注文書を開きます。
  2. 承認履歴のコメントで差戻理由を確認します。
  3. 明細を修正して「保存」します。
  4. 「業務員サイン」で再提出します。

キャンセルする場合（部長・代理承認者のみ）

  1. ステータスが「最終承認済」の注文書を開きます。
  2. 「キャンセル」ボタンを押します。
  3. キャンセル理由を入力します（任意）。
  4. ステータスが「キャンセル」に変わります。
!キャンセルは元に戻せません。管理者のみ「管理者リセット」でステータスを作成中に戻すことができます。
