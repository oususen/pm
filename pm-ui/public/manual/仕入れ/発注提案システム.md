# 発注提案システム 操作マニュアル

---

## 概要

発注提案システムは、仕入先ごとに設定した発注タイミングになると自動でタスクを生成し、
業務員→班長→係長→事業部長の4段階の承認フローを経て、事務員が購入先へ発注する仕組みです。

### 全体の流れ

| ステップ | 担当 | 内容 |
| --- | --- | --- |
| 1 | **システム（毎朝自動）** | 発注タイミングに該当する仕入先を検知 |
| 2 | **業務員** | タスク通知を受信 → 発注提案書を作成・内容確認・サイン |
| 3 | **班長** | 承認タスク通知を受信 → 承認 or 差戻 |
| 4 | **係長** | 承認タスク通知を受信 → 承認 or 差戻 |
| 5 | **事業部長** | 最終承認タスク通知を受信 → 最終承認 |
| 6 | **作成者** | 送信タスク通知を受信 → 注文書作成（PDF）→ 購入先へ送信 |

---

## 事前設定（管理者）

発注提案システムを使用する前に、以下の3つの設定が必要です。

### 0. 仕入先マスタ（送信メールアドレス）

**メニュー：マスタ管理 → 仕入先マスタ**

1. 対象仕入先を編集
2. 「送信メールアドレス」に購入先の宛先メールを設定
3. 保存

> 「購入先へ送信」ボタンはこのメールアドレス宛にPDF添付で送信します。

### 1. 発注スケジュール設定

**メニュー：設定 → 発注スケジュール設定**

仕入先ごとに発注タイミングを設定します。

#### 設定手順

1. 「新規」ボタンをクリック
2. 以下の項目を入力して「保存」

| 項目 | 説明 |
| --- | --- |
| 仕入先 | 発注対象の仕入先を選択 |
| パターン | 発注タイミングのパターン（下表参照） |
| LT(日) | 発注から納入までのリードタイム日数（仕入先カレンダーの営業日換算） |
| 有効 | チェックを外すと一時停止 |
| 備考 | メモ |

#### パターン種別

| パターン | 設定例 | 使い方 |
| --- | --- | --- |
| 月の第N週の曜日 | 第2火曜日 | 「第N週」と「曜日」を選択 |
| 毎月日付 | 毎月15日 | 「日付」を入力（例：15） |
| 毎週曜日 | 毎週月曜日 | 「曜日」を選択 |

> **注意**：設定した日が自社の休日（ダイソウカレンダー）の場合、直前の営業日に自動で繰り上がります。

---

### 2. 承認者設定

**メニュー：設定 → 発注承認者設定**

各承認レベルに担当者を割り当てます。

#### 設定手順

1. 設定画面を開く
2. 各レベルの「承認可能ユーザー」欄に担当者を追加
   - 検索欄に社員コード・氏名・ユーザー名を入力
   - 候補一覧からクリック（または Enter で先頭候補を追加）
   - 追加されるとチップ表示され、`×` で削除可能
3. 必要に応じて「通知先ユーザー」（承認者以外に通知したい場合）も設定
4. レベル4（事業部長）では「代理承認者」欄に部長代理承認者を設定可能
   - 係長承認後、代理承認者には詳細画面で「部長代理承認」ボタンが表示されます
5. 「保存」ボタンをクリック

#### 承認レベル

| レベル | 役割 | 操作内容 |
| --- | --- | --- |
| 1 | 業務員 | 発注提案書を作成・内容確認・サイン |
| 2 | 班長 | 内容を確認して承認 or 差戻 |
| 3 | 係長 | 内容を確認して承認 or 差戻 |
| 4 | 事業部長 | 最終確認・最終承認（代理承認者設定可） |

> 事業部長承認後の「送信」担当は「通知先ユーザー」欄に設定してください。

---

## 業務員の操作

### タスクを確認する

毎朝、システムが発注タイミングを確認します。発注日に該当する仕入先がある場合、業務員に通知が届きます。

- **右上「タスク」 → タスク受信箱** を開く
- 状態を「未対応」、タスク種別を「発注提案書作成」にして確認
- または **通知** で「発注提案書作成タスクが生成されました」を確認

---

### 発注提案書を作成する（手動作成）

タスクが自動生成されず手動で作成する場合：

1. 「仕入れ管理 → 発注提案」を開く
2. 「新規作成」ボタンをクリック
3. 以下を入力して「作成」

| 項目 | 説明 |
| --- | --- |
| 仕入先 | 発注先の仕入先を選択（必須） |
| 発注日 | 発注日を選択（デフォルト：今日） |
| 希望納入日 | 空欄の場合、LT設定から自動計算 |
| 備考 | 特記事項があれば入力 |

---

### 明細を入力する

発注提案書の詳細画面で明細（何をいくつ発注するか）を設定します。

#### 自動提案を使う場合（推奨）

1. 詳細画面で提案元を選んでボタンをクリック
   - 先に「参照日数」を入力（1〜365日、初期値30日）
   - 「進度から提案」
   - 「計画在庫から提案」
2. 選んだ基準で不足数を計算し、発注数量を自動入力
   - 希望納入日は自動提案では変更されません
3. 内容を確認して修正が必要な場合は手動で修正

> 「進度から提案」: 進度がマイナスの不足分を提案します。  
> 「計画在庫から提案」: 計画在庫が最小在庫数を下回る不足分を提案します。

#### 手動入力する場合

1. 「行追加」ボタンで明細行を追加
2. 各行に以下を入力

| 項目 | 説明 |
| --- | --- |
| 品番 | 発注する品番を選択 |
| 購買ライン | 対象の購買ラインを選択 |
| 不足日 | 在庫が不足する予定日（任意） |
| 不足数 | 不足する数量（任意） |
| 発注数 | 実際に発注する数量（必須） |
| 備考 | 行ごとのメモ |

3. 「保存」ボタンで下書き保存

---

### 業務員サインをする

明細の内容が確定したら業務員サインを行います。サイン後は内容の編集ができなくなります。

1. 詳細画面で内容を最終確認
2. 「業務員サイン」ボタンをクリック
3. 班長に承認タスクが自動通知されます

> **注意**：明細が1件もない状態ではサインできません。

### 班長通知先の決まり方（重要）

業務員サイン時の班長通知先（`APPROVE_L2`）は、次の順で決まります。

1. 承認者設定のレベル2（班長）「承認可能ユーザー」を基準にする
2. 作成者と同じ班の班長（role=supervisor）がいれば優先して割り当てる
3. 同じ班の班長がいない場合は、レベル2の設定ユーザーにフォールバックする
4. レベル2の「通知先ユーザー」に登録したユーザーにも通知する

---

### 差戻された場合

差戻通知が届いた場合：

1. 発注提案書一覧から対象の提案書を開く（ステータス：差戻）
2. 承認履歴のコメントで差戻理由を確認
3. 内容を修正して「保存」→「業務員サイン」で再提出

---

## 班長・係長・事業部長の操作

### 承認タスクを確認する

前のレベルが承認すると、通知が届きます。

- **右上「タスク」 → タスク受信箱** を開く
- 班長が確認する場合は、タスク種別を「班長承認（APPROVE_L2）」にして検索

---

### 承認する

1. 一覧から対象の提案書の「詳細」をクリック
2. 明細・承認履歴を確認
3. 問題なければ「承認」ボタンをクリック
4. 承認コメントを入力（任意）して確定
5. 次のレベルへ自動通知

---

### 差戻する

内容に問題がある場合：

1. 詳細画面で「差戻」ボタンをクリック
2. **差戻理由を入力（必須）**
3. 作成者（業務員）に差戻通知が自動送信される

---

## 作成者の操作

### 送信タスクを確認する

事業部長が最終承認すると、まず作成者に「注文書作成」タスクが届きます。
注文書作成後に「購入先送信」タスクへ進みます。

**メニュー：仕入れ管理 → 発注提案 → ステータス「最終承認済」で検索**

---

### 発注書を購入先へ送信する

1. 対象の提案書の「詳細」を開く（ステータス：最終承認済）
2. 明細・承認履歴を確認
3. 「注文書作成」ボタンを押してPDFを作成（新規タブ表示。ポップアップ不可時はダウンロード）
   - 出力帳票は「購入品注文書」フォーマットです。
   - 押印欄は「承認」「確認」「作成」で表示されます。
   - 作成欄は作成者の姓、確認欄は班長/係長承認者を表示します（確認者が複数なら確認欄も増えます）。
   - 部長代理承認時は承認欄に「姓(代)」と表示されます。
4. 注文書作成タスクが完了し、購入先送信タスクが作成される
5. 「購入先へ送信」ボタンが表示されるので押す
6. 送信ダイアログで「宛先メールアドレス」「件名」「本文」を確認・必要に応じて編集（本文には作成者名・作成者メールが初期表示）
7. 「送信」ボタンを押すと、PDF添付メールが送信される
8. 送信時にPDFが `pm_backend/media/purchase_orders/{年}/{月}/{仕入先コード}/` に保存される
9. 送信成功後、ステータスが「送信済」に更新される

## 発注提案書の一覧画面

**メニュー：仕入れ管理 → 発注提案**

### フィルター機能

| フィルター | 説明 |
| --- | --- |
| 仕入先 | 特定の仕入先で絞り込み |
| ステータス | 承認状況で絞り込み |
| 発注日From/To | 発注日の期間で絞り込み |
| 自分のタスクのみ | 自分に割り当てられた対応待ちの提案書のみ表示 |

### 一覧の操作

- 「詳細」: 提案書詳細を開く
- 「削除」: ステータスが「作成中」かつ作成者本人の行にのみ表示され、削除可能

### ステータス一覧

| ステータス | 意味 |
| --- | --- |
| 作成中 | 業務員が編集中（サイン前） |
| 業務員サイン済 | 班長の承認待ち |
| 班長承認済 | 係長の承認待ち |
| 係長承認済 | 事業部長の最終承認待ち |
| 最終承認済 | 作成者が購入先へ送信待ち |
| 送信済 | 購入先への送信完了 |
| 差戻 | いずれかのレベルで差戻（業務員が修正中） |
| キャンセル | 発注キャンセル |

---

## 発注タスク一覧画面

**メニュー：右上「タスク」 → タスク受信箱**

### できること

- 自分宛タスクの一覧確認（未対応/完了/スキップ）
- タスク種別での絞り込み（発注提案書作成、注文書作成、班長承認、係長承認、事業部長承認、購入先送信）
- 「提案書へ」ボタンで対象提案書詳細へ遷移

### 班長の `APPROVE_L2` 確認手順

1. 発注タスク一覧を開く
2. 状態を「未対応」、タスク種別を「班長承認（APPROVE_L2）」に設定して検索
3. 該当行が表示されれば、班長承認待ちタスクが割り当てられている

## よくある質問

**Q: 発注タイミングになっても通知が来ない**

- 設定 → 発注スケジュール設定で「有効」にチェックが入っているか確認
- 設定 → タスク設定で「発注タイミング日次チェック」が有効・時刻設定されているか確認
- 設定 → 発注承認者設定でレベル1（業務員）にユーザーが登録されているか確認

**Q: 自動提案で明細が生成されない**

- 対象品番の在庫引当マスタに「最小在庫数」が設定されているか確認（在庫/残量一覧画面）
- 対象品番のLineBacklogに将来の計画在庫データがあるか確認
- 品番マスタに「発注倍数」「最小発注数」が適切に設定されているか確認

**Q: 差戻後に再提出したい**

- 詳細画面でステータスが「差戻」の場合、内容を修正して「保存」→「業務員サイン」で再提出できます

**Q: 「購入先へ送信」できない**

- 仕入先マスタの「送信メールアドレス」が設定されているか確認
- 自分（または管理者）のSMTP設定が有効か確認
- 先に「注文書作成」ボタンを実行しているか確認
- ステータスが「最終承認済」か確認

**Q: 業務員サイン後に班長の `APPROVE_L2` が出ない**

- 承認者設定でレベル2（班長）の「承認可能ユーザー」が登録されているか確認
- 作成者ユーザーに班情報が設定されているか確認
- 班長ユーザーに班情報・役職（班長）が設定されているか確認
- 右上「タスク」から状態「未対応」を確認
