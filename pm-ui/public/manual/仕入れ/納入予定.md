# 納入予定

業務員向けの納品リスト運用画面です。  
仕入先へ送る納品リストの出力と、返送されたExcelの取込を行います。

## 画面への行き方

1. 上のグローバルナビゲーションの「仕入」を開く
2. 「仕入れ管理メニュー」→「納入予定」を選択

## 納品リスト出力

1. 仕入先を選択
2. 対象日（納入日）を確認
3. Gフィルタを確認（仕入先区分に応じて自動設定される）
4. 「進度再計算」ボタンを押す
5. 再計算完了後、「納品リスト出力」ボタンを押す
6. Excelファイルがダウンロードされる

### Gフィルタ

品番の末尾が「G」で終わるかどうかで、納品リストに含める製品を絞り込みます。仕入先を選択すると、仕入先マスタの「仕入先区分」に応じて自動設定されます。

| 仕入先区分 | Gフィルタ初期値 | 納品リストに含まれる製品 |
| ---------- | --------------- | ---------------------- |
| 外作       | 有              | 品番末尾Gの製品のみ    |
| 購入       | 無              | 品番末尾Gなしの製品のみ |
| 両方       | 全              | 全製品                 |

手動でボタンを切り替えて変更することもできます。

### 納品リストの中身（3シート）

**シート1「納品リスト」**

| 列             | 説明                                                 |
| -------------- | ---------------------------------------------------- |
| 品番           | 製品コード                                           |
| 品名           | 製品名                                               |
| 移動先         | 製品マスタに設定された移動先                         |
| 数量           | 需要データから自動計算された予定数量                   |
| 納品日         | 選択した対象日                                       |
| 日別列         | カバー期間（納入日～次回納入日前日）の各日の数量内訳   |
| 仕入先コード   | 仕入先のコード                                       |
| 伝票番号       | 空欄（仕入先が記入）                                 |

数量は社内の需要データ（内示+確定）からカバー期間分を自動計算しています。

**シート2「確認・修正方法」**

仕入先が数量の修正方法を確認するためのシートです。

**シート3「製品リスト」**

品番追加時にコピーするための全製品一覧です。手入力ではなくここからコピーしてください。

## Excel取込

1. 仕入先を選択
2. 「ファイルの選択」で返送されたExcelを選ぶ
3. 取込結果が一覧に表示される
4. 内容を確認して「納入予定保存」を押す

### 取込ルール

- ヘッダー名で列を認識するため、列の並び順は問いません
- **納品日は `YYYY-MM-DD` / `YYYY/MM/DD` / `YYYY/M/D` 形式のみ取込可能**です（例: `2026-06-08`, `2026/06/08`, `2026/6/8`）
- **返送Excel内の納品日は全行同一**である必要があります
- **返送Excel内の納品日と画面の対象日は一致必須**です。不一致の場合は取込エラーになります
- 数量が空白の行は取込時に除外されます（保存しません）
- **数量が0の行は取消**として保存されます（同日同製品の計画数量を0へ上書き）
- 数量が1以上の行は計画として保存されます
- 対象外品番はエラー表示して除外
- 仕入先コード不一致はエラー表示して除外
- 同一品番が複数行ある場合は数量を合算

### 数量差異チェック（LineDemand照合）

Excel取込時、以下の照合を自動で行います。

- **日別照合**: Excelの日別列（`6/30(火)` 等）の値と、社内の需要データ（LineDemand）の各日の値を比較
- **合計照合**: Excelの「数量」列と、カバー期間のLineDemand日別合計を比較

差異がある場合、品番・移動先・差異内容を一覧表示する確認ダイアログが表示されます。

| ボタン | 動作 |
|--------|------|
| はい   | 差異を了承して取込を続行（その後「納入予定保存」で保存可能） |
| いいえ | 取込をキャンセル（データはクリアされる） |

**差異は保存をブロックしません。** 仕入先がカバー期間より多い数量を持ってくることはよくあるため、合計数が需要合計と異なるのは正常な業務ケースです。

### 修正・取消・変更

| やりたいこと | 方法                                               |
| ------------ | -------------------------------------------------- |
| 数量を修正   | 同じ仕入先・日付でExcelを再取込して保存             |
| 計画を取消   | 対象製品の数量を0にして取込・保存                   |
| 空白は除外   | 空白では取消になりません（取消は必ず0を入力）       |

## 進度表の手動出力

仕入先を選択した状態で、「進度再計算」完了後に出力できます。

| ボタン | 出力ファイル | 用途 |
|--------|------------|------|
| 納品リスト出力 | 納品リスト_{仕入先コード}_{日付}.xlsx | 仕入先へ送付して確認・修正依頼 |
| 進度表Excel | 進度表_{仕入先コード}_{日付}.xlsx | 仕入先へ送付・社内確認 |
| 進度表PDF | 進度表_{仕入先コード}_{日付}.pdf | 印刷・閲覧用 |
| 納品書PDF | 外作納品書_{仕入先コード}_{日付}.pdf | 外作納品書の印刷 |

自動送信を設定していない仕入先でも、手動で進度表を出力して送付できます。

### 出力前の注意

- 出力前に必ず「進度再計算」を実行してください。
- 「納品リスト出力 / 進度表Excel / 進度表PDF / 納品書PDF」は、進度再計算完了後に押せます。

## 自動送信との関係

自動納入リスト送信機能を設定している仕入先の場合、テンプレ出力と送付は自動で行われます。自動送信時も仕入先区分に応じたGフィルタが適用されます。  
事務員は仕入先からの返送Excelを取込・保存するだけで運用できます。  
詳細は「自動納入リスト送信」のマニュアルを参照してください。
