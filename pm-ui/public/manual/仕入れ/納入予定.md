# 納入予定

業務員向けの納品リスト運用画面です。  
仕入先から受領したExcel納品リストを取り込み、検収登録を行います。

## 手順

1. 仕入先を選択
2. 対象日を確認
3. 「納品リストテンプレ出力」でテンプレを出力
4. 納品リストExcelを選択して取り込み
5. 内容確認後「検収確定」

## テンプレ列

- 品番
- 品名
- 数量
- 納品日
- 仕入先コード
- 伝票番号

## 取込ルール

- 1ファイル = 1仕入先・1日で運用
- 対象外品番はエラー表示して除外
- 仕入先コード不一致はエラー表示して除外
- 数量1未満はエラー表示して除外
- 同一品番複数行は数量合算
