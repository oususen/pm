# 仕入れ先カレンダ

仕入先ごとの稼働カレンダを管理する画面です。カレンダの新規作成、既存カレンダの割当・割当解除、日別の稼働日設定ができます。

## 画面への行き方

1. 上のグローバルナビゲーションの「仕入」を開く
2. 「仕入れ管理メニュー」→「仕入れ先カレンダ」を選択

## 基本的な流れ

1. 仕入先を選択します。
2. カレンダが割当済みの場合はそのカレンダが自動で表示されます。
3. カレンダが未割当の場合は、既存カレンダを割り当てるか、新規作成します。
4. カレンダグリッド上で日ごとの稼働日/休みを切り替えます。

## 画面の見方

### ツールバー

| 項目 | 説明 |
|------|------|
| 仕入れ先 | 対象の仕入先を選択します。選択すると現在割当中のカレンダが自動で表示されます |
| カレンダ | 全カレンダの一覧から選択できます。選択するとカレンダ日がプレビュー表示されます |
| 割当ボタン | カレンダドロップダウンで選んだカレンダをこの仕入先に割り当てます |
| 割当解除ボタン | 現在の割当を解除します。解除するとダイソウカレンダが既定値として使われます |

### カレンダグリッド

- 月ごとに7列（日曜〜土曜）のカレンダ形式で表示されます
- 「前月へ」「次月へ」ボタンで月を切り替えます
- 各日のセルには以下が表示されます:
  - **日付番号**（大きな数字）
  - **納入日チェックボックス** — この日が納入日かどうか
  - **発注日チェックボックス** — この日が発注日かどうか
  - **稼働チェックボックス**（「稼働」/「休み」）
  - **バッジ表示** — 納入日（黄色）、発注日（青色）がONの日はバッジが表示されます
  - **メモ欄**（自由テキスト）

### セルの色分け

| 色 | 意味 |
|----|------|
| 緑系 | 稼働日 |
| 赤系 | 休み |
| グレー | 前月/翌月の日付（操作不可） |

## カレンダの割当

### 既存カレンダを割り当てる

1. 仕入先を選択します
2. カレンダドロップダウンから割り当てたいカレンダを選択します
3. カレンダグリッドにプレビューが表示されるので、内容を確認します
4. 「割当」ボタンを押します
5. 確認ダイアログで「OK」を押すと割当が完了します

### 新しいカレンダを作成して割り当てる

1. 仕入先を選択します
2. 右上の「新規作成」ボタンを押して入力欄を開きます
3. カレンダコード（例: `sup_A001`）を入力します
4. カレンダ名（例: `A社カレンダ`）を入力します
5. 「作成して割当」を押すと、カレンダが作成され自動的にこの仕入先に割り当てられます

### カレンダの割当を解除する

1. 仕入先を選択します
2. 「割当解除」ボタンを押します
3. 確認ダイアログで「OK」を押すと割当が解除されます
4. 割当解除後は、ダイソウカレンダの稼働日が既定値として使われます

## 納入日・発注日の設定

### パターンから一括生成する

納入パターンが割り当てられている仕入先では、パターンに基づいて納入日・発注日を一括生成できます。

1. 「納入日生成」または「発注日生成」の日付範囲を指定します
2. 「納入日生成」または「発注日生成」ボタンを押します
3. パターンに基づいて該当日にチェックが入ります

- 「納入日クリア」「発注日クリア」で指定期間のチェックを一括解除できます
- 納入パターンが未割当の場合、生成ボタンは無効になります

### 手動で設定する

- 各日の「納入日」「発注日」チェックボックスを個別にON/OFFできます
- パターン割当がなくても手動チェックは可能です
- 変更は即座に保存されます

## 稼働日の設定

### 日ごとに設定する

- 各日の「稼働」チェックボックスをクリックすると稼働日/休みが切り替わります
- 変更は即座に保存されます

### 曜日一括で設定する

- 曜日ヘッダ（日・月・火…）のチェックボックスを使います
- チェックを入れると、表示月内のその曜日が全て稼働日になります
- チェックを外すと、表示月内のその曜日が全て休みになります
- 例: 「土」のチェックを外す → その月の全ての土曜日が休みに設定されます

### メモを入力する

- 各日のメモ欄にテキストを入力できます（例: 「棚卸のため休業」）
- 入力欄の外をクリックすると自動保存されます

## ダイソウカレンダについて

- カレンダが未割当の仕入先や、カレンダに特定日のレコードがない場合は、**ダイソウカレンダ（社内標準カレンダ）の稼働日が既定値**として表示されます
- ダイソウカレンダにもレコードがない場合は、**平日＝稼働、土日＝休み**がデフォルトです
- 画面上部の赤字の注意書きもこの仕様を案内しています

## 注意事項

- 同じカレンダを複数の仕入先に割り当てることができます。その場合、カレンダ日を変更すると割当先すべてに影響します
- カレンダの割当変更は、仕入れ計画・納入パターンに基づく計算に影響します
- 編集には `purchase.supplier_calendar` の編集権限が必要です
