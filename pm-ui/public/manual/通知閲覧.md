# 通知閲覧

## 目的
自分に該当する通知を確認します。

## 開き方
- ヘッダーの🔔通知ボタンを押すと一覧が表示されます。
- 一覧の「一覧へ」から通知一覧画面を開けます。

## 表示条件
- 通知の対象部署・対象役職に一致するものだけ表示されます。
- 個別ユーザーが指定されている場合は、個別ユーザーと部署/役職の条件を両方満たすものだけ表示されます。
- 有効期間外の通知は表示されません。
- 対象部署は班→係→事業部の順で優先されます。

## 通知一覧画面
- 行をクリックすると詳細が展開されます。
- 対象者、説明、入力者などを確認できます。
- 一覧の並び順は「表示順→作成日（新しい順）」です。
