# 生産計画入力

ライン別の生産計画を日付ごとに入力する画面です。需要・実績・在庫を参照しながら計画と順序を入力します。

[作業手順書（日本語）](/manual/生産/生産計画入力_作業手順書.html)
[ライン編集 作業手順書](/manual/生産/生産計画入力_ライン編集_作業手順書.html)

## 画面への行き方

1. 上のグローバルナビゲーションの「生産」を開く
2. 「生産計画入力」を選択

※ `production.plan_input` の権限がないユーザーには、生産メニュー内の「生産計画入力」は表示されません。

## 使い方

1. ライン、表示開始日、期間を選択します。
2. 「表示のみ」または「需要取込」を押してデータを読み込みます（通常は「表示のみ」で十分です）。
3. 計画欄に数量を入力し、順序欄に順序番号を入力します。
4. 「保存」を押して登録します。

## 画面レイアウト

画面は上から順に以下の構成になっています。

1. **タブ行** — タンク / フロア / クボタ / フロア出荷 / ブレード / レーザ 等
2. **ツールバー** — ライン選択、表示開始日、期間、検索、各種ボタン
3. **グリッド** — 左に No・品番・品名、右に日付ごとの6列（在庫・実績・需要・計画・順・計庫）
4. **フッター** — ショートカットキー（F1〜F10）

## 画面の見方

- 1日分が6列（在庫、実績、需要、計画、順、計庫）で表示されます。
- 計画と順は入力欄、それ以外は参照値です。
- 行は品番ごとに表示されます。表示順は「表示順」ボタンで設定できます。
- 日付ヘッダーには最終工程開始時刻（緑）、その日の勤務時間（例: 08:00〜翌04:20）、勤務時間は生産→ライン勤務カレンダーで設定する。
- 日別統計（計合・需要移動平均）、および計画クリアボタン（`×`）が表示されます。
- 最終工程開始時刻の決定ルール
  1. 日付ヘッダーで設定した日別開始時刻（任意の日だけ設定可）が最優先
  2. 日別設定が無い日は「デフォルト開始時刻設定」画面でライン別に登録した値を使用
  3. デフォルド開始時刻設定は生産→デフォルド開始時間設定で設定してください
  4. どちらも未設定の場合は 08:00 を使用
  ※ 休憩明け補正は各設定に紐づいた ON/OFF を用います。

## ツールバー

### フィルタ・設定

| 項目 | 説明 |
| ---- | ---- |
| ライン | 対象ラインを選択（必須） |
| 表示開始日 | グリッドの表示開始日を設定 |
| 期間 | 表示日数を 7日 / 14日 / 30日 / 60日 / 90日 から選択（デフォルト: 14日） |
| 検索 | 品番・品名でグリッド行を絞り込み |
| 空白行非表示 | チェックすると、表示中に計画・需要などの値がない行を非表示にして見やすくします |
| 土日非表示 | チェックすると土曜・日曜の列を非表示にして画面を節約 |
| 休憩明けに補正 | 工程ガント生成時に休憩明けの時刻に補正するかどうか |

### ボタン

| ボタン | 説明 |
| ------ | ---- |
| 計画一括削除 | 表示中の全計画を削除 |
| 計画変更 | ロック期間内の計画を変更する際に変更理由を入力するダイアログを表示。理由を入力して「確定」すると、ロック期間内のセルが編集可能になります |
| 保存 | 計画データをサーバーに保存。保存後は工程展開・在庫再計算・ガント再生成が自動実行されます |
| 表示順 | 製品の表示順・行色・ボタン色を設定するダイアログを表示（詳細は後述） |
| ガント表示 | 工程ガント計画の表示/非表示を切り替え |
| 負荷表示 | 工程別の負荷時間の表示/非表示を切り替え |
| 時間数量保存 | 工程ガント表示中の既存バーの開始時刻・終了時刻・数量変更を一括保存します |
| 追加削除保存 | 工程ガント表示中の手動追加とバー削除を一括保存します |
| ライン編集 | ラインごとの対象ライン設定や前日シフト台数など、ライン別の画面設定を開きます |

### フッターショートカットキー

| キー | 説明 |
| ---- | ---- |
| F1 | 戻る（ブラウザ履歴を1つ戻る） |
| F2 | 進む（ブラウザ履歴を1つ進む） |
| F3 | クリア（表示中の全行を削除） |
| F4 | 表示のみ（計算なしでデータ取得・表示） |
| F5 | キャンセル（入力内容をクリア） |
| F6 | 需要取込（後工程需要を再計算してから表示） |
| F8 | 取込＋在庫計算（需要＋在庫・計画在庫を再計算してから表示） |
| F10 | 印刷（出力形式選択ダイアログを表示） |

## 製品表示順・色設定

「表示順」ボタンを押すと、現在のラインの製品表示順と行色を設定するダイアログが開きます。

ダイアログは左右2列の構成です。

### 左側: 製品リスト

| # | 品番 | 品名 | 行色(R G B) | +色(R G B) | 操作 |
| - | ---- | ---- | ----------- | ---------- | ---- |
| 1 | YD40008670K | フロア(55UR CAB)検査 | 191 219 254 | | ↑ ↓ |
| 2 | YD40006245K | フロア(U-5CAB)検査 | | | ↑ ↓ |
| 3 | YD40007003K | フロア(U-6EN 3ton CAB)検査 | | | ↑ ↓ |

### 右側: 色サンプル（参考用）

行背景色:

- R191 G219 B254 … キャブ青
- R187 G247 B208 … キャノピー緑

+ボタン色:

- R212 G165 B116 … A 茶
- R187 G187 B187 … B グレー
- R68 G68 B68 … C 濃灰
- R251 G191 B36 … D 黄

### 操作手順

1. データを取り込んだ状態で「表示順」ボタンをクリック
2. ダイアログに現在のラインの製品一覧が表示される
3. ↑↓ボタンで表示順を変更（移動した行は青くハイライト）
4. 行色: 製品行の背景色をR/G/B（0〜255）で指定。右側の色サンプルを参考に入力
5. +色: ロット追加ボタン（+）の色をR/G/B で指定
6. 「保存」で確定。画面に即座に反映される

### 補足

- 設定はライン別にDBに保存され、次回以降も維持されます
- フロアラインの「フロア出荷」タブは別のコンテキストとして独立に設定できます
- DB未設定のラインではシステム既定の表示順が使われます

## ライン編集

「ライン編集」を開くと、現在のタブ単位でライン別の補助設定を変更できます。

- 対象ライン: タブごとに表示・操作対象にするラインを設定します
- 前日シフト台数: ライン×工程ごとに、前日シフトとして扱う台数を設定します
- ガント開始時間: ライン×工程ごとに、工程ガントの開始時刻を設定します
- 計算特例: ライン×工程×計算対象ごとに計算ルールを追加します
- フロア出荷タブは、通常のフロアタブとは別設定で管理されます

### 設定できる内容

- 前日シフト台数設定（ライン×工程）
  指定したラインと工程に対して「前日シフト何台分として扱うか」を登録します。
- ガント開始時刻設定（ライン×工程）
  指定したラインと工程に対して、工程ガントの開始時刻を `HH:mm` で登録します。
- 計算特例（ライン×工程×計算対象×設定）
  指定したラインと工程に対して、計算対象ごとの特例ルールを登録します。現在は `計画在庫` / `在庫` / `需要` を対象に、設定値として `ORDER_QTY使用` を選択できます。

## 印刷・出力

F10キーまたはフッターの「F10: 印刷」ボタンを押すと、出力形式の選択ダイアログが表示されます。

| 出力形式 | 説明 |
| -------- | ---- |
| Excel出力 | 現在の絞り込み結果をExcelファイルとしてダウンロード |
| PDF出力 | 現在の絞り込み結果をPDFファイルとして印刷用に出力 |

対象データは現在のフィルタ条件（ライン・期間・検索キーワード）で表示されている行です。

## 計画変更（ロック期間の編集）

通常、過去の計画はロック期間として編集できません。ロック期間内の計画を修正する場合は以下の手順で行います。

1. 「計画変更」ボタンをクリック
2. 変更理由入力ダイアログが表示される
3. 変更理由を入力して「確定」をクリック
4. ロック期間内のセルが編集可能になる
5. 計画を修正して「保存」

## 日別計画クリアと順序の自動採番

### 日付ヘッダーの `×` ボタン

各日付列のヘッダーに `×` ボタンがあります。押すと確認ダイアログが表示され、確定するとその日の **計画（LinePlan）・ガントチャート・LineBacklog の計画行** がすべてクリアされます（需要・実績・在庫は維持）。

### 順序の自動採番

計画数量を入力した順番に「順」が自動で設定されます。

| 操作 | 動作 |
| ---- | ---- |
| 数量 > 0 を入力（順が未設定） | その日の最大順 + 1 を自動セット |
| 数量 > 0 を入力（順が設定済み） | 既存の順をそのまま維持 |
| 数量を 0 またはクリア | その行の順もクリア |

**順序の振り直し手順:**

1. 日付ヘッダーの `×` ボタンでその日の計画をクリア
2. 生産したい製品の数量を入力した順番に 1、2、3… と「順」が自動セットされる
3. 「保存」で登録

## 操作のポイント

- 「クリア」は表示中の行を削除します。
- キーボードの矢印キーと Enter で入力セルを移動できます。
- 「工程ガント表示」で工程ガントを表示します。
- 工程ガントのバー上で、数量（左側の数値）クリックで数量変更、開始時刻クリックで開始時刻変更ができます。
- 工程ガントのバーをドラッグして開始位置を調整できます（分解表示のみ）。
- 工程ガントのバーにカーソルを置くと、工程・品番・数量・時間帯・所要分などの詳細が表示されます。
- 工程ガントの手動追加と削除は、その場ではまだ保存されず、「追加削除保存」でまとめて反映されます。
- 工程ガントの時間変更と数量変更は、「時間数量保存」でまとめて反映されます。
- 「工程負荷表示」で工程別の負荷を表示します。
- 計画セルの「+」ボタンで同日に複数ロットを追加できます。

## 注意点

- ラインを選択しないと保存・取り込みはできません。
- 保存後は工程展開とガント再計算が実行されます。
- **土日・非稼働日に再計算（F6/F8）を実行した場合**: 計算基準日は直前の営業日に調整されます。例：日曜日（6/28）に実行すると基準日は金曜日（6/26）になります。計算の開始日は「基準日 −（自LT＋1）営業日」で決まるため、開始日より前の日付は再計算されず、既存の値がそのまま残ります。
- 工程ガントの「連結」表示中は、バー編集（ドラッグ/開始時刻/数量）と各保存ボタンは使えません。編集する場合は「分解」表示に切り替えてください。
- 追加・削除の未保存中は、時間変更・数量変更は始められません。
- 時間変更・数量変更の未保存中は、追加・削除は始められません。
- 各保存ボタンは、対象カテゴリに未保存変更がある間だけ赤くなります。
