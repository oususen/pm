# 生産計画入力

ライン別の生産計画を日付ごとに入力する画面です。需要・実績・在庫を参照しながら計画と順序を入力します。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「生産計画入力」を選択

## 使い方

1. 処理区分、ライン、表示開始日、期間を選択します。
2. 「取り込み」を押してライン別のデータを読み込みます。
3. 計画欄に数量を入力し、順序欄に順序番号を入力します。
4. 「保存」を押して登録します。

## 画面の見方

- 1日分が6列（需要、実績、在庫、計画、順序、計画在庫）で表示されます。
- 計画と順序は入力欄、それ以外は参照値です。
- 行は品番ごとに表示され、並び替えボタンで順序を変更できます。
- 日付ヘッダーには最終工程開始時刻（緑）と、その日の勤務時間（赤、例: 08:00〜17:00）が表示されます。

## 操作のポイント

- 「新規行追加」で空行を追加できます。
- 「クリア」は表示中の行を削除します。
- キーボードの矢印キーと Enter で入力セルを移動できます。
- 「工程ガント表示」で工程ガントを表示します。
- 「工程負荷表示」で工程別の負荷を表示します。

## 注意点

- ラインを選択しないと保存・取り込みはできません。
- 保存後は工程展開とガント再計算が実行されます。
