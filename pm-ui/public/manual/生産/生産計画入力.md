# 生産計画入力

ライン別の生産計画を日付ごとに入力する画面です。需要・実績・在庫を参照しながら計画と順序を入力します。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「生産計画入力」を選択

## 使い方

1. ライン、表示開始日、期間を選択します。
2. 「表示のみ」または「需要取込」を押してデータを読み込みます（通常は「表示のみ」で十分です）。
3. 計画欄に数量を入力し、順序欄に順序番号を入力します。
4. 「保存」を押して登録します。

## 画面の見方

- 1日分が6列（需要、実績、在庫、計画、順序、計画在庫）で表示されます。
- 計画と順序は入力欄、それ以外は参照値です。
- 行は品番ごとに表示され、並び替えボタンで順序を変更できます。
- 日付ヘッダーには最終工程開始時刻（緑）、その日の勤務時間（赤、例: 08:00〜17:00）、および計画クリアボタン（`×`）が表示されます。
- 最終工程開始時刻の決定ルール
  1. 日付ヘッダーで設定した日別開始時刻（任意の日だけ設定可）が最優先
  2. 日別設定が無い日は「デフォルト開始時刻設定」画面でライン別に登録した値を使用
  3. どちらも未設定の場合は 08:00 を使用
  ※ 休憩明け補正は各設定に紐づいた ON/OFF を用います。

## ツールバー

### フィルタ・設定

| 項目 | 説明 |
|------|------|
| ライン | 対象ラインを選択（必須） |
| 表示開始日 | グリッドの表示開始日を設定 |
| 期間 | 表示日数を 14日 / 30日 / 60日 / 90日 から選択（デフォルト: 14日） |
| 検索 | 品番・品名でグリッド行を絞り込み |
| デフォルト開始時刻 | 日別設定がない日に使うライン別デフォルト開始時刻（別画面で設定、未設定なら 08:00） |
| 休憩明けに補正 | 工程ガント生成時に休憩明けの時刻に補正するかどうか |

### ボタン

| ボタン | 説明 |
|--------|------|
| クリア | 表示中の全行を削除 |
| 計画変更 | ロック期間内の計画を変更する際に変更理由を入力するダイアログを表示。理由を入力して「確定」すると、ロック期間内のセルが編集可能になります |
| 保存 | 計画データをサーバーに保存。保存後は工程展開・在庫再計算・ガント再生成が自動実行されます |
| 表示のみ | 計算なしでデータを取得して表示します。定時タスクで最新化済みの場合はこちらで十分です（F4） |
| 需要取込 | 後工程需要を再計算（pickup）してからデータを表示します。需要だけ最新化したい場合に使用します（F6） |
| 取込＋在庫計算 | 後工程需要の再計算に加え、在庫・計画在庫の再計算も実行してからデータを表示します（F8） |
| 工程ガント表示 | 工程ガント計画の表示/非表示を切り替え |
| 時間数量保存 | 工程ガント表示中の既存バーの開始時刻・終了時刻・数量変更を一括保存します |
| 追加削除保存 | 工程ガント表示中の手動追加とバー削除を一括保存します |
| 工程負荷表示 | 工程別の負荷時間の表示/非表示を切り替え |

### フッターショートカットキー

| キー | 説明 |
|------|------|
| F1 | 戻る（ブラウザ履歴を1つ戻る） |
| F2 | 進む（ブラウザ履歴を1つ進む） |
| F3 | クリア（表示中の全行を削除） |
| F4 | 表示のみ（計算なしでデータ取得・表示） |
| F5 | キャンセル（入力内容をクリア） |
| F6 | 需要取込（後工程需要を再計算してから表示） |
| F8 | 取込＋在庫計算（需要＋在庫・計画在庫を再計算してから表示） |
| F10 | 印刷（出力形式選択ダイアログを表示） |

## 印刷・出力

F10キーまたはフッターの「F10: 印刷」ボタンを押すと、出力形式の選択ダイアログが表示されます。

| 出力形式 | 説明 |
|----------|------|
| Excel出力 | 現在の絞り込み結果をExcelファイルとしてダウンロード |
| PDF出力 | 現在の絞り込み結果をPDFファイルとして印刷用に出力 |

対象データは現在のフィルタ条件（ライン・期間・検索キーワード）で表示されている行です。

## 計画変更（ロック期間の編集）

通常、過去の計画はロック期間として編集できません。ロック期間内の計画を修正する場合は以下の手順で行います。

1. 「計画変更」ボタンをクリック
2. 変更理由入力ダイアログが表示される
3. 変更理由を入力して「確定」をクリック
4. ロック期間内のセルが編集可能になる
5. 計画を修正して「保存」

## 日別計画クリアと順序の自動採番

### 日付ヘッダーの `×` ボタン

各日付列のヘッダーに `×` ボタンがあります。押すと確認ダイアログが表示され、確定するとその日の **計画（LinePlan）・ガントチャート・LineBacklog の計画行** がすべてクリアされます（需要・実績・在庫は維持）。

### 順序の自動採番

計画数量を入力した順番に「順」が自動で設定されます。

| 操作 | 動作 |
| ---- | ---- |
| 数量 > 0 を入力（順が未設定） | その日の最大順 + 1 を自動セット |
| 数量 > 0 を入力（順が設定済み） | 既存の順をそのまま維持 |
| 数量を 0 またはクリア | その行の順もクリア |

**順序の振り直し手順:**

1. 日付ヘッダーの `×` ボタンでその日の計画をクリア
2. 生産したい製品の数量を入力した順番に 1、2、3… と「順」が自動セットされる
3. 「保存」で登録

## 操作のポイント

- 「クリア」は表示中の行を削除します。
- キーボードの矢印キーと Enter で入力セルを移動できます。
- 「工程ガント表示」で工程ガントを表示します。
- 工程ガントのバー上で、数量（左側の数値）クリックで数量変更、開始時刻クリックで開始時刻変更ができます。
- 工程ガントのバーをドラッグして開始位置を調整できます（分解表示のみ）。
- 工程ガントのバーにカーソルを置くと、工程・品番・数量・時間帯・所要分などの詳細が表示されます。
- 工程ガントの手動追加と削除は、その場ではまだ保存されず、「追加削除保存」でまとめて反映されます。
- 工程ガントの時間変更と数量変更は、「時間数量保存」でまとめて反映されます。
- 「工程負荷表示」で工程別の負荷を表示します。
- 計画セルの「+」ボタンで同日に複数ロットを追加できます。

## 注意点

- ラインを選択しないと保存・取り込みはできません。
- 保存後は工程展開とガント再計算が実行されます。
- 工程ガントの「連結」表示中は、バー編集（ドラッグ/開始時刻/数量）と各保存ボタンは使えません。編集する場合は「分解」表示に切り替えてください。
- 追加・削除の未保存中は、時間変更・数量変更は始められません。
- 時間変更・数量変更の未保存中は、追加・削除は始められません。
- 各保存ボタンは、対象カテゴリに未保存変更がある間だけ赤くなります。
