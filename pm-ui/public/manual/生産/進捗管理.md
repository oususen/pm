# 進捗管理

ライン・工程・品番ごとの日別「計画(P)」「実績(A)」を一覧で確認する画面です。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「進捗管理」を選択

## 使い方

1. 画面を開くと現在の日付範囲のデータが自動的に読み込まれます。
2. ライン・工程・品番のフィルターに入力すると、即座に表示が絞り込まれます（再取得不要）。
3. 表示開始日や期間（7/14/30/60/90日）を変更した場合は「更新」を押してデータを再取得します。

## 画面の見方

- 左端に「ライン / 工程 / 品目」が表示されます。
- 日付列には P: 計画、A: 実績が表示されます（どちらも0の日は空欄）。
- 色の意味:
  - 実績 > 計画: 黄色
  - 実績 = 計画: 緑
  - 実績 < 計画: 赤
- 1ページあたり20件表示。表示件数が多い場合はページ切替で移動します（最初/前へ/ページ番号/次へ/最後）。

## 注意点

- ライン・工程・品番フィルターは入力と同時にリストが絞り込まれます（「更新」ボタン不要）。
- 表示開始日や期間を変更した場合は「更新」ボタンでサーバーからデータを再取得してください。
- データがない場合は「データがありません」と表示されます。
