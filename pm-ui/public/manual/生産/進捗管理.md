# 進捗管理

ライン・工程・品番ごとの日別「計画(P)」「実績(A)」を一覧で確認する画面です。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「進捗管理」を選択

## 使い方

1. ライン・工程・品番で絞り込みます。
2. 表示開始日と期間（7/14/30/60/90日）を指定します。
3. 「更新」を押します。

## 画面の見方

- 左端に「ライン / 工程 / 品目」が表示されます。
- 日付列には P: 計画、A: 実績が表示されます。
- 色の意味:
  - 実績 > 計画: 黄色
  - 実績 = 計画: 緑
  - 実績 < 計画: 赤
- 表示件数が多い場合はページ切替で移動します。

## 注意点

- フィルタ変更後は「更新」で再読込してください。
- データがない場合は「データがありません」と表示されます。
