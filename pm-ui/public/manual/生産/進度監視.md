# 進度監視

登録した製品について、選択したグループに所属するラインの進度を日付横持ちで確認する画面です。

## 確認方法

1. 「グループ」を選択します。
2. 「開始日」を指定します。初期値は当月1日です。
3. 「期間」を30日・60日・90日・120日から選びます。
4. 「更新」を押します。

監視製品は工程ごとのカードで表示され、日付ごとに「内示・確定・計画・実績・調整・計進・進度」を確認できます。期間内のデータがない監視対象も空カードとして表示されます。調整のマイナスは赤字、計進・進度のマイナスは強調した赤字で表示されます。カードは参照専用です。

## お気に入り

グループを選び、「お気に入り名」を入力して「★」を押します。お気に入りにはグループだけが保存されます。ラインの所属変更は、次に表示したとき自動的に反映されます。

## 監視対象の登録

編集権限がある場合、「監視対象追加」から次を登録できます。

- ライン
- 製品
- 表示順
- メモ
- 有効／無効

製品は有効な製品マスタから品番または品名で検索します。同じ製品とラインの組み合わせは重複登録できません。一覧の「編集」から内容変更または無効化ができます。「対象管理」には無効化済みの対象も表示され、「再有効化・編集」から再び有効にできます。

グループとラインの紐付はラインマスタの「所属グループ」設定を使用します。選択肢に必要なラインがない場合は、所属グループ設定を確認してください。
