# 進度監視

登録した製品について、選択したグループに所属するラインの進度・在庫を日付横持ちで確認する画面です。監視対象ごとに「監視モード」（進度／在庫）を選べます。

[作業手順書（日本語）](/manual/生産/進度監視_作業手順書.html)

## 確認方法

1. 「グループ」をチェックボックスで選択します（複数選択可）。選択した全グループに所属するラインの監視対象がまとめて表示されます。
2. 「開始日」を指定します。初期値は当月1日です。
3. 「期間」を30日・60日・90日・120日から選びます。
4. 「更新」を押します。

監視製品は工程ごとのカードで表示され、カードごとに監視モードが表示されます。ヘッダの「詳細表示」／「簡易表示」ボタンで表示する項目数を切り替えられます。

- **簡易表示（初期値）**: 監視モードを問わず「計進・進度・計庫・在庫」の4項目だけを表示します。
- **詳細表示**: 上記4項目に加えて、監視モードごとの項目を表示します。
  - 進度監視: 内示・確定・計画・実績・調整
  - 在庫監視: 計需・実需・計画・実績・調整・仕損

在庫監視の「計需・実需」は、後工程の計画数量・実績数量を集計した値です（最終ラインでは受注数量が反映された値になります）。進度監視の「内示・確定」とは取得元が異なります。

進度監視・在庫監視のカードは同じ画面に混在して表示されます。期間内のデータがない監視対象も空カードとして表示されます。調整のマイナスは赤字、計進・進度・在庫・計庫のマイナスは強調した赤字で表示されます。カードは参照専用です。

## お気に入り

グループを選び（複数可）、「お気に入り名」を入力して「★」を押します。お気に入りには選択中のグループ一覧だけが保存されます（開始日・期間は保存されません）。ラインの所属変更は、次に表示したとき自動的に反映されます。

## 監視対象の登録

編集権限がある場合、「監視対象追加」から次を登録できます。

- 監視モード（進度／在庫）
- 対象グループ（複数グループを選択中のとき、どのグループのラインから選ぶかを指定）
- ライン（「対象グループ」で選んだグループに所属するラインだけが選択肢になります）
- 製品
- 表示順
- メモ
- 有効／無効

製品は有効な製品マスタから品番または品名で検索します。同じ製品とラインの組み合わせは重複登録できません（監視モードを問わず1組み合わせにつき進度・在庫どちらか一方のみ）。一覧の「編集」から内容変更または無効化ができます。「対象管理」には無効化済みの対象も表示され、「再有効化・編集」から再び有効にできます。監視モードは編集画面から後から変更できます。

グループとラインの紐付はラインマスタの「所属グループ」設定を使用します。選択肢に必要なラインがない場合は、所属グループ設定を確認してください。

## 選択できるグループ

- 自分が所属するグループと、リーダーとして担当するグループが選択肢になります。
- 班長（supervisor）は、自分が統括する班の配下にある全グループが選択肢になります（2026-10-20対応。それまでは班長はグループを一切選べない不具合がありました）。
- 事業部長・課長・係長は、この画面の対象外です（配下グループは選択肢に出ません）。
