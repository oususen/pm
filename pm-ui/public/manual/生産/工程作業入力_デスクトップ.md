# 工程作業入力（デスクトップ）

工程ごとの作業記録を、デスクトップ向け4列レイアウトで登録する画面です。  
対象URL: `/production/desktop-process-input`

## 画面への行き方

1. 上部メニューの「生産管理」を開く
2. 「工程作業入力（デスクトップ）」を選択

## 画面構成

- 左列: 記録種別、表示設定、作業者入力
- 左から2列目: 製品リスト（部番検索、ページ送り）
- 左から3列目: 登録フォーム（数量、アクション、備考）
- 右列: 最近の記録

## 基本操作

1. ラインと工程を選択します
2. 記録種別（生産記録 / 設備状態 / 仕損）を選択します
3. 製品を選択し、必要項目を入力します
4. 「記録を登録」を押します

## デスクトップ固有の操作

- 表示設定のトグルで、`加工済`、`明日計画`、`前日表示`、`現在時刻のみ` を切り替えます
- 時間帯表示は `«` / `»` で移動できます
- 部番検索で対象製品を絞り込めます
- 「手入力」に切り替えると、計画リスト外の品番入力モードに変更できます

## 生産記録での注意

- ライン・工程・製品は必須です
- 「終了」「中断」時は数量入力が必須です
- 数量は実績として保存され、進捗計算に反映されます

## 設備状態での注意

- 状態（稼働 / 故障 / 段取りなど）を選択して登録します
- 備考は任意入力です

## 補足

- 詳細な業務ルールは「工程作業入力」マニュアル（共通版）も参照してください
