# 朝礼

## 概要

生産メニュー内で朝礼を登録し、参加者確認と実行結果の記録を行います。

## 使い方

1. `生産 > 朝礼` を開く
2. `新規作成` で朝礼日、タイトル、対象部署、対象ライン、司会者、議題を登録する
3. 対象部署は複数選択でき、対象ラインは選択部署に紐づく社内ラインから複数選択できる
4. 必要に応じて PDF / 写真 / Excel の資料を添付する
5. `部署メンバー反映` で参加者を設定し、必要に応じて個別調整する
6. 一覧から `実行` を開き、資料を見ながら開始後に参加者の出席/欠席を記録する
7. 実行メモを入力して `完了` する

## 主な項目

- 朝礼日: 朝礼の実施日
- 対象部署: 参加者と対象ライン候補の基準部署。複数選択可
- 対象ライン: 対象部署に紐づく社内ライン。複数選択可
- 議題: 当日の進行内容
- 連絡事項: 共有事項
- 注意事項: 安全・品質などの注意内容
- 資料添付: PDF / 写真 / Excel を複数登録可能
- 実行メモ: 実施後の補足メモ

## 参加者確認

- `未確認`
- `出席`
- `欠席`
- `遅刻`

実行画面で各参加者の状態と備考を保存できます。

## 資料活用

- 添付した資料は実行画面から開けます
- PDF を見ながらの説明、写真を使った注意喚起、Excel を使った勉強会資料共有に使えます
