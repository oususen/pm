1画面を開く
上部ナビゲーションから 生産 → 生産計画入力 を選択し、「レーザ」タブ → 「加工頻度パターン」サブタブを開きます。
2頻度種別を理解する
3つの頻度種別から選択できます。
毎日（DAILY）毎営業日に加工します。デフォルトの動作と同じです。
毎週曜日（WEEKLY）特定の曜日（月〜金）にのみ加工します。非加工日の需要は加工日にまとめて計上されます。
N営業日ごと
（EVERY_N_DAYS）		N営業日ごとに加工します。非加工日の需要は次の加工日にまとめて計上されます。

3パターンを新規作成する
1. 新規 をクリック
2. ダイアログで以下を入力：
パターンコード必須。識別コード（例: W-MON, E2D）
パターン名必須。表示名（例: 週1回（月曜））
頻度種別毎日 / 毎週曜日 / N営業日ごと から選択
加工曜日「毎週曜日」選択時のみ表示。月〜金から選択
間隔営業日数「N営業日ごと」選択時のみ表示。最小2
有効チェックで有効化
備考任意のメモ
3. 保存 をクリック
4パターンを編集・削除する
編集一覧テーブルの「編集」ボタンをクリック → ダイアログで修正 → 保存
削除一覧テーブルの「削除」ボタンをクリック → 確認後に削除
⚠レーザパターンに紐づけ済みの頻度パターンを削除すると、そのレーザパターンは「毎日」と同じ動作になります。
5レーザパターンに紐づける
作成した頻度パターンを実際のレーザパターンに適用します。

1. 「パターン編集」サブタブを開く
2. 対象のレーザパターンを選択
3. 右ペインの「加工頻度パターン」ドロップダウンから作成したパターンを選択
4. 「N営業日ごと」の場合は「加工頻度適用開始日」も設定
5. 保存
🛈「N営業日ごと」は「加工頻度適用開始日」を起点に営業日をカウントして加工日を決定します。
6週間計画への影響
加工頻度パターンを設定すると、週間計画に以下の変化があります。
非加工日自数・手数セルが空白表示になります（0.00 や 0 は非表示）
需要の集約非加工日の需要は次の加工日にまとめて計上されます
加工日集約された需要に基づいて自数が計算され、手数の初期値になります
✓パターンを設定しなければ従来通り「毎日」加工として計算されます。
