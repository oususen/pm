# 負荷計算

実績からサイクルタイムを集計し、ライン別の長期負荷を確認するためのメニューです。

## 画面パス

`生産 > 負荷計算`

## 全体の流れ

```text
① 出来高集計 → ② ラインサイクルタイム → ③ 長期負荷チャート
```

1. **出来高集計** で工程実績から実績CTを計算・保存し、BOM展開で完成品CTまで保存します。
2. **ラインサイクルタイム** で長期負荷計算用のライン別CTを登録します。出来高CTを取得して仮反映もできます。
3. **長期負荷チャート** で需要×CTからライン別・工程別の負荷時間を確認し、Excelで出力します。

## 各画面の詳細手順

### ステップ1: [出来高集計](出来高集計.md)

工程実績から製品別の実績CTを計算し、稼働率で補正してDBに保存します。BOM展開で完成品CTも算出・保存できます。係数設定タブで稼働率・設備台数を管理します。

[作業手順書（日本語）](出来高集計_作業手順書.html)

### ステップ2: [ラインサイクルタイム](ラインサイクルタイム.md)

長期負荷計算で使うライン別の完成品×工程CTを登録します。出来高集計で保存した完成品CTを取得して仮反映し、必要に応じて修正・保存します。

[作業手順書（日本語）](ラインサイクルタイム_作業手順書.html)

### ステップ3: [長期負荷チャート](長期負荷チャート.md)

顧客需要×ラインCTから日別・週別・月別の負荷時間を棒グラフで表示します。グループ合算、ライン別、工程別のチャートが確認でき、Excel出力も可能です。

[作業手順書（日本語）](長期負荷チャート_作業手順書.html)

## 補足

- 3画面間は画面右上のボタンで直接遷移できます。
- ラインカレンダが未設定のままでは正しく計算できないため、ラインカレンダを設定してから計算を実行してください。
