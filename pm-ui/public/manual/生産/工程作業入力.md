# 工程作業入力

工程単位で、生産記録または設備状態を登録する画面です。ラインと工程を選んで記録します。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「工程作業入力」を選択

## 使い方

1. ラインと工程を選択します。
2. 記録タイプ（設備状態/生産記録）を選択します。
3. 必要な項目を入力し「記録を登録」を押します。

## 生産記録の入力

- 製品: 本日の計画から選択、または手入力します。
- 作業時刻: 製品の状態に応じて「開始 / 終了 / 中断 / 再開 / 一時終了 / 中止」を選択します。
- 生産数量: 「終了」「中断」選択時のみ必須です。
- ロット番号、記入者、備考は必要に応じて入力します。
- 「終了」で登録した数量は `LineBacklog.actual_qty` に反映されます。
- 「終了」で登録した時は、作業時刻記録に加えて生産実績記録（工程実時間記録）も保存されます。
- 「中断」でも入力数量は生産実績として保存され、`LineBacklog.actual_qty` に反映されます。
- 「中止」は一時終了後に選択でき、数量不要・生産実績は作成されません。
- 連産品（仮想セット品番）の場合は、「中断」「終了」どちらでも子品番へ実績が展開されます。
- セッションは以下で分割されます。
  - 中断なし: `開始 → 終了` が1セッション
  - 中断あり: `開始 → 中断`、`中断 → 再開`、`再開 → 終了` をそれぞれ1セッション

## 計画カードの時間帯と「現在時刻のみ」

画面上部には、選択した工程の計画カードが時間帯ごとに表示されます。

- `«` / `»` ボタン: 表示する時間帯を前後に切り替えます。
- **現在時刻のみ** チェックボックス: オンにすると、現在時刻が含まれる時間帯の計画カードのみ表示されます。通常の作業中はオンにしておくと、今の時間帯の製品をすぐに選択できます。 `«` / `»` で目的の時間帯に切り替えてください。計画外の時間帯の製品を加工する場合は、チェックを外して製品選択ができます

## 設備状態の入力

- 状態ボタンから稼働状態を選択します。
- 備考は任意です。

## 注意点

- ラインと工程の選択が必須です。
- 生産記録は「製品」が必須です。
- 「終了」の場合は「数量」が必須です。
