# ガントチャート設定

共生産（連産品）ラインで、工程ガントチャートの表示設定を行う画面です。`ガントチャート生成表示品マップ` と `ガントチャート工程順編集` の2タブがあります。

[作業手順書（日本語）](/manual/生産/ガント生成表示品マップ_作業手順書.html)

## 画面への行き方

1. 上部ナビゲーションの「生産」メニューを開く
2. 「ガントチャート設定」をクリック

## 使い方

### ガントチャート生成表示品マップ

1. 一覧画面で「新規」をクリックし、登録画面を開きます。
2. ライン・ライン最終品・工程・表示品の4項目をすべて選択します。
3. 「保存」で登録します。同じ最終品に複数工程を登録する場合は「保存して工程追加」が便利です。
4. 既存のマッピングは一覧から「編集」「削除」できます。

### ガントチャート工程順編集

1. タブを `ガントチャート工程順編集` に切り替えます。
2. ラインを選択すると、そのラインで使用する工程一覧が表示されます。
3. `↑` `↓` ボタンで工程の表示順を並べ替えます。
4. 「保存」でラインごとのガント表示順を保存します。

## 補足

- 単品生産ラインにはこの設定は通常不要です。
- 設定変更は次回の生産計画保存（ガント再生成）から反映されます。
- 工程順編集は、製品ごとの工程番号ではなく、ラインごとのガント表示順を決めるための設定です。
- production.plan_input の編集権限が必要です。
