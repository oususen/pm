# デフォルト開始時刻設定

ラインごとの「デフォルト開始時刻」と「休憩明けに補正」を設定する画面です。生産計画入力のガント生成で、日別設定が無い日に参照されます。

## 画面への行き方
1. 生産管理メニューで「デフォルト開始時刻設定」をクリックする。

## 使い方
1. 画面上部の区分フィルタで表示対象ラインを選ぶ。  
   - すべて：全ラインを表示  
   - 社内：`line_type = PROD` のラインだけ表示  
   - 購買先：`line_type = PURCHASE` のラインだけ表示
2. 表の「デフォルト開始時刻」に HH:mm 形式で入力する。未入力の場合は 08:00 相当で扱われます。
3. 「休憩明けに補正」チェックを必要に応じてON/OFFする。
4. 「保存」を押して一括保存する。保存後は生産計画入力の工程ガント生成に即時反映されます。

## 補足
- 日別スケジュール設定（生産計画入力ヘッダーの時刻欄）があればそちらが優先され、無い日だけ本設定が使われます。
- フィルタは表示行の絞り込みのみで、保存対象は全ラインです。
