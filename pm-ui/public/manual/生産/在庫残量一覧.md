# 在庫/残量一覧

製品情報と日別の数量（計需・実需・計画・実績・調整・仕損・在庫・計画在庫・進度）を一覧表示します。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「在庫/残量一覧」を選択

## 使い方

1. ライン、工程、品番のいずれかで絞り込みます（どれか1つは必須）。
2. 開始日と期間（30日・60日・90日・120日）を指定します。
3. 「更新」を押して一覧を表示します（データ取得のみ、高速）。
   - 各フィルター入力欄で **Enter** を押しても更新と同等の動作になります。
4. 需要・仕損・在庫を最新化する場合は「再計算」を押します。

## ボタンの役割

| ボタン | 処理内容 | 用途 |
|--------|----------|------|
| **更新** | データ取得のみ（高速） | 現在のデータを確認したいとき |
| **再計算** | 需要再計算 + 仕損再計算 + 在庫/進度再計算 | 最新の受注・実績を反映したいとき |

※ 画面を開いた時点ではデータは取得されません。フィルター入力後に「更新」を押してください。

## ライン・工程コード参照

ラインまたは工程の入力欄で以下の操作でコード一覧を表示できます。

| 操作 | 説明 |
|------|------|
| **F4キー** | コード一覧モーダルを表示 |
| **ダブルクリック** | ラインまたは工程の入力欄をダブルクリックしてモーダルを表示 |

モーダルにはライン一覧・工程一覧が表示され、選択するとフィルター欄にセットされます。

## 画面の見方

### 左側（製品情報）

各製品カードの左側に以下の情報が表示されます。

| 項目 | 説明 |
|------|------|
| 品番 | 製品の品番 |
| 品名 | 製品の品名 |
| 工程名 | 工程名（購買の場合は仕入先名） |
| 工程コード | 工程コード（購買の場合は仕入先コード） |
| 予定 | 表示月の計需合計 |
| 実需 | 表示月の実需合計 |
| 翌月 | （現在は表示なし・将来用） |
| 翌々月 | （現在は表示なし・将来用） |
| 完成品向けLT | 完成品までの総リードタイム（日） |
| 自LT | 自工程のリードタイム（日） |

### 右側（日付マトリクス）

- 行は「計需」「実需」「計画」「実績」「調整」「仕損」「在庫」「計画在庫」「進度」です。
- 数値が 0 の場合は空欄で表示されます。
- 在庫・計画在庫・進度がマイナスのときは赤色で表示されます。

## 調整の参照

この画面の「調整」行は**読み取り専用**です。現在の調整数量を確認するだけで、この画面から直接編集することはできません。

調整値を変更する場合は、別途用意されている調整専用画面から操作してください。

## 注意点

- ライン、工程、品番がすべて未入力の場合、一覧は表示されません。
- 「再計算」は表示中のラインのみを対象とします（全ラインではありません）。
