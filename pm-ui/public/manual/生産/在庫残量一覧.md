# 在庫/残量一覧

製品情報と日別の数量（内示・確定・計画・実績・在庫など）を一覧表示します。調整値の入力やBOM子製品の展開も行えます。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「在庫/残量一覧」を選択

## 使い方

1. ラインまたは工程で絞り込みます（どちらか必須）。
2. 品番で絞り込み、開始日と期間を指定します。
3. 「更新」を押して一覧を表示します。
4. 在庫計算をやり直す場合は「在庫再計算」を押します。

## 画面の見方

### 左側（製品情報）

- 品番・品名・工程名・工程コードが表示されます。
- 「BOM展開」を押すと子製品が表示されます。

### 右側（日付マトリクス）

- 行は「内示」「確定」「計画」「実績」「調整」「仕損」「在庫」「計画在庫」です。
- 数値が 0 の場合は空欄で表示されます。
- 在庫・計画在庫がマイナスのときは赤色で表示されます。

## 調整の入力

1. 調整行のセルに数値を入力します。
2. セルからフォーカスを外すと保存されます。
3. 保存後、在庫と計画在庫が再計算されます。

## 注意点

- ラインまたは工程が未選択の場合、一覧は表示されません。
- 子製品は表示のみで、調整入力はできません。
