# ブレーキベンダー 共通手順

## 目的

ブレーキベンダー作業で、作業者ごとの差を減らし、安全と品質を揃えるための共通手順です。

## 作業前確認

1. 当日の計画、図面、工程、数量を確認する
2. 使用設備と金型が合っているか確認する
3. 金型の取付状態、摩耗、汚れ、異物を確認する
4. 材料の材質、板厚、表裏、方向を確認する
5. 安全装置、非常停止、足元、周辺干渉を確認する

## 段取り

1. 金型を確実に固定する
2. 原点、バックゲージ、角度条件を確認する
3. 必要に応じて傷防止材や保護材を使う
4. 初回は必ず試し曲げを行う

## 試し曲げと初品確認

1. 角度、寸法、曲げ方向、キズ、割れを確認する
2. 戻り量が大きい時は補正量を調整する
3. 問題があれば量産に入らず、原因を切り分ける
4. 初品OK後に量産を開始する

## 量産中の注意

- 材料ロットや板厚差で角度が変わらないか見る
- 曲げ順を省略しない
- キズ、当たり、反転違い、左右違いを見逃さない
- 異常時は止める判断を優先する

## 作業終了時

1. 残材、仕掛、完成品を区分して置く
2. 不良が出た場合は事例を残す
3. 次作業者に引き継ぐ注意点を設備別注意へ反映する
