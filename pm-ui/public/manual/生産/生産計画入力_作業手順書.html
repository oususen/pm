⚙ 生産計画を作成する前提条件

以下のマスタ・設定が登録済みであることが前提です。不足があると計画の保存・工程展開・ガント生成が正しく動作しません。
#前提条件設定画面備考
1ラインマスタマスタラインが存在しないと何もできない
2製品マスタマスタ計画対象の製品
3工程マスタマスタ → 工程マスタライン×工程の紐づけ
4ルーティング・工程マスタ → ルーティング工程順序・サイクルタイム（所要時間）。保存後の工程展開・ガント負荷計算に必要
5BOM（構成マスタ）マスタ → BOM数量換算・共生産の判定に必要
6カレンダマスタマスタ → カレンダラインに紐づくカレンダ定義
7勤務パターンマスタ → 勤務パターン開始時刻・終了時刻・休憩時間の定義
8ライン勤務カレンダ生産 → ライン勤務カレンダ日付ごとに稼働日・勤務パターンを割当
9タブ別ライン設定生産計画入力 → ライン編集タブにラインを割り当てないとドロップダウンに出ない

⚙ ガントチャート生成の追加前提条件

上記すべてに加えて、以下が必要です。

11ガント生成表示品マップ生産 → ガント生成表示品マップ共生産ラインでバーに表示する品番を指定
12ライン編集の各種ルール生産計画入力 → ライン編集前日シフト・ガント開始時刻・ガント展開除外（任意）

3
データを読み込む
ラインを選択したら、フッターのキーでデータを読み込みます。3種類の読み込み方法があり、目的に応じて使い分けます。
F4: 表示のみ F6: 需要取込 F8: 取込+在庫計算
F4: 表示のみ再計算せずにDBの現在値をそのまま表示。通常はこれで十分
F6: 需要取込後工程の需要データを取り込んでから表示
F8: 取込+在庫計算需要取込 + 在庫・計画在庫を再計算してから表示。最も時間がかかる
ⓘ 通常の操作: まず F4（表示のみ） でデータを確認 → 計画入力 → 保存。保存時に自動で在庫再計算されるため、F8は計画入力前に最新データが必要な場合のみ使用します。
⚠ ラインが未選択だとF4/F6/F8は使えません。先にラインを選択してください。

▶ 順序の振り直し

順序を最初から振り直したい場合: 日付ヘッダーの「×」ボタンでその日の計画をクリア → 新しい順番で数量を入力し直すと、入力順に1, 2, 3… と自動採番されます。
⚠ 「×」でクリアすると、その日の計画（LinePlan）・ガントチャート・LineBacklogの計画行がすべて削除されます。需要・実績・在庫は維持されます。

計画を保存する
計画を入力したら、ツールバーの「保存」ボタンを押します。
保存
保存ボタンを押すと、保存対象期間を指定するダイアログが表示されます。from（開始日）とto（終了日）を指定して「保存」をクリックします。デフォルトは表示期間全体です。
保存対象期間
from2026-07-23
to2026-08-21
保存を実行すると以下の処理が自動で順番に実行されます。
1. 計画データ保存入力した計画数量・順序をDBに保存
2. 工程展開製品の計画をルーティングに基づいて工程レベルに展開
3. 在庫再計算在庫・計画在庫を再計算
4. ガント再生成工程ガントチャートを再生成（ガント表示中の場合）
✓ 保存完了後、グリッドが最新データで再表示されます。計画在庫（計庫）も更新されます。
ⓘ 日付ヘッダーの最終工程開始時刻を変更した場合も、保存時に一緒に保存されます。

時間数量保存 追加削除保存
時間数量保存既存バーの時刻・数量変更を保存。未保存変更がある間は赤く表示

▶ 計画変更（ロック期間の編集）

過去〜近い将来の計画はロック期間として編集できません。修正が必要な場合のみ、以下の手順でロックを解除します。
1 ツールバーの「計画変更」ボタンをクリック
2 変更理由入力ダイアログが表示される → テキストエリアに理由を入力（必須）
3 「確定」をクリック → ロック期間のセルが編集可能になる
4 計画を修正して「保存」 → 変更理由がログに記録される
ⓘ 保存が完了するとロック解除状態はリセットされます。再度修正する場合は改めて「計画変更」が必要です。

▶ 計画一括削除

表示中のライン・期間の全計画を一括削除します。
1 ツールバーの「計画一括削除」ボタンをクリック
2 確認ダイアログにライン名・期間・削除対象（plan / gantt / linebacklog）が表示される
3 「OK」で実行 → 削除件数が表示される
⚠ 計画・ガント・LineBacklog（計画行）がすべて削除されます。需要・実績・在庫は維持されます。

▶ 日別計画クリア（×ボタン）

各日付列のヘッダーにある×ボタンで、その日だけの計画をクリアします。
7/24(木)
09:00 08:00〜翌04:20 ×
← ヘッダーの × をクリック
クリア後、その日の計画・順序・ガント・LineBacklog（計画行）がサーバーから削除されます。
需要・実績・在庫は維持されるため、改めて計画を入力すれば順序は自動採番されます。

▶ 順序の自動採番

計画数量を入力すると、「順」欄に自動で順番が割り振られます。手動入力も可能です。
数量 > 0 を入力（順が空）その日の最大順 + 1 を自動セット
数量 > 0 を入力（順が設定済み）既存の順をそのまま維持
数量を 0 またはクリアその行の順もクリア
ⓘ 順番の振り直し方法: ×ボタンでその日の計画をクリア → 生産したい順に数量を入力すると 1, 2, 3… と自動セットされます。

▶ ライン開始時刻設定

ラインごとの最終工程のデフォルト開始時刻と休憩明け補正を設定する画面です。ガントチャート生成時に、日別設定が無い日のデフォルト値として使われます。
詳細はライン開始時刻設定 作業手順書を参照してください。
ⓘ 開始時刻の優先順位: (1) 日付ヘッダーの日別設定（最優先） → (2) ライン開始時刻設定 → (3) 08:00

▶ 自動計画

自動計画が設定されているラインでは「自動計画」ボタンが表示されます。需要データに基づいて計画を自動生成します。
1 「自動計画」ボタンをクリック
2 確認ダイアログにライン名と対象期間が表示される（デフォルト: 明後日以降）
3 「はい」で即実行 / 「いいえ」で開始日を変更してから実行
4 需要を取り込み、各日の需要を計画欄にコピー → 保存で確定
ⓘ まとめ設定がある製品は、指定曜日にまとめて計画されます（下記「まとめ設定」参照）。日付ヘッダーの→ボタンで1日分だけ需要→計画コピーも可能です。
⚠ 「自動計画」「まとめ設定」ボタンはライン編集の「自動計画適用設定」で有効化されたラインのみ表示されます（設定方法はライン編集手順書 STEP 8を参照）。フロア出荷タブでは非表示です。

⚠ 注意事項

  • ラインが必須: ラインを選択しないと保存・取込・表示は実行できません
  • 保存の期間指定: 保存ボタンを押すと期間指定ダイアログが表示されます。from/toで保存対象期間を絞り込めます（デフォルトは表示期間全体）
  • 保存後の自動処理: 保存ボタン押下後は工程展開 → 在庫再計算 → ガント再生成が自動実行されます。処理中は「データ更新中」と表示されます
  • ロック期間: 過去の計画はロック期間として編集不可です。「計画変更」ボタンで理由入力後に編集できます
  • 休日セル: 非稼働日のセルは読み取り専用です（入力不可）
  • ガント連結モード: 連結表示中はバー編集と各保存ボタンは使えません。編集は「分解」モードで行ってください
  • ガント保存の排他: 追加・削除の未保存中は時間・数量変更を始められません。逆も同様です
  • 土日の再計算: 土日・非稼働日にF6/F8を実行した場合、計算基準日は直前の営業日に調整されます
  • 日替わり時刻: 8:00が日替わり時刻です。7:59以前は前日として扱われます
  • 最終工程開始時刻の優先順位: (1) 日付ヘッダーの日別設定 → (2) デフォルト開始時刻設定 → (3) 08:00
  • ツールバー折りたたみ: ▲/▼ボタンでツールバーを折りたためます。折りたたみ時はライン名・期間・検索条件がサマリー表示されます
  • 開始時刻全削除: 表示期間内の日別開始時刻の上書き設定を一括削除してデフォルト開始時刻に戻します。日別上書きが無い場合はボタンが無効になります
  • フッターショートカット: F1:戻る / F2:進む / F3:クリア / F4:表示のみ / F5:キャンセル / F6:需要取込 / F8:取込+在庫計算 / F10:印刷
