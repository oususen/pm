# 進捗のみ

ライン・工程・品番ごとの「進度」を一覧で確認する画面です。
顧客需要に対する実績の遅れ/先行（進度）を把握するために使用します。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「進捗のみ」を選択

## 使い方

1. 画面を開くと現在の日付範囲のデータが自動的に読み込まれます。
2. ライン・工程・品番のフィルターに入力すると、即座に表示が絞り込まれます。
3. 表示開始日や期間を変更した場合は「更新」を押してデータを再取得します。
4. 「再計算」ボタンで、表示中の品番の進度を最新化できます。

## 画面の見方

- 日付列には日別の進度（累積）が表示されます。
- **進度**: 顧客需要（確定/内示）に対する実績の過不足累計です。
  - プラス: 先行（余裕あり）
  - マイナス: 遅れ（要対策）
  - マイナスの場合は赤色で表示されます。

## ボタン

- **更新**: データを再取得します。
- **再計算**: 表示されている品番に対して進度再計算を実行します。

## 注意点

- この画面は「進度」のみを表示します。計画数や実績数を確認したい場合は「進捗管理」画面を使用してください。
