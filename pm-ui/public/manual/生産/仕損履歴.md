# 仕損履歴

仕損記録の検索と、BOM展開の明細確認・戻し処理・仕損確定を行う画面です。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「仕損履歴」を選択


## 使い方

### 検索

1. 期間・工程・品番・理由・判定を指定します。
2. 「検索」を押します。
3. 「リセット」で検索条件を初期状態に戻し再検索します。
4. 「CSV出力」で一覧を出力できます。

### BOM展開明細の確認

1. 画面上の記録表で対象行をクリックします（画面を開いた際は直近の1件が自動的に選択されます）。
2. 下段の「BOM展開明細」で減算対象を確認します。
3. 明細は「加工/購入先」フィルター（購買/工程）やテキスト検索で絞り込めます。

### 補充完了

- 明細の「この品を完了」で個別に補充完了を登録します。
- 「全品目を完了にする」で一括完了にします。

### 戻し・仕損確定

1. 「戻し数量」を入力します。
2. 「使用可として戻す」で在庫に戻します。
3. 「仕損確定」で廃棄確定にします。

## 記録一覧の列

| 列 | 説明 |
|----|------|
| 記録時刻 | 仕損を記録した日時 |
| 工程 | 仕損が発生した工程 |
| 品番・品名 | 仕損した製品 |
| 仕損数 | 仕損数量 |
| 判定 | 現在の判定状態（下表参照） |
| 戻し数量 | 在庫に戻した数量 |
| 理由 | 仕損理由 |
| 理由詳細 | 理由の詳細（「その他」の場合） |
| 記入者 | 登録者名 |
| 補充 | 全品目の補充完了時に ✅ が表示 |

## 判定ステータス

| 判定 | 説明 |
|------|------|
| 判定待ち | まだ廃棄か使用可か未決定の状態 |
| 使用可 | 使用可能として在庫に戻した状態 |
| 仕損確定 | 廃棄が確定した状態 |
| 一部使用可 | 一部を在庫に戻し、残りが仕損確定の状態 |

## 注意点

- 戻し数量は残数量以内で入力してください。
- 明細がない場合は「明細がありません」と表示されます。
- フィルター適用時に該当明細がない場合は「該当する明細がありません」と表示されます。
