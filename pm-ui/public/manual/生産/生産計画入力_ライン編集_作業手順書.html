1
ライン編集タブを開く
生産計画入力画面のタブバーで「ライン編集」をクリックします。確認メッセージは表示されず、直接設定画面に切り替わります。
タンク 2班 クボタ … ライン編集
ⓘ ライン編集タブは常にタブバーの最後に表示されます。他のタブはDB設定で変更可能ですが、ライン編集タブは固定です。
2
タブ管理
タブバーに表示されるタブを追加・名前変更・削除します。

▶ タブを追加する

▼ タブ管理
タブキー（英数字） タブ名 追加
tank タンク 削除
floor 2班 削除
タブキー英数字で一意のキーを入力（例: tank, floor, kubota）。後から変更不可
タブ名画面に表示される名前（日本語可）。後から変更可能

▶ タブ名を変更する

既存タブの名前欄を直接書き換えます。変更は「保存」ボタン押下時に反映されます。

▶ タブを削除する

タブ行右端の「削除」ボタンで削除します。削除は「保存」ボタン押下時に反映されます。
⚠ タブを削除すると、そのタブに紐づいた対象ライン設定も失われます。
3
タブ別ライン選択
各タブで表示・操作対象とするラインを設定します。ここで選択したラインのみが、計画入力画面のライン選択ドロップダウンに表示されます。
▼ タブ別ライン選択
対象タブ 2班
☑ L2100 - フロアライン
☑ L2200 - フロアサブ
☐ L3000 - タンクライン
☐ L4000 - ブレード
手順: 「対象タブ」ドロップダウンでタブを選択 → チェックボックスで対象ラインを選択/解除 → 「保存」
ⓘ フロア出荷タブは通常のフロアタブとは独立した設定を持ちます。同じラインでもタブごとに別々に管理されます。
4
前日シフト台数設定
ライン×工程ごとに、前日シフトとして扱う台数を設定します。ガントチャートの計算に使用されます。
▼ 前日シフト台数設定（ライン×工程）3件
ライン選択 工程選択 台数 追加
L2100 / 4003 / 前日シフト 2台 削除
L2100 / 4002 / 前日シフト 3台 削除
手順: ライン → 工程 → 台数を入力 → 「追加」 → 「保存」
5
ガント開始時刻設定
ライン×工程ごとに、工程ガントチャートの開始時刻を設定します。工程によって開始時刻が異なる場合に使用します。
▼ ガント開始時刻設定（ライン×工程）2件
ライン選択 工程選択 08:00 追加
L2100 / 4003 / 開始 08:00 削除
L2100 / 4001 / 開始 09:30 削除
手順: ライン → 工程 → 時刻を入力（HH:mm形式） → 「追加」 → 「保存」
ⓘ この設定は工程ガントのバー位置計算に使われます。日付ヘッダーの最終工程開始時刻とは別の設定です。
6
ガント展開除外
ライン×工程ごとに、ガントチャートに表示しない工程を設定します。一部の工程をガントから除外したい場合に使用します。
▼ ガント展開除外（ライン×工程）1件
ライン選択 工程選択 追加
L2100 / 4005 / ガント展開除外 削除
手順: ライン → 工程を選択 → 「追加」 → 「保存」
ⓘ ライン選択後、そのラインに紐づく工程のみが工程ドロップダウンに表示されます。
7
計算特例
ライン×工程×計算対象ごとに、在庫・計画在庫・需要の計算に関する特例ルールを設定します。
▼ 計算特例（ライン×工程×計算対象×設定）0件
ライン選択 工程選択 計画在庫 ▼ ORDER_QTY使用 ▼ 追加
設定なし
計算対象計画在庫 / 在庫 / 需要 から選択
設定値現在は ORDER_QTY使用 のみ選択可能
手順: ライン → 工程 → 計算対象 → 設定値を選択 → 「追加」 → 「保存」
8
自動計画適用設定
自動計画ボタンを表示するラインと、対象製品を設定します。ここに設定されたラインでは、計画入力画面に「自動計画」ボタンが表示されます。
▼ 自動計画適用設定（ライン×製品）4件
自動計画ボタンを表示するラインと対象製品を設定します。
ライン選択 製品選択 追加
L2100 / YD40008720K フロア検査 削除
L2100 / YD40008750K フロア検査B 削除
手順: ライン → 製品を選択 → 「追加」 → 「保存」。ラインを選択すると、そのラインのルーティングに紐づく製品のみが製品ドロップダウンに表示されます。
ⓘ 自動計画は、登録された製品の需要データをもとに計画を自動生成する機能です。まとめ生産設定がある場合、集約ルールに従って複数日分をまとめて計画します。
9
設定を保存する
すべての設定変更が完了したら、画面下部の「保存」ボタンをクリックします。
保存
保存すると全セクションの設定が一括でDBに保存されます。保存完了後、メッセージが表示されます。
✓ 保存後は他のタブに切り替えて、設定が反映されていることを確認してください（ライン選択の候補が変わるなど）。

⚠ 注意事項

  • 保存忘れ: 「追加」「削除」ボタンはルール一覧を画面上で編集するだけです。「保存」を押さないとDBに反映されません
  • タブキーは変更不可: タブ追加時に設定したタブキー（英数字）は後から変更できません。タブ名（表示名）は変更可能です
  • フロア出荷の独立性: フロア出荷タブは通常のフロアタブとは独立した設定を持ちます。同じラインでもタブごとに別管理です
  • ルール重複: 同じライン×工程の組み合わせでルールを重複追加するとエラーになる場合があります
  • ガント展開除外: 除外した工程はガントチャートに表示されなくなります。工程展開自体は行われますが、ガントのバーが生成されません
