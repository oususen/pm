# カメラ実績入力

## 概要
- 現場スマホの内蔵カメラを使って実績を入力する画面です。
- 入力単位は `ライン × 工程 × 製品` です。

## 操作手順
1. ライン・工程・製品を選択します。
2. モードを選択します（`自動検知（YOLO PoC）` / `手動検知（PoC）`）。
3. `カメラ開始` を押して映像を表示します。
4. 自動モードでは約1.2秒ごとにフレーム送信し、通過判定時に実績を自動加算します。
5. 手動モードでは `検知+1（PoC）` を押すと実績を1件登録します。
6. `カメラ停止` で入力を終了します。

## 補足
- 通信失敗時は端末内キューに退避し、再送します。
- 業務日は8:00締めで集計されます。
