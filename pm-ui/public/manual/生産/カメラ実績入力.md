# カメラ実績入力

## 概要
- 現場スマホの内蔵カメラを使って実績を入力する画面です。
- 入力単位は `ライン × 工程 × 製品` です。

## 操作手順
1. ライン・工程・製品を選択します。
2. モードを選択します（`自動検知（YOLO PoC）` / `手動検知（PoC）`）。
3. `カメラ開始` を押して映像を表示します。
4. 自動モードでは約1.2秒ごとにフレーム送信し、通過判定時に実績を自動加算します。
5. 手動モードでは `検知+1（PoC）` を押すと実績を1件登録します。
6. `カメラ停止` で入力を終了します。

## 設定パラメータ

画面下部のチューニング欄で検知精度を調整できます。値は端末ごとにブラウザに保存されます。

- 判定点はフレーム上の固定点ではなく、**各検出枠の中に毎フレーム計算される点**です。

**通過カウント条件**
- `判定点` はフレーム固定点ではなく、**検出枠の中に置く代表点**です。
- その代表点が `判定ライン` を横切ると `実績+1` になります。
- ただし、`最低Y比率ライン` より上にある判定点はカウントしません。

### パラメータと図の対応

| パラメータ | 図のどこに効くか | 調整の目安 |
|---|---|---|
| ライン位置(0-1) | `判定ライン` の左右位置 | ワークが実際に通る位置へ合わせる |
| ライン余白(0-1) | `左余白 / 右余白`（無効帯） | 端で誤検知するなら広げる |
| 人物下側比率 | `判定点` の上下位置 | 足元判定を上げ下げして安定点を探す |
| 最低Y比率 | `最低Y比率ライン` の高さ | 上側遠景の誤検知を除外したい時に上げる |

| パラメータ | 既定値 | 範囲 | 説明 |
|---|---|---|---|
| 送信間隔ms | 1200 | 200〜5000 | フレームをサーバーへ送る間隔（ミリ秒）。小さいほど検知頻度が上がるがサーバー負荷も増加 |
| ライン位置(0-1) | 0.5 | 0.1〜0.9 | 通過判定ラインの水平位置。0=左端、1=右端。カメラ映像内でワークが通過する横位置に合わせる |
| ライン余白(0-1) | 0.03 | 0.01〜0.3 | 通過判定ラインの左右に設ける無効マージン。端で誤検知する場合に広げる |
| 人物下側比率 | 0.78 | 0.5〜0.95 | 検出バウンディングボックスの上端から何割の位置を判定点とするか。デフォルトモデル（人物検知）では足元付近を判定点にする |
| 最低Y比率 | 0.45 | 0.1〜0.95 | 判定点のY座標がフレーム高さに対してこの比率未満の場合は無視する。画面上部の遠景誤検知を除外する |
| YOLO閾値 | 0.5 | 0.1〜0.95 | YOLOモデルの信頼度しきい値。高くすると誤検知が減るが見逃しが増える |
| 重複防止秒 | 1.2 | 0.2〜5.0 | 同一物体が連続通過と判定されないためのクールダウン時間（秒） |
| 動体閾値比率 | 0.01 | 0.002〜0.08 | フレーム間差分による動体検知のしきい値。小さいほど微小な動きも検知する |

### よくある調整パターン

- 1. カウントされない: `ライン位置` をワーク通過位置へ寄せる → `人物下側比率` を調整
- 2. 上側の誤検知が多い: `最低Y比率` を上げる（例: 0.45 → 0.55）
- 3. 同じワークを2回拾う: `重複防止秒` を上げる

## 補足
- 通信失敗時は端末内キューに退避し、再送します。
- 業務日は8:00締めで集計されます。
