# 長期負荷チャート

顧客需要×ラインサイクルタイムから、ライン別・工程別の負荷時間（h）を日別・週別・月別で表示する画面です。

[作業手順書（日本語）](長期負荷チャート_作業手順書.html)

## 画面パス

`生産 > 負荷計算 > 長期負荷チャート`

---

## 操作手順

### 1. 期間設定

1. **開始日** を指定します。
2. **期間** を選択します（3ヶ月 / 6ヶ月 / 1年 / カスタム）。カスタム選択時は終了日も指定します。
3. **集計** を選択します（日別 / 週別 / 月別）。

### 2. 需要設定（任意）

1. `需要設定` ボタンを押すとポップオーバーが開きます。
2. **OrderLine使用最終日** を設定すると、その日までは受注明細（OrderLine）、翌日以降はLineDemandで需要を集計します。
3. 未設定の場合は全期間LineDemandを使用します。
4. `保存` を押して設定を保存します。設定変更は管理者のみ可能です。

### 3. ライン・グループ選択

1. **グループ選択**: チェックを入れるとグループ合算チャートが表示されます。
2. **ライン個別選択**: チェックを入れるとライン別チャートが表示されます。
3. `全選択` / `全解除` ボタンで一括操作できます。

### 4. 計算・表示

1. `計算` を押すと負荷チャートが表示されます。
2. 棒グラフの上に負荷時間（h）が表示されます。
3. 棒にマウスを乗せるとツールチップで工程別の負荷詳細が確認できます。

### 5. チャートの見方

- **グループチャート**: 選択グループ配下のライン負荷合算（紫色の棒）
- **ラインチャート**: ライン全体の負荷時間（赤色の棒）
- **工程チャート**: ライン配下の各工程の負荷時間（青色の棒）。設備台数2台以上の工程は按分後の値を表示します。
- すべてのグラフは共通のY軸スケール（最大負荷基準）で表示されるため、グラフ間で負荷量を直接比較できます。

### 6. Excel出力

1. 計算結果が表示された状態で `Excel出力` を押します。
2. 以下のシートが出力されます:
   - **グループ名シート**: グループ合算の負荷時間
   - **負荷(h)シート**: ライン別の負荷時間（月別は H/月・稼働日・H/日 の3列構成）
   - **完成品別各工程ライン負荷シート**: ライン×工程×完成品 単位の負荷時間
3. 各シートにはタイトル・作成日・作成者が付与されます。

---

## カレンダー未設定ライン

- カレンダーが未設定のラインは警告メッセージが表示されます。
- 稼働率（%）ではなく負荷時間（h）のみで表示されます。

## 補足

- 画面右上のボタンから **出来高集計** / **サイクルタイム入力** に遷移できます。
- 工程負荷は **設備台数** で按分されます（負荷 ÷ 設備台数）。設備台数は出来高集計の係数設定タブで設定します。
- 需要日付の補正: 前倒しフラグ付きの需要は、リードタイム分をカレンダ基準で戻した日付に再配置して表示します。
- 月初内示均等配分: 月初3営業日の需要合計が前月平均の10倍以上の場合、月合計内示と判定し当月営業日へ均等配分します。
