# 仕損品記録

工程単位で仕損（不良品・廃棄品）を登録する画面です。

## 画面への行き方

1. グローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「仕損品記録」を選択

## 使い方

1. **ライン**と**工程**を選択します。
2. 製品一覧から対象製品を選択します（カード形式で表示）。
   - 絞り込み: 「自工程製品」「購入品」「社内製作品」で区分フィルタできます。品番・品名でのテキスト検索も可能です。
   - 一覧にない場合は「手入力に切替」で全製品から選択できます。
3. **仕損数量**を入力します（既定値: 1）。
4. **判定**を選択します。
5. **実績入力済み**を選択します。
6. **理由**を選択します。
7. **記入者**を入力します（ログインユーザー名が自動入力されます）。
8. 「記録を登録」を押します。

## 入力項目

| 項目 | 必須 | 説明 |
|------|:----:|------|
| 仕損数量 | ○ | 1 以上の数値 |
| 判定 | ○ | **仕損確定**: 廃棄が確定した場合 / **判定待ち**: 後日判断する場合 |
| 実績入力済み | ○ | **はい**: 生産実績を入力した後に仕損が判明した場合 / **いいえ**: 生産途中で仕損が発生した場合 |
| 理由 | ○ | リストから選択（錆、変形、ブローホール、精度NG 等） |
| 理由詳細 | △ | 理由が「その他」の場合は必須 |
| 記入者 | ○ | 登録者の名前 |
| ロット番号 | - | 任意 |
| 備考 | - | 任意 |

## 製品区分と処理の違い

製品の区分は工程選択時にシステムが自動判定します。ユーザーが意識する必要はありませんが、区分により内部の処理が異なります。

| 区分 | 対象 | 実績入力済みの場合の処理 |
|------|------|--------------------------|
| 自工程製品 | 選択中の工程で生産している製品 | 当該工程の実績から仕損数を減算 |
| 購入品 | 仕入先から購入した材料・部品 | 実績は減算せず、在庫・進度を調整 |
| 社内製作品 | 前工程で生産された中間品 | 実績は減算せず、在庫・進度を調整 |

## 注意点

- 本日の計画がない場合でも、工程に関連する製品がカード一覧に表示されます。一覧にない製品は「手入力に切替」から選択できます。
- 登録すると在庫・進度に即時反映されます。誤登録した場合は管理者に連絡してください。
