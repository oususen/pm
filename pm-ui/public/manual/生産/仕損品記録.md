# 仕損品記録

工程単位で仕損（SCRAP）を登録する画面です。仕損数・理由・判定を入力します。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「仕損品記録」を選択

## 使い方

1. ラインと工程を選択します。
2. 製品を選択、または手入力します。
3. 仕損数量、判定、理由を入力します。
4. 「記録を登録」を押します。

## 入力項目

- 仕損数量: 1 以上の数値を入力します。
- 判定: 仕損確定 / 判定待ち を選択します。
- 理由: リストから選択します。
- 理由詳細: 理由が「その他」の場合は必須です。
- 記入者: 必須です。
- ロット番号、備考は任意です。

## 注意点

- 記録タイプは仕損品記録に固定されています。
- 本日の計画がない場合は手入力になります。
