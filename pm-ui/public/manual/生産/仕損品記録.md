# 仕損品記録

工程単位で仕損（不良品・廃棄品）を登録する画面です。

## 画面への行き方

1. グローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「仕損品記録」を選択

## 使い方

1. **ライン**と**工程**を選択します。
2. 製品一覧から対象製品を選択します（カード形式で表示）。
   - 絞り込み: 「自工程製品」「購入品」「社内製作品」で区分フィルタできます。品番・品名でのテキスト検索も可能です。
   - 仕損記録では時間帯で候補を絞り込まず、取得した候補全体から選択できます。計画数量は表示しません。
   - 一覧にない場合は「手入力に切替」で全製品から選択できます。
3. **仕損数量**を入力します（既定値: 1）。
4. **判定**を選択します。
5. **実績入力済み**を選択します。
6. **理由**を選択します。
7. **記入者**はログイン者が表示され、変更できません。**起因者**・**報告者**をユーザー一覧から選択します（起因者は任意で最初は空欄、報告者は必須で最初はログイン者です。自由入力はできません）。
8. 「記録を登録」を押します。

## 入力項目

| 項目 | 必須 | 説明 |
|------|:----:|------|
| 仕損数量 | ○ | 1 以上の数値 |
| 判定 | ○ | **仕損確定**: 廃棄が確定した場合 / **判定待ち**: 後日判断する場合 |
| 実績入力済み | ○ | **はい**: 生産実績を入力した後に仕損が判明した場合 / **いいえ**: 生産途中で仕損が発生した場合 |
| 理由 | ○ | リストから選択（錆、変形、ブローホール、精度NG 等） |
| 理由詳細 | △ | 理由が「その他」の場合は必須 |
| 記入者 | ○ | ログイン者固定。変更不可 |
| 起因者 | - | 任意。仕損の起因者を一覧から選択、未選択でも登録可 |
| 報告者 | ○ | 仕損を報告したユーザーを一覧から選択 |
| ロット番号 | - | 任意 |
| 備考 | - | 任意 |

## 製品区分と処理の違い

製品の区分は工程選択時にシステムが自動判定します。ユーザーが意識する必要はありませんが、区分により内部の処理が異なります。

| 区分 | 対象 | 実績入力済みの場合の処理 |
|------|------|--------------------------|
| 自工程製品 | 選択中の工程で生産している製品 | 当該工程の実績から仕損数を減算 |
| 購入品 | 仕入先から購入した材料・部品 | 実績は減算せず、在庫・進度を調整 |
| 社内製作品 | 前工程で生産された中間品 | 実績は減算せず、在庫・進度を調整 |

## 注意点

- 仕損記録ではチェックシート実施・設備点検、加工中/中断表示、本日計画対象・現在時刻のみ・時間帯移動、計画未取得ヒントを表示しません。分類・検索・製品選択・手入力切替は利用できます。
- 本日の計画がない場合でも、工程に関連する製品がカード一覧に表示されます。一覧にない製品は「手入力に切替」から選択できます。
- 登録すると在庫・進度に即時反映されます。誤登録した場合は管理者に連絡してください。
- 記入者は常にログイン者です。登録成功後、起因者は空欄、報告者はログイン者に戻ります。起因者は選択後も空欄に戻せます。ユーザー一覧の取得失敗時は登録できません。エラーが表示された場合は画面を再読み込みしてください。
- 起因者が未選択の場合は、起因者の専用列にNULLを保存します。
- 三者のユーザーコード（username）のみ専用列に保存します。姓名は三者情報として保存しません。表示用の記入者名は従来どおり保存します。
