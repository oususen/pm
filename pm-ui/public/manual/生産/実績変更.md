# 実績変更

生産実績照会で確認したレコードID（セッションID）を使い、実績の修正・削除を行う画面です。

## 画面への行き方

1. 上部ナビの「生産管理」を開く
2. 「生産管理メニュー」→「実績変更」を選択

## できること

- レコードIDを指定して対象セッションを検索
- 開始時刻 / 終了時刻 / 実績数量を更新
- セッションを削除

## 反映ルール

- 更新時: `WORK` かつ `END/PAUSE` 終了のセッションは、実績数量の差分を `LineBacklog.actual_qty` に反映
- 削除時: 同条件のセッションは、元の実績数量を `LineBacklog.actual_qty` から減算
- 削除時は該当セッションに紐づく `PRODUCTION` 記録も削除

## 注意

- 数量は0以上で入力してください。
- 終了時刻は開始時刻以降にしてください。
