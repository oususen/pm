# 実績変更

過去の工程実績セッションを検索し、数量・時刻の修正・削除、または登録漏れの後入力を行う画面です。
変更内容は在庫・計画在庫・進度・計進・構成部品の実需にも即時反映されます。

## 画面への行き方

1. 上部ナビの「生産管理」を開く
2. 「生産管理メニュー」→「実績変更」を選択

---

## セッションの検索

画面上部の検索フォームで対象を絞り込み、「検索」ボタンを押します。

| 検索条件 | 説明 |
|----------|------|
| レコードID | セッションIDを直接指定（生産実績照会画面で確認できます） |
| 期間 | 実績の日付範囲で絞り込み |
| ライン | ライン名で絞り込み |
| 工程 | 工程コード・工程名で絞り込み |

---

## 追加・変更・削除の調査

検索結果一覧の「操作調査」列と、画面下部の「追加・変更・削除調査一覧」で、後入力追加・更新・削除履歴を確認できます。
下部の「追加・変更・削除調査一覧」は、上部の検索条件とは連動せず独立して表示されます。

| 表示 | 意味 |
|------|------|
| 追加 | `新規セッション追加（登録し忘れ補完）` から登録された後入力セッション |
| 変更 | 実績変更画面で「保存」されたセッション |
| 削除 | 実績変更画面で「削除」されたセッション |

補足:
- 調査一覧は `実績変更` 画面から追加 / 保存 / 削除した `PROCESS` セッションのみ対象です。
- 通常の実績入力で作成・終了したセッションは表示しません。
- レーザー / ブレーキ実績は対象外です。
- 一覧には `変更内容` `変更者` `変更時刻` `変更理由` を表示します。
- 変更内容には `品番` `品名` `作業日` `作業者` `開始時刻` `終了時刻` `実績数量` `仕損` のうち、該当する項目が表示されます。
- 保存時は変更理由の入力が必須です。
- 削除時は削除理由の入力が必須です。

---

## セッションの修正・削除

検索結果の一覧から対象行を編集します。

### 修正手順

1. 該当行の「開始時刻」「終了時刻」「実績数量」を変更
2. 「保存」ボタンを押す

### 削除手順

1. 該当行の「削除」ボタンを押す
2. 削除理由を入力して確定する
3. 確認後、セッションが削除される

---

## 登録漏れの後入力（新規セッション追加）

過去日付の実績を登録し忘れた場合、「▼ 新規セッション追加（登録し忘れ補完）」ボタンで入力フォームを開きます。

### 入力項目

| 項目 | 説明 |
|------|------|
| ライン | 実績を登録するライン |
| 工程 | 実績を登録する工程 |
| 品番 | 品番または品名で検索・選択 |
| 開始日時 | 作業開始の日時 |
| 終了日時 | 作業終了の日時 |
| 実績数量 | 生産した数量（0以上） |
| 追加理由 | なぜ後入力するのかを記録する理由 |

「追加登録」ボタンを押すと登録され、在庫・進度が即時更新されます。

---

## 変更後の自動反映

修正・削除・後入力のいずれの操作でも、変更日から当日までの以下の数値が自動的に差分更新されます。

### 変更した製品（親製品）

| フィールド | 更新範囲 | 変化 |
|-----------|----------|------|
| 在庫 | 変更日〜当日 | 差分を加算 |
| 計画在庫 | 変更日〜当日 | 差分を加算 |
| 進度 | 変更日〜当日 | 差分を加算 |
| 計進（計画進度） | 変更日〜当日 | 差分を加算 |

### BOM構成品（子製品）

| フィールド | 更新範囲 | 変化 |
|-----------|----------|------|
| 在庫 | 変更日〜当日 | 差分×BOM使用数を減算（消費量に連動） |
| 計画在庫 | 変更日〜当日 | 差分×BOM使用数を減算 |
| 実需 | 変更日のみ | 差分×BOM使用数を加算（消費実績に連動） |

> **例**: 実績を 24 → 2 に変更（差分 = -22）、BOM使用数 = 1 の場合
>
> - 親製品の在庫・進度: -22
> - 子製品の在庫: +22（消費が減ったため在庫回復）
> - 子製品の実需: -22（出庫実績が減少）

---

## 注意事項

- 実績数量は 0 以上で入力してください。
- 終了時刻は開始時刻以降にしてください。
- 変更対象は過去日付のセッションのみです（未来日は反映対象外）。
- 変更は `WORK` タイプかつ `END` または `PAUSE` で終了したセッションのみ在庫・進度に反映されます。
