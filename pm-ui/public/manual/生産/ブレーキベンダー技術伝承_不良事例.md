# ブレーキベンダー 不良事例

## 目的

同じ不良を繰り返さないために、症状と原因と対策を残します。

## 残すべき事例

- 角度不足、角度過多
- 曲げ順ミス
- キズ、打痕、当たり
- 割れ、変形
- 左右違い、表裏違い
- 寸法ずれ、バックゲージ合わせ不良

## 記録の基本形

- `症状`: 何が起きたか
- `発生条件`: 材質、板厚、金型、設備、作業状態
- `原因`: なぜ起きたか
- `その場対応`: 現場でどう直したか
- `再発防止`: 次回どう防ぐか

## 運用

- ブレーキ実績入力画面の `作業のコツ・注意事項` パネルから編集できます
- 品番別標準条件はここではなく、別途作業標準側で管理します
- 原因が設備依存なら設備別注意にも反映します
