# 安全在庫一覧

## 1. 画面概要

品番ごとの安全在庫（最小在庫）と、現在の不足状況を確認する画面です。  
生産メニューの「安全在庫一覧」から開きます。

## 2. 主な表示項目

- 品番 / 品名
- 保管場所
- 現在在庫
- 引当済
- 可用在庫
- 安全在庫
- 不足数
- 更新日時

不足数は、`安全在庫 - 可用在庫`（0未満は0）で表示します。
安全在庫（最小在庫）は整数で管理します。

## 3. 検索

- 品番/品名
- 保管場所
- 加工先
- 購入先
- 安全在庫割れのみ

「検索」で絞り込みを実行し、「リセット」で条件を初期化します。

## 4. 操作

- 再読込: 最新データを取得
- CSV出力: 表示中データをCSVで出力
- 在庫引当一覧へ: 在庫引当管理画面へ遷移
- 編集: 該当在庫引当の編集画面を開く（権限が必要）

## 5. 権限

- 閲覧: 生産メニューの在庫閲覧権限に準拠
- 編集ボタン: `production.stock_allocations` の編集権限が必要
