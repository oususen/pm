# 仕入れ在庫 / 残量一覧

購入品を対象に、日付別の数量（計需・実需・計画・実績・調整・仕損・在庫・計画在庫・進度）を一覧表示します。

## 画面への行き方

1. 上のグローバルナビゲーションの「購買管理」を開く
2. 「在庫/残量」を選択

## 使い方

1. **仕入先**をドロップダウンから選択します（必須）。
2. 品番/品名で絞り込む場合は、テキスト欄に入力します（任意）。
3. 開始日と期間（30日・60日・90日・120日）を指定します。
4. 「更新」を押して一覧を表示します。

※ 仕入先が未選択の場合、「更新」ボタンは押せません。

## ボタンの役割

| ボタン | 処理内容 | 用途 |
|--------|----------|------|
| **更新** | 需要再計算 + 仕損再計算 + データ取得 | 最新の受注・実績を反映したいとき |
| **在庫再計算** | 在庫・計画在庫の再計算のみ | 調整値変更後など在庫だけ更新したいとき |

※「更新」は内部で需要再計算と仕損再計算も自動で実行します。

## 画面の見方

### 左側（製品情報）

各製品カードの左側に以下の情報が表示されます。

| 項目 | 説明 |
|------|------|
| 品番 | 購入品の品番。「▶ BOM展開」ボタン付き |
| 品名 | 購入品の品名 |
| 仕入先 | 仕入先名 |
| 仕入先コード | 仕入先コード |
| 翌月 | （現在は表示なし・将来用） |
| 翌々月 | （現在は表示なし・将来用） |
| 完成品向けLT | 完成品までの総リードタイム（日） |
| 自LT | 自工程のリードタイム（日） |

### 右側（日付マトリクス）

- 行は「計需」「実需」「計画」「実績」「調整」「仕損」「在庫」「計画在庫」「進度」です。
- 数値が 0 の場合は空欄で表示されます。
- 在庫・計画在庫・進度がマイナスのときは赤色で表示されます。
- 土日・休日の列はピンク色で表示されます。

## BOM展開

品番の右にある「▶ BOM展開」ボタンを押すと、その購入品を使用しているBOM子製品の日付マトリクスを展開表示します。

- 子製品ごとに品番・品名・工程・BOM数量と日付別数量が確認できます。
- 「▼ BOM展開」を再度押すと閉じます。
- BOM子製品が存在しない場合は「BOM子製品がありません」と表示されます。

## 調整の参照

この画面の「調整」行は**読み取り専用**です。現在の調整数量を確認するだけで、この画面から直接編集することはできません。

調整値を変更する場合は、別途用意されている調整専用画面から操作してください。

## 注意点

- 仕入先が未選択の場合、一覧は表示されません。
- 「在庫再計算」は確認ダイアログが表示されます。
- 「在庫再計算」は選択中の仕入先のラインのみを対象とします。
