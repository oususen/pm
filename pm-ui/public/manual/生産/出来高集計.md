# 出来高集計

工程実績から製品別の実績サイクルタイム（CT）を計算し、BOM展開で完成品CTまで保存する画面です。

[作業手順書（日本語）](出来高集計_作業手順書.html)

## 画面パス

`生産 > 負荷計算 > 出来高集計`

## タブ構成

画面上部に **計算** / **照会** / **係数設定** の3タブがあります。

---

## 計算タブ

### 1. 実績CT計算

1. **工程** を選択します（必須）。
2. **ライン** を選択します（省略時は自動判定）。
3. **開始日** と **終了日** を指定します。
4. `計算` を押すと、指定期間内の工程実績から製品別の平均CTを一覧表示します。

表示される情報:
- 品番 / 品名 / 生産数量 / 有効稼働時間 / CT（秒/個） / セッション数

### 2. 実績CT保存

1. 計算結果を確認したら `実績CT保存` を押します。
2. 稼働率の確認ダイアログが表示されます。
   - 稼働率100%（未設定）の場合: 「稼働率を設定しましたか？」と確認されます。
   - 稼働率が設定済みの場合: 「この稼働率で補正して保存しますか？」と確認されます。
3. **OK**: 実績CTと補正CT（実績CT ÷ 稼働率）の両方をDBに保存します。
4. **キャンセル**: 係数設定タブに遷移します。稼働率を設定してからやり直してください。

### 3. 完成品CT計算・保存

1. 実績CT保存後、`完成品CT計算` が押せるようになります。
2. 押すと、補正CT/生CTのどちらで計算するか確認ダイアログが表示されます（稼働率100%以外の場合）。
   - **OK**: 補正CT（稼働率適用済み）で計算
   - **キャンセル**: 生CT（実測値そのまま）で計算
3. BOM逆展開で完成品ごとのCT合計と内訳が表示されます。
4. `完成品CT保存` を押して保存します。保存完了ダイアログに使用したCT種別（補正CT/生CT）が表示されます。

---

## 照会タブ

保存済みの実績CTと完成品CTを一覧で確認できます。

- **実績CT一覧**: 工程 / ライン / 期間 / 品番 / CT / 補正CT / 稼働率 / 計算日時
- **完成品CT一覧**: 工程 / ライン / 期間 / 完成品コード / CT / CT種別（補正CT/生CT） / 計算日時

工程やラインで絞り込み可能です。

---

## 係数設定タブ

工程ごとの **稼働率（%）** と **設備台数** を設定します。

- **稼働率**: 実績CT保存時の補正に使用します（補正CT = 実績CT ÷ 稼働率）。稼働率は `勤務 > 加工費集計 > 期間集計` の 加工時間 ÷ 勤務時間 で算出します。参照: <a href="/manual/勤務/加工費集計.md" style="color:#2563eb;">加工費集計マニュアル</a> / <a href="/manual/勤務/加工費集計_作業手順書.html" style="color:#2563eb;">加工費集計 作業手順書</a>
- **設備台数**: 長期負荷チャートで負荷時間を按分するときに使用します（負荷 ÷ 設備台数）。

### 操作手順

1. 工程フィルタで対象工程を絞り込みます（任意）。
2. 各工程の稼働率・設備台数を編集します（変更行は黄色でハイライトされます）。
3. `保存` を押します。

---

## 補足

- 画面右上のボタンから **ラインサイクルタイム入力** / **長期負荷チャート** に遷移できます。
- CT計算式: 有効稼働時間（秒） ÷ 生産数量（個） = サイクル時間（秒/個）
- 補正CT計算式: 実績CT ÷ （稼働率 ÷ 100） = 補正CT
