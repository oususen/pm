# 配送計画（フロア出荷）

フロア出荷ラインの配送計画と実績を、同じ画面で登録・更新するためのマニュアルです。  
本手順は「2週間計画を作成し、実績は後でまとめ入力する」運用を想定しています。

## 画面への行き方

1. 上部メニューで「生産」を開く
2. 「生産計画入力」を開く
3. タブ「フロア出荷」を選択
4. サブタブ「進度基準」を選択

## 事前設定

1. ラインで `L2102 - フロア配送` を選択
2. `表示開始日` と `期間` を設定
3. `表示のみ` で対象データを表示

## 配送計画の入力

1. `計画` 列に数量を入力
2. 必要に応じて `順` を入力（同日同品番の複数便を表現）
3. `保存` を押して計画を登録

## 実績のまとめ入力（推奨フロー）

1. `一括実績入力` を押す
2. 期間（開始日・終了日）を指定して `セット`
3. 指定期間の `計画合計（メイン+追加ロット）` が `実績` セルに入る
4. 計画と異なる日のみ `実績` セルを手修正
5. `実績保存` を押して保存
6. `過去から再計算` を押して進度を更新

## 過去から再計算

- ボタン: `過去から再計算`（進度基準タブで表示）
- 対象: 画面表示中の品番
- 再計算内容: 進度のみ再計算（在庫再計算なし）
- 開始日: 各品番の `calc_start_date`（ルーティング/BOM由来LT）を取得し、最も古い日を使用

## ボタンの使い分け

| ボタン | 用途 |
|------|------|
| 一括実績入力 | 期間内の計画値を実績セルへ一括セット |
| 実績保存 | 実績セルの値を保存 |
| 過去から再計算 | 保存済み実績を進度へ反映 |
| 保存 | 計画/順の保存 |

## 注意点

- `実績保存` 前に再計算しても、未保存の入力値は反映されません。
- 実績セルは数値で入力してください。
- フロア配送は同一日・同一品番で2件までの運用です。
