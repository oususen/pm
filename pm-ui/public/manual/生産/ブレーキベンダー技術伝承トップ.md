# ブレーキベンダー 作業のコツ・注意事項

このカテゴリは、ブレーキベンダーの曲げ作業に関する作業のコツや注意事項を残すための入口です。  
製品別の曲げ標準はまだ対象外とし、まずは現場で共通化しやすい知識から整理します。

## 構成

- [共通手順](ブレーキベンダー技術伝承_共通手順.md)
- [不良事例](ブレーキベンダー技術伝承_不良事例.md)
- [設備別注意](ブレーキベンダー技術伝承_設備別注意.md)
- [新人チェックリスト](ブレーキベンダー技術伝承_新人チェックリスト.md)

## 使い分け

- `共通手順`: 誰が作業しても揃えるべき基本動作
- `不良事例`: 失敗と対策を残す再発防止台帳
- `設備別注意`: 機械ごとのクセや立上げ時の注意
- `新人チェックリスト`: 教育到達度の確認

## 運用方針

- 品番別の詳細条件はここに混ぜない
- 迷いやすい判断、再発しやすい不良、設備固有の注意を優先して残す
- 画面上の `作業のコツ・注意事項` パネルからも、不良事例と設備別注意は更新できます
