# 在庫引当一覧

可用在庫と最小在庫を確認し、引当・解除・編集を行う画面です。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「在庫引当」を選択

## 使い方

### 検索

1. 品番/品名、保管場所、ボトルネックを指定します。
2. 「検索」を押します。
3. 条件を初期化する場合は「リセット」を押します。

### 引当

1. 対象行の「引当」を押します。
2. 引当数量を入力して「引当実行」を押します。

### 解除

1. 対象行の「解除」を押します。
2. 解除数量を入力して「解除実行」を押します。

### 一括解除

1. 一覧左のチェックを付けます。
2. 「一括解除」を押します。

### 新規/編集

- 「新規」で在庫引当を追加します。
- 「編集」で選択行の内容を変更します。

### 新規/編集で入力する項目

- 製品: 品番/品名で検索して選択します。
- 保管場所: 例) MAIN, SUB-01
- 現在在庫 / 引当済数量: 数量を入力します。
- 最小在庫（安全在庫）: 整数で入力します。
- ボトルネック: 必要に応じてチェックします。
- 可用在庫: 「現在在庫 - 引当済」で自動表示されます。

## 画面の見方

- 可用在庫が最小在庫を下回る場合、赤字で表示されます。
- 「最小在庫割れのみ」にチェックすると不足品のみ表示されます。
- 「CSV出力」で一覧をCSV形式でダウンロードできます。

## 注意点

- 引当/解除の数量は 0 以上で入力してください。
- 一括解除は引当済の行のみ対象になります。
