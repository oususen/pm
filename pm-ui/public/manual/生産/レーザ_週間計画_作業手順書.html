1画面を開く
上部ナビゲーションから 生産 → 生産計画入力 を選択し、「レーザ」タブ → 「週間計画」サブタブを開きます。
2対象設定を登録する（初回のみ）
対象設定 をクリックして設定パネルを開き、レーザ加工の計算対象を登録します。
後工程ライン後工程のラインを選択
後工程製品番号後工程の製品を選択
レーザ完成品番号レーザ完成品を選択
レーザパターン使用するパターンを選択（複数選択可）
後工程数量取得元「後工程需要」または「後工程計画」を選択
LT日数リードタイム日数を入力
設定を保存すると一覧テーブルに表示されます。Excel出力 で設定一覧をExcelダウンロードできます。
🛈対象設定は一度登録すれば次回以降も保持されます。変更がない限り再登録は不要です。
3週間計画を計算する
1. 「週開始日」に表示開始日を入力（自動的に月曜日に丸められます）
2. 再計算 をクリック
3. 2週間分（月〜金の営業日）の計画が計算・表示されます
🛈TK=1号機、AJ=2号機として表示されます。日付ヘッダーに設備別の稼働時間が表示されます。

製品別明細（折りたたみ可）

製品ごとの日別データを表示します。

レーザ加工計画（パターン別合計）

パターン単位で集約した計画データです。手数は直接入力で調整できます。
後工程取h/枚LT板厚製品番号P番号設備期首09-07
需要自数手数進度
3班2工場60.1816.0V053143C60092号08814.7151.6
需要日別の需要合計数
自数自動計算された加工回数
手数手動調整した加工回数（入力可）
進度期首 + 累積手数 − 累積自数

🛈自数と手数に差がある場合、小さい方が赤太字で表示されます。加工頻度パターンにより非加工日のセルは空白表示になります。

日別材料必要枚数 / ロット数（折りたたみ可）

材料ごとの日別必要枚数・ロット数（枚数 ÷ 発注倍数）と週合計を表示します。
5手回数を調整・保存する
1. パターン別合計の「手数」セルで加工回数を直接入力して調整
2. 手回数を保存 をクリック
3. 保存対象を選択（1週目 / 2週目 / 全期間）
4. 保存 をクリック
⚠手数を変更して保存せずに再計算すると、変更は失われます。

期首進度の設定

パターン別合計の「期首」列で期首進度を入力できます。
「固定」ボタンをクリックすると値がロックされ、再計算時も保持されます。
「入力」状態にすると再計算時に自動計算された値に置き換わります。
6印刷・リセット
印刷印刷 をクリック。印刷期間（開始日・終了日）と向き（横/縦）を選択して印刷します
手数リセット手数リセット をクリック。指定期間の保存済み手回数を削除し、自数と同じ初期値に戻します
7材料発注・進度
「材料発注・進度」セクション（折りたたみ可）で、仕入先別の材料発注を管理します。
仕入先は 佐藤商事 と 名成鋼機 の2社です。
手数入力ロット数と端数枚数を入力。佐藤商事に入力すると残りは名成鋼機に自動配分されます
進度を保存材料発注の手回数を保存します
注文書出力佐藤商事/名成鋼機の注文書をExcel出力（期間指定可、デフォルトは翌週月〜金）
手動追加材料・仕入先・納期・ロット数を手動で追加。黄色背景+「手動」タグ付きで表示
🛈特定材料コード（SPHCT2.3X1524X3048、SS400T8.0X1219X2810）のみ佐藤商事の行が表示されます。
