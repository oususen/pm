# 工程実績入力

製造指示ごとの工程別実績を登録・編集する画面です。

## 画面への行き方

1. 「製造指示一覧」で対象の指示を表示
2. 対象行の「実績入力」を選択

## 使い方

1. 工程（ルーティング）または工程を選択します。
2. ライン、完了数量、実績工数、完了日時を入力します。
3. 「登録」または「更新」を押します。
4. 一覧から「編集」「削除」を実行できます。

## 画面の見方

- 上部に製造指示の概要が表示されます。
- 登録済み実績は下段の一覧に表示されます。

## 注意点

- 中止済みの製造指示には実績を登録できません。
- 必須項目が未入力の場合は登録できません。
