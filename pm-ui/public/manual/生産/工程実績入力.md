# 工程実績入力

製造指示ごとの工程別実績を登録・編集する画面です。

## 画面への行き方

1. 「製造指示一覧」で対象の指示を表示
2. 対象行の「実績入力」を選択

## 使い方

1. 工程（ルーティング）を選択します（選択すると工程・ラインが自動入力されます）。
2. または「工程」プルダウンから直接工程を選択します。
3. ライン、完了数量、実績工数（分）、完了日時を入力します。
4. 必要に応じて作業者・備考を入力します。
5. 「登録」または「更新」を押します。
6. 一覧から「編集」「削除」を実行できます。

## 画面の見方

- 上部に製造指示の概要（指示番号・製品・数量・ライン・ステータス・予定期間）が表示されます。
- 登録済み実績は右側の一覧に表示されます。

## 入力項目

| 項目 | 必須 | 説明 |
|------|:----:|------|
| 工程（ルーティング） | - | ルーティングの工程ステップを選択。選択すると「工程」と「ライン」が自動入力されます |
| 工程 | ○ | 実績を登録する工程を選択 |
| ライン | ○ | 実績を登録するラインを選択 |
| 完了数量 | ○ | 完了した数量（0以上） |
| 実績工数(分) | ○ | 作業にかかった時間（分）。1以上で入力 |
| 完了日時 | ○ | 完了した日時 |
| 作業者 | - | 任意入力 |
| 備考 | - | 任意入力 |

## ボタン

| ボタン | 説明 |
|--------|------|
| 登録 | 新規で実績を登録 |
| 更新 | 選択中の実績を更新（一覧の「編集」を押した後に表示） |
| リセット | 入力フォームを初期状態に戻す |
| 編集（一覧） | 登録済み実績の内容をフォームに読み込む |
| 削除（一覧） | 登録済み実績を削除（確認ダイアログあり） |

## 注意点

- 中止済みの製造指示には実績を登録できません。
- 必須項目（工程・ライン・完了日時）が未入力の場合は登録できません。
- 実績工数は1分以上で入力してください。
- 編集権限がない場合は閲覧のみ可能です（「閲覧のみ可能です」とメッセージが表示されます）。
