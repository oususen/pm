# レーザー実績入力

レーザー専用の実績入力画面です。  
既存の「工程作業入力」とは別画面で、`パターン番号 + 回数` で登録します。

## 画面への行き方

1. 上部メニューで「生産管理」を開く
2. 生産管理メニューで「レーザー実績入力」を選択

## 登録手順

1. 作業日、設備を選択します
2. パターン番号を検索して選択します
3. 回数（1以上の整数）を入力します
4. 必要に応じて備考を入力します
5. 「保存」を押します

## 参照表示と自動計算

パターン選択後、以下が自動表示されます。

- 使用材料
- 構成部品一覧（品番、取り数、換算数）
- 完成品一覧（品番、取り数、換算数）
- 1回あたり加工時間
- 総加工時間（回数×加工時間）

## 一覧検索

以下の条件で検索できます。

- 作業日（From/To）
- 設備
- パターン番号

一覧列:

- 日付
- 設備
- パターン番号
- 回数
- 総加工時間
- 登録者
- 登録日時

## 注意点

- 回数は1以上の整数のみ登録できます
- パターン未選択では保存できません
- 保存時にパターン情報は実績にスナップショット保存されます
