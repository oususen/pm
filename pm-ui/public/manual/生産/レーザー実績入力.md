# レーザー実績入力

レーザー専用の実績入力画面です。  
既存の「工程作業入力」とは別画面で、`パターン番号 + 作業時刻 + 回数` で登録します。

## 画面への行き方

1. 上部メニューで「生産管理」を開く
2. 生産管理メニューで「レーザー実績入力」を選択

## 登録手順

1. パターン番号を検索して選択します
2. 作業時刻（開始 / 終了 / 中断 / 一時終了 / 再開）を選択します
3. 中断・一時終了の場合は理由を選択します
4. 回数を入力します（終了/中断の時だけ表示されます）
5. 「保存」を押します

※ 作業日は画面入力せず、8:00日替わり基準の営業日で自動設定されます。

## 作業時刻ボタンの表示タイミング

- 未開始: 「開始」
- 進行中: 「終了」「中断」
- 中断中: 「再開」「一時終了」
- 一時終了中: 「再開」

## 参照表示と自動計算

パターン選択後、以下が自動表示されます。

- 使用材料
- 構成部品一覧（品番、取り数、換算数）
- 完成品一覧（品番、取り数、換算数）
- 1回あたり加工時間
- 総加工時間（回数×加工時間）

## 一覧検索

以下の条件で検索できます。

- 作業日（From/To）
- 設備
- パターン番号

一覧列:

- 日付
- 設備
- パターン番号
- 作業時刻
- 回数
- 総加工時間
- 登録者
- 登録日時

## 注意点

- 作業時刻は「開始 / 終了 / 中断 / 一時終了 / 再開」から選択します
- 中断・一時終了では理由入力が必須です
- 回数欄は終了/中断時のみ表示され、1以上必須です
- パターン未選択では保存できません
- 保存時にパターン情報は実績にスナップショット保存されます
