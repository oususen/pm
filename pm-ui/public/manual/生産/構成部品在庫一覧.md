# 構成部品在庫一覧

親製品のBOMを展開し、全ての子部品（孫以下含む）の在庫・計画在庫を日別で表示します。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「構成部品在庫一覧」を選択

## 使い方

1. 品番検索欄に親製品の品番または品名を入力し「検索」を押します。
2. 検索結果から親製品を選択します。
3. 表示期間（7日/15日/30日/60日）を選択します。デフォルトは15日です。
4. 「更新」を押してBOM展開と在庫データを取得します。

## 画面の見方

### 表示項目

| 列 | 説明 |
|----|------|
| 階層 | BOMの深さ（├─ └─ で表現） |
| 品番 | 子部品の品番 |
| 品名 | 子部品の品名 |
| 区分 | 調達区分（製造/購買/外注） |
| BOM数量 | 親1個あたりの使用数 |
| 在庫 | 各日の実在庫（stock_qty） |
| 計画在庫 | 各日の計画在庫（planned_stock_qty） |

### 表示ルール

- 各子部品について「在庫」行と「計画在庫」行の2行が表示されます。
- 在庫・計画在庫がマイナスの場合は赤色で警告表示されます。
- BOMが登録されていない製品は「BOMが登録されていません」と表示されます。

## 用途

- 生産計画を入力した後、部品が揃うか（ものが歩くか）を確認する
- 計画在庫がマイナスになる部品を特定し、事前に対策を打つ
- 購買品の発注タイミングを検討する

## 注意点

- 在庫データはLineBacklogから取得されます。最新データを見るには事前に「在庫/残量一覧」で再計算を実行してください。
- BOMが循環参照している場合はエラーが表示されます。
- 表示される在庫は、子部品が所属するラインの在庫です。
