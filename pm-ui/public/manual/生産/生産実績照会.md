# 生産実績照会

工程作業入力で登録された作業時刻を、セッション単位で確認する画面です。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「生産実績照会」を選択

## 使い方

1. 期間、ライン、工程、品番などで条件を指定します。
   - 期間は業務日付で判定します。1日は `08:00 ～ 翌07:59` です。
2. 「検索」を押すと、該当セッションが一覧表示されます。
3. 必要に応じて「区分（作業/中断/中止）」「不整合あり/なし」「作業未終了」「生産数0除き」で絞り込みます。
4. 一覧の「CSV出力 / Excel出力 / 印刷(PDF)」ボタンで一覧を保存できます。

## セッションの表示ルール

- 中断なし: `開始 → 終了` を1行で表示します（区分: 作業）。
- 中断あり:
  - `開始 → 中断` を1行（区分: 作業）
  - `中断 → 再開` を1行（区分: 中断）
  - `再開 → 終了` を1行（区分: 作業）
- 強制終了後に「中止」を選択した場合は、区分: 中止 として表示します。
- 「中断」区分の行は背景色を変えて表示します。
- 実績数量は `終了` で閉じた作業セッションのみ表示します。

## 主な列

- 開始 / 終了: セッションの開始・終了時刻
- 区分: 作業（WORK）、中断（PAUSE）、または中止（CANCEL）
- 開始操作 / 終了操作: START, PAUSE, RESUME, END, TEMP_END, CANCEL
- 中断理由: 中断時（PAUSE）の理由。工程作業入力で登録した中断理由を表示
- 継続時間: セッション秒数
- 作業時間（休憩除き）: 休憩時間を除いた時間（中断時間は含む）
- 作業時間（休憩、中断除き）: 休憩と中断の両方を除いた時間（中断セッションは 00:00:00）
- 実績数量: `END` で終了した作業セッションの数量
- 不整合: 操作順の異常がある場合にコード表示（詳細は下記参照）

## 不整合コード一覧

作業者の操作順序が正常なフロー（開始→中断→再開→終了）から外れた場合に記録されます。不整合ありのセッションはデータの信頼性が低い可能性があります。

| コード | 意味 |
|---|---|
| DUPLICATE_START | 既に作業中なのに再度「開始」された |
| OVERLAP_OTHER_PRODUCT | 同じ工程で別品番がまだ作業中なのに開始された |
| PAUSE_WITHOUT_START | 開始されていないのに「中断」された |
| DUPLICATE_PAUSE | 既に中断中なのに再度「中断」された |
| RESUME_WITHOUT_PAUSE | 中断していないのに「再開」された |
| RESUME_WHILE_WORK | 作業中なのに「再開」された |
| CANCEL_WITHOUT_START | 開始されていないのに「取消」された |
| END_WITHOUT_START | 開始されていないのに「終了」された |
| TEMP_END_WITHOUT_START | 開始されていないのに「仮終了」された |
| END_WHILE_PAUSED | 中断中に「終了」された |
| TEMP_END_WHILE_PAUSED | 中断中に「仮終了」された |
| MISSING_PRODUCT | 品番が特定できなかった |

## 作業未終了フィルタ

「作業未終了」フィルタを「未終了のみ」に設定すると、終了操作がされていない（状態が OPEN のまま残っている）セッションだけを検索できます。

以下の2パターンで未終了セッションが発生します:

1. **作業中の閉じ忘れ**: 開始または再開した後、終了・強制終了の操作をしなかった
2. **中断の放置**: 中断した後、再開も強制終了もしなかった

未終了セッションは継続時間・出来高が確定しないため、実績集計に含まれません。発見した場合は工程作業入力から終了操作を行ってください。

## 注意点

- 「終了」数量は工程作業入力側で必須です。
- 「終了」数量は `LineBacklog.actual_qty` に加算反映されます。
- サマリーの「期間合計作業時間（中断含む）」は、休憩時間を除いた時間です。
- サマリーの「中断時間」は、中断セッション（PAUSE）の継続時間合計です。
