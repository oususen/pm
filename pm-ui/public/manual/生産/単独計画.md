# 単独計画

メイン工程の生産計画を参照しながら、サブ工程（タンクサブーなど）の計画を入力する画面です。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産」を開く
2. 「単独計画」を選択

※ `production.plan_input` の権限がないユーザーには表示されません。

## 使い方

1. **参照ライン**を選択します（社内ラインのみ表示されます）。
2. **参照工程**を選択します（メインの工程ガントを参照用に表示）。
3. **サブ工程**を選択します（計画を入力する対象工程）。
4. **期間**を設定して「読込」を押します。
5. 上段の参照グリッドを見ながら、下段の入力グリッドで製品と数量を入力します。
6. 「保存」を押して登録します。

## 画面レイアウト

画面は上から順に以下の構成です。

1. **ヘッダーバー** — ライン・工程選択、期間、読込/保存、土日非表示、お気に入り
2. **候補製品編集**（折りたたみ） — サブ工程の製品候補を絞り込む設定
3. **参照グリッド** — 参照工程のガントプラン（読み取り専用）
4. **入力グリッド** — サブ工程の計画入力欄
5. **工程ガント** — サブ工程のガントチャート表示

## ヘッダーバー

| 項目 | 説明 |
| ---- | ---- |
| 参照ライン | 対象ラインを選択（必須）。社内ライン（生産ライン）のみ |
| 参照工程 | 参照用のメイン工程を選択。上段グリッドに表示される |
| サブ工程 | 計画を入力するサブ工程を選択 |
| 期間 | 表示・保存対象の日付範囲 |
| 読込 | データを取得して表示 |
| 保存 | 入力した計画をサーバーに保存 |
| 土日非表示 | チェックすると土曜・日曜の列を非表示にして画面を節約 |
| お気に入り | ライン・工程の組み合わせを保存・呼び出し |

## 参照グリッド

参照工程のガントプランを日別・順序別に表示します（読み取り専用）。メイン工程の計画を確認しながらサブ工程の計画を立てるために使います。

- 各日付に製品コードと数量が表示されます
- 合計行で日別の総数量を確認できます

## 入力グリッド

サブ工程の計画を入力します。

- **製品列**: ドロップダウンから製品を選択
- **数量列**: 計画数量を入力（整数）
- Enter / 矢印キーでセル移動できます
- 合計行で日別の総数量を確認できます

## 候補製品編集

サブ工程を選択すると「候補製品編集」パネルが表示されます。

- 未設定時: 関連製品を全表示
- 設定済み時: 選択した品番のみ表示
- 「全選択」で全製品を選択
- 「個別設定解除」で絞り込みを解除
- 「候補保存」で設定を保存

## 工程ガント

入力グリッドの下に、サブ工程のガントチャートが表示されます。

| ボタン | 説明 |
| ------ | ---- |
| ＋表示 | バー追加アンカーの表示/非表示 |
| 空行非表示 | 空の行を非表示 |
| 土日非表示 | ガント上の土日列を非表示 |
| 時間数量保存 | ガント上のバーの開始時刻・終了時刻・数量変更を保存 |
| 追加削除保存 | ガント上の手動追加・削除を保存 |

## 保存の動作

「保存」を押すと以下が実行されます。

1. 表示期間のサブ工程の既存計画（LineBacklog + LineGanttPlan）を削除
2. 入力データから新しい計画を作成
3. サイクルタイムをもとにガントの時間を自動計算
4. 保存後、画面を再読込してガントも更新

保存結果は画面上にメッセージで表示されます（例: 「保存完了（Backlog: 削除5 → 作成5件、ガント: 削除5 → 作成5件）」）。

## お気に入り

よく使うライン・工程の組み合わせを保存できます。

1. ライン・参照工程・サブ工程を選択
2. 名前を入力して ★ ボタンで保存
3. ドロップダウンから選んで呼び出し
4. ✕ ボタンで削除

## 注意事項

- ラインを選択しないと読込・保存はできません。
- 土日非表示でも、保存時は土日を含む全期間のデータが処理されます（土日の計画が残ることはありません）。
- この画面の保存では在庫再計算・工程展開は実行されません。必要に応じて「生産計画入力」画面から実行してください。
- 工程ガントの時間・数量の直接編集は「時間数量保存」「追加削除保存」で別途保存が必要です。
