レーザ 材料発注承認 作業手順書

佐藤商事・名成鋼機への材料注文書の作成から承認・送信までの手順
生産計画入力 › レーザ › 週間計画 › 材料発注
承認フロー概要
材料発注は仕入先ごと（佐藤商事・名成鋼機）に個別の承認フローで処理します。
本フローでは確認②を未使用に設定しているため、3段階で承認が完了します。
作成リーダ
→
確認班長
→
承認係長（代理）
→
送信係長 ※全担当者可
段階担当者操作
作成リーダ発注数量入力 → 注文書作成 → 確認依頼
確認班長注文書PDFを確認 → 確認 or 却下
承認係長（部長の代理）注文書PDFを確認 → 承認 or 却下
送信承認者（係長）※全担当者可承認済み注文書を仕入先にメール送信
ℹ️
通常は「作成 → 確認① → 確認② → 承認」の4段階ですが、材料発注では係長が部長の代理として承認するため、確認②は未使用です。承認設定画面で変更できます。ただし、承認依頼の通知とメール通知は部長へも送られます。

手順一覧

── 作成者（リーダ）の操作 ──
1
発注数量を入力する
担当: リーダ
  1. 生産計画入力画面を開き、レーザ → 週間計画タブを選択します。
  2. レーザー翌週週間計画を作成後、材料発注セクションを展開します。
  3. 注文書期間（通常は翌週）を設定します（対象の開始日〜終了日）。
  4. 各材料の佐藤商事の手数（ロット数・枚数）を確認します。手数は所要枚数から自動セットされますが、変更が必要な場合は修正します。残りは名成鋼機へ自動配分されます。名成鋼機の手数も確認し、必要に応じて修正します。
  5. 確認・変更後、変更を保存 ボタンを押します。
  6. 保存ダイアログが表示されるので、保存する週を選択して 保存 を押します。
ℹ️
手数とは：材料を何ロット発注するかの数量です。上段にロット数（L）、下段に端数枚数（枚）を入力します。所要枚数÷ロット倍数で必要ロット数が算出され、佐藤商事に入力した分の残りロット数が名成鋼機へ自動配分されます。
ℹ️
手動で材料を追加するには 手動追加 を押し、材料・納期・数量を入力して登録します。
2
注文書を作成する
担当: リーダ
  1. 佐藤商事注文書作成 ボタンを押します。
  2. 未保存の数量変更がある場合、自動的に保存されてからPDFが生成・保存されます。
  3. 同様に 名成鋼機注文書作成 ボタンを押します。
  4. ステータスが「作成済（作成者）」に変わります。
⚠️
注文書作成後は、注文書期間内の日付の数量編集がロックされます。修正が必要な場合はステップ8を参照してください。

注文書PDFの確認

佐藤商事注文書開く / 名成鋼機注文書開く で保存済みPDFを別タブで表示できます。
PDFには承認印欄があり、承認が進むにつれて各段階の担当者名と日付が自動的に記載されます。
3
確認依頼を出す
担当: リーダ
  1. 注文書PDFの内容を確認します。
  2. 佐藤商事確認依頼 ボタンを押します。
  3. 同様に 名成鋼機確認依頼 ボタンを押します。
  4. 班長にタスク通知が届き、メールも送信されます。
  5. ステータスが「確認中（確認者）」に変わります。
ℹ️
確認依頼後は承認完了または却下されるまで、数量の編集・手動追加・手動行削除がロックされます。
── 確認者（班長）の操作 ──
4
注文書を確認する
担当: 班長
  1. タスク受信箱に届いた「確認①依頼」の 材料発注へ リンクをクリックして画面を開きます。
  2. 佐藤商事注文書開く / 名成鋼機注文書開く でPDFを確認します。
  3. 問題なければ 佐藤商事確認 / 名成鋼機確認 を押します。
  4. 係長にタスク通知が届き、メールも送信されます。

問題がある場合

  1. 佐藤商事却下 / 名成鋼機却下 を押します。
  2. 却下理由を入力して確定します。
  3. リーダに差し戻しタスクが届きます（ステップ7参照）。
── 承認者（係長）の操作 ──
5
注文書を承認する
担当: 係長（部長の代理）
  1. タスク受信箱に届いた「承認依頼」の 材料発注へ リンクをクリックして画面を開きます。
  2. 佐藤商事注文書開く / 名成鋼機注文書開く でPDFを確認します。
  3. 問題なければ 佐藤商事承認 / 名成鋼機承認 を押します。
  4. 全関係者に承認完了通知が届きます。
  5. PDFの承認印欄に係長の名前と日付が記載されます（代理の場合は名前に「（代）」が付きます）。

問題がある場合

  1. 佐藤商事却下 / 名成鋼機却下 を押します。
  2. 却下理由を入力して確定します。
  3. リーダに差し戻しタスクが届きます（ステップ7参照）。
ℹ️
承認設定画面で係長が「代理ユーザー」に設定されている場合、PDFの承認印に「（代）」マークが自動で付与されます。
── 送信（係長 ※全担当者可）の操作 ──
6
注文書を仕入先に送信する
担当: 承認者（係長） ※承認済みであれば全担当者が送信可能
  1. ステータスが「承認済」になっていることを確認します。
  2. 佐藤商事送信 / 名成鋼機送信 を押します。
  3. 承認済みPDFが仕入先マスタに登録されたメールアドレスへ送信されます。
  4. ステータスが「送信済」に変わります。
✅
メール本文とCCユーザーは メール設定 で仕入先ごとに変更できます（設定 → 材料注文書メール設定）。
⚠️
仕入先マスタにメールアドレスが登録されていない場合、送信できません。マスタ画面で事前に登録してください。
── 却下時の対応 ──
7
却下された場合
担当: リーダ
  1. タスク受信箱に「差戻し修正」タスクが届きます。
  2. 材料発注へ リンクから画面を開きます。
  3. ステータスに却下理由が表示されているので内容を確認します。
  4. 数量を修正して 変更を保存 を押します。
  5. 佐藤商事注文書再作成 / 名成鋼機注文書再作成 でPDFを再生成します。
  6. 再度 確認依頼 を出して、ステップ3からやり直します。
ℹ️
却下されると数量のロックが解除され、編集可能になります。
8
作成後に修正する場合
担当: リーダ
注文書を作成したが、確認依頼を出す前に数量を修正したい場合の手順です。
  1. 佐藤商事修正 / 名成鋼機修正 を押します。
  2. 確認ダイアログで「OK」を押すと、注文書期間の日付ロックが解除されます。
  3. 数量を修正して 変更を保存 を押します。
  4. 佐藤商事注文書再作成 / 名成鋼機注文書再作成 でPDFを再生成します。
  5. 内容を確認後、確認依頼 を出します。
⚠️
修正ボタンは確認依頼を出す前（ステータスが「作成済」）のときだけ使えます。確認依頼後は、班長または係長に却下してもらう必要があります。
9
納期調整する場合
担当: 全担当者
承認済み・送信済みの注文書に対して、納期（数量）を調整する必要が発生した場合の手順です。
元の注文書PDFは削除されず、「納期変更」として別PDFが生成されます。承認フローは流れません。
  1. 佐藤商事納期調整 / 名成鋼機納期調整 を押します。
  2. 確認ダイアログで内容を確認し「OK」を押します。
  3. 納期調整ダイアログが表示されるので、調整する期間（開始日〜終了日）を指定して 調整開始 を押します。
  4. 指定期間の日付ロックが解除され、数量を編集できるようになります。ステータスに「納期調整中」と表示されます。
  5. 数量を修正します。
  6. 佐藤商事納期調整保存 / 名成鋼機納期調整保存 を押します。
  7. 変更が保存され、「納期変更」PDFが別ファイルとして生成されます。
ℹ️
納期調整は承認フローを経由しません。調整後のPDFは「納期変更_」プレフィックス付きの別ファイルとして保存され、元の承認済みPDFはそのまま残ります。
⚠️
納期調整で変更した内容を仕入先に連絡する場合は、別途メールや電話で対応してください。納期調整PDFの自動送信機能はありません。
補足情報

ボタンの色分け

ボタンは担当者の役割ごとにグループ化・色分けされています。
グループ色対象者
作成者緑系リーダ（数量保存・注文書作成・確認依頼・修正・手動追加・納期調整）
確認者黄系班長（確認）
承認者青系係長（承認・送信）※送信は承認済みなら全担当者可
却下赤系班長・係長（却下）
共通紫系全員（注文書PDF表示・Excel出力・メール設定）

注文書PDFの承認印欄

PDFの右上に承認印欄があり、各段階が完了するたびに担当者名と日付が自動記載されます。
代理ユーザーが操作した場合は名前に「（代）」が付きます。

仕入先別の独立管理

佐藤商事と名成鋼機はそれぞれ独立した承認フローです。
一方を先に承認・送信し、もう一方は後から処理することも可能です。
片方が承認中でも、もう一方の仕入先の数量は編集できます。

タスク受信箱からのアクセス

確認・承認のタスクはタスク受信箱に表示されます。
「材料発注へ」リンクをクリックすると、該当週の材料発注画面に直接移動します。
ナビゲーションバーのタスクバッジにも件数が反映されます。
