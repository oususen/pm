# レーザートラブル対応

## 概要

レーザー設備トラブル時に、過去事例の確認と実運用用の手順入力を切り替えて使う画面です。  
画面パス: `/production/laser-trouble-response`

## 画面構成

### 1. タブ

- `事例 2026-08-17`
- `手順`

### 2. 事例 2026-08-17

- 復旧日時の仮定
- 必要部品の有無確認
- 2号機で加工するかの判断
- 外作部品の選定
- 部品別必要情報の整理
- 材料段取り
- 応援先への加工計画送付

補足として、塗装事業部への早期連絡、社内関係者連絡、ネスティングデータ変換/単品データ作成も表示します。

### 3. 手順

- 2026年8月17日版の応援加工依頼表を表示します。
- 手順1「復旧日時を仮定する」で、想定復旧日時を入力できます。
- 手順2「トラブル設備」で、設備マスタの設備をドロップダウンから選択できます。
- 手順3「加工対象」で、手順2で選択した設備に紐づく全パタンを表形式で表示できます。
- 表の列は `パタン` `完成品` `加工時間` `板厚` `材料` です。
- 手順4以降は、各ステップごとにメモ入力できます。

## データについて

- `事例 2026-08-17` タブは `Book1 のコピー.xlsx` を元にした固定表示です。
- `手順` タブの入力内容は画面上の一時保持のみで、保存はされません。
