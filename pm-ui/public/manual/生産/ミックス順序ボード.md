# ミックス順序ボード

当日の製造指示の順序をドラッグで並べ替える画面です。順序は優先度として保存されます。

## 画面への行き方

1. 上のグローバルナビゲーションの「生産管理」を開く
2. 「生産管理メニュー」→「ミックス順序ボード」を選択

## 使い方

1. ラインと対象日を指定します。
2. 「読み込み」を押します。
3. カードをドラッグして順序を並べ替えます。
4. 「順序を保存」を押します。

### テンプレート

- 「テンプレ保存」で現在の順序を保存します。
- 「テンプレ適用」で保存済み順序を反映します。

## 画面の見方

- 固定7品は強調表示されます。
- 「未保存の順序変更があります」が表示されたら保存してください。

## 注意点

- ライン未選択の状態では読み込みできません。
- テンプレートはブラウザに保存されます。
