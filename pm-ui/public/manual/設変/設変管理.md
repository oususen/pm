# 設変管理

打ち切り予定品の旧部品について、切替日までの必要量と現在の発注・生産計画を比較し、過剰仕入れ・過剰生産を確認する画面です。

## 画面への行き方

1. グローバルナビゲーションの「設変新規管理」を開く
2. 「設変新規管理メニュー」から「設変タイル」を選ぶ

## 利用できる操作

- `engineering_change` の閲覧権限がある場合: メニューと一覧を表示できます
- `engineering_change` の編集権限がある場合: 新規登録、編集、再計算、削除ができます

## 画面構成

### 設変新規管理メニュー

- `新規タイル`: 2026年3月6日時点では未実装です
- `設変タイル`: 設変対象の登録と過剰管理一覧の確認を行います

### 設変タイル

- `新規作成`: 設変対象の入力欄を開きます
- `設変対象 登録`: 案件名、完成品切替予定日、旧部品・新部品の組み合わせを登録します
- `設変過剰管理一覧`: 切替日と LT 反映日を基準に過剰数を確認します

## 新規登録手順

1. 「設変タイル」で「新規作成」を押します
2. 必要に応じて `案件名` を入力します
3. `完成品切替予定日` を入力します
4. 部品行で `旧部品コード` を選びます
5. 必要なら `新部品コード` を選びます
6. `打ち切り後必要量` を入力します
7. 複数部品をまとめて登録する場合は「部品行を追加」を押します
8. 「一括追加」を押します

## 入力時のポイント

- `旧部品コード` は 1 行以上必須です
- `新部品コード` は空欄でも登録できます
- `案件名` は空欄でも登録できますが、一覧で見分けやすくするため入力を推奨します
- `完成品切替予定日` が未入力だと、一覧上の基準日が分かりにくくなるため入力を推奨します
- 部品候補は、各行の絞り込み欄で品番・品名検索できます

## 一覧の見方

### 絞り込み

- `案件名`: 案件名で絞り込みます
- `部品名`: 旧部品コードまたは旧部品名で絞り込みます
- `LT反映日の進度`: `＋` / `－` / `0` で絞り込みます

### 集計表示

- `件数`: 絞り込み後の表示件数
- `発注過剰合計`: 絞り込み後の発注過剰の合計
- `生産過剰合計`: 絞り込み後の生産過剰の合計

### 主な列の意味

| 項目 | 説明 |
|------|------|
| 案件コード | 自動採番される設変案件コード |
| 切替日 | 完成品の切替予定日 |
| LT反映日 | 旧部品の累積 LT を使って切替日から営業日逆算した基準日 |
| LT反映日まで必要量 | LT反映日までに旧部品として必要な数量 |
| LT反映日の生産計画在庫 | LT反映日時点の計画在庫 |
| LT反映日の進度 | LT反映日時点の進度 |
| LT反映日の計進 | LT反映日時点の計画進度 |
| 在庫 | 当日時点の在庫 |
| 進度 | 当日時点の進度 |
| 発注過剰 | 発注計画量から LT反映日まで必要量を引いた値 |
| 生産過剰 | 生産計画量から打ち切り後必要量を引いた値 |

## 一覧でできる操作

### 再計算

- 各行の「再計算」は案件単位で実行します
- 設変登録後に計画や在庫条件が変わった場合に使います
- 再計算後は一覧が再読込され、最新値が反映されます

### 編集

- 「編集」から変更できるのは、現行画面では `旧部品`、`新部品`、`切替日` です
- `案件名` と `打ち切り後必要量` は登録後に画面上で変更できません

### 削除

- 「削除」は対象の部品行を削除します
- 案件内の最後の 1 行を削除すると、案件自体も削除されます

### CSV出力

- 「CSV出力」は一覧データをファイル出力します
- 出力対象は画面の絞り込み結果ではなく、登録済みの全件です

## 注意点

- `共用親製品` には、旧部品を使用している親製品が表示されます
- 過剰数がプラスでも、即削除や発注停止は行われません。現場判断前に関連計画を確認してください
- 一覧に `打ち切り後必要量` 列は表示されません。登録値を見直したい場合は、登録時の内容を別途管理してください
