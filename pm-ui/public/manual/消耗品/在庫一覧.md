# 消耗品 在庫一覧

全消耗品の在庫状況をカード形式で一覧表示する画面です。

[作業手順書（日本語）](/manual/消耗品/在庫一覧_作業手順書.html)

## 画面への行き方

1. グローバルナビゲーション「消耗品」→「在庫一覧」

## 使い方

### フィルタ（画面上部に固定）

- **検索**: コード・発注コード・品名で絞り込み（Enter で実行）
- **注文状態**: 未発注 / 依頼中 / 発注準備 / 発注済 で絞り込み
- **欠品**: 安全在庫以下の品目のみ表示
- **カテゴリ**: カテゴリ別に絞り込み
- **保管場所**: 保管場所別に絞り込み

### カード表示

各カードには以下が表示されます。

- 品名・コード・写真
- 在庫数・安全在庫
- 保管場所・購入先
- 注文状態（未発注/依頼中/発注準備/発注済）
- 欠品表示（安全在庫以下の場合）
- 未完了の依頼情報
- 直近の入庫履歴

### 操作ボタン

各カード下部のボタンから、該当品目の出庫・入庫・注文依頼画面へ直接遷移できます。

## 注意点

- 件数が多い場合は画面右下の「最上部」ボタンでページ先頭に戻れます。
- 欠品カードは赤枠で表示されます。
