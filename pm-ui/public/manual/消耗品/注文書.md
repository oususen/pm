# 消耗品 注文書

注文書の承認・PDF出力・メール送信・一括入庫を行う画面です。

[作業手順書（日本語）](/manual/消耗品/注文依頼_作業手順書.html)

## 画面への行き方

1. グローバルナビゲーション「消耗品」→「注文書」

## 使い方

### 注文書一覧

- 作成済みの注文書が一覧表示されます
- ステータス: 下書き → 承認済 → 送信済 → 入庫完了

### 操作

- **承認**: 注文書の内容を確認して承認
- **PDF出力**: 注文書をPDFで出力
- **メール送信**: 購入先へ注文書をメール送信
- **一括入庫**: 注文書の品目を一括で入庫処理

## 注意点

- 承認後の注文書は編集できません。
- 一括入庫を実行すると在庫数に反映されます。
