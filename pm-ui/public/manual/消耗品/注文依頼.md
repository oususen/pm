# 消耗品 注文依頼

消耗品の注文依頼を管理し、購入先別の注文書を作成する画面です。

[作業手順書（日本語）](/manual/消耗品/注文依頼_作業手順書.html)

## 画面への行き方

1. グローバルナビゲーション「消耗品」→「注文依頼」

## 使い方

### 依頼一覧

- 未処理の依頼が一覧表示されます
- ステータス: 依頼中 → 発注準備 → 発注済

### 操作

- **発注準備**: 依頼を発注準備状態に移行
- **却下**: 不要な依頼を却下
- **注文書作成**: 購入先別に注文書を生成

## 注意点

- 安全在庫割れの品目は自動で依頼が生成される場合があります（定時タスク設定による）。
