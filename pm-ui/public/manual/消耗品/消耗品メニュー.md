# 消耗品メニュー

消耗品管理で使用する機能へ遷移するためのメニュー画面です。

## 画面への行き方

1. 上のグローバルナビゲーションの「消耗品」を開く
2. 「消耗品メニュー」を表示

## メニュー項目

- 在庫一覧  
  全消耗品の在庫数・注文状態・欠品状況をカード形式で一覧表示します。
- 入出庫  
  QRコード読取または品名検索で消耗品を選び、出庫・入庫・注文依頼を行います。スマホ対応。
- 注文依頼  
  依頼の発注準備・却下、購入先別の注文書作成を行います。
- 注文書  
  注文書の承認・PDF出力・メール送信・一括入庫を行います。
- 入出庫履歴  
  期間・部署別の入出庫集計と明細を確認します。
- 消耗品マスタ  
  消耗品・購入先の登録・編集、CSV取込を行います。

## 注意点

- ここはメニュー画面です。データ更新は各遷移先画面で実行します。
- 権限のない機能のタイルは表示されません。
