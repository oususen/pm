# 工程一体チェックシート

製品の各工程におけるチェック項目を一体管理し、台目ごとに記録・承認するシステムです。

## 画面への行き方

1. グローバルナビゲーションの「品質管理」を開く
2. 「品質チェックシート」→「工程一体」を選択
3. 目的の機能を選択:
   - **テンプレート管理**: チェック項目の定義・承認フロー
   - **チェック実施**: 日々の検査記録入力
   - **リーダー・班長確認**: 記録の確認・承認

---

## テンプレート管理

テンプレートは製品×ラインごとに作成し、工程ブロック・チェック項目・台紙を定義します。

### テンプレートの作成

1. 「新規作成」ボタンを押す
2. 基本情報を入力:
   - **ライン**: 対象ライン（必須）
   - **製品**: 品番で検索して選択（必須）
   - **テンプレート名**: 自動生成されるが変更可（必須）
   - **改訂内容**: 変更理由を記載（必須）
   - 班長担当・係長担当・部長担当: 承認フローの担当者
3. 「下書き保存」で保存

### テスト実施

- テンプレート編集画面の「テスト実施」から、承認前の版を作業者目線で確認できます。
- テスト実施で入力した内容は **DB保存されません**。
- テスト画面を閉じると、入力した内容は破棄されます。

### 工程ブロックの追加

1. 「ブロック追加」ボタンを押す
2. 工程を選択し、並び順を設定
3. 「項目追加」でチェック項目を追加

> **並び順は重要**: 工程ロック機能により、前の工程の必須項目が完了するまで次の工程は入力できません。実際の工程順で設定してください。

### チェック項目の種類

| 記録種別 | 説明 | 入力方法 |
|---|---|---|
| **CHECK** | OK/NG判定 | OK / NG ボタン |
| **NUMERIC** | 数値記録 | 数値入力（自動判定あり） |
| **TEXT** | テキスト記録 | 自由入力 |

### 数値項目の自動判定機能

NUMERIC項目では、**判定基準**を設定すると入力値から自動でOK/NGを判定します。

#### 判定基準の書き方

| 書き方 | 意味 | 例 |
|---|---|---|
| `300-360` | 範囲内ならOK | 300以上360以下 |
| `300~360` / `300～360` | 同上（チルダも可） | |
| `333以上` | 下限のみ | 333以上ならOK |
| `360以下` | 上限のみ | 360以下ならOK |
| `>=300` / `≧300` | 下限のみ | 300以上ならOK |
| `<=360` / `≦360` | 上限のみ | 360以下ならOK |
| `±10` | 基準値からの公差 | 基準値が333なら323-343がOK |
| `±10%` | 基準値からの%公差 | 基準値が333なら299.7-366.3がOK |

- 全角数字（３３３以上）にも対応しています
- **基準値**欄は公差（±）を使う場合の基準値として使われます
- 判定基準が未設定の場合、自動判定は行われません（手入力のみ）
- 自動判定後も手動でOK/NGを変更できます

#### 表示

- **OK**: 入力欄が緑枠になり「OK」バッジが表示されます
- **NG**: 入力欄が赤枠になり「NG」バッジが表示されます
- マトリックス一覧でも、判定結果に応じてセルが色付きで表示されます

### 台紙（略図）の設定

各工程ブロックに台紙画像をアップロードし、チェック位置を視覚的に定義できます。

1. 「台紙PDF」または「台紙画像」からファイルを選択
2. アップロード後、「配置エディタを開く」でフィールドを配置
3. 台紙上をクリックしてフィールドを追加
4. ドラッグで位置調整、右下ハンドルでサイズ変更
5. 「適用して閉じる」で保存

### 承認フロー

テンプレートは以下のフローで承認されます:

1. **下書き** → 「確認依頼」で班長へ
2. **班長確認待ち** → 班長が「班長承認」
3. **係長確認待ち** → 係長が「係長承認」
4. **部長承認待ち** → 部長が「部長承認」
5. **承認済み** → チェック実施で使用可能

差し戻しはどの段階でも可能で、コメント付きで下書きに戻ります。

### 改訂

承認済みテンプレートを変更する場合は「改訂」ボタンで新しい版を作成します。

## チェック実施

### バッチの選択

1. ライン・計画日を選択
2. 対象のバッチ（製品×テンプレート）を選択
3. 台目一覧が表示される

### 台目ごとの入力

1. マトリックス表のセルをクリック、または台目行をクリック
2. 入力モーダルが開く
3. 各工程の項目を入力:
   - **CHECK**: OK / NG ボタンをクリック
   - **NUMERIC**: 数値を入力（判定基準があれば自動判定）
   - **TEXT**: テキストを入力
4. 工程ごとに「保存」ボタンで保存

### 工程ロック

前の工程の**必須項目**がすべて完了するまで、次の工程は入力できません（グレーアウト表示）。

### マトリックス表示の見方

| セル色 | 意味 |
|---|---|
| 緑（✓） | OK |
| 赤（✗） | NG |
| 白（値表示） | 入力済み（判定なし） |
| 空白 | 未入力 |
| グレー | ロック中（前工程未完了） |

---

## 注意点

- テンプレートが「承認済み」でないとチェック実施で使用できません
- 工程の並び順を変更した場合、ロック順も変わるので注意してください
- 台紙アップロードは構造を保存した後に行ってください

*不明点があればシステム担当者または上長に確認してください。*
