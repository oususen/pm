# 携帯端末管理規定

## 1. 目的

製缶事業部で使用する携帯端末（タブレット・スマートフォン）の適正な管理を行い、資産の把握・紛失防止・セキュリティ確保を図る。

## 2. 適用範囲

製缶事業部が保有・運用するすべての携帯端末（タブレット・スマートフォン）に適用する。

## 3. 管理番号体系

### 3.1 採番ルール

```
YY-NNX
```

| 要素 | 意味 | 例 |
|------|------|-----|
| YY | 導入年度（和暦下2桁） | 26 = 令和8年 |
| NN | 連番（01〜99） | 01, 02, ... |
| X | 種別 | T=タブレット, S=スマートフォン |

例: `26-09T` = 令和8年度導入、9台目、タブレット

### 3.2 採番手順

- 新規購入時、その年度の最新連番+1を付与する
- 欠番の再利用は行わない

## 4. 登録・変更手順

### 4.1 新規登録（購入時）

1. 管理番号を採番する
2. 管理台帳（PMシステム）に以下を登録する
   - 管理No.、製造元、型番、S/N、導入年月日、配置場所、管理責任者
3. 現物にラベルを貼付する（管理No.・型番・配置場所を記載）
4. 関係者へ登録通知を行う

### 4.2 変更時

以下の場合、管理台帳を速やかに更新する。

| 変更事項 | 更新項目 | 届出先 |
|----------|----------|--------|
| 配置場所変更 | 配置場所 | 管理責任者 |→だれにする？
| 管理責任者変更 | 管理責任者 | 新旧管理責任者 |→誰にする？
| 故障・修理 | 備考 | 管理責任者 |誰にする？

変更後、ラベルの記載内容と差異がある場合はラベルも再発行・貼り替えを行う。

### 4.3 遊休化

- 使用しなくなった端末は「遊休」ステータスに変更し、遊休化年月を記録する
- 遊休端末は所定の保管場所にまとめて保管する
- 遊休化後1年以上経過した端末は廃却を検討する→どうする？

### 4.4 廃却

- 廃却時は管理台帳のステータスを「廃却」に変更し、管理除外年月を記録する
- 端末内データの初期化を確認してから廃却処理を行う
- ラベルを剥がし、廃却記録を備考に残す
- 廃却品は誰に処分してもらう？経営管理課？

## 5. ラベル管理

### 5.1 ラベル仕様　→サイズ確認して

- 幅: 10mm
- 記載内容: 管理No.、型番、配置場所
- 貼付位置: 端末背面の視認しやすい場所

### 5.2 ラベル貼り替え

以下の場合にラベルを再発行・貼り替える。

- 配置場所変更時
- ラベルの劣化・剥がれ・判読不能時
- 棚卸で不備が発見された時

## 6. 紛失・盗難時の対応

1. 直ちに管理責任者および上長に報告する
2. 管理台帳の備考に紛失日・状況を記録する
3. 必要に応じてセキュリティ措置を実施する
