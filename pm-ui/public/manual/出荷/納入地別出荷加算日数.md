# 納入地別出荷加算日数

納入先ごとの出荷加算日数を登録・更新する画面です。出荷指示書などで使う出荷日計算の基準を、顧客と納入先コード単位で管理します。

## 画面への行き方

1. 上のグローバルナビゲーションの「出荷管理」を開く
2. 「出荷管理メニュー」→「納入地別出荷加算日数」を選択

## 画面でできること

- 登録済みの加算日数一覧を確認できます。
- 顧客ごとに納入先コードを選んで、新しい設定を追加できます。
- 登録済み設定の納入地名、出荷加算日数、有効/無効を変更できます。
- 不要になった設定を削除できます。

## 使い方

### 一覧確認

1. 画面を開くと一覧が自動表示されます。
2. 最新状態を取り込みたい場合は「更新」を押します。

### 新規追加

1. 「追加」を押します。
2. 「顧客」を選択します。
3. 「納入先コード」を選択します。
   受注データに候補がない場合は手入力します。
4. 「納入地名」を入力します。
5. 「出荷加算日数」に日数を入力します。
6. 必要に応じて「有効」を設定し、「保存」を押します。

### 編集

1. 対象行の「編集」を押します。
2. 「納入地名」「出荷加算日数」「有効」を変更します。
3. 「保存」を押します。

### 削除

1. 対象行の「削除」を押します。
2. 確認メッセージで内容を確認し、削除を確定します。

## 一覧の見方

- 「顧客コード」「顧客名」で対象顧客を確認できます。
- 「納入先コード」「納入地名」で設定対象の納入地を確認できます。
- 「出荷加算日数」は、出荷日に加算する日数です。
- 「有効」が「はい」の設定だけを通常利用します。

## 注意点

- 新規追加時は「顧客」と「納入先コード」が必須です。
- 編集時は顧客と納入先コードは変更できません。
- 同じ顧客・納入先コードの重複登録はできません。保存時にエラーが表示された場合は既存設定を確認してください。
