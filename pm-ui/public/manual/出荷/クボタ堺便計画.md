# クボタ堺便計画

クボタ堺向けの納入計画を、便ごとに割り付ける画面です。品番・納入地ごとの数量を見ながら、便選択と数量配分を行います。

[詳しい作業手順書はこちら](/manual/出荷/クボタ堺便計画_作業手順書.html)

## 画面への行き方

1. 上のグローバルナビゲーションの「出荷管理」を開く
2. 「出荷管理メニュー」→「クボタ堺便計画」を選択

## 使い方

1. 「出荷開始日」と「期間」を指定します。
2. 必要に応じて「検索」に品番を入力します。
3. 「取込」または「表示」で一覧を読み込みます。
4. 各明細の便・容器・容器数を入力すると、数量が自動表示されます。
5. 「保存」を押して割付を保存します。

## 画面の見方

- 左側に「品番」「納入場」が表示されます。
- 日付ごとに便列が並び、各セルは「注番」「需要」「振分」「便選択」「残」「進捗」で構成されます。
- 納期調整画面で業務連絡メモが登録されている明細は、注番欄に `連絡` バッジと本文が表示されます。
- 行表示順と色設定は、便計画専用の設定です。生産計画とは連動しません。
- 宵積み便の割付は<span style="color:red">**着日の列**</span>で行います（出発日の列ではありません）。画面下部の積み荷明細では前営業日の列に表示されます。

## 主な操作

### 便割付

- 便選択欄で便を選び、容器を確認してから容器数を入力します。数量は `容器数 × 入り数` で自動表示されます。
- 便の右に**容器選択**があります。製品に複数の容器が登録されている場合、容器を切り替えられます。
  - 容器を変更すると入数が変わり、容器数と占有率が自動で再計算されます。
  - 選択した容器は保存され、PDF出力にも反映されます。
- `+` で同じ明細を複数便に分割できます。
- `-` で分割行を削除できます。

### 表示順

- 「表示順」で、品番 + 納入地単位の表示順と色を設定できます。
- 行色と `+` ボタン色を保存できます。

### 占有CSV / 集荷明細PDF

- 「占有CSV」で便ごとの積載状況をCSV出力できます。
- 「集荷明細PDF」で指定期間の集荷明細をPDF出力できます。

### 便詳細

- 「便詳細」で便マスタ一覧を表示できます。
- 日ずれがある便は宵積み便です。

### 擬似便対象製品 / 自動便振分

- 擬似便対象製品では、製品ごとにA便・P便の対象設定を行います。
- 自動便振分では、設定済みの擬似便情報を使って自動で割付できます。

## 積み荷明細

- 表の最下段に積み荷明細が表示されます。
- 明細は「便」「製品1」「製品2」の3列構成です。
- 製品欄は `品番×数量 納入地` 形式で表示されます。
- 宵積み便は当日列ではなく前営業日の明細に表示されます。

## 注意点

- 便計画の需要数は<span style="color:red">**納期調整画面の納入数**</span>から取得しています。実際に乗せる製品の数量が納期調整の納入数と異なる場合は、<span style="color:red">**先に納期調整画面で納入数を修正**</span>してから便計画を行ってください。
- 同様に、納期を変更した場合も<span style="color:red">**必ず納期調整画面に反映**</span>してください。納期調整と便計画の不一致は、前工程の需要日計算に影響します。
- トラックが手配できない、容器が足りない、納入できない、または予定より多く納入した等の事情があった場合は、<span style="color:red">**必ず納期調整担当者へ連絡**</span>してください。納期調整画面の計画数を修正しないと、需要数が実態と合わなくなります。
- 既に割付済みの便は、<span style="color:red">**変更が必要なときだけ**</span>編集してください。誤って割付済みの便を触ってしまうと、保存時に上書きされます。
- 保存前の割付変更は、画面再読込で消えます。
- 休日非表示をオンにすると、休日列（土日 + クボタ堺カレンダ休日）は非表示になります。
- 進捗調整を使う場合は、調整保存まで実行してください。
