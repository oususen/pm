# 出荷進度照会

受注明細を基準に、日付別の内示・確定・実績・調整・進度を一覧表示します。品番・得意先・納入先ごとの日次進度を確認したいときに使用します。

## 画面への行き方

1. 上のグローバルナビゲーションの「出荷管理」を開く
2. 「出荷管理メニュー」→「出荷進度照会」を選択

## 使い方

1. 必要に応じて「品番/品名」「得意先」「納入先」で絞り込みます。
2. 「開始日」と「期間（30/60/90日）」を指定します。
3. 「更新」を押してデータを読み込みます。

## 画面の見方

### 左側（グループ情報）

- 品番・品名・得意先・納入先の組み合わせで1カード表示されます。
- 合計内示/合計確定/合計実績/合計調整/進度が表示されます。
- 合計調整がマイナスのときは赤で表示されます。

### 右側（日付マトリクス）

- 開始日から期間分の日付が列に並びます。
- 行は「内示」「確定」「実績」「調整」「進度」です。
- 内示/確定/実績/調整は 0 の場合は空欄です。
- 調整がマイナスのときは赤背景で表示されます。
- 進度は 0 を含めて常に表示されます。

## 進度の考え方

- 日次の進度は累積で計算されます。
- 需要は「確定がある日は確定」「確定がない日は内示」として扱います。
- 実績と調整が需要に対してどれだけ進んでいるかを確認できます。

## 注意点

- 合計値は表示期間外の受注明細も含んだ集計になります。
- 条件変更後は「更新」を押して再取得してください。
- 調整は現状画面上で更新されないため、常に 0 になります。
