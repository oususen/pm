# 出荷実績照会

出荷実績の検索・閲覧・履歴確認を行う画面です。品番や日付で絞り込み、登録済み実績を確認します。

## 画面への行き方

1. 上のグローバルナビゲーションの「出荷管理」を開く
2. 「出荷管理メニュー」→「出荷実績照会」を選択

## 使い方

### 検索

1. 品番・得意先・納入先・期間を入力します。
2. 「検索」を押すと一覧が更新されます。
3. 条件を初期化する場合は「クリア」を押します。

### Excel出力

1. 品番・得意先・納入先・期間を必要に応じて指定します。
2. 「Excel出力」を押すと、現在の検索条件に一致する出荷実績をExcelで保存できます。
3. 出力列は「出発日 / 到着日 / 品番 / 数量 / 生産日 / 注番」です。

### 履歴

1. 一覧の「履歴」を押します。
2. 修正履歴テーブルで変更内容を確認します。

## 注意点

- この画面では新規登録・編集・削除はできません。
- 読み込み中は「読込中...」が表示されます。
- データがない場合は「データがありません」と表示されます。
