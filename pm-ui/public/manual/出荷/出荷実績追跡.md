# 出荷実績追跡

## 概要

出荷実績から、以下を1画面で追跡します。

- どの製品か
- どの納入先か
- どの注番か
- いつ出発した便か
- いつ到着実績として保存されたか

## 画面で確認できる項目

- 到着日
- 出発日
- 便
- 業務区分
- 品番
- 品名
- 納入先
- 得意先
- 数量
- 注番
- 生産日内訳

## 検索条件

- 品番
- 納入先
- 注番
- 便名
- 出発日 From/To
- 到着日 From/To

## 補足

- 注番は `出荷実績内訳` に保存された値を表示します。
- 出発日は便明細、到着日は出荷実績の保存日です。
- 実績が便明細にひも付いていない旧データは、便情報が空欄になる場合があります。
