Observações importantes

  • A coluna "Real" é calculada automaticamente pela soma das datas de produção. Não é possível inserir valores diretamente.
  • Condição para "Carga concluída": todos os produtos devem ter "Planejado = Real (soma das datas de produção)".
  • Viagens com carga noturna (宵積み) são exibidas pela data real de partida, não pela data de chegada. A data de produção pode ser diferente da data exibida na tela.
  • Viagens com vários destinos são agrupadas em um único cartão. O cabeçalho mostra os locais concatenados como "5476+ZGHC".
  • O salvamento da data de produção deve ser feito produto por produto. Não há botão para salvar todos de uma vez.
  • "Confirmação concluída" é registrada na tela do pessoal administrativo. Não é possível registrar nesta tela.
