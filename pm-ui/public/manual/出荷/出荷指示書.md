# 出荷指示書

出荷指示書を PDF で出力する画面です。出荷日を選択し、4便に分かれた指示書を生成します。

## 画面への行き方

1. 上のグローバルナビゲーションの「出荷管理」を開く
2. 「出荷管理メニュー」→「出荷指示書」を選択

## 使い方

1. 「出荷日」を入力します。
2. 必要に応じて「利用可能な日付を表示」を押し、一覧から日付を選択します。
3. 「作成者名」を入力します。
4. 内容を確認したい場合は「データプレビュー」を押します。
5. 「PDF生成」を押してファイルをダウンロードします。

## プレビューの見方

- 1便目〜4便目の品目数が表示されます。
- 各便ごとに、製品コード・製品名・機種名・数量・容器入り数・グループが一覧表示されます。
- 「注意」欄が表示される場合は、別途の付帯情報がある製品です。
- 2便目の「特記事項」には、特定グループの容器数が表示されます。

## 出力されるPDF

- ファイル名は `出荷指示書_YYYY-MM-DD.pdf` です。
- 作成者名はPDF内に印字されます。

## 注意点

- 出荷日は本日以降の日付のみ選択できます。
- 作成者名が空欄のままではPDFを生成できません。
- データがない場合は「出荷データが存在しません」と表示されます。
- 容器マスタでは同じ容器名を登録できます。既存容器の再利用や更新の判定は容器コードで行われます。
- 容器取込で既存容器を更新したい場合は、対象容器に同じ容器コードを設定してください。
