# 出荷実績

出荷実績の検索・登録・修正・削除を行う画面です。品番や日付で絞り込み、実績を管理します。

## 画面への行き方

1. 上のグローバルナビゲーションの「出荷管理」を開く
2. 「出荷管理メニュー」→「出荷実績」を選択

## 使い方

### 検索

1. 品番・得意先・納入先・期間を入力します。
2. 「検索」を押すと一覧が更新されます。
3. 条件を初期化する場合は「クリア」を押します。

### 登録・更新

1. 上部の入力欄に出荷日、品番、得意先、数量を入力します。
2. 必要に応じて納入先と備考を入力します。
3. 「登録」または「更新」を押します。

### 編集

1. 一覧の「編集」を押します。
2. 入力欄に内容が反映されるので修正します。
3. 「更新」で保存します。取り消す場合は「キャンセル」を押します。

### 削除

1. 一覧の「削除」を押します。
2. 確認ダイアログで OK を選びます。

### 履歴

1. 一覧の「履歴」を押します。
2. 修正履歴テーブルで変更内容を確認します。

## 注意点

- 出荷日・品番・得意先・数量は必須です。
- 読み込み中は「読込中...」が表示されます。
- データがない場合は「データがありません」と表示されます。

## 権限による表示の違い

| 権限 | 表示内容 |
| --- | --- |
| 編集権限あり | 登録フォーム・編集ボタン・削除ボタンすべて表示 |
| 閲覧権限のみ | 一覧と履歴ボタンのみ表示。登録フォーム・編集・削除は非表示 |

権限の設定は「設定 > 権限テンプレート」または「設定 > ユーザー管理」で行います。
