  • 1ナビゲーションバー — 「出荷」から画面に入ります。
  • 2ツールバー — 開始日・期間の設定、品番フィルタ、取込・保存・EXCEL出力などの操作ボタンがあります。
  • 3日付列 — 左端に日付が並びます。土日・休日は色付き表示。
  • 4サブ列（4列1組） — 品番+納入地ごとに「注番・受注・計画・注残」の4列があります。
  • 5列ヘッダボタン（× ⇔ →） — 各品番+納入地ごとの操作ボタン。後のステップで詳しく説明します。
  • 6繰越行 — 表示開始日より前の累積注残です。
  • 7総残行 — その品番・納入地の最終注残合計です。0になれば受注と計画が一致しています。

列ヘッダの見方

各品番+納入地の列ヘッダには、品番・納入地・操作ボタンが表示されます。

V053143521A 833B × ⇔ → C
注番 受注 計画 注残 D
  • A品番（製品番号） — この列が対象とする製品コードです（例: V053143521）。
  • B納入地 — クボタの納入場所コードです（例: 833, ZGHC, 5476）。同じ品番でも納入地が違えば別の列になります。
  • C操作ボタン — この列専用の3つのボタンです。下の表で詳しく説明します。
  • Dサブ列ヘッダ — 注番・受注・計画・注残の4列で構成されます。左端に日付列（7/23木 のように「月/日＋曜日」表示）があります。同じ日に複数の注番がある場合や、納入数が注番の受注数を超えて注番単位で分割される場合は、1日に複数行表示されます。土日・休日はピンク背景になります。

列ヘッダの3つのボタン

×
計画一括削除
この列の計画数をまとめて 0 にクリアします。
押すとダイアログが開き、開始日を変更できます（デフォルトは一括入力開始日）。
画面上の変更のみ。保存前ならリロードで元に戻せます。
⇔
前倒し注番紐づけ
内示のまま前倒し計画した行を、確定注番に紐づけます。
例: 8/4に確定(注番1369380)が入った → 7/23〜8/3の前倒し行も1369380に紐づく。
即座にDBに保存されます（保存ボタン不要）。画面は自動リロード。
→
受注→計画コピー
受注数をそのまま計画列にコピーします（一括入力開始日以降が対象）。
手入力する手間を省けます。
画面上の変更のみ。保存前ならリロードで元に戻せます。

サブ列（4列）の意味

注番 確定の場合は注文番号が表示されます。内示の場合は「内示」と表示されます。
受注 取り込んだ受注数量です。編集できません。
計画 納入計画数量です。ここを入力します。黄色い背景のセルが入力可能です。
注残 累積の残量（計画 − 受注の累計）。マイナス＝不足、プラス＝過剰です。

ツールバーの各項目

開始日 表示する期間の開始日です。
期間 開始日からの表示日数（7/14/30/60日）。
品番OR検索 2つのキーワードのどちらかに一致する品番を表示。
一括入力
開始日 「→」ボタンや「×」ボタンの対象開始日です。
取込 受注明細から最新データを読み込みます。
計画変更 ロック日以前を編集するための変更理由入力。
保存 入力した計画数をDBに保存します。
EXCEL出力 現在表示している一覧をEXCELファイルで保存します。
表示 条件に合うデータを画面に表示します。

色・表示の意味

ピンク行 土日・休日です。
内示 まだ確定していない注文（予測値）です。
グレー行 ロック日以前。変更理由なしでは編集不可。
注番あり 確定した注文です（注文番号が表示）。

注意事項

  • 計画数を変更したら必ず「保存」を押してください。保存前にリロードすると入力内容は消えます。
  • EXCEL出力は画面に表示中の内容をそのまま出力します。出力前に必要な条件で「表示」を押してください。
  • 締め日以前のデータは編集・取込ともにできません。
  • 納入数や納期に変更があった場合、口頭連絡だけで済ませず必ずこの画面で計画数を修正してください。計画数は便計画の需要数に直結します。
  • ⇔ボタンは即座にDBに反映されます（保存ボタン不要）。×ボタンと→ボタンは画面上の変更のみで、保存が必要です。
