# 枚方集荷依頼書

枚方製造所向けの集荷依頼書を作成する画面です。

## 画面への行き方

1. 上のグローバルナビゲーションの「出荷管理」を開く
2. 「出荷管理メニュー」→「枚方集荷依頼書」を選択

## 操作手順

1. 開始日と終了日を入力します。
2. 集荷期間が表示されたら、必要な出力を選びます。
   - 集荷依頼書PDF生成
   - 集荷製品詳細Excel
   - 製品リスト表示（画面内で確認）
3. PDF/Excelは自動ダウンロードされます。
4. 集荷依頼は集荷前日の17時までにメール送付します。

## 出力内容

### 集荷依頼書PDF
- 日付ごとに容器種類と数量を表示します。
- ファイル名例: `枚方集荷依頼書_YYYYMMDD_YYYYMMDD.pdf`

### 集荷製品詳細Excel
- 集荷製品明細シート（製品ごとの数量と必要容器数）
- 日別サマリシート（納品日ごとの集計）
- ファイル名例: `枚方集荷製品詳細_YYYYMMDD_YYYYMMDD.xlsx`

### 日別製品リスト
- 画面上で日付別の製品明細を確認できます。

## 集荷日計算

- 製品のリードタイム（日数）を基に集荷日を自動計算します。
- 稼働日はカレンダマスタに登録された稼働日を使用します。

## 対象データの条件

- 受注ステータスが `OPEN` の確定（`FIRM`）受注のみ対象です。
- 製品グループ名に「枚方」が含まれる、またはグループコードに「HIRAKATA」が含まれる製品が対象です。
- 容器入り数は容器マスタの設定値を使用します。

## 注意点

- 集荷依頼は集荷前日の17時までにメールで送信してください。
- 送信先: `kyouto03@otomo-logi.co.jp`
- 対象期間に出荷予定が無い場合、集荷期間は空になります。

## トラブルシューティング

### PDF/Excelが作成できない

- 対象期間に出荷予定が存在するか確認してください。
- 製品グループ設定や容器マスタ設定が正しいか確認してください。

### 集荷期間が表示されない

- カレンダマスタに稼働日が登録されているか確認してください。
