# 便進捗サマリー

指定期間の便進捗を、日別集計と便一覧で確認する画面です。クボタ堺の宵積み便は、到着予定日ではなく**実際の出発日**で集計・表示します。

## 画面への行き方

1. 上のグローバルナビゲーションの「出荷」を開く
2. 「出荷管理メニュー」→「便進捗サマリー」を選択

## 使い方

1. 「開始日」「終了日」を指定します。
2. 必要に応じて「業務区分」「ステータス」「お気に入り」「登録名」で絞り込みます。
3. 「表示」を押して一覧を更新します。

## 画面の見方

### 日別進捗

- `出発日` は、この画面での集計基準日です。
- クボタ堺の宵積み便は、到着予定日ではなく前営業日の `出発日` に集計されます。
- 日別進捗には `総便数 / 未着手 / 準備完了 / 出発済` が表示されます。

### 便一覧

- 同じ論理便は1行に統合して表示されます。
- 納入地違いで複数レコードがあっても、一覧上は1便として扱います。
- `出発日` は集計上の出発日、`予定時刻` は便マスタの予定出発時刻、`実出発` は出発ボタンを押した日時です。
- ステータスは `未着手 / 準備完了 / 出発済 / 完了` で表示されます。
- 実出発が未登録の便は、`実出発` 列は空欄のままです。

### ステータスの意味

- `未着手`
  まだ作業を始めていない便です。生産日内訳は入力できますが、準備完了にも出発済にもなっていません。
- `準備完了`
  積み込み準備が終わった便です。各明細の数量合計が計画数と一致した状態で、出荷担当が `準備完了` を押すとこの状態になります。まだ出発はしていません。
- `出発済`
  便が実際に出発した状態です。`出発` を押した時点でこの状態になり、実出発時刻も記録されます。この時点で出荷実績が登録されます。
- `完了`
  業務員側で実績確認まで終わった状態です。到着日や実績内容の最終確認が済んだ便を表します。

## 注意点

- クボタ堺以外の通常便は、登録されている出発日がそのまま表示日です。
- 宵積み便を確認するときは、到着予定日ではなく実際に出発する日の範囲で検索してください。
- この画面は便単位の進捗確認用です。品番・注番単位の出荷実績確認は `出荷情報追跡` を使用してください。
