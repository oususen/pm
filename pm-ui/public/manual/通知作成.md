# 通知作成

## 目的
通知の新規作成と編集を行います。

## 開き方
- 上部メニューの「通知作成」をクリックします。
- ダッシュボードの「通知作成」カードからも開けます。

## 新規登録
1. タイトル、カテゴリ、種別を入力します。
2. 対象者（事業部/係/班/役職）を必要に応じて選びます。
3. 有効開始日・有効終了日、表示順、説明、入力者を設定します。
4. 「登録」を押します。

## 編集・削除
- 一覧の「編集」を押すと内容を読み込みます。
- 更新後に「更新」を押すと保存されます。
- 「削除」を押すと削除できます。

## 対象者の考え方
- 対象部署や役職を選ばない場合は全員向けになります。
- 係/班の選択肢は上位の選択に応じて絞り込みされます。

## 注意点
- 入力者はログインユーザー名が初期値です。
- 有効期間外の通知は表示されません。
