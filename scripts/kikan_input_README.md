# 基幹システム自動入力ツール 使用手順

生産実績照会の「**基幹システム入力用Excel**」で出力したデータを、基幹システム（SSE0040 生産実績入力）に自動でキー入力するGUIアプリです。

---

## 起動方法

`dist\基幹自動入力\基幹自動入力.exe` をダブルクリック（インストール不要）

> `_internal` フォルダは必須。exe と同じフォルダに置いておくこと。

---

## 使用手順

1. 生産管理アプリにログイン → **生産実績照会** → 担当班（ライン）タブを開く
2. **「基幹システム入力用Excel」** をクリックしてExcelをダウンロード・保存
3. **基幹システム**にログイン → 生産管理 → 生産実績入力（社内生産）→ SSE0040 を開く
4. **「基幹自動入力.exe」** を起動する
5. **「参照...」** で手順2のExcelファイルを選択 → **「読み込み」**
6. プレビューで入力対象レコード・Enter回数を確認
7. **「▶ 入力開始」** をクリック
8. カウントダウン中に基幹システムに切り替えて**生産日フィールドにカーソルを置く**
9. カウントダウン終了後、自動入力開始（マウスが固定される）

---

## 注意事項

- **入力中はキーボード・マウス操作をしないこと**（誤入力の原因になります）
- **基幹システムの画面を前面に保つこと**（別ウィンドウが前面に出ると入力がずれます）
- 入力結果は必ず**基幹システム側で確認**すること（ツールは入力操作を行うだけで、登録成否の完全な保証はありません）

---

## 入力中の操作

| 操作 | 動作 |
|------|------|
| 右クリック 1回 | マウス固定を解除（入力は継続） |
| 右ダブルクリック | 即座に停止 |
| Ctrl + P | 停止リクエスト |
| マウスを画面左上角に移動 | フェイルセーフ緊急停止 |

---

## 設定（通常は変更不要）

### Enter回数設定（デフォルト値）

| 項目 | デフォルト |
|------|:---:|
| 生産日 → 品番 | 1 |
| 品番確定後 → 工程順位 | 1　※Excelの設定値が優先 |
| 工程順位 → 生産数 | 3 |
| 生産数 → 加工時間開始 | 8 |
| 加工時間開始 → 終了 | 1 |

### 待機時間（デフォルト値）

| 項目 | デフォルト |
|------|:---:|
| キー間 | 1.0秒 |
| 品番確定後 | 2.0秒 |
| 登録後 | 1.0秒 |
| 開始前（カウントダウン） | 10秒 |

> 「品番確定後」「登録後」は**タイムアウト上限値**です。
> 通常は画面変化を検知した瞬間に次へ進みます。
> 基幹システムが極端に重く画面変化が検知できない場合のみ値を大きくしてください。

設定変更後は「設定保存」を押すと次回起動時に引き継がれます。
設定ファイル: `kikan_input_config.json`（exeと同じフォルダ）

## 入力フィールド対応表

| Excelの列 | 基幹システムフィールド |
|-----------|----------------------|
| 生産日（YYYYMMDD） | 生産日（YYYY/MM/DD変換） |
| 基幹品番 | 品番 |
| 工順 | 工程順位 |
| 生産数量 | 生産数(完成) |
| 開始時間（HHMM） | 加工時間1 開始（HH:MM変換） |
| 終了時間（HHMM） | 加工時間1 終了（HH:MM変換） |

※ マッピング状態が「変換済み」かつ生産数量が1以上のレコードのみ入力対象

---

## トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| 基幹ウィンドウが見つからない | SSE0040を開いてから再実行 |
| 入力がズレる | Enter回数設定を見直す |
| 動作が遅い / 入力が抜ける | 「キー間」待機時間を増やす |
| 品番確定後・登録後に止まる | 「品番確定後」「登録後」の待機時間を増やす |
| 途中で止まる | ログを確認（エラーダイアログが出た可能性あり） |
