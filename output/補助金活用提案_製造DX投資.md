# 補助金活用の提案：製造DX基盤構築プロジェクト

| 項目 | 内容 |
| --- | --- |
| 作成日 | 2026年9月24日 |
| 作成者 | 王　崇栓（製缶事業部） |
| 対象補助金 | 新事業進出・ものづくり商業サービス補助金（第1回公募） |

---

## 1. 提案の趣旨

生産管理システムのDX拡張に必要な設備投資について、国の補助金を活用することを提案します。

現在開発・運用中の生産管理アプリを基盤として、AI・IoT・画像認識などの先端技術を導入するための設備投資が今後必要です。本投資は「新事業進出・ものづくり商業サービス補助金」の対象となる可能性が高く、投資額の最大1/2〜2/3の補助を受けられる見込みです。

---

## 2. 補助金の概要

| 項目 | 内容 |
| --- | --- |
| 制度名 | 新事業進出・ものづくり商業サービス補助金 |
| 管轄 | 中小企業庁 |
| 申請枠 | 革新枠（革新的な製品・サービス・生産プロセスの開発） |
| 補助率 | 中小企業 1/2、小規模事業者 2/3 |
| 補助上限額 | 最大2,500万円（賃上げ特例で最大3,500万円） |
| 第1回公募締切 | **2026年10月30日（金）18:00** |
| 採択発表 | 2026年12月頃（見込み） |

※ 従来の「ものづくり補助金」と「新事業進出補助金」が2026年度に統合された新制度です。

---

## 3. 投資計画と対象設備

以下は、生産管理アプリの本番稼働および機能拡張に必要な設備投資です。

### 3-1. 本番サーバーPC

| 項目 | 内容 |
| --- | --- |
| 用途 | 生産管理アプリ本番サーバー、ローカルLLM実行基盤、画像認識学習環境 |
| 主要構成 | Intel Core Ultra 9 285K / RTX 5090 / DDR5 64GB / NVMe SSD 2TB |
| 概算金額 | 約95〜100万円 |

### 3-2. 現場端末（タブレット）

| 項目 | 内容 |
| --- | --- |
| 用途 | 全生産現場への段階展開（残り半数のラインへの運用拡大） |
| 内容 | 各ライン設置用タブレット端末 |
| 概算金額 | 約30〜80万円（台数による） |

### 3-3. 検査用カメラ・画像認識機器

| 項目 | 内容 |
| --- | --- |
| 用途 | 画像認識モデルの学習・検証による検査自動化 |
| 内容 | 産業用カメラ、照明、設置治具 |
| 概算金額 | 約50〜150万円（構成による） |

### 3-4. IoT連携機器

| 項目 | 内容 |
| --- | --- |
| 用途 | 設備運転情報のリアルタイム取得、稼働監視・予防保全 |
| 内容 | センサー、データ収集機器、通信機器 |
| 概算金額 | 約30〜100万円（対象設備数による） |

### 3-5. 通話録音・文字起こし機器

| 項目 | 内容 |
| --- | --- |
| 用途 | 社内通話の録音・Whisperによる自動文字起こし、ナレッジ蓄積基盤 |
| 内容 | 録音機器、マイク |
| 概算金額 | 約5〜20万円 |

### 3-6. ネットワーク・インフラ機器

| 項目 | 内容 |
| --- | --- |
| 用途 | サーバー安定運用、IoT通信、バックアップ |
| 内容 | UPS（無停電電源装置）、外付けHDD、ネットワーク機器 |
| 概算金額 | 約10〜30万円 |

## 4. 投資金額と補助見込み

| 区分 | 概算金額 |
| --- | --- |
| 設備投資合計 | 約220〜480万円 |
| 補助率 | 1/2〜2/3 |
| **補助見込額** | **約110〜320万円** |
| **実質負担額** | **約110〜160万円** |

※ 金額は概算であり、見積取得後に確定します。

## 5. 補助金で実現する機能（PC導入後に実装予定）

| No. | 機能 | 概要 |
| --- | --- | --- |
| 1 | 全ライン展開 | 残り半数の生産現場へのアプリ展開（タブレット導入） |
| 2 | 注文書自動送信 | 注文書Excel/PDF・進度表・外作納品書の自動生成・自動メール送信 |
| 3 | トラック積載判定 | 荷台寸法と容器情報に基づく積載可否・占有率の自動判定 |
| 4 | 自動計画の高度化 | 工程間連携方式から計画在庫に基づく自動計画へ拡張 |
| 5 | 通話文字起こし | Whisperモデルによる社内通話の自動文字起こし、ナレッジ蓄積 |
| 6 | ローカルLLM | Ollamaによる社内完結のAI環境（社外秘情報の流出防止） |
| 7 | AI知識基盤 | Dify + pgvectorによるRAG構築、業務特化AIエージェント |
| 8 | トラブル分析 | 生産データ（実績・仕損・品質記録）の傾向分析・再発防止 |
| 9 | IoT連携 | 設備稼働状態・サイクルタイム・停止要因のリアルタイム取得 |
| 10 | 画像認識検査 | カメラ画像による検査自動化（モデル学習・検証） |

## 6. 申請に必要なこと

| 項目 | 内容 |
| --- | --- |
| 事業計画書 | 3〜5年の事業計画（付加価値額・給与支給総額の伸び率を記載） |
| 認定支援機関 | 商工会議所・税理士等の確認書が必須 |
| GビズIDプライム | 電子申請に必要（取得に2〜3週間） |
| 見積書 | 各設備の見積書（2社以上の相見積もりが望ましい） |

---

## 7. スケジュール（第1回公募に間に合わせる場合）

| 時期 | 作業 |
| --- | --- |
| 9月下旬 | 社内承認、認定支援機関への相談、GビズID確認 |
| 10月上旬 | 事業計画書作成、設備見積の取得 |
| 10月中旬 | 認定支援機関の確認書取得、申請書類の最終確認 |
| 10月30日 | **申請締切（18:00厳守）** |
| 12月頃 | 採択発表 |
| 採択後 | 交付決定→設備発注→導入→実績報告 |

---

## 8. リスクと注意事項

| リスク | 内容 |
| --- | --- |
| 不採択 | 採択率は約40〜50%。不採択でも次回再申請可能 |
| 事前購入不可 | **交付決定前に発注・購入した設備は補助対象外** |
| 報告義務 | 採択後、実績報告書の提出が必要（経費の証拠書類を保管） |
| 賃上げ要件 | 事業計画期間中の付加価値額・給与の年率増加が求められる |
| 成果未達 | 技術的に成功しなくても、設備を導入し事業に活用していれば問題なし |

**重要**: PCの購入を急ぐ場合、補助金申請と切り離して先行購入するか、交付決定後に購入するかの判断が必要です。交付決定前に購入すると補助対象外になります。

---

## 9. 結論

- 現在開発中の生産管理システムの実績と、今後のDX拡張計画を合わせれば、補助金の申請ストーリーとして十分成立する。
- 第1回公募の締切は**2026年10月30日**。申請準備には約1ヶ月必要であり、社内承認を早期に得たい。
- まずは認定支援機関（商工会議所または顧問税理士）に本資料を持参し、申請可否と支援の可否を確認することを提案する。
