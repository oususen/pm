# 設備リスト（50人規模・1台構成）

## 前提

- サーバーはPC1台で運用（画面アプリ / バックエンドAPI / データベース をDocker同居）
- 外付けHDDは2台構成
  - HDD-A（1TB）: システム全体イメージバックアップ用
  - HDD-B（2TB）: DBバックアップ + 録画データ/旧モデル/写真/PDF保管用

## 設備一覧

1. メインPC（本番機）1台
- 用途: アプリ・DBの本番稼働
- 推奨スペック（画像認識学習拡張対応）:
  - OS: Windows 11 Pro
  - CPU: Intel Core i7-14700K または AMD Ryzen 9 9900X
  - メモリ: 64GB（DDR5-5600 / 32GB×2）
    - 空きスロットまたは32GB×4対応マザーボードを選定し、最大128GBへ増設可能
  - GPU: GeForce RTX 5070 Ti（16GB）
    - 将来、RTX 5080 / RTX 5090 へ換装可能（電源1000W級・ケース寸法・12V-2x6対応前提）
  - ストレージ: NVMe SSD 2TB（PCIe Gen4x4以上）
  - マザーボード:
    - ATX（拡張性重視）
    - DDR5 4スロット（最大128GB以上）
    - PCIe x16（将来GPU換装対応）
    - M.2 NVMeスロット 2基以上
    - 2.5GbE LAN
    - Intel（i7-14700K）を選ぶ場合:
      - Z790 または B760 チップセット搭載
      - 例: ASUS TUF GAMING Z790-PLUS、ASRock Z790 Pro RS
    - AMD（Ryzen 9 9900X）を選ぶ場合:
      - X870 または B650 チップセット搭載
      - 例: ASRock B650 Pro RS、ASUS PRIME X870-P
  - 電源: 850W〜1000W（80PLUS GOLD以上 / ATX 3.1または3.0）
  - CPUクーラー: 360mm簡易水冷
- 予備案（1ランク下 / 予算重視）:
  - OS: Windows 11 Pro
  - CPU: Intel Core i7-13700K または AMD Ryzen 7 7700
  - メモリ: 32GB（DDR5）
  - GPU: GeForce RTX 5070（12GB）
  - ストレージ: NVMe SSD 2TB（PCIe Gen4x4以上）
  - 電源: 850W（80PLUS GOLD以上 / ATX 3.0以上）
  - CPUクーラー: 240mm簡易水冷
- 推奨案と予備案の違い:
  - 学習速度: 推奨案の方が高速（GPU/CPU性能差）
  - 同時運用安定性: 推奨案はメモリ64GBで余裕、予備案32GBは高負荷時に余裕が少ない
  - 大規模データ対応: 推奨案は有利、予備案はバッチサイズや解像度の調整が必要
  - 将来拡張性: 推奨案は上位GPU換装・128GB増設前提で長期運用に向く
  - 初期費用: 予備案の方が安価

2. 外付けHDD-A 1台（システム全体イメージ用）
- 用途: OS、Docker環境、ソースコード、設定ファイルを含む全体バックアップ
- 容量: 1TB
- 運用目安: 週次バックアップ、4〜8世代保持

3. 外付けHDD-B 1台（DBバックアップ + 保管用）
- 用途:
  - 日次DBバックアップ保存
  - 現場録画データ、旧学習モデル（`.pt`）、写真、PDFなどの保管
- 容量: 2TB
- 運用目安: DBは14〜30世代保持

4. UPS（無停電電源装置）1台
- 用途: 停電・瞬停時の安全停止、DB破損リスク低減

5. ネット環境
- 無線ルータ二台以上

6. クライアント端末
- PC: 新規購入なし（現有の事務員PCを利用）
- 現場タブレット/ハンディ: 必要分

7. バーコードリーダー 10〜15台
- 現時点: 導入不要
- 将来: 必要に応じて導入（工程入力、検収、出荷実績などのコード入力省力化）

8. プリンタ
- ラベルプリンタ（Luck Jingle可）: 必要に応じて数台
- 補足: Luck Jingleは直接印刷できないため、いったん端末に保存してから印刷
- A4帳票プリンタ: 新規購入不要（事務所の既存プリンタを利用）

9. 保守用備品
- 予備HDD

10. 開発PC（ノート）1台（任意）
- 用途: 開発・検証・軽量学習テスト（本番機と分離）
- 補足:
  - 未購入でも開発は可能
  - 将来、画像学習機能の開発・検証を本格化する場合は、開発PCがあると効率と安全性が高い
- 推奨最小構成:
  - OS: Windows 11 Pro
  - CPU: Ryzen 7 7840HS/8845HS 以上（または Core i7 Hシリーズ）
  - メモリ: 32GB（増設可モデル優先）
  - GPU: RTX 4060 Laptop 以上
  - ストレージ: NVMe SSD 1TB（可能なら2TB）
  - 画面: 15〜16インチ（WQXGA推奨）
- 価格目安: 18万〜28万円

11. システムディスク2台ミラー（RAID1）（任意）
- 用途: アプリ本体（OS、Docker、画面アプリ、バックエンドAPI、データベース）の可用性向上
- 効果: システムディスクが1台故障しても、アプリ停止リスクを下げて運用継続しやすい
- 推奨: 内蔵NVMe SSD 2台でRAID1を構成
- 注意:
  - RAID1はバックアップの代替ではないため、外付けHDDバックアップは継続する
  - 故障時は不良ディスク交換とリビルド作業が必要
- 追加費用目安:
  - NVMe SSD 2TBを1台追加: 約1.5万〜3万円

## バックアップ運用（簡易）

- HDD-A（全体イメージ 1TB）: 週次
- HDD-B（DB + 保管 2TB）: 日次/随時
- 月1回: 本番切り離し環境で復元テスト（本番上書きしない）
