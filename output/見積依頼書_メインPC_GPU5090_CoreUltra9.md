# 見積依頼書

| 項目 | 内容 |
| --- | --- |
| 作成日 | 2026年9月3日 |
| 件名 | 本番サーバー用メインPC 1台の見積依頼 |

## 依頼内容

生産・業務管理アプリの本番サーバー、および将来的な画像認識学習環境として使用するPC 1台について、下記仕様を満たす完成品PCの見積をお願いします。

- 用途: 画面アプリ、バックエンドAPI、データベースをDockerで同一PC上に稼働
- 台数: 1台
- 希望: 組立・動作確認済みの完成品PC

## 必須仕様

| 区分 | 要求仕様 |
| --- | --- |
| OS | Windows 11 Pro（64bit） |
| CPU | Intel Core Ultra 9 285K |
| メモリ | DDR5 64GB（32GB x 2）。将来128GBへ増設可能な4スロット構成 |
| GPU | NVIDIA GeForce RTX 5090（搭載メーカー・型番を明記） |
| ストレージ | NVMe SSD 2TB以上、PCIe Gen4 x4以上 |
| マザーボード | ATX、Intel Z890またはB860、DDR5 4スロット、PCIe x16 1基以上、M.2 NVMe 2基以上、2.5GbE LAN搭載 |
| 電源 | 1200W以上、80PLUS GOLD以上、ATX 3.1対応、GPU用12V-2x6電源ケーブルを使用できること |
| CPUクーラー | 360mm簡易水冷 |
| ケース | RTX 5090を問題なく搭載できる大型GPU対応ケース |
| その他 | 有線LANポート、USBポートを使用可能なこと |

## 任意見積

必須構成とは別に、下記の追加費用を分けて記載してください。

| 項目 | 要求仕様 |
| --- | --- |
| システムディスク RAID1 | 上記NVMe SSD 2TBと同等品を1台追加し、OS・アプリ用にRAID1を構成 |
| 予備SSD | RAID1故障時の交換用として、上記NVMe SSD 2TBと同等品を1台追加 |

## 見積書への記載依頼

- 各部品のメーカー名・型番・数量・単価
- 本体価格、任意見積、送料、消費税、合計金額
- 納期・見積有効期限
- 保証期間と保証内容
- 初期不良時および故障時の対応窓口・対応条件
- OSの初期設定、BIOS更新、各部品の動作確認の実施有無
- RTX 5090の搭載可否、およびGPU用補助電源ケーブルの接続確認

## 補足

- 同等以上の仕様で代替する場合は、変更箇所と理由を事前に提示してください。
- GPU、電源、ケースは相性・搭載可否を確認した構成でお願いします。
- Docker環境・業務アプリ・データ移行の設定作業は、本見積の対象外です。
