# 見積依頼書

| 項目 | 内容 |
| --- | --- |
| 作成日 | 2026年9月27日 |
| 件名 | 本番サーバー用メインPC 1台（外部AI API利用構成）の見積依頼 |

## 依頼内容

生産・業務管理アプリの本番サーバーとして使用するPC 1台について、下記仕様を満たす完成品PCの見積をお願いします。

- 用途: 画面アプリ、バックエンドAPI、データベース、社内文書検索基盤をDockerで同一PC上に稼働
- AI機能: 文章生成・要約・RAG回答は当面外部AI APIを利用する。一方、カメラ検査・YOLO画像認識にはRTX 5060 Ti 16GBを使用し、将来はローカルLLM等のためRTX 5090へ換装できる構成とする
- 台数: 1台
- 希望: 組立・動作確認済みの完成品PC

## 必須仕様

| 区分 | 要求仕様 |
| --- | --- |
| OS | Windows 11 Pro（64bit） |
| CPU | Intel Core Ultra 9 285K |
| メモリ | DDR5 64GB（32GB x 2）。将来128GBへ増設可能な4スロット構成 |
| GPU | NVIDIA GeForce RTX 5060 Ti 16GBを搭載した構成を必須見積とする。8GB版は不可とし、搭載メーカー・型番・VRAM容量を明記すること。将来は既存のRTX 5060 Tiを取り外してRTX 5090へ換装できること。RTX 5090本体は今回の見積対象外 |
| ストレージ | NVMe SSD 2TB以上、PCIe Gen4 x4以上 |
| マザーボード | ATX、Intel Z890またはB860、DDR5 4スロット、PCIe x16 1基以上、M.2 NVMe 2基以上、2.5GbE LAN搭載 |
| 電源 | 1200W以上、80PLUS GOLD以上、ATX 3.1対応、RTX 5090に使用できる600W対応ネイティブ12V-2x6電源ケーブルを使用できること |
| CPUクーラー | 360mm簡易水冷 |
| ケース | RTX 5060 Tiを問題なく搭載でき、将来のRTX 5090換装にも対応する大型4スロットGPU対応ケース。採用候補のRTX 5090の寸法を基に、GPU長・厚み・補助電源ケーブルの曲げ余裕を確認すること |
| その他 | 有線LANポート、USBポートを使用可能なこと |

## 任意見積

必須構成とは別に、下記の追加費用を分けて記載してください。

| 項目 | 要求仕様 |
| --- | --- |
| システムディスク RAID1 | 上記NVMe SSD 2TBと同等品を1台追加し、OS・アプリ用にRAID1を構成 |
| 予備SSD | RAID1故障時の交換用として、上記NVMe SSD 2TBと同等品を1台追加 |
| メモリ128GB | DDR5 128GB（32GB x 4）へ増設した場合の差額 |
| RTX 5090換装確認 | 今回提示するマザーボード・電源・ケース・CPUクーラーのままで、RTX 5060 Tiを取り外してRTX 5090へ換装できること。換装時に必要な部品・工賃を明記すること |

## 見積書への記載依頼

- 各部品のメーカー名・型番・数量・単価。
- 本体価格、任意見積、送料、消費税、合計金額。
- 納期・見積有効期限。
- 保証期間と保証内容。
- 初期不良時および故障時の対応窓口・対応条件。
- OSの初期設定、BIOS更新、各部品の動作確認の実施有無。
- RTX 5060 Ti 16GBの搭載可否、GPU用補助電源ケーブルの接続確認。
- 将来採用可能なRTX 5090のメーカー・型番候補、換装時の搭載確認結果、換装手順上の注意点。

## 補足

- 外部AI APIの月額利用料、AI API連携のアプリ開発、Docker環境・業務アプリ・データ移行の設定作業は、本見積の対象外です。初期GPUはカメラ検査・YOLO画像認識用とし、将来はRTX 5060 TiをRTX 5090へ換装する想定です。
- 同等以上の仕様で代替する場合は、変更箇所と理由を事前に提示してください。
- 将来のRTX 5090は、既存のRTX 5060 Tiを取り外して同一PCへ換装する前提です。2枚同時搭載は本見積の対象外です。
