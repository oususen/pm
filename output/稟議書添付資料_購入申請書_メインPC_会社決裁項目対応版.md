# 購入申請書
稟議書添付資料｜生産管理業務用PC
購入予算：税込30万円以下／予算内

| 項目 | 内容 |
| --- | --- |
| 作成日 | 2026年10月6日 |
| 件名 | 生産管理業務用PC購入の件 |
| 申請部署・申請者 | 製缶事業部／王　崇栓 |
| 導入時期・効果検証 | 承認後に導入／導入後1年以内に効果検証 |

## 1．決裁事項
生産計画・進度・在庫などの情報を各ラインで共有し、管理業務を効率化するため、生産管理業務用PC 1台の購入について承認を求める。PC本体、送料、必要な設定作業等を含む購入総額は税込300,000円以下とする。

## 2．背景
- 既存の基幹システムは、製缶領域では実績の入力・管理に機能が限定されており、生産計画や進度管理の基盤として十分に活用されていない。
- 生産計画は各ラインで個別のExcelファイルにより管理されており、計画・進度・在庫を部門横断で確認しにくく、属人化されやすい。
- 外作品・購入品の一部は、仕入先へ進度表を共有する運用となっており、納期・納入数量の一元管理が不足している。
- 上記に加え、製造業ではIoT・DX・AIの活用が加速しており、生産データのリアルタイム管理、業務プロセスのデジタル化、AIによる自動化が競争力の要素となっている。紙・Excelに依存した業務からの脱却と、データに基づく生産管理体制の構築が急務である。

### 現在の取組とPCの課題
- この課題に対応するため、社内で生産・業務管理システムを整備している。受注、生産計画、工程実績、進度、在庫、発注、納入、検収をまとめて管理し、工程計画の自動生成と出荷便の自動振り分けを行う仕組みである。
- 現場ラインの半数で実運用している一方、利用者の増加により現存サーバーPCの処理能力が不足しつつある。全ライン展開と機能拡張に向け、本番運用基盤を確保する必要がある。

## 3．目的、ねらい
- 全ラインへ段階的に展開し、生産計画・進度・在庫の一元管理を進める。管理業務の簡易化、属人化の解消、計画変更・納入遅れ・在庫不足の早期把握を図る。
- 帳票作成・発注処理・計画処理の自動化を進め、業務処理時間の削減を図る。

## 4．コスト
| 項目 | 内容 |
| --- | --- |
| 購入先・対象 | ドスパラ なんば店掲載の中古完成品PC／1台 |
| 購入総額 | 税込300,000円以下（本体・送料・必要な設定作業等を含む） |
| 予算区分 | 予算内 |

購入前に在庫、販売価格、諸費用を確認して上限内で購入する。システム改修費は本PC購入費に含めず、別途管理する。


## 5．効果試算
管理業務の効率化と本番処理の改善を見込む。効果金額は未定。削減時間や処理性能は下記の方法で導入前後を比較し、導入後1年以内に効果を検証する。既存システムの効果全体と、今回のPC導入による追加効果を分けて評価する。

| 評価項目 | 試算・検証方法 |
| --- | --- |
| 管理業務の削減時間 | 対象作業を決め、導入前後の作業時間を比較。年間削減時間を試算 |
| 金額換算・回収期間 | 年間効果額＝年間削減時間×社内の時間単価。費用差を反映した年間純効果で、購入総額÷年間純効果により回収期間を算定（純効果が正の場合） |

効果金額・回収期間は未算定とし、上記は今後の算定方法として記載する。導入後の検証では、対象作業の測定値、時間単価、費用差を確認し、定量効果と定性効果を報告する。

## 6．導入計画
承認後、購入から本番稼働までを次の順に進める。具体的な作業日は、販売店の在庫・納期と現場の運用予定に合わせて調整する。

| 段階 | 実施内容 | 期日 |
| --- | --- | --- |
| 導入準備 | 現行データ容量と設置場所・電源・ネットワークを確認。バックアップ、移行・復旧手順を準備 | 承認後、導入前 |
| 購入・受入 | 在庫・価格・保証範囲を確認して購入。SSD状態とPCの動作を確認 | 承認後 |
| 設置・環境構築 | PCを設置し、OS、ネットワーク、業務システム、データベース、自動起動・バックアップを設定 | 受入後 |
| データ移行・動作確認 | 現行データを移行し、接続、画面、帳票、想定同時利用での動作と復旧手順を確認 | 本番切替前 |
| 本番切替・稼働開始 | 現行環境の最終バックアップを取得し、新PCへ切替。正常稼働を確認 | 動作確認後、現場と調整 |

## 7．判断根拠
- 現存PCの処理能力不足に対し、本番運用基盤を整備することが全ラインへの展開に必要と判断する。

## 8．導入しないリスク
- 現行PCはメモリ・ハードディスク容量が不足しており、使用中にシステムが停止するリスクがある。


### 導入後に進める機能
- 残りの現場ラインへの段階展開と、計画在庫に基づく自動計画の高度化。
- 注文書・進度表・外作納品書の自動生成と自動送信、安全在庫・ロット丸めを加味した発注数量算出、トラック積載可否・占有率の自動判定。
- 生産実績・仕損・設備状態・品質記録の集計と傾向確認、設備とのデータ連携による稼働状況の把握。
