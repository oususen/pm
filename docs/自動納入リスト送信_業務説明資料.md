# 自動納入リスト送信 ― 業務説明資料

---

## 背景と目的

仕入先への納品リスト送付から返送内容の取込、現場での検収までをひとつの流れとして運用するための資料です。

- 事務員: 送信設定、返送Excelの取込・保存を担当
- 検収担当: 納入物の三点照合と検収確定を担当
- システム: 指定時刻の自動送信を担当

## 事前準備（運用開始前に必要なこと）

| 項目 | 担当 | 内容 |
|------|------|------|
| 納入パターン設定 | 担当者 | 仕入先の納入スケジュールを設定（毎週○曜日等） |
| 仕入先区分設定 | 担当者 | 仕入先マスタで「外作」「購入」「両方」を設定（Gフィルタに影響） |
| 仕入先メール設定 | 担当者 | 仕入先マスタに送信先メールアドレスを登録 |
| 自動送信設定 | 担当者 | 設定画面で各項目を入力して保存 |
| テスト送信 | 担当者 | 「今すぐ実行」ボタンでテスト送信し、内容を確認 |
| 仕入先への案内 | 担当者 | 仕入先に新しい運用フローを説明 |

---

## 準備事項の説明

事前準備の各項目は、次の順番で意味を押さえると運用全体が理解しやすくなります。

### 1. 納入パターン設定

まず、仕入先が「いつ納入する会社か」を決めます。  
この設定がないと、自動送信の納入日判定や、検収画面でのカバー期間計算ができません。

- 毎週月曜、毎週月・木、2営業日ごと、などのルールを定義する
- そのルールを各仕入先に割り当てる
- 自動送信は「実行日からN営業日後」がこのパターン上の納入日かどうかで送信可否を判定する

### 2. 仕入先区分設定

次に、仕入先が `外作` `購入` `両方` のどれに当たるかを設定します。  
この設定は、品番末尾 `G` の製品を送るかどうかの判定に使います。

| 仕入先区分 | 送信・表示対象 |
|-----------|----------------|
| 外作 | 品番末尾がGの製品のみ |
| 購入 | 品番末尾がGでない製品のみ |
| 両方 | 全製品 |

このフィルタは自動送信、手動納品リスト出力、検収画面で共通です。

### 3. 仕入先メール設定

仕入先マスタに送信先メールアドレスを登録します。  
メールアドレスが未設定だと、自動送信は失敗通知となります。

### 4. 自動送信設定

自動納入リスト送信の設定画面で、実行時刻、納入日、返信先、CC、通知先を登録します。  
ここで「いつ」「誰に」「どの条件で」送るかが決まります。

### 5. テスト送信

本番運用前に `今すぐ実行` でテスト送信し、以下を確認します。

- 宛先、CC、返信先が正しいか
- 添付ファイル4件が意図どおり出るか
- 件名、本文、納入日が正しいか
- 仕入先が受信・返送できるか

### 6. 仕入先への案内

最後に、仕入先へ新しいやり方を案内します。  
特に、返送時は `納品リスト.xlsx` の数量列を修正してそのまま返すこと、品番追加時は `製品リスト` シートからコピーすることを伝えます。

## 納入パターン設定

仕入（あるいは設定） > **納入パターン設定**

納入パターンとは、仕入先がどの頻度で納入するかを定義するスケジュールルールです。自動送信や検収画面のカバー期間計算に使用されます。

### パターン定義

まずパターン（繰り返しルール）を作成します。

| 項目 | 説明 | 例 |
|------|------|-----|
| パターンコード | 一意のコード | W-MON |
| パターン名 | わかりやすい名前 | 毎週月曜 |
| 繰返し種別 | スケジュールの種類（下表参照） | 毎週曜日 |
| 条件 | 種別に応じた詳細設定 | 月曜日 |
| 有効 | パターンのON/OFF | ON |

### 繰返し種別一覧

| 種別 | 説明 | 条件の設定 |
|------|------|-----------|
| 毎週曜日 | 毎週の指定曜日に納入 | 曜日を複数選択（例: 月・木） |
| 毎月日付 | 毎月の指定日に納入 | 日付を複数選択（例: 1日・15日） |
| 月の第N週の曜日 | 毎月第N週の指定曜日に納入 | 第N週と曜日を選択（例: 第1・第3の火曜） |
| 毎営業日 | 営業日は毎日納入 | 条件なし |
| N営業日ごと | N営業日おきに納入 | 間隔営業日数を入力（例: 2＝2営業日ごと） |

### 仕入先割当

作成したパターンを仕入先に割り当てます。1仕入先に1パターンを割り当てます。

| 項目 | 説明 | 例 |
|------|------|-----|
| 仕入先 | 対象の仕入先を選択 | 000095 有限会社ゼンツー |
| パターン | 割り当てるパターンを選択 | ゼンツー 1回/2日 |
| 開始基準日 | 「N営業日ごと」の場合の起算日 | 2026-06-01 |
| LT(日) | 外作・購入品注文書の納入日計算用リードタイム（発注日からLT営業日後が納入日） | 0 |
| 有効 | 割当のON/OFF | ON |

### 設定のポイント

- パターンを作成してから仕入先割当を行う（先にパターン定義が必要）
- 「N営業日ごと」の場合は、仕入先割当に開始基準日の設定が必要
- リードタイム(LT)は外作・購入品注文書の納入日計算用であり、自動送信の納入日計算とは別（自動送信は自動送信設定画面の「納入日」で設定する）
- パターンが未設定の仕入先は「毎日納入」として扱われる

## 運用フロー

### 手動運用フロー

自動送信を使わない場合の手順です。

| 手順 | 作業者 | 内容 |
|------|--------|------|
| 1 | 事務員 | 納入予定画面で納品リスト出力（数量は自動計算済み） |
| 2 | 事務員 | メールで仕入先へ送付 |
| 3 | 仕入先 | 数量を確認・修正して返送 |
| 4 | 事務員 | 返送Excelを取込・保存 |
| 5 | 検収担当 | 検収画面で三点照合→検収確定 |

### 自動送信フロー

自動送信を設定した場合、手順1・2がシステムにより自動化されます。

| 手順 | 作業者 | 内容 |
|------|--------|------|
| 1 | **システム** | 数量を自動計算してExcel作成 |
| 2 | **システム** | 仕入先へメール自動送信 |
| 3 | 仕入先 | 数量を確認・修正して返送 |
| 4 | 事務員 | 返送Excelを取込・保存 |
| 5 | 検収担当 | 検収画面で三点照合→検収確定 |

**効果**: 手順1・2が完全自動化。毎朝指定時刻にシステムが実行する。

## 送信処理の仕組み

### 自動送信の流れ

```
毎朝 指定時刻（例: 7:00）に自動実行
         │
         ▼
  ┌─────────────────────────┐
  │  N営業日後が納入日か判定   │
  │  （納入パターンに基づく）   │
  └─────────┬───────────────┘
            │
     ┌──────┴──────┐
     ▼             ▼
  納入日          納入日でない
     │             │
     ▼             ▼
  数量を自動     担当者へ通知して
  計算して       終了
  Excel作成
     │
     ▼
  仕入先へ
  メール送信
  （CC: 業務員）
```

### 仕入先区分によるGフィルタ（品番末尾G）

仕入先マスタの「仕入先区分」に応じて、送信対象の製品が自動フィルタされます。

| 仕入先区分 | 送信対象 | 説明 |
|-----------|---------|------|
| 外作 | 品番末尾がGの製品のみ | 外作品のみ送信 |
| 購入 | 品番末尾がGでない製品のみ | 購入品のみ送信 |
| 両方（デフォルト） | 全製品 | フィルタなし |

このフィルタは自動送信・手動納品リスト出力・検収画面のすべてに共通で適用されます。

### 送信される添付ファイル（4件）

| ファイル | 内容 | 用途 |
|---------|------|------|
| 納品リスト.xlsx | 品番・品名・移動先・数量・日別内訳 + 修正方法説明 + 製品リスト + 納品リスト印刷用 | 仕入先が確認・修正して返送 |
| 進度表.xlsx | 全製品の内示・確定・計画・実績・進度・計進 | 仕入先が進度状況を把握 |
| 進度表.pdf | 同上（PDF版） | 印刷・閲覧用 |
| 外作納品書.pdf | 品目ごとの納品書・受領書・購入先控（3枚組） | 仕入先が納品時に添付 |

## 納品リストExcelの中身

### シート構成（4シート）

**シート1「納品リスト」** ― 仕入先が記入・返送するメインシート

| 品番 | 品名 | 移動先 | 数量 | 納品日 | 6/9(月) | 6/10(火) | 仕入先コード | 伝票番号 |
|------|------|--------|------|--------|---------|----------|------------|---------|
| YD400... | ブラケット | 社内塗装 | 15 | 2026-06-09 | 8 | 7 | 000095 | |
| YD400... | カバー | CWL | 20 | 2026-06-09 | 20 | | 000095 | |

- **数量**: システムが自動計算した値がセット済み
- **移動先**: 製品マスタに設定された移動先を表示
- **日別列**: カバー期間（納入日～次回納入日前日）の各日の内訳
- 仕入先は「数量」列だけ確認・修正すればOK
- 並び順は `社内塗装 → CWL → 興和 → 直納 → 社内ライン`、同じ移動先内は品番順

**シート2「確認・修正方法」** ― 仕入先向けの操作説明

- 数量を変更したい → 数量列を書き換える
- 納入しない製品がある → 数量を0にする
- 新しい品番を追加 → 「製品リスト」シートからコピー

**シート3「製品リスト」** ― 品番コピー用の全製品一覧

- 手入力すると品番不一致でエラーになるため、ここからコピーしてもらう

**シート4「納品リスト印刷用」** ― ダイソウ宛ての印刷用納品書

仕入先がダイソウへ納品する際に印刷して使う納品書です。

| No. | 品番 | 品名 | 数量 | 単価 | 金額 | 備考 |
|---|---|---|---|---|---|---|
| 1 | YD400... | ブラケット | 15 | | | |
| 2 | YD400... | カバー | 20 | | | |

- **宛先**: ダイソウ工業株式会社　御中（固定）
- **発行元**: 仕入先名（右上に表示）
- **単価・金額**: 空欄（将来用）
- **合計行**: 数量の合計を末尾に表示
- **受領・納入先サイン欄**: 合計行の下に署名欄あり
- **印刷設定**: A4縦、横幅1ページに収まるよう自動縮小、1ページ50行で改ページ

## 外作納品書PDFの見方

品目ごとに「納品書」「受領書」「購入先控」の3枚組がセットになった納品書PDFです。

### レイアウト（A4横・1ページ3品目）

```
┌──────────────────┬─────────┬─────────┐
│    納品書（左50%）  │ 受領書   │ 購入先控  │
│                    │（中25%） │（右25%）  │
│  宛先: ダイソウ工業  │         │          │
│  取引先: 仕入先名   │ 同じ品目  │ 同じ品目   │
│  部品番号・品名     │ 情報     │ 情報      │
│  搬入月日・搬入数   │         │          │
│  得意先 / QRコード  │ QRコード │ QRコード   │
│  荷姿 / 発行受領入力│ 当社/取引先│ 当社/取引先│
└──────────────────┴─────────┴─────────┘
```

- **QRコード**: 内容は `品番,納品日ISO,数量`（検品用）
- 品目が3件を超えると自動的にページが増える
- 品目間は破線で区切り

## 進度表の見方

全製品の進度状況を一覧で確認できます。

| | 繰越 | 5/27 水 | 5/28 木 | ... | **6/3 火** | 6/4 水 | ... |
|--|------|---------|---------|-----|-----------|--------|-----|
| **品番: YD400...** | | | | | | | |
| 内示 | | | | | 12 | | |
| 確定 | | 13 | 12 | | 13 | 13 | |
| 計画 | | 10 | 10 | | 12 | 12 | |
| 実績 | | | | | | | |
| 進度 | -88 | -100 | -112 | | **-150** | -163 | |
| 計進 | -88 | -90 | -102 | | **-138** | -151 | |

- **当日の列**: 薄い青で強調
- **休日の列**: ピンクで表示
- **進度がマイナス（遅れ）**: 赤字
- **進度がプラス（先行）**: 青字
- **繰越**: 表示開始日の前日の進度値
- **内示**: 顧客からの予定需要です。まだ確定していない見込み数量です。
- **確定**: 顧客から正式確定された需要です。出荷・生産として確実に必要な数量です。
- **計画**: その日納入予定の数量です。
- **実績**: その日納入された数量です。
- **進度**: 納入が需要に対してどれだけ先行/遅れしているかを表す差分です。
- **計進**: 納入計画ベースでの進度です。納入計画数量まで含めた進み具合を見るための数です。発行日の納入実績は計算されません。
- 左側に `当月` と `翌月` の合計列があります。`内示 / 確定 / 計画 / 実績` は月合計を表示し、`進度 / 計進` は月合計を表示しません。

## 通知について

自動タスクの実行結果は、設定した通知先に社内通知が届きます。

| 状況 | 通知先 | 通知内容 |
|------|--------|---------|
| 送信成功 | ― | 通知なし（設定画面のステータスで確認） |
| 送信失敗 | 失敗時通知先 | 「自動納入リスト送信失敗: ○○」+ エラー内容 |
| 納入日でない | 納入日でない時通知先 | 「○月○日は○○の納入日ではありません」 |
| パターン未設定 | 納入日でない時通知先 | 「○○の納入パターンが未設定です」 |
| メール未設定 | 失敗時通知先 | 「○○のメールアドレスが未設定です」 |

## 納入予定画面の操作ボタン

納入予定画面では、以下のボタンで手動出力・取込ができます。

| ボタン | 説明 |
|--------|------|
| 納品リスト出力 | 数量入りExcelをダウンロード。仕入先に送付して確認・修正してもらう |
| 進度再計算 | 出力前に進度を最新化する |
| 進度表Excel | 進度表Excelをダウンロード。仕入先へ送付・社内確認用 |
| 進度表PDF | 進度表PDFをダウンロード。印刷・閲覧用 |
| 納品書PDF | 外作納品書PDF（納品書・受領書・購入先控の3枚組）をダウンロード |
| 返送Excel取込 | 仕入先から返送されたExcelを取込む。取込後「納入予定保存」で確定 |

### 納品リスト出力

自動送信と同じ形式のExcel（数量入り + 日別内訳 + 確認修正方法シート + 製品リストシート）をダウンロードします。

- 自動送信に登録していない仕入先でも手動で出力・送付可能
- Gフィルタ（全/有/無）ボタンで出力対象を切り替え可能
- 仕入先選択時に仕入先区分に応じた初期値が自動設定される
- 並び順は `移動先` 優先

### 進度表の手動出力

納入予定画面から進度表Excel・PDFを個別にダウンロードできます。

| ボタン | 出力ファイル | 用途 |
|--------|------------|------|
| 進度表Excel | 進度表_{仕入先コード}_{日付}.xlsx | 仕入先へ送付・社内確認 |
| 進度表PDF | 進度表_{仕入先コード}_{日付}.pdf | 印刷・閲覧用 |

自動送信を設定していない仕入先でも、手動で進度表を出力して送付できます。

- 出力前に `進度再計算` が必要
- `納品リスト出力 / 進度表Excel / 進度表PDF / 納品書PDF` は、進度再計算完了後に押せる

### 返送Excel取込

仕入先が数量を確認・修正して返送したExcelファイルを取り込みます。取込後、一覧で内容を確認し「納入予定保存」を押して確定します。

## 検収画面での運用（検収担当向け）

仕入先から返送されたExcelを事務員が取り込み・保存した後は、検収担当が `仕入れ検収` 画面の `納入リスト` タブで検収を行います。

### 検収の流れ

| 手順 | 作業者 | 内容 |
|------|--------|------|
| 1 | 検収担当 | `仕入れ > 仕入れ検収` を開き、対象仕入先と当日を選択 |
| 2 | 検収担当 | `納入リスト` タブを選び、`検収データ取得` で当日の納入予定を表示 |
| 3 | 検収担当 | 現物・納品書・画面の数量を三点照合し、各行を `確認済` にする |
| 4 | 検収担当 | 全対象行の確認後、`検収確定` を押して実績を登録 |
| 5 | 検収担当 | 必要に応じて `検収履歴` で登録結果を確認 |

### 検収時に見るポイント

| 項目 | 見る内容 |
|------|----------|
| 品番・品名 | 納入された現物と一致しているか |
| 予定 | 事務員が取り込んだ納入予定数量 |
| 実績 | すでに検収済みの数量。予定に達している行は再検収不要 |
| 実数 | 今回受け入れる数量。通常は予定数量が初期表示される |
| 備考 | 数量変更理由や特記事項があれば記入 |

### 数量が違う場合

- 一部品番だけ数量が違う場合は、その行の `数変更` を押して保留にします。
- 保留していない行を先に `検収確定` し、差異がある行は後で `数変更検収確定` します。
- 数変更の状態はブラウザに保持されるため、途中で画面を開き直しても作業を継続できます。

### 検収確定後の結果

- 検収確定すると、検収実績がシステムに記録されます。
- `検収履歴` では日時・品番・数量・検収者・備考を確認できます。
- 予定数量まで検収済みになった行は `検収済` 表示となり、重複検収を防止します。

## よくある質問

**Q: 仕入先が数量を修正して返送したら？**
A: 事務員が納入予定画面でExcelを取込→保存するだけ。従来と同じ手順です。

**Q: 自動送信を一時停止したい**
A: 設定画面で「有効」チェックを外して保存。再開時はチェックを入れるだけ。

**Q: 送信に失敗したらどうなる？**
A: 設定した通知先に社内通知が届きます。設定画面のステータス・メッセージでも確認できます。

**Q: 数量計算はどこのデータを使っている？**
A: 社内の需要データ（内示+確定）から、納入日～次回納入日前日分を合計しています。

**Q: 仕入先が品番を追加したい場合は？**
A: Excelの「製品リスト」シートから品番をコピーして追記してもらいます。手入力はエラーの原因になります。

**Q: CCに複数人を入れたい**
A: 設定画面のCC送信先メール欄に、1行に1アドレスずつ入力します。

**Q: 休日（土日・祝日）にはどうなる？**
A: 休日でもスケジューラは指定時刻にタスクを起動します。ただし「実行日＋N営業日後」の納入日が納入パターンに含まれない場合は送信をスキップし、「納入日でないときの通知先」に通知が届きます。休日だからといって起動自体がスキップされることはありません。

**Q: カバー期間に休日が含まれる場合は？**
A: カバー期間は「今回の納入日～次回納入日の前日」の全カレンダー日です。土日・祝日もスキップせず含まれます。たとえば金曜納入→月曜納入の場合、カバー期間は金・土・日の3日間になります。

**Q: どのカレンダーを使っている？**
A: `daiso` カレンダー（ダイソウ工業の営業日カレンダー）を使用しています。リードタイム計算（実行日からN営業日後の納入日算出）と進度表の日付計算に使われます。カバー期間自体はカレンダーに関係なく連続日です。

**Q: 納入先の納入日を一時的に変更したい場合は？**
A: 納入パターン設定の「開始基準日」を変更してください。開始基準日を変更すると、次回以降の納入日が再計算されます。一時的な変更後は元に戻すことを忘れないようにしてください。

## 関連マニュアル

自動納入リスト送信に関連する操作は、以下の画面へ遷移して確認します。

| マニュアル/画面 | 参照説明 | 遷移先 |
|---|---|---|
| 自動納入リスト送信設定 | 自動送信の実行時刻、納入日、通知先、CC、返信先などの設定を確認・変更する | `仕入れ > 自動納入リスト送信` |
| 納入予定 | 手動での納品リスト出力、進度表出力、返送Excel取込、納入予定保存を行う | `仕入れ > 納入予定` |
| 仕入れ検収 | 返送Excel取込後の数量確認、検収確定、検収履歴確認を行う | `仕入れ > 仕入れ検収` |
| 納入パターン設定 | 仕入先ごとの納入曜日・週次/月次パターン、開始基準日を設定する | `仕入れ > 納入パターン設定` |

参照説明:
遷移先は上記のとおり `仕入れ` メニュー配下から開きます。
