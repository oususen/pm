# 残業申請 サイン画像保存不具合 修正概要

- 作成日: 2026-03-15
- 対象機能: 残業申請（サイン画像アップロード）

## 事象

- 残業申請画面でサインを描いて申請しても、画像が保存されないケースが発生。

## 原因

- APIクライアントで `FormData` 送信時の `Content-Type` 制御が不安定で、`upload_signature` へ正しい multipart リクエストが届かない場合があった。
- サインアップロード失敗時にフロント側で例外を握りつぶしており、利用者に失敗が伝わらなかった。
- 保存済みサインの返却URLが相対パスになり、環境によっては表示できない場合があった。

## 修正内容

1. `FormData` 送信時は `Content-Type` をブラウザに委譲するように変更（boundary 自動付与）。
2. 残業APIの `uploadSignature` で不要な `Content-Type` 明示指定を削除。
3. サインアップロード失敗時は例外を再送出し、画面エラーとして表示するよう変更。
4. 残業申請シリアライザの `signature` を絶対URLで返すよう変更。

## 変更ファイル

- `pm-ui/src/api/client.js`
- `pm-ui/src/api/resources/overtime.js`
- `pm-ui/src/views/overtime/OvertimeApplicationForm.vue`
- `pm_backend/apps/overtime/serializers.py`

## 確認

- フロントエンドビルド: `npm run build` 成功
- Django設定チェック: `python manage.py check` 成功
