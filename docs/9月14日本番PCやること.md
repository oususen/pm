# 9月14日 本番PCデプロイ作業

## 概要
2人1設備入力の修正をデプロイする。作業者ごとの独立セッション管理と、検査工程の2人1設備専用化。

## 1. デプロイ

```bash
# 開発PCでpush
git push origin main

# 本番PCで
git pull origin main
docker compose up -d --build
```

## 2. マイグレーション実行

```bash
docker exec -it pm-backend python manage.py migrate
```

`0084_add_two_person_only_to_process` が適用される。

## 3. DB確認・クリーンアップ

### 3-1. OPENセッション確認

```sql
SELECT id, product_code, operator_name, status, started_at
FROM t_process_work_session
WHERE process_id = (SELECT id FROM m_process WHERE process_code = '4003')
  AND status = 'OPEN';
```

### 3-2. 旧OPENセッションをCLOSE（operator_nameが空 = 修正前のセッション）

```sql
UPDATE t_process_work_session
SET status = 'CLOSED', ended_at = started_at, end_action = 'ADMIN_CLOSE'
WHERE process_id = (SELECT id FROM m_process WHERE process_code = '4003')
  AND status = 'OPEN'
  AND (operator_name = '' OR operator_name IS NULL);
```

### 3-3. 旧レコードからtwo_person_same_equipmentフラグ削除

今後は新規STARTで正しくフラグが付くので、既存レコードのフラグを全削除して白紙にする。

```sql
UPDATE t_process_realtime_record
SET event_data = JSON_REMOVE(event_data, '$.two_person_same_equipment')
WHERE process_id = (SELECT id FROM m_process WHERE process_code = '4003')
  AND JSON_EXTRACT(event_data, '$.two_person_same_equipment') IS NOT NULL;
```

## 4. 工程マスタ設定

工程マスタ画面（/masters/process）で **4003 フロア検査** の「2人1設備専用」チェックをONにする。

これにより：
- 通常の工程入力画面（デスクトップ/モバイル/タブレット等）から4003が非表示になる
- 2人1設備画面でのみ4003が表示される

## 5. 動作確認

白紙状態から2人1設備画面でテスト：
- A/B両方で同じ製品を開始できること
- Aが終了してもBは引き続き作業中と表示されること
- Bも独立して終了できること
