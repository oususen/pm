# デプロイ手順 (2026-02-12)

生産計画自動生成（AUTO_PLAN）機能の追加デプロイ。

## 1. コード反映

```bash
cd /path/to/pm
git pull origin main
```

## 2. Dockerビルド・再起動

```bash
docker-compose up -d --build
```

## 3. マイグレーション実行

```bash
docker exec -it pm_backend_prod python manage.py migrate production
```

追加されるカラム/制約:
- `production_schedule_config.scheduled_dom` - 実行日（1-31）
- `production_schedule_config.line` - 対象ライン（FK）
- `production_schedule_config.include_next_month` - 翌月を対象
- `production_schedule_config.include_second_month` - 翌々月を対象
- `production_schedule_config.include_third_month` - 翌々翌月を対象
- `production_schedule_config.task_name` の `unique` 制約を削除し `(task_name, line)` の複合ユニーク制約に変更
- データマイグレーション: 既存AUTO_PLAN設定を全PRODライン分に展開

## 4. 確認

1. 定時タスク設定画面 (`/settings/scheduled-tasks`) を開く
2. 「生産計画自動生成」セクションにライン別の設定が表示されることを確認
3. 各ラインの実行日・時刻・対象期間（翌月/翌々月/翌々翌月）を設定して保存
4. 任意のラインで「今すぐ実行」を押して動作確認
5. 生産計画入力画面で計画数が表示されることを確認
6. 在庫/残量一覧で計画在庫が反映されていることを確認
